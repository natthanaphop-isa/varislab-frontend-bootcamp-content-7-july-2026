บทเรียน 01 · เริ่มต้น (Getting Started)

บทนำ: Workshop นี้เราจะสร้างอะไร

Intro

เราจะสร้างอะไร

ใน workshop นี้ เราจะทำงานเหมือน frontend developer ที่ได้รับ design handoff จากทีมออกแบบ โดยใช้ไฟล์ Figma ของ Purity UI Dashboard จาก Figma Community ผลงานของ Creative Tim และ Simmmple ต้นฉบับสร้างด้วย Chakra UI ส่วนเวอร์ชันของเราจะใช้ Tailwind CSS และให้ Cursor Agent ช่วยเขียนโค้ดตามกรอบที่เรากำหนด

ดีไซน์ที่ต้องสร้างมี 4 หน้าจอ มาดูทีละหน้ากันก่อน

หน้า Dashboard

หน้าหลักของแอป อัดแน่นที่สุด: ด้านซ้ายคือ sidebar ที่มีโลโก้ "PURITY UI DASHBOARD" เมนูหลัก (Dashboard, Tables, Billing, RTL) หมวด "ACCOUNT PAGES" (Profile, Sign In, Sign Up) และการ์ดเขียวมิ้นต์ "Need help?" ด้านบนมี navbar ที่มี breadcrumb กับช่องค้นหา ส่วนเนื้อหาไล่จากบนลงล่าง: การ์ดสถิติ 4 ใบ (Today's Money $53,000 +55%, Today's Users 2,300 +5%, New Clients +3,052 -14%, Total Sales $173,000 +8%) การ์ดโปรโมท 2 ใบ กราฟแท่ง "Active Users" บนพื้นน้ำเงินเข้ม กราฟเส้น "Sales overview" ตาราง "Projects" (มีงบประมาณและ % ความคืบหน้า) และ timeline "Orders overview"

หน้า Tables

หน้านี้มีตารางข้อมูล 2 ชุด: "Authors Table" แสดงรายชื่อพร้อมรูป avatar อีเมล ตำแหน่ง badge สถานะ Online (เขียว) / Offline (เทา) และวันที่เริ่มงาน ส่วนตาราง "Projects" มีงบประมาณ สถานะ (Working / Canceled / Done) และ progress bar สีเขียวมิ้นต์ ตารางเป็นส่วนที่พบบ่อยใน admin dashboard เราจึงจะลงรายละเอียดกันพอสมควร

หน้า Profile

หน้าโปรไฟล์ผู้ใช้: hero ลายคลื่นสีเขียวมิ้นต์ การ์ดโปรไฟล์ลอยทับ hero (รูป, ชื่อ Esthera Jackson, แท็บ Overview / Teams / Projects) แล้วตามด้วย 3 คอลัมน์ — Platform Settings (รายการ toggle), Profile Information และ Conversations — ปิดท้ายด้วยการ์ดโปรเจกต์แบบมีรูปภาพ หน้านี้เราจะไม่สร้างในบทเรียน แต่เก็บไว้เป็นโจทย์ใหญ่ท้าย workshop ให้คุณทำครบลูปด้วยตัวเอง

หน้า Sign Up

หน้าสมัครสมาชิก: navbar แบบลอยกลาง hero สีเขียวมิ้นต์ หัวข้อ "Welcome!" และการ์ดฟอร์มสีขาว — ปุ่ม social (Facebook, Apple, Google) ช่อง Name / Email / Password สวิตช์ "Remember me" และปุ่ม SIGN UP หน้านี้พิเศษตรงที่ไม่มี sidebar — layout คนละแบบกับหน้าอื่น ซึ่งจะสอนเราเรื่องการจัด route

ทักษะทั้งสี่ของ workshop

นอกจากจะได้เว็บที่ตรงกับดีไซน์แล้ว คุณจะได้ฝึกทักษะ 4 ข้อที่นำไปใช้กับงาน UI อื่นได้ด้วย

  • ถอด screenshot, wireframe หรือ requirement ออกมาเป็น prompt สำหรับ UI ที่ชัดเจน — มองภาพให้ออกว่าโครงสร้างคืออะไร แล้วเขียนสื่อสารให้ AI เข้าใจตรงกับเรา
  • ใช้ Cursor Agent สร้าง UI ฉบับแรก หลังเข้าใจโครงสร้างแล้ว — ให้ AI ทำงานหนักส่วน generate โดยมีเรากำหนดกรอบ
  • ตรวจโค้ด Tailwind ที่ AI สร้าง — ทั้งการรองรับทุกขนาดหน้าจอ (responsive), accessibility และการดูแลรักษา (maintainability)
  • Refactor UI ที่ AI สร้างให้เป็น React component ที่นำกลับมาใช้ซ้ำได้ — เปลี่ยนโค้ดฉบับร่างให้เป็นโค้ดที่ทีมอยู่ด้วยได้ระยะยาว

ลูปการทำงาน: prompt → generate → review → refactor

ตลอด workshop เราจะทำงานวนอยู่ใน 4 ขั้นตอนนี้

  1. Prompt — อ่านดีไซน์ให้แตก แล้วเขียนคำสั่งที่ชัดเจน
  2. Generate — ให้ Cursor Agent สร้างโค้ดฉบับแรก
  3. Review — ตรวจสามเลนส์: responsive / accessibility / maintainability
  4. Refactor — แยกของที่ซ้ำเป็น component ที่ใช้ซ้ำได้

ให้มองโค้ดจาก AI เป็นฉบับร่าง แม้หน้าตาจะตรงดีไซน์และรันได้ เราก็ยังต้องรับผิดชอบโค้ดก่อนนำไปใช้จริง ในครึ่งหลังของ workshop เราจึงใช้เวลากับการ review และ refactor เพื่อดูว่าปัญหาที่มองไม่เห็นจากหน้าจอมีอะไรบ้าง

ต่างจากคอร์ส E-commerce อย่างไร

นอกจากคอร์สนี้ ยังมีคอร์สสร้างเว็บ e-commerce ซึ่งเน้นการเขียนแอปทั้งแอปด้วยมือ ทั้ง logic, API และ state ส่วน workshop นี้เน้นการกำกับ AI ให้สร้าง UI จากดีไซน์จริง ตัวอย่างก็เป็นคนละประเภทกัน: admin dashboard มีทั้งตาราง การ์ดสถิติ และฟอร์ม ซึ่งพบได้บ่อยในงานจริง เนื้อหาของทั้งสองคอร์สจึงเสริมกัน

เตรียมเครื่องมือ

  • Cursor — ดาวน์โหลดจาก cursor.com แผน free เพียงพอสำหรับ workshop นี้ (มีโควตาการใช้ Agent จำกัดต่อเดือน ใช้อย่างประหยัดตามที่บทเรียนแนะนำ)
  • Node.js เวอร์ชัน 22 ขึ้นไป — ตัวเดียวกับที่ใช้มาตั้งแต่คอร์ส React
  • ไฟล์ Figma ต้นแบบ — เปิดดูได้ฟรี ไม่ต้องมี license: Purity UI Dashboard (Figma Community)

แผนที่คอร์ส

  1. เริ่มต้น — ตั้งโปรเจกต์ React + Tailwind v4 และทำความรู้จัก Cursor (บทเรียน 01–02)
  2. Tailwind CSS พื้นฐาน — utility-first, responsive, states และ design tokens ให้พอตรวจงาน AI ได้อย่างมั่นใจ (บทเรียน 03–05)
  3. จาก Screenshot สู่ Prompt — อ่านดีไซน์ให้แตก แล้วเขียน prompt ที่ชัดเจน (บทเรียน 06–08)
  4. สร้าง UI ด้วย Cursor Agent — ลงมือสร้าง app shell, หน้า Dashboard, หน้า Tables และ Sign Up (บทเรียน 09–11)
  5. ตรวจโค้ดที่ AI สร้าง — สามเลนส์: responsive, accessibility, maintainability (บทเรียน 12–14)
  6. Refactor เป็น Component — แยกเป็น component ที่ใช้ซ้ำได้ และสรุปงาน (บทเรียน 15–16)

พร้อมแล้ว ไปตั้งเครื่องมือกันในบทถัดไป
