Display Components

บทสุดท้ายของช่วงคอมโพเนนต์กลาง! คราวนี้เป็นชุดคอมโพเนนต์แสดงผล (presentational components) สี่ตัว — งานของพวกมันคือรับ props เข้ามาแล้ว render ให้สวย ไม่ยุ่งกับ API ไม่รู้จัก business logic ของแอปเลย (มีตัวเดียวที่มี state ภายใน คือ CountdownTimer ซึ่งจะได้ทวนเรื่อง effects กันเต็ม ๆ) แต่ละตัวมีที่ไปชัดเจน:

  • StarReview — ดาวคะแนนรีวิว จะโผล่ทั้งบน ProductCard (บทที่ 15) และหน้า Product detail ทั้งส่วนข้อมูลสินค้าและการ์ดรีวิว (บทที่ 18)
  • FeatureCard — การ์ดจุดขายของร้าน (ส่งฟรี, คืนสินค้าได้, …) เรียงแถวอยู่บนหน้า Home (บทที่ 16)
  • CountdownTimer — นาฬิกานับถอยหลังของโซนดีลพิเศษบนหน้า Home (บทที่ 16)
  • ImageZoom — รูปที่ซูมนุ่ม ๆ ตอน hover ใช้กับรูปดีลและแบนเนอร์บนหน้า Home (บทที่ 16)

ไม่มีไลบรารีใหม่ให้ติดตั้งบทนี้ — ทุกอย่างสร้างจากของที่มีอยู่แล้ว ลุยเลย

StarReview

ทุกเว็บขายของต้องมีดาว ⭐ โจทย์ของเราคือ: รับตัวเลขคะแนนมาหนึ่งตัว แล้ว render ดาว 5 ดวงโดยแบ่งเป็นดวงทึบ (ได้คะแนน) กับดวงโปร่ง (ไม่ได้) — Font Awesome ที่ติดตั้งไว้ตั้งแต่บทที่ 7 มีดาวให้ทั้งสองแบบ

mkdir -p src/shared/components/StarReview

สร้าง src/shared/components/StarReview/StarReview.module.scss:

@use "../../../styles/variables";

.star {
  margin-right: 5px;
  color: variables.$orange01;
}

แล้วสร้าง src/shared/components/StarReview/StarReview.tsx:

import React from "react";
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome";
import { faStar as solidStar } from "@fortawesome/free-solid-svg-icons";
import { faStar as regularStar } from "@fortawesome/free-regular-svg-icons";
import styles from "./StarReview.module.scss";

interface StarReviewProps {
  score: number; // Score between 0 and 10
}

const StarReview: React.FC<StarReviewProps> = ({ score }) => {
  const stars = Math.round(score / 2);
  const fiveStars = [...Array(5)];

  return (
    <div className={`${styles.starReview} flex fs-16`}>
      {fiveStars.map((_, index) => (
        <FontAwesomeIcon
          key={index}
          icon={index < stars ? solidStar : regularStar}
          className={styles.star}
        />
      ))}
    </div>
  );
};

export default StarReview;

เลขคณิตของดาวทำงานแบบนี้:

  • Math.round(score / 2) — contract ของคอมโพเนนต์ (ตาม comment ในโค้ด) คือรับ score สเกล 0–10 การหารสองแปลงเป็นสเกล 0–5 แล้วปัดเป็นจำนวนเต็ม ได้ "จำนวนดาวทึบ" เช่น score 9 → 4.5 → ปัดเป็น 5 ดวงทึบ
  • [...Array(5)] — ท่าสร้าง array ยาว 5 ช่องเพื่อเอาไว้ .map() — ทำไมต้อง spread? เพราะ Array(5) เฉย ๆ ได้ array โปร่ง (sparse) ที่ .map() จะข้ามช่องว่างไปเลย spread ก่อนหนึ่งทีจะเติม undefined ให้ครบทุกช่อง map ได้ครบ 5 รอบ
  • index < stars ? solidStar : regularStar — ดาวดวงที่ index 0 ถึง stars - 1 เป็นดวงทึบ ที่เหลือเป็นดวงโปร่ง สังเกตท่า import เท่ ๆ: icon ทั้งสองชื่อ faStar เหมือนกันแต่มาจากคนละแพ็กเกจ (free-solid กับ free-regular) เราเลยใช้ as ตั้งชื่อเล่นแยกกันตอน import
  • key={index} — ปกติเราหลีกเลี่ยง index เป็น key แต่กรณีนี้ list ยาว 5 ตายตัว ไม่มีการสลับลำดับหรือเพิ่มลด ใช้ index ได้ปลอดภัย

CountdownTimer

ตัวเดียวในบทนี้ที่มีชีวิต — นาฬิกาถอยหลังของโซน "ดีลจะหมดใน…" บนหน้า Home ตัวเลขต้องเดินทุกวินาที ซึ่งแปลว่าเราต้องได้ใช้สองเครื่องมือจากคอร์ส React พื้นฐาน พร้อมกัน: useState เก็บเวลาที่เหลือ และ useEffect จัดการ side effect (ตั้ง interval) พร้อม cleanup

mkdir -p src/shared/components/CountdownTimer

สร้าง src/shared/components/CountdownTimer/CountdownTimer.module.scss:

@use "../../../styles/variables";

.countdownContainer {
  background-color: variables.$light-blue;
  border: 1px dashed variables.$primary-color;
}

แล้วสร้าง src/shared/components/CountdownTimer/CountdownTimer.tsx:

import React, { useState, useEffect } from "react";
import styles from "./CountdownTimer.module.scss";

interface CountdownTimerProps {
  targetDate: string;
}

const CountdownTimer: React.FC<CountdownTimerProps> = ({ targetDate }) => {
  const [timeLeft, setTimeLeft] = useState<{
    days: number;
    hours: number;
    minutes: number;
    seconds: number;
  }>({
    days: 0,
    hours: 0,
    minutes: 0,
    seconds: 0,
  });

  useEffect(() => {
    const calculateTimeLeft = () => {
      const now = new Date().getTime();
      const target = new Date(targetDate).getTime();
      const difference = target - now;

      if (difference > 0) {
        setTimeLeft({
          days: Math.floor(difference / (1000 * 60 * 60 * 24)),
          hours: Math.floor((difference / (1000 * 60 * 60)) % 24),
          minutes: Math.floor((difference / (1000 * 60)) % 60),
          seconds: Math.floor((difference / 1000) % 60),
        });
      } else {
        setTimeLeft({ days: 0, hours: 0, minutes: 0, seconds: 0 });
      }
    };

    const timer = setInterval(calculateTimeLeft, 1000);

    return () => clearInterval(timer);
  }, [targetDate]);

  return (
    <div
      className={`${styles.countdownContainer} flex flex-center pt-15 pb-15 pl-30 pr-30 fs-18 gap-20 fw-medium`}
    >
      <span>{timeLeft.days}</span>:<span>{timeLeft.hours}</span>:
      <span>{timeLeft.minutes}</span>:<span>{timeLeft.seconds}</span>
    </div>
  );
};

export default CountdownTimer;

มาแกะการคำนวณเวลาที่เหลือกันช้า ๆ เพราะนี่คือโจทย์คลาสสิกที่เจอบ่อยในงานจริง:

  • หา "ระยะห่าง" เป็นมิลลิวินาที — new Date(targetDate).getTime() แปลงเวลาเป้าหมาย (string เช่น วันพรุ่งนี้เที่ยงคืน) เป็นตัวเลข timestamp แล้วลบด้วยเวลาปัจจุบัน ได้ difference = จำนวนมิลลิวินาทีที่เหลือ
  • วัน — หนึ่งวันมี 1000 * 60 * 60 * 24 มิลลิวินาที (ms → วินาที → นาที → ชั่วโมง → วัน) หาร difference แล้ว Math.floor ปัดลง ได้จำนวนวันเต็ม
  • ชั่วโมง — หารด้วยมิลลิวินาทีต่อชั่วโมง ได้จำนวนชั่วโมงทั้งหมด (เช่น 50 ชั่วโมง) แล้ว % 24 ตัดส่วนที่ถูกนับเป็นวันไปแล้วออก เหลือ 2 ชั่วโมง — modulo คือพระเอกของสูตรนี้
  • นาที / วินาที — ตรรกะเดียวกัน: หารให้เป็นหน่วยนั้น แล้ว % 60 เอาเฉพาะเศษที่ไม่ถูกหน่วยใหญ่กว่านับไปแล้ว
  • กันเวลาติดลบ — ถ้าเลยเวลาเป้าหมายไปแล้ว (difference <= 0) ตั้งทุกช่องเป็นศูนย์ ไม่ปล่อยให้โชว์ตัวเลขติดลบประหลาด ๆ

ส่วนโครง effect คือแพตเทิร์น interval + cleanup ตรงตำราจากคอร์ส React พื้นฐาน: setInterval(calculateTimeLeft, 1000) สั่งให้คำนวณใหม่ทุกวินาที (แต่ละรอบเรียก setTimeLeft → re-render → ตัวเลขบนจอเดิน) และบรรทัดที่สำคัญที่สุดคือ return () => clearInterval(timer) — ถ้าไม่มี cleanup ตอนคอมโพเนนต์ unmount (ผู้ใช้กดไปหน้าอื่น) interval จะยังวิ่งอยู่เบื้องหลังและเรียก setState ใส่คอมโพเนนต์ที่ตายไปแล้ว กลายเป็น memory leak สะสม dependency array [targetDate] ก็ทำงานร่วมกับ cleanup อย่างถูกต้อง: ถ้าเป้าหมายเปลี่ยน React จะ cleanup interval เก่าก่อนแล้วตั้งตัวใหม่ให้เอง

💡 สังเกตอะไรไหม? calculateTimeLeft ถูกเรียกครั้งแรกเมื่อ interval ครบวินาทีแรก แปลว่าหลัง mount นาฬิกาจะโชว์ 0:0:0:0 ประมาณหนึ่งวินาทีก่อนกระโดดเป็นค่าจริง — ถ้าอยากให้ขึ้นทันทีก็แค่เรียก calculateTimeLeft() หนึ่งครั้งก่อน setInterval โปรเจกต์นี้เลือกแบบเรียบง่ายตามต้นฉบับ แต่การมองเห็นรายละเอียดแบบนี้ในโค้ดคือทักษะ code review ที่ดี

กลไกอยู่ที่การจับคู่สอง class: .image ขยายตัวเป็น 105% ตอน hover (พร้อม transition ครึ่งวินาทีให้เคลื่อนนุ่ม ไม่กระตุก) ส่วน container ครอบด้วย overflow: hidden — ส่วนที่ขยายเกินขอบถูกตัดทิ้ง ผลลัพธ์เลยดูเหมือน "ซูมอยู่ในกรอบ" ไม่ใช่รูปบวมดันเพื่อนบ้าน ส่วน className ที่รับมาช่วยให้หน้า Home กำหนดขนาด/สัดส่วนของแต่ละรูปจากข้างนอกได้ (|| "" กัน undefined ไปโผล่เป็นข้อความใน class)
