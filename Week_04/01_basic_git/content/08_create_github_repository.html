บทเรียน 08 · ส่งงานขึ้น GitHub (GitHub & Remote Repository)

Local, Remote และการสร้าง Repository บน GitHub

Create a GitHub Repository

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายความต่างระหว่าง local repository และ remote repository
  • สร้าง repository ว่างบน GitHub
  • อธิบายได้ว่าทำไมไม่ควรเลือก Add README ตอนสร้าง repository ในกรณีนี้

Local Repository และ Remote Repository

ตอนนี้ commit ทั้ง 3 ตัวของเราอยู่ในเครื่อง (ในโฟลเดอร์ .git) เราเรียกมันว่า Local Repository ถ้าเครื่องพังหรือหาย ประวัติทั้งหมดก็หายไปด้วย ขั้นตอนต่อไปคือส่งสำเนาไปเก็บไว้บน GitHub ซึ่งเราเรียกว่า Remote Repository 

Local Repository
เครื่องของเรา
        ↓ git push

Remote Repository

คำสั่ง git push คือการส่ง commit จาก local ขึ้นไปยัง remote ซึ่งเราจะได้ใช้ในบทถัดไป

สร้าง Repository บน GitHub

เข้าสู่ระบบ github.com แล้วทำตามขั้นตอน:

  1. กดปุ่ม New repository (หรือปุ่ม + มุมขวาบน → New repository)
  2. ตั้งชื่อ repository ว่า developer-profile-page
  3. เลือก Public
  4. ไม่ต้องเลือก Add README
  5. ไม่ต้องเลือก .gitignore
  6. ไม่ต้องเลือก License
  7. กด Create repository

ตั้งชื่อให้ตรงกับชื่อโฟลเดอร์ในเครื่อง จะช่วยให้จำง่ายว่า repository ไหนคู่กับโปรเจกต์ไหน

ทำไมไม่สร้าง README บน GitHub

เพราะเรามี README.md ใน local repository อยู่แล้ว ถ้าให้ GitHub สร้าง README ให้อีก GitHub จะสร้าง commit ของมันเองขึ้นมา ทำให้ local กับ remote มีประวัติเริ่มต้นไม่ตรงกัน และการ push ครั้งแรกจะถูกปฏิเสธ ซึ่งแก้ยากสำหรับมือใหม่ ดังนั้นเมื่อมีโปรเจกต์ในเครื่องอยู่แล้ว ให้สร้าง Empty Repository เสมอ

ถ้าเผลอติ๊ก Add README, .gitignore หรือ License ไปแล้ว วิธีที่ง่ายที่สุดสำหรับตอนนี้คือลบ repository นั้นทิ้ง (Settings → Danger Zone → Delete this repository) แล้วสร้างใหม่แบบว่างเปล่า

หน้าที่ GitHub แสดงหลังสร้าง

เมื่อสร้าง repository ว่างเสร็จ GitHub จะแสดงหน้า “Quick setup” พร้อม URL ของ repository และชุดคำสั่งตัวอย่าง ให้เลือกแบบ HTTPS แล้วจด URL ไว้ ซึ่งจะหน้าตาประมาณนี้ (username คือชื่อ GitHub ของคุณ): 

https://github.com/username/developer-profile-page.git

เปิดหน้านี้ค้างไว้ บทถัดไปเราจะใช้ URL นี้เชื่อมเครื่องเราเข้ากับ GitHub

  • อธิบายได้ว่า local repository อยู่ในเครื่อง ส่วน remote repository อยู่บน GitHub
  • มี repository ชื่อ developer-profile-page แบบ Public บน GitHub
  • repository นั้นว่างเปล่า (ไม่มี README, .gitignore หรือ License)
  • มี URL แบบ HTTPS ของ repository พร้อมใช้
ก่อนหน้า: สร้าง Commit History และ README สารบัญบทเรียน ถัดไป: เชื่อม Local กับ GitHub และ Push ครั้งแรก
