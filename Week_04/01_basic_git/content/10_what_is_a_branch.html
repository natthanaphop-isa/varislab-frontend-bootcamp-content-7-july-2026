บทเรียน 10 · Branch และ Merge (Branch & Merge)

Branch คืออะไร และสร้าง Feature Branch

Introduction to Branch

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายได้ว่า branch คืออะไร และช่วยแก้ปัญหาอะไร
  • อธิบายบทบาทของ main, feature branch และ merge
  • ดู branch ปัจจุบันด้วย git branch
  • สร้างและย้ายไป feature branch ด้วย git switch -c
  • ตั้งชื่อ branch ตามรูปแบบ feature/ชื่อ-feature

Branch คืออะไร

Branch คือเส้นทางแยกของการพัฒนาโปรเจกต์ สมมติว่า main คือโค้ดหลักที่ทำงานได้:

main

เมื่อต้องการเพิ่ม feature ใหม่ เราสามารถสร้าง branch แยกออกมา:

main
  \
   feature/add-projects-section

จากนั้นพัฒนา feature บน branch นั้น โดยไม่แก้ main โดยตรง

ทำไมต้องแยก branch

ตอนนี้หน้าเว็บหลักของเราทำงานได้แล้ว และเรากำลังจะเพิ่ม Projects Section แต่ยังไม่รู้ว่าโค้ดจะเสร็จเมื่อไร หรือจะออกมาดีหรือเปล่า ถ้าแก้บน main โดยตรง โค้ดหลักอาจค้างอยู่ในสถานะที่ยังไม่สมบูรณ์ branch ช่วยให้เราสร้างพื้นที่แยกออกมาทดลองก่อน เมื่อ feature เสร็จและตรวจสอบแล้ว เราจึง merge กลับเข้า main

Mental Model

คำความหมาย
mainเวอร์ชันหลักที่ควรทำงานได้เสมอ
feature branchพื้นที่แยกสำหรับพัฒนา feature
mergeนำ feature ที่ทำเสร็จกลับมารวมกับ main

ดู Branch ปัจจุบัน

git branch
* main

ตอนนี้เรามี branch เดียวคือ main และกำลังอยู่บนมัน (ดูจากเครื่องหมาย *)

ก่อนสร้างหรือสลับ branch ให้รัน git status ก่อนเสมอ ถ้ายังมีไฟล์ที่แก้แต่ยังไม่ได้ commit ให้ commit ให้เรียบร้อยก่อน เพื่อไม่ให้งานที่ค้างอยู่ติดข้ามไปอีก branch จนสับสน ในคู่มือนี้เราจะเริ่ม branch ใหม่จากสถานะ working tree clean เท่านั้น

สร้าง Feature Branch

สร้าง branch ใหม่และย้ายไปใช้งานทันที:

git switch -c feature/add-projects-section
Switched to a new branch 'feature/add-projects-section'

คำสั่งนี้ทำ 2 อย่างในครั้งเดียว:

  1. สร้าง branch ใหม่ (-c ย่อมาจาก create) โดยเริ่มจาก commit ล่าสุดของ branch ที่เรายืนอยู่
  2. ย้ายไปอยู่บน branch ใหม่นั้น

ตรวจสอบ:

git branch
* feature/add-projects-section
  main

ตอนนี้ * ย้ายมาอยู่หน้า feature/add-projects-section แล้ว แปลว่า commit ต่อจากนี้จะถูกบันทึกบน branch นี้ (Git เรียงรายชื่อ branch ตามตัวอักษร feature/... จึงขึ้นก่อน main — ให้ดูที่ * เป็นหลักว่าตอนนี้อยู่ branch ไหน)

การตั้งชื่อ Branch

รูปแบบที่แนะนำ:

feature/ชื่อ-feature

ตัวอย่าง:

feature/add-projects-section
feature/add-learning-goals
feature/add-social-links
feature/update-profile-design

สำหรับการแก้ bug อาจใช้ prefix fix/:

fix/contact-button
fix/mobile-spacing

ชื่อ branch ใช้ตัวพิมพ์เล็กและคั่นคำด้วยขีด - ไม่ใช้ช่องว่าง ชื่อที่ดีบอกได้ทันทีว่า branch นี้ทำอะไร ในคู่มือนี้เราจะใช้ feature/ เป็นหลัก

  • อธิบายได้ว่าทำไมไม่ควรพัฒนา feature ที่ยังไม่เสร็จบน main โดยตรง
  • รัน git switch -c feature/add-projects-section สำเร็จ
  • git branch แสดง * อยู่หน้า feature/add-projects-section
  • ตั้งชื่อ branch ตามรูปแบบ feature/... หรือ fix/... ได้
ก่อนหน้า: เชื่อม Local กับ GitHub และ Push ครั้งแรก สารบัญบทเรียน ถัดไป: พัฒนา Feature บน Branch แยก
