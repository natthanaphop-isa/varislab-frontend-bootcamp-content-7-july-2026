Wrap Up, Practice & Homework

เมื่อจบบทนี้ คุณจะสามารถ

  • ทบทวน workflow ทั้งหมดตั้งแต่ commit จนถึง merge ได้ในภาพเดียว
  • ทำ feature branch workflow ครบวงจรด้วยตัวเองผ่านแบบฝึกหัด
  • ตรวจความเข้าใจด้วยแบบทดสอบ และส่งการบ้านตามเกณฑ์

ในคู่มือนี้เราไม่ได้เรียนแค่วิธีส่งโค้ดขึ้น GitHub แต่ได้เรียน workflow พื้นฐานที่ developer ใช้ทำงานจริง: แก้ไฟล์ ตรวจสถานะ เลือกไฟล์ และสร้าง commit จากนั้นใช้ branch แยกพื้นที่พัฒนา feature โดยไม่กระทบ main เมื่อ feature พร้อมจึง merge กลับเข้า main และ push ขึ้น GitHub ต่อจากนี้ (เช่นเมื่อเริ่มทำ React project) เราจะใช้ workflow นี้ซ้ำกับทุก feature จน Git กลายเป็นส่วนหนึ่งของกระบวนการพัฒนา software ตามธรรมชาติ

แบบฝึกหัด: เพิ่ม Learning Goals Section

ทำ feature branch workflow ครบวงจรอีกรอบด้วยตัวเอง เริ่มจาก main ที่ git status ขึ้น working tree clean

1. สร้าง feature branch ใหม่:

git switch -c feature/add-learning-goals

2. เพิ่ม section นี้ใน index.html (วางต่อจาก My Projects และก่อนปุ่ม Contact Me):

<section>
  <h2>Learning Goals</h2>

  <ul>
    <li>Build responsive websites</li>
    <li>Learn React</li>
    <li>Build a full-stack application</li>
  </ul>
</section>

3. ตรวจสอบ เพิ่มไฟล์ และ commit:

git status
git add index.html
git commit -m "Add learning goals section"

4. กลับ main:

git switch main

5. Merge:

git merge feature/add-learning-goals

6. Push:

git push

7. ลบ branch:

git branch -d feature/add-learning-goals

หน้าเว็บบน main มี Learning Goals Section, GitHub มี commit Add learning goals section และ git branch เหลือแค่ * main

ข้อกำหนด

1. เริ่มจาก main — ตรวจสอบว่า * อยู่หน้า main:

git branch

2. สร้าง feature branch ตัวอย่าง:

git switch -c feature/add-education-section

3. เพิ่ม feature — เพิ่ม HTML และ CSS ตามความเหมาะสม

4. สร้างอย่างน้อย 1 commit ตัวอย่าง:

git add .
git commit -m "Add education section"

5. Merge กลับ main

git switch main
git merge feature/add-education-section

6. Push

git push

7. ลบ branch

git branch -d feature/add-education-section

สิ่งที่ต้องส่ง

  1. GitHub Repository URL
  2. ชื่อ feature branch ที่ใช้
  3. Commit message
  4. Screenshot หน้า repository
  5. Screenshot commit history
  6. คำตอบสั้น ๆ: “Branch และ Merge ใช้ทำอะไร?”
