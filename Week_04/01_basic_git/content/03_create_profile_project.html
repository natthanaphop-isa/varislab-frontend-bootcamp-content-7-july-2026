สร้าง Developer Profile Page

Create the Sample Project

เมื่อจบบทนี้ คุณจะสามารถ

  • สร้างโฟลเดอร์โปรเจกต์และเปิดด้วย VS Code จาก Terminal
  • สร้างไฟล์ index.html และ style.css ของ Developer Profile Page
  • เปิดดูหน้าเว็บใน browser เพื่อยืนยันว่าทำงานได้

ก่อนจะใช้ Git เราต้องมีอะไรให้ Git ติดตามก่อน บทนี้เราจะสร้างหน้า profile แบบง่าย ๆ ที่มีแค่ HTML กับ CSS ซึ่งจะเป็นโปรเจกต์ที่ใช้ฝึกตลอดคู่มือ

สร้างโฟลเดอร์โปรเจกต์

ใน Terminal ให้ cd ไปยังที่ที่คุณเก็บโปรเจกต์ แล้วสร้างโฟลเดอร์ใหม่:

mkdir developer-profile-page

เข้าไปในโฟลเดอร์:

cd developer-profile-page

เปิดโฟลเดอร์นี้ด้วย VS Code:

code .

จุด . หมายถึง “โฟลเดอร์ปัจจุบัน” คำสั่งนี้จึงแปลว่า “เปิดโฟลเดอร์ที่ฉันอยู่ตอนนี้ด้วย VS Code”

ถ้า code . ใช้ไม่ได้ ให้เปิด VS Code เอง แล้วเลือก File → Open Folder จากนั้นเลือกโฟลเดอร์ developer-profile-page

สร้างไฟล์ index.html

สร้างไฟล์ชื่อ index.html ในโฟลเดอร์โปรเจกต์ แล้วใส่โค้ดนี้:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />

    <meta
      name="viewport"
      content="width=device-width, initial-scale=1.0"
    />

    <title>Developer Profile</title>

    <link rel="stylesheet" href="style.css" />
  </head>

  <body>
    <main class="profile-card">
      <h1>Somchai Developer</h1>

      <p class="role">Aspiring Software Developer</p>

      <p class="description">
        I am learning web development and preparing to begin a career in
        technology.
      </p>

      <section>
        <h2>Current Skills</h2>

        <ul>
          <li>HTML</li>
          <li>CSS</li>
          <li>JavaScript Basics</li>
        </ul>
      </section>

      <a class="contact-button" href="mailto:hello@example.com">
        Contact Me
      </a>
    </main>
  </body>
</html>

โครงหน้าเรียบง่าย: การ์ด main.profile-card หนึ่งใบ มีชื่อ ตำแหน่ง (.role) คำอธิบายสั้น ๆ (.description) รายการทักษะ และปุ่มติดต่อ (.contact-button) ที่เป็นลิงก์ mailto: ส่วน <link rel="stylesheet" href="style.css" /> คือการดึงไฟล์ CSS ที่เรากำลังจะสร้างเข้ามา

สร้างไฟล์ style.css

สร้างไฟล์ชื่อ style.css ในโฟลเดอร์เดียวกัน แล้วใส่โค้ดนี้:

* {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100vh;

  display: grid;
  place-items: center;

  padding: 24px;

  font-family: Arial, sans-serif;

  background-color: #f4f6f8;
}

.profile-card {
  width: 100%;
  max-width: 420px;

  padding: 32px;

  border-radius: 16px;

  background-color: white;

  box-shadow: 0 12px 30px rgb(0 0 0 / 10%);
}

.profile-card h1 {
  margin-top: 0;
  margin-bottom: 8px;
}

.role {
  margin-top: 0;

  font-weight: bold;
  color: #2563eb;
}

.description {
  line-height: 1.6;
}

.profile-card section {
  margin-top: 24px;
}

.profile-card ul {
  padding-left: 20px;
}

.contact-button {
  display: inline-block;

  margin-top: 16px;
  padding: 12px 20px;

  border-radius: 8px;

  color: white;
  background-color: #2563eb;

  text-decoration: none;
}

.contact-button:hover {
  background-color: #1d4ed8;
}

body ใช้ display: grid คู่กับ place-items: center เพื่อจัดการ์ดไว้กลางจอ .profile-card กว้างเต็มที่แต่ไม่เกิน 420px จึงดูดีทั้งบนมือถือและจอใหญ่ ที่เหลือเป็นการแต่งสี ระยะห่าง และเงาของการ์ด

เปิดดูใน Browser

ดับเบิลคลิกไฟล์ index.html (หรือลากไปวางใน browser) เพื่อตรวจสอบว่าเว็บไซต์ทำงานได้

ควรเห็นการ์ดสีขาวมุมโค้งอยู่กลางจอบนพื้นสีเทาอ่อน มีชื่อ Somchai Developer ตำแหน่งตัวหนาสีน้ำเงิน รายการ Current Skills และปุ่ม Contact Me สีน้ำเงินที่เข้มขึ้นเมื่อเอาเมาส์ไปชี้

ตอนนี้โครงสร้างโปรเจกต์ของเราเป็นแบบนี้:

developer-profile-page/
├── index.html
└── style.css

ถ้าหน้าเว็บไม่มีสไตล์เลย ให้ตรวจว่าไฟล์ชื่อ style.css สะกดตรงกับใน href และอยู่ในโฟลเดอร์เดียวกับ index.html และอย่าลืม save ไฟล์ทั้งสองก่อน refresh

  • มีโฟลเดอร์ developer-profile-page และเปิดอยู่ใน VS Code
  • มีไฟล์ index.html และ style.css พร้อมโค้ดครบ
  • เปิด index.html ใน browser แล้วเห็นการ์ด profile ที่มีสไตล์ถูกต้อง
ก่อนหน้า: ตรวจสอบการติดตั้งและตั้งค่า Git สารบัญบทเรียน ถัดไป: เริ่ม Repository ด้วย git init และ git status
