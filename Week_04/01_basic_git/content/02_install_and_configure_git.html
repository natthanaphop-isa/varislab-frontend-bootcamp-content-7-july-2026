บทเรียน 02 · รู้จัก Git และเตรียมเครื่อง (Getting Started)

ตรวจสอบการติดตั้งและตั้งค่า Git

Install Check & Git Config

เมื่อจบบทนี้ คุณจะสามารถ

  • ตรวจสอบว่าเครื่องติดตั้ง Git แล้วหรือยัง
  • ตั้งชื่อและอีเมลสำหรับ commit ด้วย git config --global
  • ตรวจสอบค่าที่ตั้งไว้ได้

ตรวจสอบการติดตั้ง Git

เปิด Terminal (macOS/Linux) หรือ PowerShell (Windows) แล้วรัน:

git --version

ผลลัพธ์ตัวอย่าง:

git version 2.50.1

ถ้าเห็นเลขเวอร์ชัน (ตัวเลขในเครื่องคุณอาจต่างจากนี้ได้) แสดงว่า Git ถูกติดตั้งแล้ว พร้อมใช้งาน

ถ้าเห็นข้อความทำนอง command not found: git หรือ 'git' is not recognized แปลว่ายังไม่ได้ติดตั้ง Git ให้ดาวน์โหลดจาก git-scm.com/downloads ติดตั้งให้เสร็จ แล้วปิด-เปิด Terminal ใหม่ก่อนลองอีกครั้ง

ตั้งชื่อและอีเมล

ทุก commit ต้องมีข้อมูลของคนที่สร้างมัน Git จึงต้องรู้ว่า “เราเป็นใคร” ชื่อและอีเมลนี้จะติดไปกับ commit history ของเราตลอด

ตั้งชื่อ:

git config --global user.name "Your Name"

ตั้งอีเมล:

git config --global user.email "your-email@example.com"

แทน Your Name และ your-email@example.com ด้วยข้อมูลจริงของคุณ ส่วน --global หมายถึงตั้งค่าครั้งเดียวใช้ได้กับทุก repository ในเครื่องนี้ ไม่ต้องตั้งใหม่ทุกโปรเจกต์

ตรวจสอบค่าที่ตั้งไว้

git config --global user.name
git config --global user.email

ทั้งสองบรรทัดควรแสดงชื่อและอีเมลที่เพิ่งตั้งไป

แนะนำให้ใช้อีเมลเดียวกับ GitHub account เพื่อให้ GitHub เชื่อม commit เข้ากับ profile ของเราได้ถูกต้อง

ถ้าข้ามขั้นตอนนี้ไป ตอนสร้าง commit แรกอาจเจอ error Author identity unknown วิธีแก้คือกลับมารันสองคำสั่ง git config --global ข้างบนแล้ว commit ใหม่

  • git --version แสดงเลขเวอร์ชันของ Git
  • git config --global user.name แสดงชื่อของคุณ
  • git config --global user.email แสดงอีเมลของคุณ (ควรตรงกับ GitHub)
ก่อนหน้า: ทำไมต้องใช้ Git และ Git ต่างจาก GitHub อย่างไร สารบัญบทเรียน ถัดไป: สร้าง Developer Profile Page
