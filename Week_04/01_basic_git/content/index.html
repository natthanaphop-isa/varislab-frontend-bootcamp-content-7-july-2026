Git, GitHub, Branch & Merge พื้นฐาน

คู่มือนี้พาเราสร้างโปรเจกต์เล็ก ๆ ชื่อ Developer Profile Page (HTML + CSS ล้วน) เพื่อใช้ฝึก Git โดยเฉพาะ เราจะเริ่มจากโฟลเดอร์ว่าง สร้าง Git repository บันทึก commit ส่งงานขึ้น GitHub แล้วต่อด้วยการแยกพัฒนา feature บน branch และ merge กลับเข้า main คู่มือเน้นให้เข้าใจภาพรวม (mental model) มากกว่าการท่องคำสั่ง จึงเหมาะกับคนที่ไม่เคยใช้ Git มาก่อน

สิ่งที่ต้องเตรียม

  • ติดตั้ง Git ในเครื่อง (ดูวิธีติดตั้งได้ที่ git-scm.com/downloads)
  • VS Code และ Terminal (macOS/Linux) หรือ PowerShell (Windows)
  • บัญชี GitHub (github.com)
  • ไม่ต้องใช้ npm, Vite, JavaScript หรือ framework ใด ๆ — เราอยากให้โฟกัสกับ Git อย่างเดียว
