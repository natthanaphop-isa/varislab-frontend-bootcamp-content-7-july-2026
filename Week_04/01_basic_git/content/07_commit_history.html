สร้าง Commit History และ README

Build Commit History

เมื่อจบบทนี้ คุณจะสามารถ

  • ดู commit history ด้วย git log และ git log --oneline
  • แก้ไฟล์ที่ Git ติดตามอยู่ แล้วเห็นสถานะ modified
  • ทำ workflow แก้ไฟล์ → status → add → commit ซ้ำได้ด้วยตัวเอง
  • สร้างไฟล์ README.md อธิบายโปรเจกต์

ดู Commit History

ดูแบบเต็ม:

git log

Git จะแสดงข้อมูลของแต่ละ commit ได้แก่ commit ID, author, date และ commit message ประมาณนี้:

commit 8c41a22... (HEAD -> main)
Author: Your Name <your-email@example.com>
Date:   ...

    Create developer profile page

ดูแบบสั้น บรรทัดละหนึ่ง commit:

git log --oneline
8c41a22 Create developer profile page

ถ้า git log ยาวจนล้นจอ Terminal จะเข้าโหมดเลื่อนดู (pager) ใช้ลูกศรขึ้นลงเพื่อเลื่อน และกด q เพื่อออก

สร้าง Commit ที่สอง

ข้อมูลในหน้าเว็บตอนนี้ยังเป็นของ “Somchai” ถึงเวลาเปลี่ยนเป็นของเราเอง เปิด index.html แล้วแก้ทีละจุด

เปลี่ยนชื่อ (ใส่ชื่อจริงของคุณแทน Your Name):

<h1>Your Name</h1>

เปลี่ยนตำแหน่ง:

<p class="role">Junior Frontend Developer</p>

เปลี่ยนคำอธิบาย:

<p class="description">
  I am learning full-stack web development and building projects to prepare
  for my first software developer role.
</p>

เปลี่ยนรายการทักษะ:

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
  <li>TypeScript Basics</li>
</ul>

เปลี่ยนอีเมล:

<a class="contact-button" href="mailto:your-email@example.com">
  Contact Me
</a>

หลังแก้ครบ ส่วน <body> ของ index.html ควรเป็นแบบนี้:

  <body>
    <main class="profile-card">
      <h1>Your Name</h1>

      <p class="role">Junior Frontend Developer</p>

      <p class="description">
        I am learning full-stack web development and building projects to prepare
        for my first software developer role.
      </p>

      <section>
        <h2>Current Skills</h2>

        <ul>
          <li>HTML</li>
          <li>CSS</li>
          <li>JavaScript</li>
          <li>TypeScript Basics</li>
        </ul>
      </section>

      <a class="contact-button" href="mailto:your-email@example.com">
        Contact Me
      </a>
    </main>
  </body>

save ไฟล์แล้ว refresh browser เพื่อดูผล

ตรวจสอบการเปลี่ยนแปลง

git status

ควรเห็น:

Changes not staged for commit:
  (use "git add <file>..." to update what will be committed)
  (use "git restore <file>..." to discard changes in working directory)
        modified:   index.html

ครั้งนี้ไม่ใช่ Untracked แล้ว แต่เป็น modified เพราะ Git ติดตาม index.html มาตั้งแต่ commit แรก มันจึงรู้ว่าไฟล์นี้ถูกแก้ไปจากเวอร์ชันที่บันทึกไว้

Commit การเปลี่ยนแปลง

git add index.html
git commit -m "Update personal profile information"

ตรวจสอบ history:

git log --oneline
92da187 Update personal profile information
8c41a22 Create developer profile page

commit ใหม่ล่าสุดจะอยู่ด้านบนสุดเสมอ

สร้าง README

README.md คือไฟล์แนะนำโปรเจกต์ เขียนด้วย Markdown เมื่อเราส่งโปรเจกต์ขึ้น GitHub ในบทต่อไป GitHub จะแสดงไฟล์นี้ที่หน้าแรกของ repository ให้อัตโนมัติ สร้างไฟล์ README.md ที่ root ของโปรเจกต์ แล้วใส่เนื้อหา: 

# Developer Profile Page

A simple personal profile page created with HTML and CSS.

This project was created for practicing basic Git and GitHub workflows.

## Features

- Personal introduction
- Skills list
- Contact button
- Responsive profile card

## Technologies

- HTML
- CSS

## Git Commands Practiced

- git init
- git status
- git add
- git commit
- git log
- git branch
- git switch
- git merge
- git push

บางคำสั่งในรายการเรายังไม่ได้ใช้ ไม่เป็นไร เราจะได้ใช้ครบก่อนจบคู่มือ

Commit:

git add README.md
git commit -m "Add project README"

ตรวจสอบ:

git log --oneline

ผลลัพธ์ควรคล้าย:

f18ad55 Add project README
92da187 Update personal profile information
8c41a22 Create developer profile page

ตอนนี้โปรเจกต์ของเรามีครบสามไฟล์ และมี 3 commit:

developer-profile-page/
├── index.html
├── style.css
└── README.md

ถ้า git status ขึ้น nothing to commit, working tree clean ทั้งที่เพิ่งแก้ไฟล์ ให้ตรวจว่าได้ save ไฟล์ใน VS Code แล้ว (แท็บที่ยังไม่ save จะมีจุดกลมขึ้น)

  • git log --oneline แสดง 3 commit เรียงจากใหม่ไปเก่า
  • หน้าเว็บแสดงชื่อ ตำแหน่ง ทักษะ และอีเมลของคุณเอง
  • มีไฟล์ README.md และ git status ขึ้น working tree clean
  • อธิบายความต่างระหว่างสถานะ Untracked กับ modified ได้
ก่อนหน้า: สร้าง Commit แรกและเขียน Commit Message ที่ดี สารบัญบทเรียน ถัดไป: Local, Remote และการสร้าง Repository บน GitHub
