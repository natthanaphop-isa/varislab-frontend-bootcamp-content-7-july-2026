บทเรียน 11 · Branch และ Merge (Branch & Merge)

พัฒนา Feature บน Branch แยก

Develop on a Feature Branch

เมื่อจบบทนี้ คุณจะสามารถ

  • แก้โค้ดและสร้าง commit บน feature branch
  • สลับกลับไป main ด้วย git switch
  • อธิบายได้ว่าทำไม Projects Section “หายไป” เมื่ออยู่บน main
  • อ่าน commit graph ด้วย git log --oneline --graph --all

จากบทที่แล้ว เรากำลังอยู่บน branch feature/add-projects-section (ตรวจด้วย git branch ก่อนเริ่มได้) ตอนนี้ถึงเวลาลงมือพัฒนา feature จริง

เพิ่ม Projects Section

เปิด index.html แล้วเพิ่ม section นี้ก่อนปุ่ม Contact Me (ต่อจาก section Current Skills):

<section>
  <h2>My Projects</h2>

  <ul>
    <li>Bootcamp Landing Page</li>
    <li>Developer Profile Page</li>
  </ul>
</section>

หลังเพิ่มแล้ว <main> ของเราจะเป็นแบบนี้:

    <main class="profile-card">
      <h1>Your Name</h1>

      <p class="role">Junior Frontend Developer</p>

      <p class="description">
        I am learning full-stack web development and building projects to prepare
        for my first software developer role.
      </p>

      <section>
        <h2>Current Skills</h2>

        <ul>
          <li>HTML</li>
          <li>CSS</li>
          <li>JavaScript</li>
          <li>TypeScript Basics</li>
        </ul>
      </section>

      <section>
        <h2>My Projects</h2>

        <ul>
          <li>Bootcamp Landing Page</li>
          <li>Developer Profile Page</li>
        </ul>
      </section>

      <a class="contact-button" href="mailto:your-email@example.com">
        Contact Me
      </a>
    </main>

เราไม่ต้องแก้ CSS เลย เพราะ selector .profile-card section และ .profile-card ul ใน style.css จัดรูปแบบ section ใหม่ให้อัตโนมัติ save แล้ว refresh browser เพื่อตรวจสอบ

จากนั้นตรวจสอบ Git:

git status
On branch feature/add-projects-section
Changes not staged for commit:
  ...
        modified:   index.html

สังเกตบรรทัดแรก — git status บอกด้วยว่าเราอยู่บน branch ไหน

Commit บน Feature Branch

git add index.html
git commit -m "Add projects section"

ตรวจสอบ history:

git log --oneline
7f2a1b3 (HEAD -> feature/add-projects-section) Add projects section
f18ad55 (origin/main, main) Add project README
92da187 Update personal profile information
8c41a22 Create developer profile page

ข้อความในวงเล็บคือ “ป้าย” ที่บอกว่า branch ไหนชี้อยู่ที่ commit ใด: commit ใหม่ Add projects section อยู่บน feature/add-projects-section ส่วน main (และ origin/main บน GitHub) ยังชี้อยู่ที่ Add project README แปลว่า commit ใหม่ยังไม่ได้อยู่บน main

สลับกลับไปดู main

git switch main

ตรวจสอบ:

git branch
  feature/add-projects-section
* main

ตอนนี้ลองเปิด index.html ใน VS Code หรือ refresh หน้าเว็บ — Projects Section หายไป!

ไม่ต้องตกใจ Projects Section ไม่ได้ถูกลบ มันยังอยู่บน feature branch ครบถ้วน เราแค่สลับกลับมาอยู่บน main ซึ่งเป็นเวอร์ชันก่อนที่เราจะเพิ่ม feature เมื่อสลับ branch Git จะเปลี่ยนไฟล์ใน working directory ให้ตรงกับ branch นั้นให้เอง นี่คือประโยชน์สำคัญของ branch: แต่ละ branch มีเวอร์ชันของไฟล์ต่างกันได้

ลองสลับไปมาดูเองสักรอบ: git switch feature/add-projects-section แล้ว refresh (section กลับมา) จากนั้น git switch main แล้ว refresh (section หายไป) ก่อนไปต่อให้แน่ใจว่าจบที่ main

ดู Commit Graph

git log --oneline --graph --all

--graph วาดเส้นความสัมพันธ์ของ commit และ --all แสดง commit ของทุก branch ไม่ใช่แค่ branch ปัจจุบัน ผลลัพธ์จะคล้าย:

* 7f2a1b3 (feature/add-projects-section) Add projects section
* f18ad55 (HEAD -> main, origin/main) Add project README
* 92da187 Update personal profile information
* 8c41a22 Create developer profile page

ในกรณีนี้ history ยังดูเป็นเส้นตรง เพราะหลังแยก branch ยังไม่มี commit ใหม่เกิดบน main แต่ให้สังเกตว่าป้าย branch อยู่คนละตำแหน่ง: main ชี้ที่ f18ad55 ส่วน feature branch ชี้ที่ 7f2a1b3 ซึ่งอยู่ถัดไปหนึ่ง commit ส่วน HEAD บอกว่าเรากำลังยืนอยู่ที่ main

ถ้า git switch main ไม่ยอมสลับและบอกว่ามีการเปลี่ยนแปลงที่จะถูกเขียนทับ แปลว่ายังมีไฟล์ที่แก้แต่ไม่ได้ commit ให้รัน git status แล้ว add + commit งานบน feature branch ให้เรียบร้อยก่อนสลับ

  • มี commit Add projects section บน feature/add-projects-section
  • เมื่ออยู่บน main หน้าเว็บไม่มี Projects Section และเมื่อสลับไป feature branch section กลับมา
  • git log --oneline --graph --all แสดงป้าย main และ feature branch อยู่คนละ commit
  • ตอนจบบท git branch แสดง * อยู่หน้า main
ก่อนหน้า: Branch คืออะไร และสร้าง Feature Branch สารบัญบทเรียน ถัดไป: Merge Feature กลับเข้า main
