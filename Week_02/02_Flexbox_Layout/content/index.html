Flexbox Layout

เมื่อเรารู้แล้วว่าทุก element คือกล่อง คำถามถัดไปคือ "ถ้ามีกล่องหลายใบ จะจัดวางมันยังไง?" ในคอร์สนี้เราจะตอบด้วย Flexbox ผ่านการสร้าง Landing Page ของ Full-Stack Bootcamp หนึ่งหน้า — navbar ที่ logo อยู่ซ้ายเมนูอยู่ขวา, hero section แบบซ้าย-ขวา, feature cards และ pricing cards ที่กว้างเท่ากัน โดยใช้ display: flex, justify-content, align-items, gap, flex: 1 และปิดท้ายด้วย responsive เบื้องต้นด้วย @media และ flex-wrap

สิ่งที่ต้องเตรียม

  • Code editor (เช่น VS Code) และเบราว์เซอร์สำหรับเปิดไฟล์ index.html
  • พื้นฐาน Semantic HTML และ CSS Box Model (padding, margin, max-width)
  • โฟลเดอร์โปรเจกต์ของคอร์สนี้: start/ คือโค้ดฉบับร่าง และ finish/ คือโค้ดฉบับสมบูรณ์ ใช้เทียบกับของเราเมื่อทำตามคู่มือจบ
