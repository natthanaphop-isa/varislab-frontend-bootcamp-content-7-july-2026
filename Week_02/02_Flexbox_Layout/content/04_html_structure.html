HTML Structure & Base Styles

เมื่อจบบทนี้ คุณจะสามารถ

  • เขียน HTML ของหน้า landing page ครบทุก section ด้วย Semantic HTML

  • ตั้งค่า CSS พื้นฐานของหน้า (box-sizing, พื้นหลัง, ฟอนต์)

อ่านโครงสร้างแบบ "แม่-ลูก"

ก่อนเขียน CSS ลองไล่ดูว่ากล่องไหนจะเป็น flex container และลูกของมันคืออะไร นี่คือแผนที่ของทั้งบทที่เหลือ:

Parent (flex container)Childrenอยากให้เป็นแบบไหนบทที่
.navbar.logo, .nav-linkslogo ซ้าย เมนูขวา05
.nav-linksลิงก์ <a> 3 ตัวเรียงเป็นแถว มีระยะห่าง05
.hero-section.hero-content, .hero-cardข้อความซ้าย กล่องข้อมูลขวา06
.features-section.feature-card 3 ใบcard เรียงแถว กว้างเท่ากัน07
.pricing-cards.pricing-card 2 ใบcard เรียงแถว กว้างเท่ากัน08

สังเกตว่าเราใช้ Semantic HTML จากคอร์ส HTML/CSS พื้นฐานเต็มที่: <aside> สำหรับกล่องข้อมูลเสริมข้าง hero, <article> สำหรับ card แต่ละใบที่เนื้อหาจบในตัว ส่วน <div> ใช้เฉพาะกล่องที่มีไว้จัด layout อย่าง .nav-links และ .pricing-cards

CSS พื้นฐานของหน้า

เปิด style.css แล้วเริ่มจากส่วนที่ใช้กับทั้งหน้า:

* {
    box-sizing: border-box;
}

body {
    margin: 0;
    font-family: Arial, sans-serif;
    background: #0f172a;
    color: white;
}
  • box-sizing: border-box — ให้ width รวม padding และ border ไว้แล้ว คำนวณขนาดกล่องง่ายขึ้น (ทบทวนจากเรื่อง Box Model)
  • margin: 0 ที่ body — ลบระยะขอบที่เบราว์เซอร์ใส่มาให้
  • background: #0f172a และ color: white — ธีมสีเข้ม ตัวอักษรสีขาว

เปิด index.html ในเบราว์เซอร์ จะเห็นพื้นหลังสีน้ำเงินเข้ม ตัวอักษรสีขาว และทุกอย่างยังเรียงลงมาเป็นบน-ล่าง ลิงก์ยังเป็นสีน้ำเงินขีดเส้นใต้ นี่คือจุดเริ่มต้นที่ถูกต้อง เพราะเรายังไม่ได้ใส่ Flexbox เลย

ถ้าหน้าเว็บยังเป็นพื้นขาว ให้ตรวจว่า <link rel="stylesheet" href="style.css" /> สะกดชื่อไฟล์ถูก และ style.css อยู่ในโฟลเดอร์เดียวกับ index.html

  • index.html มีครบ: header/navbar, hero, features, pricing และ footer
  • หน้าเว็บเป็นพื้นหลังสีเข้ม ตัวอักษรสีขาว
  • ชี้ได้ว่า flex container ในหน้านี้มีกี่ตัว และแต่ละตัวมีลูกอะไรบ้าง
