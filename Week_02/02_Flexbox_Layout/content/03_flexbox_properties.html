บทเรียน 03 · พื้นฐาน Flexbox (Flexbox Fundamentals)

Property หลักของ Flexbox ที่ควรรู้

Flexbox Properties

เมื่อจบบทนี้ คุณจะสามารถ

  • ใช้ justify-content จัดตำแหน่งตามแนวหลัก (ปกติคือแนวนอน)
  • ใช้ align-items จัดตำแหน่งตามแนวตั้ง
  • ใช้ gap สร้างระยะห่างระหว่าง item
  • ใช้ flex: 1 แบ่งพื้นที่ให้ item เท่า ๆ กัน และใช้ flex-wrap ให้ item ขึ้นบรรทัดใหม่ได้

บทนี้เป็น "กล่องเครื่องมือ" ที่เราจะหยิบไปใช้ในบทถัด ๆ ไป ทุก property ในบทนี้จะปรากฏในโค้ดจริงของโปรเจกต์ ลองอ่านให้เห็นภาพก่อน แล้วค่อยกลับมาเปิดดูตอนลงมือเขียน

1. display: flex — เปิดโหมด Flexbox

.container {
  display: flex;
}

ใช้เปิดโหมด Flexbox ให้ container เมื่อเปิดแล้ว ลูกโดยตรงจะเรียงต่อกันเป็นแถวแนวนอนโดยอัตโนมัติ property อื่น ๆ ในบทนี้ส่วนใหญ่จะทำงานก็ต่อเมื่อมี display: flex อยู่ก่อน

2. justify-content — จัดตำแหน่งในแนวหลัก

ใช้จัดตำแหน่งของลูกในแนวหลัก ซึ่งโดยปกติคือแนวนอน (ซ้าย-ขวา)

.navbar {
  display: flex;
  justify-content: space-between;
}

ค่าที่ควรรู้ก่อน:

justify-content: flex-start;
justify-content: center;
justify-content: space-between;
ค่าผลลัพธ์
flex-startชิดซ้าย (เป็นค่าเริ่มต้น)
centerอยู่กลาง
space-betweenดันตัวแรกไปซ้ายสุด ตัวสุดท้ายไปขวาสุด แล้วกระจายที่ว่างไว้ตรงกลาง

3. align-items — จัดตำแหน่งในแนวตั้ง

.navbar {
  display: flex;
  align-items: center;
}

align-items: center ใช้จัดลูกใน container ให้อยู่กึ่งกลางแนวตั้ง ใช้บ่อยมากใน navbar เพราะเราอยากให้ logo กับลิงก์อยู่กึ่งกลางแนวเดียวกัน แม้ขนาดตัวอักษรจะไม่เท่ากัน

ค่าเริ่มต้นของ align-items คือ stretch ซึ่งยืดลูกทุกตัวให้สูงเท่ากับ container เราจะได้ใช้ค่า stretch นี้อีกครั้งตอนทำ responsive ในบทที่ 09

4. gap — ระยะห่างระหว่างลูก

.nav-links {
  display: flex;
  gap: 20px;
}

gap กำหนดระยะห่างระหว่างลูกแต่ละตัว ดีกว่าการใส่ margin ซ้ายขวาให้ item ทีละตัว เพราะ:

  • เขียนที่เดียว (ที่ parent) ควบคุมระยะห่างได้ทั้งหมด
  • ไม่มีระยะเกินที่หัวหรือท้ายแถว ไม่ต้องมาลบ margin ของตัวสุดท้าย
  • อ่านง่ายกว่า เห็นปุ๊บรู้เลยว่าระยะห่างระหว่าง item คือเท่าไร

5. flex: 1 — แบ่งพื้นที่ให้ลูก

property นี้ต่างจากตัวอื่นตรงที่ ใส่ที่ลูก ไม่ใช่ที่แม่ ใช้บอกว่าลูกตัวนี้ควรยืดขยายกินพื้นที่ว่างในแถวแค่ไหน

.feature-card {
  flex: 1;
}

ถ้ามี card 3 ใบ และทุกใบมี flex: 1 พื้นที่ในแถวจะถูกแบ่งให้ card แต่ละใบใกล้เคียงกัน ตัวเลขยังใช้เป็นสัดส่วนได้ด้วย เช่น ลูกตัวหนึ่ง flex: 1.4 อีกตัว flex: 1 ตัวแรกจะกว้างกว่าเล็กน้อย เราจะใช้เทคนิคนี้ใน hero section (บทที่ 06)

6. flex-wrap — ขึ้นบรรทัดใหม่เมื่อพื้นที่ไม่พอ

.features-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

ค่าเริ่มต้นของ Flexbox คือพยายามบีบลูกทุกตัวให้อยู่ในแถวเดียว ถ้าหน้าจอแคบลงแล้ว item เรียงในแถวเดียวไม่พอ flex-wrap: wrap จะอนุญาตให้ item ขึ้นบรรทัดใหม่ได้ ในโปรเจกต์เราจะใช้กับ .nav-links ตอนทำ responsive

สรุปเป็นตาราง

Propertyใส่ที่หน้าที่
display: flexparentเปิดโหมด Flexbox
justify-contentparentจัดตำแหน่งแนวหลัก (ปกติคือแนวนอน)
align-itemsparentจัดตำแหน่งแนวตั้ง
gapparentระยะห่างระหว่างลูก
flex-wrapparentอนุญาตให้ลูกขึ้นบรรทัดใหม่
flex: 1childให้ลูกแบ่งพื้นที่ในแถว

อยากดูค่าอื่น ๆ เพิ่มเติม อ่านได้ที่ MDN: Flexbox แต่สำหรับโปรเจกต์นี้ 6 ตัวนี้เพียงพอแล้ว

  • บอกได้ว่า justify-content: space-between ทำอะไร
  • อธิบายได้ว่าทำไม gap ดีกว่าการใส่ margin ให้ item ทีละตัว
  • บอกได้ว่า property ไหนใส่ที่ parent และตัวไหนใส่ที่ child
