Hero Section แบบซ้าย-ขวา และ Flex Ratio

Hero Layout & Flex Ratio

เมื่อจบบทนี้ คุณจะสามารถ

  • จัด container ของเนื้อหาหลักด้วย max-width และ margin: 0 auto
  • สร้าง layout สองฝั่งซ้าย-ขวาด้วย display: flex, align-items และ gap
  • ใช้ flex ratio (flex: 1.4 กับ flex: 1) กำหนดให้ฝั่งหนึ่งกว้างกว่าอีกฝั่ง
  • ตกแต่งข้อความ hero, ปุ่ม และกล่องข้อมูลให้ดูเป็นมืออาชีพ

container ของ main

เนื้อหาทุก section อยู่ใน <main> เราจัดให้กว้างไม่เกิน 1100px เท่ากับ navbar เพื่อให้ขอบซ้าย-ขวาของทั้งหน้าตรงกัน:

main {
    max-width: 1100px;
    margin: 0 auto;
    padding: 64px 32px;
}

ขั้นที่ 1: เรียงสองฝั่งซ้าย-ขวา

.hero-section มีลูก 2 ตัว คือ .hero-content (ข้อความ) และ .hero-card (กล่องข้อมูล):

.hero-section {
    display: flex;
    align-items: center;
    gap: 40px;
    margin-bottom: 72px;
}
  • display: flex — ทำให้สองฝั่งนี้เรียงซ้าย-ขวา
  • align-items: center — ฝั่งข้อความสูงกว่าฝั่ง card จึงจัดให้ทั้งสองอยู่กึ่งกลางแนวตั้ง card จะไม่ถูกยืดให้สูงเท่าฝั่งข้อความ
  • gap: 40px — ระยะห่างระหว่างสองฝั่ง
  • margin-bottom: 72px — ระยะห่างจาก section ถัดไป (ยังไม่เกี่ยวกับ Flexbox)

ขั้นที่ 2: Flex Ratio

เราอยากให้ฝั่งข้อความกว้างกว่าฝั่ง card เล็กน้อย จึงกำหนด flex ที่ลูกแต่ละตัวเป็นสัดส่วน:

.hero-content {
    flex: 1.4;
}

.hero-card {
    flex: 1;
    padding: 28px;
    border-radius: 24px;
    background: #1e293b;
    box-shadow: 0 24px 60px rgba(0, 0, 0, 0.35);
}

.hero-content ได้ flex: 1.4 ส่วน .hero-card ได้ flex: 1 พื้นที่จึงถูกแบ่งในอัตรา 1.4 : 1 แปลว่าฝั่งข้อความใหญ่กว่าฝั่ง card เล็กน้อย

property อื่นของ .hero-card คือการแต่งกล่อง: padding ระยะด้านใน, border-radius มุมโค้ง, background สีพื้นที่อ่อนกว่าพื้นหลังหน้า และ box-shadow เงาให้กล่องดูลอยขึ้นมา

ลองเปลี่ยน flex: 1.4 เป็น flex: 1 แล้ว refresh จะเห็นว่าสองฝั่งกว้างใกล้เคียงกัน ลองเป็น flex: 2 ฝั่งข้อความจะกว้างขึ้นอีก ตัวเลขไม่ได้เป็นหน่วย px แต่เป็นสัดส่วนเมื่อเทียบกับลูกตัวอื่น

ขั้นที่ 3: ตกแต่งข้อความใน hero

ป้ายเล็ก ๆ เหนือหัวข้อ (.eyebrow) และป้ายใน card (.card-label) หน้าตาเหมือนกัน เราจึงเขียน selector รวมกันด้วยเครื่องหมายจุลภาค:

.eyebrow,
.card-label {
    margin: 0 0 16px;
    color: #38bdf8;
    font-weight: bold;
    text-transform: uppercase;
    letter-spacing: 0.04em;
}

h1 {
    margin: 0 0 24px;
    font-size: 52px;
    line-height: 1.1;
}

.hero-description {
    margin: 0 0 32px;
    color: #cbd5e1;
    font-size: 20px;
    line-height: 1.7;
}
  • margin: 0 0 16px — เขียนแบบ 3 ค่า: บน 0, ซ้าย-ขวา 0, ล่าง 16px (ได้ผลเหมือน 0 0 16px 0 แต่สั้นกว่า)
  • text-transform: uppercase และ letter-spacing — ทำให้ป้ายเป็นตัวพิมพ์ใหญ่และห่างขึ้นเล็กน้อย
  • line-height: 1.1 ที่ h1 — หัวข้อตัวใหญ่ไม่ต้องห่างบรรทัดมาก ส่วนย่อหน้าใช้ 1.7 ให้อ่านสบาย

ขั้นที่ 4: ปุ่ม และรายการใน card

.primary-button {
    display: inline-block;
    padding: 14px 24px;
    border-radius: 999px;
    background: #38bdf8;
    color: #0f172a;
    font-weight: bold;
    text-decoration: none;
}

.primary-button:hover {
    background: #7dd3fc;
}

.hero-card h2 {
    margin: 0 0 16px;
    font-size: 36px;
}

.hero-card ul {
    margin: 0;
    padding-left: 20px;
    color: #cbd5e1;
    line-height: 1.8;
}
  • display: inline-block — <a> เป็น inline ทำให้ padding บน-ล่างไม่ดันพื้นที่รอบข้าง เปลี่ยนเป็น inline-block เพื่อให้ปุ่มมีขนาดตาม padding จริง
  • border-radius: 999px — ค่าใหญ่มาก ๆ ทำให้ปุ่มโค้งมนเป็นทรงแคปซูล
  • .hero-card h2 และ .hero-card ul — แต่งเฉพาะหัวข้อและรายการที่อยู่ใน card เท่านั้น ไม่กระทบ h2 ใน section อื่น

hero section มีข้อความและปุ่มสีฟ้าทรงแคปซูลอยู่ทางซ้าย กล่อง "Bootcamp Format / 12 Weeks" พร้อมรายการ 4 ข้ออยู่ทางขวา มีเงา มุมโค้ง และฝั่งข้อความกว้างกว่าฝั่ง card เล็กน้อย

align-items แล้วไม่เห็นผล? บางครั้ง align-items อาจดูเหมือนไม่มีผล เพราะลูกทุกตัวสูงใกล้กันอยู่แล้ว ใน hero นี้ลองคอมเมนต์ align-items: center ออก จะเห็นว่า card ถูกยืดให้สูงเท่าฝั่งข้อความ (ค่าเริ่มต้น stretch) ถ้ายังไม่เห็นชัด ให้ลองเพิ่มเนื้อหาในฝั่งข้อความให้ยาวขึ้น

  • ข้อความอยู่ซ้าย card อยู่ขวา มีระยะห่าง 40px
  • อธิบายได้ว่า flex: 1.4 กับ flex: 1 ทำให้สองฝั่งกว้างต่างกันอย่างไร
  • ปุ่มเปลี่ยนสีเมื่อ hover และ card มีเงาและมุมโค้ง
