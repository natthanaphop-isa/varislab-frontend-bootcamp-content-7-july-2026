  • ทบทวนความเข้าใจด้วยคำถามท้ายบท

สิ่งที่เราได้เรียน

ถ้าเรื่อง Box Model สอนให้เรามองว่า element ทุกตัวคือกล่อง คอร์สนี้ก็สอนวิธีจัดกล่องหลายใบให้อยู่ในตำแหน่งที่ต้องการ สิ่งที่อยากให้จำที่สุดคือ:

Flexbox ใส่ที่ parent
แล้วมันจะจัด children ข้างใน

property หลักที่ควรจำ:

display: flex
justify-content
align-items
gap
flex: 1
flex-wrap

Flexbox ในโปรเจกต์ของเรา

ส่วนของหน้าFlexbox ที่ใช้
Navbardisplay: flex + justify-content: space-between + align-items: center
Nav linksdisplay: flex + gap: 20px (และ flex-wrap: wrap บนจอเล็ก)
Herodisplay: flex + align-items: center + gap: 40px, ลูก flex: 1.4 / flex: 1
Feature cardsdisplay: flex + gap: 20px, ลูก flex: 1
Pricing cardsdisplay: flex + gap: 20px, ลูก flex: 1
จอเล็ก@media (max-width: 768px) + flex-direction: column + align-items: stretch

เมื่อเข้าใจ Flexbox แล้ว เราสร้าง layout ที่เหมือนเว็บจริงได้มากขึ้น เช่น navbar, hero section, card layout, pricing section และ responsive layout เบื้องต้น ขั้นต่อไปคือ CSS Grid และ Responsive Layout ซึ่งช่วยจัด layout ที่ซับซ้อนขึ้น เช่น การจัดทั้งแถวและคอลัมน์พร้อมกัน

การบ้าน: Flexbox Landing Page Layout

สร้างหรือปรับหน้า landing page โดยใช้ Flexbox เป็นหลัก หัวข้อเลือกเองได้ เช่น:

  • Bootcamp Landing Page
  • Portfolio Landing Page
  • Product Landing Page
  • Service Page
  • Event Page

Requirements

  1. มี navbar ที่ใช้ Flexbox
  2. มี hero section แบบ 2 columns
  3. มี feature cards อย่างน้อย 3 ใบ
  4. มีอีก 1 section ที่ใช้ Flexbox เช่น pricing, testimonial หรือ target audience
  5. ใช้ gap อย่างน้อย 2 จุด
  6. ใช้ justify-content อย่างน้อย 1 จุด
  7. ใช้ align-items อย่างน้อย 1 จุด
  8. ใช้ flex: 1 หรือ flex ratio อย่างน้อย 1 จุด
  9. มี responsive เบื้องต้นด้วย @media

ใช้โปรเจกต์ในคู่มือนี้เป็นต้นแบบได้ แต่ลองเปลี่ยนเนื้อหา สี และจำนวน card ให้เป็นของตัวเอง แล้วตรวจทุกข้อใน Requirements ด้วย DevTools ว่า flex container อยู่ถูกที่

Reflection

ตอบคำถามสั้น ๆ แนบมากับการบ้าน:

  1. Flexbox ใช้แก้ปัญหาอะไร?
  2. Parent container กับ child item ต่างกันอย่างไร?
  3. justify-content กับ align-items ต่างกันอย่างไร?
  4. gap มีประโยชน์อย่างไร?
  5. ตอนทำ responsive layout เจอปัญหาอะไร?

คำถามทบทวน

ลองตอบด้วยตัวเองก่อน ถ้าไม่แน่ใจให้ย้อนกลับไปอ่านบทที่เกี่ยวข้อง

  1. Flexbox ต้องใส่ที่ element แบบไหน?
  2. display: flex; ใช้ทำอะไร?
  3. justify-content: space-between; ทำอะไร?
  4. align-items: center; ใช้ทำอะไร?
  5. gap ใช้ทำอะไร?
  6. flex: 1; หมายถึงอะไรโดยทั่วไป?
  7. ถ้าอยากให้ card หลายใบเรียงในแถวเดียวกัน ควรใส่ display: flex ที่ไหน?
  8. flex-wrap: wrap; ใช้ทำอะไร?
  9. @media ใช้ทำอะไร?
  10. navbar ที่มี logo ซ้าย เมนูขวา ควรใช้ property ของ Flexbox ตัวไหนบ้าง?
  • หน้า landing page ของคุณตรงกับ finish/ ทั้งบนจอกว้างและจอเล็ก
  • อธิบายประโยค "Flexbox ใส่ที่ parent แล้วมันจะจัด children ข้างใน" ให้เพื่อนฟังได้
  • ตอบคำถามทบทวนได้ครบทุกข้อ
