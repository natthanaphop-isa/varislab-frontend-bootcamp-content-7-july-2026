บทเรียน 01 · พื้นฐาน Flexbox (Flexbox Fundamentals)

ภาพรวมบทเรียนและโปรเจกต์

Intro & Project Overview

เมื่อจบบทนี้ คุณจะสามารถ

  • ทบทวนแนวคิด "ทุก element คือกล่อง" และเครื่องมือ padding, margin, max-width จากเรื่อง Box Model ได้
  • อธิบายได้ว่าคอร์สนี้จะตอบคำถาม "มีกล่องหลายใบ จะจัดวางยังไง" ด้วย Flexbox
  • เห็นภาพหน้า landing page ที่เราจะสร้าง และรู้ว่าไฟล์ของโปรเจกต์อยู่ตรงไหน

ทบทวนสิ่งที่เรียนมาแล้ว

ก่อนเริ่มคอร์สนี้ เราควรมีพื้นฐาน HTML/CSS ต่อไปนี้ ซึ่งคอร์สนี้จะต่อยอดโดยตรง:

  • HTML ควรมีความหมาย ด้วย Semantic HTML (header, nav, main, section, article, footer)
  • ทุก element บนหน้าเว็บคือกล่อง และเราใช้ padding, margin, border, width ควบคุมพื้นที่ของกล่องแต่ละใบ
  • padding คือระยะห่างด้านใน ส่วน margin คือระยะห่างด้านนอก
  • max-width คู่กับ margin: 0 auto ใช้จัด container ให้อยู่กลางหน้า

คำถามหลักของคอร์สนี้

เมื่อเราควบคุมกล่องทีละใบได้แล้ว คำถามถัดไปคือ:

ถ้ามีกล่องหลายใบ เราจะจัดวางมันยังไงให้เป็น layout ที่ดูเป็นมืออาชีพ?

ตัวอย่างสิ่งที่เราอยากทำบ่อย ๆ ในเว็บจริง:

  • ให้ logo อยู่ซ้าย และเมนูอยู่ขวาใน navbar
  • ให้ hero section มีข้อความด้านซ้าย และกล่องข้อมูลด้านขวา
  • ให้ feature card 3 ใบเรียงอยู่ในแถวเดียวกัน โดยมีระยะห่างเท่า ๆ กัน
  • ให้ layout เปลี่ยนเป็นเรียงบน-ล่างเมื่อหน้าจอเล็กลง

เครื่องมือหลักที่เราจะใช้ตอบโจทย์ทั้งหมดนี้คือ Flexbox ซึ่งเป็นเครื่องมือ CSS ที่ใช้บ่อยมากในการจัด layout หน้าเว็บจริง โดยเฉพาะ navbar, card layout, section layout และ component ต่าง ๆ

คอร์สนี้ยังไม่ต้องจำทุก property ของ Flexbox ให้ได้ทั้งหมด ขอแค่เข้าใจภาพหลักประโยคเดียว: Flexbox คือการบอก parent ว่าให้จัดลูก ๆ ข้างในอย่างไร

โปรเจกต์: Bootcamp Pricing & Feature Section

เราจะสร้างหน้า landing page ของ Full-Stack Bootcamp ที่ใช้ Flexbox หลายจุด ประกอบด้วย:

  1. Navbar — logo ซ้าย เมนูขวา
  2. Hero layout แบบซ้าย-ขวา — ข้อความแนะนำคอร์ส กับกล่องสรุป course stats
  3. Feature cards 3 ใบ — เรียงเป็นแถวและกว้างเท่ากัน
  4. Pricing cards 2 ใบ — แผนจ่ายครั้งเดียว และแผนผ่อน
  5. Responsive เบื้องต้น — จอเล็กแล้วเปลี่ยนเป็นเรียงบน-ล่าง

ไฟล์ของโปรเจกต์

โปรเจกต์นี้มีแค่ 2 ไฟล์ คือ index.html และ style.css ตั้งชื่อโฟลเดอร์ว่า flexbox-layout (หรือชื่ออื่นที่คุณสะดวก):

flexbox-layout/
├── index.html
└── style.css

ในโฟลเดอร์ของคอร์สนี้จะมีโค้ดให้ 2 ชุด:

โฟลเดอร์คืออะไรใช้ทำอะไร
start/โค้ดฉบับร่างที่หน้าตาใกล้เสร็จแล้ว แต่ยังมีจุดที่ต้องเก็บงานใช้ดูระหว่างเรียน และฝึกหาจุดที่ต่างจากฉบับเสร็จ (เราจะไล่ดูกันในบทที่ 09)
finish/โค้ดฉบับสมบูรณ์ใช้เทียบกับของเราเมื่อทำตามคู่มือจบ

ในคู่มือนี้เราจะเขียนทีละส่วนจนได้โค้ดเหมือน finish/ ทุกบรรทัด เปิดไฟล์ index.html ในเบราว์เซอร์ไว้ แล้ว refresh ดูผลทุกครั้งที่เพิ่ม CSS

เส้นทางของคู่มือ

  • บทที่ 02–03 — แนวคิด parent/children และ property หลักของ Flexbox
  • บทที่ 04–08 — ลงมือสร้างหน้า: HTML, navbar, hero, feature cards, pricing และ footer
  • บทที่ 09–11 — responsive เบื้องต้น, error ที่เจอบ่อย, challenge และการบ้าน
  • อธิบายได้ว่า padding กับ margin ต่างกันอย่างไร
  • บอกได้ว่าหน้าที่เราจะสร้างมีกี่ส่วน และส่วนไหนต้องจัดวางกล่องหลายใบ
  • สร้างโฟลเดอร์โปรเจกต์ที่มี index.html และ style.css พร้อมแล้ว
