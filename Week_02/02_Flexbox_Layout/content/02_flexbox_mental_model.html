บทเรียน 02 · พื้นฐาน Flexbox (Flexbox Fundamentals)

Flexbox Mental Model: Parent กับ Children

Flexbox Mental Model

เมื่อจบบทนี้ คุณจะสามารถ

  • แยกได้ว่า element ไหนคือ parent container และ element ไหนคือ child item
  • อธิบายได้ว่าทำไม display: flex ต้องใส่ที่ parent ไม่ใช่ที่ลูกแต่ละตัว
  • บอกได้ว่า Flexbox เหมาะกับ layout แบบไหน

ประโยคเดียวที่ต้องจำ

Flexbox ต้องใส่ที่ parent container
แล้วมันจะจัด layout ของ children ข้างใน

ถ้าจำประโยคนี้ได้ ปัญหาส่วนใหญ่ตอนเริ่มใช้ Flexbox จะหายไปเลย

ตัวอย่าง: card 3 ใบ

สมมติเรามี HTML แบบนี้:

<div class="card-row">
  <article class="card">Card 1</article>
  <article class="card">Card 2</article>
  <article class="card">Card 3</article>
</div>

ปกติ <article> เป็น block element แต่ละใบจึงกินความกว้างเต็มแถว และเรียงต่อกันลงมาเป็นบน-ล่าง ถ้าเราอยากให้ card 3 ใบนี้เรียงอยู่ในแถวเดียวกัน เราไม่ได้ไปใส่ display: flex ที่ .card ทีละใบ แต่ใส่ที่ กล่องที่ครอบ card ทั้งหมด:

.card-row {
  display: flex;
}

กล่องแม่ กับ กล่องลูก

  • .card-row คือ กล่องแม่ (parent / flex container)
  • .card แต่ละใบคือ กล่องลูก (children / flex items)

เมื่อใส่ display: flex; ที่กล่องแม่ เหมือนเรากำลังบอกกล่องแม่ว่า:

ช่วยจัดลูก ๆ ข้างในกล่องนี้ให้เป็น layout แบบ flex ให้หน่อย

ผลคือลูกโดยตรงทุกตัวของ .card-row จะเรียงต่อกันเป็นแถวแนวนอน

Flexbox มีผลกับ ลูกโดยตรง (direct children) เท่านั้น ถ้าข้างใน .card มี <h2> กับ <p> สองตัวนี้ไม่ได้ถูกจัดเรียงด้วย flex ของ .card-row ถ้าอยากจัดข้างใน card ด้วย ต้องใส่ display: flex ที่ .card เพิ่มอีกชั้น

element หนึ่งตัวเป็นได้ทั้งแม่และลูก

ในโปรเจกต์ของเรา navbar มีโครงแบบนี้:

<nav class="navbar">
  <p class="logo">Varis Lab</p>

  <div class="nav-links">
    <a href="#">Overview</a>
    <a href="#">Curriculum</a>
    <a href="#">Pricing</a>
  </div>
</nav>
  • .navbar เป็น parent ของ .logo และ .nav-links
  • .nav-links เป็น ลูก ของ .navbar และในเวลาเดียวกันก็เป็น แม่ ของลิงก์ 3 ตัว

เราจึงใส่ display: flex ได้ทั้งที่ .navbar (จัด logo กับกลุ่มเมนู) และที่ .nav-links (จัดลิงก์ 3 ตัว) เราจะทำจริงในบทที่ 05

Flexbox เหมาะกับอะไร

Flexbox เก่งเรื่องการจัดกล่องเรียงกันในแนวเดียว (แนวนอนหรือแนวตั้ง) เช่น:

  • navbar (logo + เมนู)
  • layout ซ้าย-ขวา เช่น hero section
  • card ที่เรียงเป็นแถว
  • layout แนวตั้งเมื่อหน้าจอเล็ก

ผิดบ่อย: ใส่ display: flex ที่ .card แล้วสงสัยว่าทำไม card ยังเรียงบน-ล่างอยู่ — เพราะ card คือลูก ต้องย้ายไปใส่ที่กล่องแม่ที่ครอบ card ทั้งหมด

ลองทำ

สร้างไฟล์ทดลองเล็ก ๆ ใส่ HTML .card-row ด้านบน เปิดในเบราว์เซอร์ดูก่อน แล้วค่อยเพิ่ม CSS .card-row { display: flex; } แล้ว refresh สังเกตว่า card เปลี่ยนจากเรียงบน-ล่าง เป็นเรียงซ้าย-ขวา จากนั้นลองย้าย display: flex ไปใส่ที่ .card แทน แล้วดูว่าเกิดอะไรขึ้น

  • ชี้ได้ว่าใน HTML ตัวอย่าง อะไรคือ parent และอะไรคือ children
  • อธิบายได้ว่า display: flex มีผลกับลูกโดยตรงเท่านั้น
  • บอกได้ว่า .nav-links เป็นทั้งลูกและแม่ได้อย่างไร
ก่อนหน้า: ภาพรวมบทเรียนและโปรเจกต์ สารบัญบทเรียน ถัดไป: Property หลักของ Flexbox ที่ควรรู้
