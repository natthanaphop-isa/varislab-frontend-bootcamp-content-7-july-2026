บทเรียน 07 · สร้าง Landing Page ด้วย Flexbox (Building the Page)

Feature Cards เรียงแถวด้วย flex: 1

Feature Cards

เมื่อจบบทนี้ คุณจะสามารถ

  • จัด card หลายใบให้เรียงเป็นแถวด้วย Flexbox ที่ parent
  • ใช้ flex: 1 ให้ card ทุกใบกว้างเท่ากัน แม้เนื้อหาจะยาวไม่เท่ากัน
  • อธิบายได้ว่าทำไม gap ช่วยให้ layout "หายใจได้"

ใครคือแม่ ใครคือลูก

<section class="features-section">
  <article class="feature-card">...</article>
  <article class="feature-card">...</article>
  <article class="feature-card">...</article>
</section>
  • .features-section เป็น parent
  • .feature-card 3 ใบเป็น children

ขั้นที่ 1: เรียงเป็นแถว

.features-section {
    display: flex;
    gap: 20px;
    margin-bottom: 72px;
}

display: flex ทำให้ card เรียงเป็นแถว และ gap กำหนดระยะห่างระหว่าง card ส่วน margin-bottom คือระยะห่างก่อน pricing section

ลอง refresh ตอนนี้ จะเห็นว่า card เรียงแถวแล้ว แต่ความกว้างของแต่ละใบอาจไม่เท่ากัน เพราะ flex item จะกว้างตามเนื้อหาข้างใน card ที่ข้อความยาวกว่าจึงกว้างกว่า (ยังไม่มีพื้นหลัง อาจสังเกตยาก ขั้นถัดไปจะเห็นชัดขึ้น)

ขั้นที่ 2: แบ่งพื้นที่เท่า ๆ กันด้วย flex: 1

.feature-card {
    flex: 1;
    padding: 24px;
    border-radius: 20px;
    background: #1e293b;
}

flex: 1 ทำให้ card แต่ละใบแบ่งพื้นที่ในแถวเท่า ๆ กัน ไม่ว่าข้อความในแต่ละใบจะยาวแค่ไหน ส่วน padding, border-radius และ background แต่งให้เป็นการ์ดสีเข้มมุมโค้ง

สังเกตว่า card ทั้ง 3 ใบสูงเท่ากันด้วย ทั้งที่ข้อความยาวไม่เท่ากัน เพราะ .features-section ไม่ได้ตั้ง align-items จึงใช้ค่าเริ่มต้น stretch ที่ยืดลูกทุกตัวให้สูงเท่ากัน — ต่างจาก hero ที่เราตั้ง center ไว้

ขั้นที่ 3: ข้อความใน card

.feature-card h2 {
    margin: 0 0 12px;
    color: #38bdf8;
}

.feature-card p {
    margin: 0;
    color: #cbd5e1;
    line-height: 1.7;
}

หัวข้อ card เป็นสีฟ้า ลบ margin บนออกเพื่อไม่ให้มีช่องว่างเกินที่หัว card และเว้นระยะล่าง 12px ก่อนย่อหน้า

ใต้ hero มี card สีเข้ม 3 ใบ (Manual First, Full-Stack Skills, AI Workflow) เรียงในแถวเดียว กว้างเท่ากัน สูงเท่ากัน และห่างกัน 20px

ทดลอง: ถ้าไม่มี gap

ลองคอมเมนต์ gap: 20px; ใน .features-section ออก แล้ว refresh:

.features-section {
    display: flex;
    /* gap: 20px; */
    margin-bottom: 72px;
}

card ยังเรียงเป็นแถวอยู่ แต่ชิดติดกันเกินไปจนแยกไม่ออกว่าใบไหนเป็นใบไหน gap คือสิ่งที่ช่วยให้ layout หายใจได้ ทดลองเสร็จแล้วเอาคอมเมนต์ออก

ผิดบ่อย: ใส่ display: flex ผิดที่

ถ้าเขียนแบบนี้ แต่ลืมใส่ที่ parent:

.feature-card {
    display: flex;
}

card จะยังเรียงบน-ล่างเหมือนเดิม แถมข้างใน card กลับเพี้ยน เพราะ h2 กับ p ถูกจัดให้อยู่แถวเดียวกันแทน ถ้าอยากจัด card หลายใบ ต้องใส่ display: flex ที่ parent ที่ครอบ card เหล่านั้น คือ .features-section

  • card 3 ใบอยู่แถวเดียวกัน กว้างเท่ากัน
  • อธิบายได้ว่า display: flex, gap และ flex: 1 แต่ละตัวทำหน้าที่อะไรใน section นี้
  • บอกได้ว่าทำไม card ทุกใบสูงเท่ากันโดยที่เราไม่ได้ตั้ง height
