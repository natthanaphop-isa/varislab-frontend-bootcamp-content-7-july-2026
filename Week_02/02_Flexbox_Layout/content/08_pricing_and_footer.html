Pricing Section และ Footer

Pricing Cards & Footer

เมื่อจบบทนี้ คุณจะสามารถ

  • นำแพตเทิร์น "parent flex + gap + ลูก flex: 1" มาใช้ซ้ำกับ pricing cards ได้ด้วยตัวเอง
  • ใช้ class เสริม (.highlight) ทำให้ card ใบหนึ่งเด่นกว่าใบอื่น
  • สังเกตผลของ specificity เมื่อ selector สองตัวแย่งกันกำหนดสีเดียวกัน
  • ปิดหน้าด้วย footer

หัวข้อของ section

ก่อนถึง card มีหัวข้อ section ที่ใช้ .eyebrow ร่วมกับ hero (เราแต่งไว้แล้วในบทที่ 06) เหลือแค่คุมความกว้างและขนาดหัวข้อ:

.section-header {
    max-width: 640px;
    margin-bottom: 28px;
}

.section-header h2 {
    margin: 0;
    font-size: 36px;
}

max-width: 640px ป้องกันไม่ให้หัวข้อยาวเป็นบรรทัดเดียวยืดเต็มความกว้างของหน้า ซึ่งอ่านยาก

ลองคิดก่อน: pricing cards

โครงสร้างของ pricing เหมือน feature cards เลย:

<div class="pricing-cards">
  <article class="pricing-card">...</article>
  <article class="pricing-card highlight">...</article>
</div>

ก่อนดูเฉลย ลองเขียน CSS เองก่อนให้ card 2 ใบเรียงแถว ห่างกัน 20px และกว้างเท่ากัน แล้วค่อยเทียบกับโค้ดด้านล่าง

Flexbox ของ pricing

.pricing-cards {
    display: flex;
    gap: 20px;
}

.pricing-card {
    flex: 1;
    padding: 28px;
    border-radius: 24px;
    background: #1e293b;
    border: 1px solid #334155;
}

.pricing-card.highlight {
    border-color: #38bdf8;
}
  • .pricing-cards คือ parent — display: flex + gap
  • .pricing-card คือ children — flex: 1 แบ่งพื้นที่เท่ากัน พร้อมขอบสีเทา
  • .pricing-card.highlight (ไม่มีช่องว่างระหว่างสอง class) — เลือก element ที่มีทั้งสอง class พร้อมกัน เปลี่ยนแค่สีขอบเป็นสีฟ้า ทำให้แผนผ่อนดูเด่น

.pricing-card.highlight (ติดกัน) กับ .pricing-card .highlight (มีช่องว่าง) ความหมายต่างกันมาก แบบมีช่องว่างแปลว่า "element ที่มี class highlight ซึ่งอยู่ข้างใน .pricing-card" ซึ่งไม่ตรงกับ HTML ของเรา

ข้อความใน card

.pricing-card h3 {
    margin: 0 0 16px;
}

.price {
    margin: 0 0 16px;
    color: #38bdf8;
    font-size: 28px;
    font-weight: bold;
}

.pricing-card p {
    color: #cbd5e1;
    line-height: 1.7;
}

ลองสังเกต: ราคาในหน้าเว็บเป็นสีฟ้าหรือสีเทา? .price ตั้งสีฟ้าไว้ แต่ .pricing-card p ก็เลือก <p class="price"> ด้วย และตั้งสีเทา selector ที่มี class + ชื่อ tag (.pricing-card p) มี specificity สูงกว่า class เดียว (.price) สีเทาจึงชนะ ราคาจึงแสดงเป็นสีเทา ตัวหนา ขนาด 28px (property ที่ไม่ได้ชนกัน เช่น font-size ยังมาจาก .price ตามปกติ)

โค้ดใน finish/ เป็นแบบนี้ ถ้าอยากทดลองให้ราคาเป็นสีฟ้า ลองเปลี่ยน selector .price เป็น .pricing-card .price ซึ่งมี 2 class จึงมี specificity สูงกว่า .pricing-card p (1 class + 1 tag) แล้ว refresh ดูผล

Footer

.site-footer {
    border-top: 1px solid #1e293b;
    padding: 24px 32px;
    text-align: center;
    color: #94a3b8;
}

footer ไม่ต้องใช้ Flexbox เพราะมีข้อความบรรทัดเดียว ใช้ text-align: center จัดกลางก็พอ และมีเส้นขอบบนสีเดียวกับเส้นใต้ header ให้หน้าดูสมดุล

Flexbox ไม่ได้จำเป็นทุกที่ ใช้เมื่อมี "กล่องหลายใบที่ต้องจัดวางร่วมกัน" ส่วนข้อความบรรทัดเดียวที่อยากจัดกลาง text-align ง่ายกว่า

ส่วน Pricing มีป้าย "PRICING" สีฟ้า หัวข้อ "เลือกรูปแบบการเรียนที่เหมาะกับคุณ" และ card 2 ใบกว้างเท่ากัน ใบขวา (Installment) มีขอบสีฟ้า ด้านล่างสุดมี footer ข้อความสีเทาอยู่กลางหน้า ตอนนี้บนจอกว้าง หน้าเว็บของเราควรเหมือน finish/ แล้ว เหลือแค่ responsive

  • pricing card 2 ใบเรียงแถว กว้างเท่ากัน ใบ Installment ขอบสีฟ้า
  • อธิบายได้ว่า .pricing-card.highlight เลือก element แบบไหน
  • บอกได้ว่าทำไมราคาแสดงเป็นสีเทาแม้ .price จะตั้งสีฟ้า
  • footer อยู่ล่างสุด ข้อความอยู่กลาง
ก่อนหน้า: Feature Cards เรียงแถวด้วย flex: 1 สารบัญบทเรียน ถัดไป: Responsive เบื้องต้นด้วย @media และ flex-wrap
