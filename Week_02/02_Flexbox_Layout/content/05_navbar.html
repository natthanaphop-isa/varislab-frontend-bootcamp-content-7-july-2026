บทเรียน 05 · สร้าง Landing Page ด้วย Flexbox (Building the Page)

สร้าง Navbar ด้วย Flexbox

Navbar with Flexbox

เมื่อจบบทนี้ คุณจะสามารถ

  • จัด logo ไว้ซ้ายและเมนูไว้ขวาด้วย justify-content: space-between
  • จัดทั้งสองฝั่งให้อยู่กึ่งกลางแนวตั้งด้วย align-items: center
  • ใช้ Flexbox ซ้อนกันสองชั้น (.navbar และ .nav-links)

เส้นคั่นใต้ header

เริ่มจากกล่องนอกสุดก่อน .site-header กินความกว้างเต็มจอ เราใส่เส้นขอบล่างบาง ๆ เพื่อแยก navbar ออกจากเนื้อหา:

.site-header {
    border-bottom: 1px solid #1e293b;
}

ขั้นที่ 1: container ของ navbar

เราไม่อยากให้ logo ไปชิดขอบจอซ้ายสุด และเมนูชิดขวาสุดบนจอกว้าง ๆ จึงใช้เทคนิค container จากเรื่อง Box Model ก่อน:

.navbar {
    max-width: 1100px;
    margin: 0 auto;
    padding: 20px 32px;
}

ตอนนี้ navbar อยู่กลางจอ กว้างไม่เกิน 1100px แต่ logo กับเมนูยังเรียงบน-ล่างอยู่

ขั้นที่ 2: เปิด Flexbox

.navbar มีลูก 2 ตัว คือ .logo และ .nav-links เพิ่ม display: flex:

.navbar {
    max-width: 1100px;
    margin: 0 auto;
    padding: 20px 32px;

    display: flex;
}

refresh ดู — logo กับกลุ่มเมนูมาอยู่แถวเดียวกันแล้ว แต่ยังชิดกันอยู่ทางซ้าย

ขั้นที่ 3: ดันไปซ้าย-ขวา และจัดกึ่งกลางแนวตั้ง

.navbar {
    max-width: 1100px;
    margin: 0 auto;
    padding: 20px 32px;

    display: flex;
    justify-content: space-between;
    align-items: center;
}
  • display: flex — เปิด Flexbox
  • justify-content: space-between — ดัน logo ไปซ้าย และ nav links ไปขวา
  • align-items: center — ทำให้ทั้งสองฝั่งอยู่กึ่งกลางแนวตั้ง

เราเว้นบรรทัดว่างแยกกลุ่ม property ของ "ขนาด/ระยะห่าง" ออกจากกลุ่ม "Flexbox" ไม่มีผลกับการแสดงผล แต่ช่วยให้อ่านโค้ดง่ายขึ้นมาก

ตกแต่ง logo

.logo {
    margin: 0;
    color: #38bdf8;
    font-size: 20px;
    font-weight: bold;
}

.logo เป็น <p> ซึ่งเบราว์เซอร์ใส่ margin บน-ล่างมาให้ ถ้าไม่ตั้ง margin: 0 ระยะนี้จะทำให้ logo ดูเยื้องและ navbar สูงเกินจำเป็น

Flexbox ชั้นที่สอง: .nav-links

ลิงก์ <a> เป็น inline element จึงอยู่แถวเดียวกันอยู่แล้ว แต่ชิดกันจนอ่านยาก .nav-links เองก็เป็น flex container ได้ เพราะข้างในมีลิงก์หลายตัวที่อยากให้เรียงเป็นแถว และเราจะใช้ gap สร้างระยะห่าง:

.nav-links {
    display: flex;
    gap: 20px;
}

.nav-links a {
    color: #cbd5e1;
    text-decoration: none;
}

.nav-links a:hover {
    color: #38bdf8;
}
  • .nav-links a — เลือกเฉพาะ <a> ที่อยู่ใน .nav-links เปลี่ยนเป็นสีเทาอ่อน และเอาเส้นใต้ออก
  • :hover — เมื่อเอาเมาส์ชี้ ลิงก์จะเปลี่ยนเป็นสีฟ้าเดียวกับ logo

navbar มี "Varis Lab" สีฟ้าอยู่ซ้าย เมนู Overview, Curriculum, Pricing สีเทาอ่อนอยู่ขวา มีระยะห่างระหว่างลิงก์ ทั้งสองฝั่งอยู่กึ่งกลางแนวตั้ง และมีเส้นบาง ๆ คั่นใต้ header ลองชี้เมาส์ที่ลิงก์จะเห็นสีเปลี่ยน

ผิดบ่อย: ใส่ justify-content: space-between ที่ .nav-links แทน .navbar — ผลคือลิงก์ 3 ตัวกระจายกันแปลก ๆ แต่ logo กับเมนูยังไม่แยกซ้าย-ขวา จำไว้ว่า property นี้ต้องใส่ที่ parent ของ "สิ่งที่อยากแยกซ้าย-ขวา" ซึ่งก็คือ .navbar

ลองทำ

เปลี่ยน justify-content ใน .navbar เป็น center แล้วดูว่า layout เปลี่ยนอย่างไร จากนั้นลอง flex-start สังเกตว่า gap ไม่ได้ใส่ไว้ที่ .navbar logo กับเมนูจึงชิดกัน เสร็จแล้วอย่าลืมเปลี่ยนกลับเป็น space-between

  • logo อยู่ซ้าย เมนูอยู่ขวา และอยู่กึ่งกลางแนวตั้งเดียวกัน
  • ลิงก์มีระยะห่าง 20px จาก gap ไม่ใช่จาก margin
  • อธิบายได้ว่าหน้านี้มี flex container ซ้อนกันสองชั้นตรงไหน
ก่อนหน้า: โครงสร้าง HTML และ CSS พื้นฐาน สารบัญบทเรียน ถัดไป: Hero Section แบบซ้าย-ขวา และ Flex Ratio
