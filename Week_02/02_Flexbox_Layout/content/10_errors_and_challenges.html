Error ที่เจอบ่อย และ Mini Challenge

Common Errors & Mini Challenges

เมื่อจบบทนี้ คุณจะสามารถ

  • วินิจฉัยและแก้ปัญหา Flexbox ที่เจอบ่อย 3 แบบได้ด้วยตัวเอง
  • ต่อยอดหน้า landing page ด้วยการเพิ่ม card และ section ใหม่
  • ทดลองเปลี่ยนค่า property แล้วอธิบายผลที่เกิดขึ้นได้

Error 1: ใส่ display: flex ผิดที่

อาการ: card ยังเรียงบน-ล่าง แต่เนื้อหาข้างใน card กลับเรียงเป็นแถวแปลก ๆ

สาเหตุ: ใส่ที่ลูก แต่ลืมใส่ที่ parent

/* ผิด: ใส่ที่ card แต่ละใบ */
.feature-card {
    display: flex;
}

วิธีแก้: ถ้าอยากจัด card หลายใบ ต้องใส่ display: flex ที่ parent ที่ครอบ card เหล่านั้น

/* ถูก: ใส่ที่ container ที่ครอบ card */
.features-section {
    display: flex;
}

Error 2: ลืม gap

อาการ: card ยังเรียงเป็นแถวอยู่ แต่ชิดติดกันเกินไป

วิธีแก้: เพิ่ม gap ที่ parent แทนการไปใส่ margin ให้ card ทีละใบ gap ช่วยทำให้ layout หายใจได้

.features-section {
    display: flex;
    gap: 20px;
}

Error 3: ใช้ align-items แล้วไม่เห็นผล

อาการ: ใส่ align-items: center แล้วหน้าตาไม่เปลี่ยน

สาเหตุที่เป็นไปได้:

  • ลูกทุกตัวสูงใกล้กันอยู่แล้ว จึงไม่มีที่ว่างในแนวตั้งให้เห็นการจัดตำแหน่ง
  • ลืมใส่ display: flex ที่ element เดียวกัน align-items จึงไม่มีผล

วิธีตรวจ: ลองเพิ่มความสูงหรือเนื้อหาให้ลูกบางตัวมากกว่าตัวอื่น แล้วสลับค่า align-items ดูผล

เครื่องมือช่วย debug ที่ดีที่สุดคือ DevTools: คลิกขวาที่ element > Inspect ในแผง Elements จะมีป้าย flex ติดอยู่ข้าง element ที่เป็น flex container ถ้าไม่เห็นป้ายนี้ที่ parent ที่คุณคิดไว้ แปลว่าใส่ display: flex ผิดที่

Mini Challenge

ใช้เวลาประมาณ 10–15 นาที ทำกับโปรเจกต์ที่เพิ่งสร้างเสร็จ

Challenge 1: เพิ่ม feature card ใบที่ 4

เพิ่ม <article class="feature-card"> อีกหนึ่งใบใน .features-section แล้วสังเกตว่าทำไมไม่ต้องแก้ CSS เลย card ทั้ง 4 ใบก็ยังกว้างเท่ากัน

Challenge 2: เปลี่ยน gap

เปลี่ยน gap ใน .features-section จาก 20px เป็น 32px แล้วดูผลลัพธ์

Challenge 3: เปลี่ยน justify-content ของ navbar

เปลี่ยน justify-content ใน .navbar เป็นค่าอื่น เช่น:

justify-content: center;

แล้วดูว่า layout เปลี่ยนอย่างไร

Challenge 4: เพิ่ม pricing card ใบที่ 3

เพิ่มแผนราคาอีกหนึ่งแผนใน .pricing-cards ลองตัดสินใจเองว่าใบไหนควรมี class highlight

Bonus: section ใหม่

เพิ่ม section ใหม่ชื่อ:

Who This Bootcamp Is For

แล้วใช้ Flexbox จัด card 3 ใบ เช่น:

  • Career Changers
  • Self-Learners
  • Working Professionals

คำใบ้: ใช้แพตเทิร์นเดียวกับ feature cards (parent display: flex + gap, ลูก flex: 1) และอย่าลืมเพิ่ม class ใหม่ของ section นี้เข้าไปใน @media ด้วย ไม่อย่างนั้นบนจอเล็ก card จะยังเรียงแนวนอน

  • อธิบายได้ว่าทำไมใส่ display: flex ที่ลูกแล้ว card ไม่เรียงแถว
  • ทำ Challenge 1–4 ครบ และหน้าเว็บยังเป็นระเบียบ
  • (Bonus) section ใหม่เรียงแถวบนจอกว้าง และเรียงบน-ล่างบนจอเล็ก
ก่อนหน้า: Responsive เบื้องต้นด้วย @media และ flex-wrap สารบัญบทเรียน ถัดไป: สรุปบทเรียนและการบ้าน
