บทเรียน 07 · Layout และรายละเอียดที่ทำให้หน้าเว็บดูเป็นมืออาชีพ

จัดแถวด้วย display: flex

Flexbox Basics

เมื่อจบบทนี้ คุณจะสามารถ

  • ใช้ display: flex ที่ container เพื่อจัด element ลูกให้เรียงเป็นแถว
  • ใช้ gap กำหนดระยะห่างระหว่างลูก และ flex: 1 ให้ลูกแบ่งพื้นที่เท่า ๆ กัน
  • จัด navbar ให้โลโก้อยู่ซ้าย เมนูอยู่ขวา ด้วย justify-content และ align-items

ทำไมต้อง flex

โดยปกติ block element อย่าง article, section หรือ div จะเรียงจากบนลงล่าง ตัวละบรรทัด นั่นคือเหตุผลที่การ์ดทั้งสามของเราตอนนี้ยังซ้อนกันเป็นแนวตั้ง ถ้าเราอยากให้การ์ดหลายใบเรียงในแถวเดียวกัน วิธีที่ง่ายที่สุดคือ display: flex

Flexbox มีสองบทบาทที่ต้องแยกให้ออก:

  • Container (parent) — กล่องที่เราใส่ display: flex เช่น .features-section
  • Item (ลูก) — element ที่อยู่ข้างใน container โดยตรง เช่น .feature-card แต่ละใบ

ขั้นที่ 1: Feature Cards เรียงเป็นแถว

เพิ่ม .features-section ไว้ก่อน .feature-card ใน style.css แล้วเพิ่ม flex: 1 เป็นบรรทัดแรกของ .feature-card:

.features-section {
  display: flex;
  gap: 20px;
}

.feature-card {
  flex: 1;
  padding: 24px;
  border-radius: 20px;
  background: #1e293b;
}
  • display: flex — ทำให้ลูกทุกตัวของ .features-section เรียงเป็นแถวแนวนอน
  • gap: 20px — ระยะห่างระหว่าง card แต่ละใบ 20px (ไม่มีระยะเกินที่ขอบซ้ายสุดหรือขวาสุด)
  • flex: 1 — ให้ card แต่ละใบแบ่งพื้นที่ในแถวเท่า ๆ กัน มี 3 ใบก็แบ่งเป็น 3 ส่วนใกล้เคียงกัน

ลำดับของ rule ใน CSS ไม่ได้บังคับ แต่การวาง container (.features-section) ไว้ก่อน item (.feature-card) ทำให้อ่านไฟล์แล้วเข้าใจตามลำดับโครงสร้าง HTML

ขั้นที่ 2: Navbar โลโก้ซ้าย เมนูขวา

ใน nav.navbar มีลูกสองตัว คือ p.logo และ div.nav-links เราอยากให้สองตัวนี้อยู่แถวเดียวกัน โดยโลโก้ชิดซ้าย เมนูชิดขวา แก้ .navbar ให้เป็นแบบนี้:

.navbar {
  max-width: 1100px;
  margin: 0 auto;
  padding: 20px 32px;
  display: flex;
  justify-content: space-between;
  align-items: center;
}
  • justify-content: space-between — ดันลูกตัวแรกไปชิดซ้ายสุด ตัวสุดท้ายไปชิดขวาสุด แล้วเอาพื้นที่ที่เหลือไว้ตรงกลาง
  • align-items: center — จัดลูกให้อยู่กึ่งกลางในแนวตั้ง โลโก้กับเมนูจึงอยู่ระดับเดียวกัน

ต่อจาก .navbar ให้เพิ่มสไตล์ของโลโก้และกลุ่มลิงก์:

.logo {
  margin: 0;
  color: #38bdf8;
  font-weight: bold;
  font-size: 20px;
}

.nav-links {
  display: flex;
  gap: 20px;
}
  • .logo — margin: 0 ล้าง margin เริ่มต้นของ p ซึ่งไม่อย่างนั้นจะดัน navbar ให้สูงเกินจำเป็น
  • .nav-links — เป็น flex container อีกชั้นหนึ่ง ซ้อนอยู่ใน navbar ทำให้ลิงก์ทั้งสามเรียงเป็นแถวพร้อมระยะห่าง 20px — นี่คือเหตุผลที่เราครอบลิงก์ด้วย div.nav-links ในบทที่ 03

navbar มีโลโก้ "Varis Lab" สีฟ้าอยู่ซ้าย และลิงก์สามลิงก์อยู่ขวาในแถวเดียวกัน การ์ดทั้งสามเรียงเป็นแถวแนวนอน กว้างเท่า ๆ กัน มีช่องว่างระหว่างกัน 20px

ข้อผิดพลาดที่พบบ่อย

ใส่ display: flex ผิดที่ — flex ต้องใส่ที่ parent/container ไม่ใช่ที่ลูก ถ้าเราใส่ display: flex ที่ .feature-card การ์ดจะยังซ้อนกันเป็นแนวตั้งเหมือนเดิม (สิ่งที่เปลี่ยนคือ h2 กับ p ข้างใน card จะเรียงเป็นแถวแทน) ถ้าอยากให้ card เรียงกัน ต้องใส่ที่ .features-section ซึ่งเป็นกล่องที่ครอบ card ทั้งหมด

/* ถูก: ใส่ที่ container */
.features-section {
  display: flex;
}

ลองทำดู

  • ลบ flex: 1 ออกจาก .feature-card ชั่วคราว แล้วสังเกตว่าความกว้างของการ์ดแต่ละใบเปลี่ยนตามความยาวของข้อความอย่างไร จากนั้นใส่กลับคืน
  • ลองเปลี่ยน gap ของ .features-section เป็น 40px แล้วเปลี่ยนกลับเป็น 20px
  • ลองลบ justify-content: space-between ออกจาก .navbar แล้วดูว่าเมนูไปอยู่ตรงไหน จากนั้นใส่กลับคืน
  • อธิบายได้ว่า display: flex ต้องใส่ที่ container และส่งผลกับลูกโดยตรง
  • อธิบายหน้าที่ของ gap, flex: 1, justify-content: space-between และ align-items: center ได้
  • navbar มีโลโก้ซ้าย เมนูขวา และการ์ดทั้งสามเรียงเป็นแถวกว้างเท่ากัน
ก่อนหน้า: padding กับ margin ต่างกันอย่างไร สารบัญบทเรียน ถัดไป: Class Selector, ปุ่ม, hover และความอ่านง่าย
