Class Selector, ปุ่ม, hover และความอ่านง่าย

Selectors, Buttons & Readability

เมื่อจบบทนี้ คุณจะสามารถ

  • เลือก class ด้วย . และ id ด้วย # ได้ถูกต้อง และแก้บั๊ก "CSS ไม่ทำงาน" ที่เกิดจากลืมจุด
  • เอาเส้นใต้ของลิงก์ออกด้วย text-decoration: none และเพิ่ม :hover state
  • ทำลิงก์ <a> ให้ดูเหมือนปุ่มด้วย display: inline-block
  • ใช้ line-height ทำให้ข้อความยาวอ่านสบายขึ้น

Class Selector: อย่าลืมจุด

ใน HTML การ์ดของเราเขียนแบบนี้:

<article class="feature-card">
  <h2>Manual Foundation</h2>
  <p>เข้าใจ HTML, CSS และ JavaScript ด้วยตัวเองก่อนใช้ AI</p>
</article>

เมื่อ HTML ใช้ class="feature-card" เวลาเลือกใน CSS ต้องเขียน .feature-card — มีจุด . ข้างหน้าเสมอ

เขียนผิด เขียนถูก 
feature-card {
  background: #1e293b;
}
 
.feature-card {
  background: #1e293b;
}

ถ้าเขียน feature-card แบบไม่มีจุด CSS จะเข้าใจว่าเรากำลังเลือก HTML tag ชื่อ feature-card (แบบเดียวกับที่ main หรือ h1 เลือก tag) แต่ในหน้าไม่มี tag นี้ rule นั้นจึงไม่ส่งผลกับอะไรเลย และเบราว์เซอร์ไม่แจ้ง error ใด ๆ ทั้งสิ้น

เลือก tag   → main, h1        (ไม่มีสัญลักษณ์)
เลือก class → .feature-card    (ใช้จุด .)
เลือก id    → #hero            (ใช้ #)

ถ้าเขียน CSS แล้วหน้าเว็บไม่เปลี่ยน สิ่งแรกที่ควรเช็กคือ selector: มีจุดหน้า class ไหม และชื่อ class ใน CSS สะกดตรงกับใน HTML ทุกตัวอักษรหรือเปล่า (เช่น feature-card กับ features-card ถือเป็นคนละชื่อ)

ขั้นที่ 1: ลิงก์ใน Navbar

ลิงก์ <a> มีค่าเริ่มต้นเป็นสีน้ำเงินและมีเส้นใต้ ซึ่งไม่เข้ากับ navbar ธีมมืดของเรา เพิ่มโค้ดนี้ต่อจาก .nav-links:

.nav-links a {
  color: #cbd5e1;
  text-decoration: none;
}

.nav-links a:hover {
  color: #38bdf8;
}
  • .nav-links a — เลือกเฉพาะลิงก์ที่อยู่ใน .nav-links เปลี่ยนเป็นสีเทาอ่อน และ text-decoration: none เอาเส้นใต้ default ออก
  • :hover — คือสถานะตอนผู้ใช้เอา mouse ไปชี้บน element เมื่อชี้ที่ลิงก์ สีจะเปลี่ยนเป็นฟ้า

เมื่อเอาเส้นใต้ออกแล้ว เราต้องมีสัญญาณอื่นบอกผู้ใช้ว่าสิ่งนี้กดได้ hover state คือส่วนเล็ก ๆ ของ user experience ที่ทำหน้าที่นี้ — ชี้แล้วสีเปลี่ยน ผู้ใช้ก็รู้ทันทีว่ามัน interactive

ขั้นที่ 2: ทำลิงก์ให้เป็นปุ่ม

ปุ่ม "ดูรายละเอียดคอร์ส" ของเราเป็น <a> เพราะมันคือลิงก์ไปยังหน้าอื่น แต่เราอยากให้มันดูเหมือนปุ่ม ปัญหาคือ <a> โดยธรรมชาติเป็น inline element ซึ่ง padding ด้านบน/ล่างจะไม่ดันพื้นที่รอบ ๆ ออกไปเหมือนกล่องปกติ เพิ่มโค้ดนี้ต่อจาก .hero-description:

.primary-button {
  display: inline-block;
  padding: 14px 24px;
  border-radius: 999px;
  background: #38bdf8;
  color: #0f172a;
  font-weight: bold;
  text-decoration: none;
}
  • display: inline-block — ยังวางต่อในบรรทัดได้เหมือน inline แต่มีคุณสมบัติของกล่องครบ ใส่ padding แล้วตัวปุ่มขยายตามจริง
  • padding: 14px 24px — ระยะด้านในของปุ่ม บน/ล่าง 14px ซ้าย/ขวา 24px
  • border-radius: 999px — ค่าที่มากกว่าความสูงของปุ่มมาก ๆ ทำให้ปลายปุ่มโค้งมนเต็มที่เป็นทรงแคปซูล
  • background สีฟ้า กับ color สีเข้ม — ตัดกันชัดเจนเพื่อให้ปุ่มเด่น
  • text-decoration: none — เอาเส้นใต้ของลิงก์ออก

สรุปสั้น ๆ: ถ้าอยากให้ link ดูเหมือนปุ่ม ใช้ display: inline-block แล้วตกแต่งด้วย padding, background และ border-radius

ขั้นที่ 3: line-height และความอ่านง่าย

line-height คือความสูงของบรรทัด ถ้าข้อความหลายบรรทัดชิดกันเกินไปจะอ่านยาก เว็บที่ดู professional ไม่ได้เกิดจากสีอย่างเดียว spacing และ readability สำคัญมาก ข้อความยาวควรมี line-height ประมาณ 1.5–1.8

เพิ่ม line-height: 1.7 ให้ข้อความยาวสองจุด คือคำอธิบายใน hero และข้อความในการ์ด:

.hero-description {
  margin: 0 0 32px;
  color: #cbd5e1;
  font-size: 20px;
  line-height: 1.7;
}
.feature-card p {
  margin: 0;
  color: #cbd5e1;
  line-height: 1.7;
}

ค่า 1.7 ที่ไม่มีหน่วย แปลว่า 1.7 เท่าของขนาดตัวอักษรของ element นั้น ส่วน h1 ใช้ 1.1 เพราะหัวข้อตัวใหญ่ไม่ต้องการช่องว่างระหว่างบรรทัดมาก

โค้ด style.css ฉบับสมบูรณ์

เมื่อรวมทุกบทเข้าด้วยกัน style.css จะเป็นแบบนี้ (ตรงกับ finish/style.css):

* {

หน้า Landing Page เสร็จสมบูรณ์: navbar ลิงก์สีเทาอ่อนไม่มีเส้นใต้ ชี้แล้วเปลี่ยนเป็นสีฟ้า ปุ่ม "ดูรายละเอียดคอร์ส" เป็นทรงแคปซูลสีฟ้า ข้อความคำอธิบายและในการ์ดมีระยะบรรทัดโปร่งอ่านสบาย

ลองทำดู

  • ลองลบจุดหน้า .primary-button ชั่วคราว แล้วสังเกตว่าปุ่มกลับไปเป็นลิงก์ธรรมดา จากนั้นใส่จุดกลับคืน
  • ลองเปลี่ยน display: inline-block ของปุ่มเป็นค่าเริ่มต้น (ลบบรรทัดนี้ออก) แล้วดูว่า padding ด้านบน/ล่างของปุ่มไปทับข้อความด้านบนหรือไม่ จากนั้นใส่กลับคืน
  • ท้าทายเพิ่ม: เพิ่ม hover state ให้ปุ่มด้วยตัวเอง เช่น .primary-button:hover { background: #7dd3fc; } (โค้ดนี้ไม่ได้อยู่ใน finish/ — เป็นแบบฝึกหัดเพิ่มเติม)
  • อธิบายได้ว่าทำไม feature-card { ... } ที่ไม่มีจุดจึงไม่ทำงาน และรู้ว่าเลือก id ต้องใช้ #
  • ลิงก์ใน navbar ไม่มีเส้นใต้และเปลี่ยนสีเมื่อ hover
  • ปุ่ม "ดูรายละเอียดคอร์ส" มี padding และมุมโค้งเหมือนปุ่มจริง
  • style.css ของคุณตรงกับโค้ดฉบับสมบูรณ์ด้านบน
ก่อนหน้า: จัดแถวด้วย display: flex สารบัญบทเรียน ถัดไป: สรุปบทเรียนและการบ้าน
