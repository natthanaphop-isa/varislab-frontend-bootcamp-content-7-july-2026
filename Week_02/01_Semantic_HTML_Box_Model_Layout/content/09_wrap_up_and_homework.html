สรุปสิ่งที่เรียนมา

ตลอดคู่มือนี้เราได้เห็นแล้วว่า HTML ที่ดีไม่ใช่แค่ "แสดงผลได้" แต่ต้องมีโครงสร้างที่มีความหมาย และ CSS ไม่ใช่แค่การเปลี่ยนสี แต่เป็นการควบคุมพื้นที่และ layout ของหน้าเว็บ concept ที่สำคัญที่สุดคือ:

Semantic HTML คือการใช้ tag ที่มีความหมายกับเนื้อหา
ทุก element คือกล่อง (content, padding, border, margin)
box-sizing: border-box ช่วยให้คุมขนาดกล่องง่ายขึ้น
padding คือระยะห่างด้านใน
margin คือระยะห่างด้านนอก
max-width ช่วยจำกัดความกว้าง
margin: 0 auto ช่วยจัด content ให้อยู่กลางหน้า
display: flex ช่วยจัด element ลูกให้อยู่ในแถว
class selector ต้องมีจุดหน้า class

ถ้าเข้าใจเรื่องกล่องและระยะห่างแล้ว การเรียน Flexbox แบบลึกขึ้น, Grid, Responsive Design และ React Component ต่อจากนี้จะง่ายขึ้นมาก

ลำดับการคิดเวลาจัดหน้าเว็บ

เมื่อเริ่มจัดหน้าเว็บใหม่ หรือเมื่อ layout เพี้ยนแล้วไม่รู้จะเริ่มแก้ตรงไหน ให้ไล่คิดตามลำดับนี้:

  1. โครงสร้าง HTML ชัดหรือยัง?
  2. ต้องการจำกัดความกว้าง content ไหม?
  3. ต้องการให้ content อยู่กลางหน้าไหม?
  4. แต่ละ section ควรมี padding เท่าไหร่?
  5. แต่ละกล่องควรมี margin ห่างจากกล่องอื่นเท่าไหร่?
  6. element ลูกควรเรียงแนวตั้งหรือแนวนอน?
  7. ถ้าเรียงแนวนอน ใช้ flex ได้ไหม?
  8. ปุ่มและ link มี hover state ไหม?
  9. ข้อความอ่านง่ายไหม?
  10. class ใน CSS เลือกถูกหรือยัง?

ข้อผิดพลาดที่พบบ่อย

ข้อผิดพลาด อาการ วิธีแก้
ลืมจุดหน้า class เขียน CSS แล้วไม่มีอะไรเปลี่ยน เขียน .feature-card ไม่ใช่ feature-card
สับสน padding กับ margin ระยะห่างไปเกิดผิดที่ เช่น card ห่างจากกันแทนที่ข้อความจะห่างจากขอบ padding = ด้านใน, margin = ด้านนอก
ลืม box-sizing: border-box width รวมกับ padding แล้ว layout กว้างเกินคาด ใส่ * { box-sizing: border-box; } ไว้บนสุดของไฟล์
ใส่ display: flex ผิดที่ card ยังซ้อนกันเป็นแนวตั้ง ใส่ flex ที่ parent/container เช่น .features-section ไม่ใช่ที่ card แต่ละใบ
ปล่อย content กว้างเต็มจอ บน desktop จอใหญ่ ข้อความยาวจนอ่านยาก ใช้ max-width คู่กับ margin: 0 auto

คำถามทบทวนตัวเอง

ลองตอบคำถามเหล่านี้โดยไม่เปิดดูบทเรียนก่อน ถ้าข้อไหนตอบไม่ได้ ให้กลับไปอ่านบทที่เกี่ยวข้องอีกครั้ง:

  1. Semantic HTML คืออะไร? และ header กับ blue-text อันไหนคือ semantic tag?
  2. main ใช้สำหรับอะไร?
  3. CSS Box Model มอง element บนหน้าเว็บเป็นอะไร และประกอบด้วยส่วนใดบ้าง?
  4. ถ้าต้องการให้เนื้อหาด้านใน card ไม่ชิดขอบ ควรใช้ property ใด?
  5. ถ้าต้องการให้ section หนึ่งห่างจาก section ถัดไป ควรใช้ property ใด?
  6. ถ้าต้องการเลือก class ชื่อ feature-card และ id ชื่อ hero ใน CSS ต้องเขียนอย่างไร?
  7. max-width และ margin: 0 auto; มักใช้เพื่ออะไร?
  8. display: flex; ใช้เพื่ออะไร และ gap ทำหน้าที่อะไร?

การบ้าน: Bootcamp Landing Page Section

สร้างหน้า Landing Page Section แบบง่าย ๆ ของตัวเอง โดยใช้สิ่งที่เรียนในคอร์สนี้: Semantic HTML, CSS Box Model, padding และ margin, container layout, Flexbox เบื้องต้น และการจัดโครงสร้างหน้าเว็บให้เป็นระบบ

หัวข้อเลือกได้เอง เช่น คอร์สเรียน, Portfolio ส่วนตัว, Product Landing Page, Service Page, Event Page หรือ Bootcamp Landing Page

เป้าหมายไม่ใช่แค่ทำให้หน้าเว็บ "แสดงผลได้" แต่ต้องฝึกจัดโครงสร้าง HTML ให้มีความหมาย และใช้ CSS ควบคุมระยะห่าง ขนาด และ layout อย่างเป็นระบบ

Requirements

  1. ใช้ Semantic HTML อย่างน้อย 4 ตัว เช่น header, nav, main, section, article, footer
  2. มี Hero Section อย่างน้อย 1 section ที่มีหัวข้อหลัก คำอธิบายสั้น ๆ และปุ่ม Call-to-Action
  3. มี Feature Cards อย่างน้อย 3 ใบ
  4. ใช้ padding จัดระยะห่างด้านในของ section หรือ card
  5. ใช้ margin จัดระยะห่างระหว่าง section หรือ element
  6. ใช้ max-width และ margin: 0 auto จัด content ให้อยู่กลางหน้า
  7. ใช้ display: flex อย่างน้อย 1 จุด เช่น จัด navbar, จัด feature cards หรือจัด layout ของ section
  8. ใช้ class selector ใน CSS อย่างถูกต้อง เช่น .feature-card { padding: 24px; }
  9. ปรับสี ข้อความ และเนื้อหาให้เป็นของตัวเอง

โครงสร้าง HTML ที่แนะนำ

<header>
  <nav>
    <!-- logo and navigation links -->
  </nav>
</header>

<main>
  <section>
    <!-- hero content -->
  </section>

  <section>
    <article>
      <!-- feature card 1 -->
    </article>

    <article>
      <!-- feature card 2 -->
    </article>

    <article>
      <!-- feature card 3 -->
    </article>
  </section>
</main>

<footer>
  <!-- footer content -->
</footer>

ใช้ Landing Page ที่เราสร้างในคู่มือนี้เป็นจุดเริ่มต้นได้ แต่พยายามเปลี่ยนหัวข้อ เนื้อหา สี และระยะห่างให้เป็นของตัวเอง — การตัดสินใจเองว่าแต่ละกล่องควรมี padding และ margin เท่าไหร่ คือส่วนที่ทำให้เข้าใจ Box Model จริง

Reflection Questions

  1. Semantic HTML คืออะไร? อธิบายด้วยคำพูดของตัวเอง

  3. CSS Box Model ช่วยให้เข้าใจ layout อย่างไร?
