บทเรียน 05 · CSS Box Model และระยะห่าง

จัด content ให้อยู่กลางหน้าด้วย max-width

Container Layout

เมื่อจบบทนี้ คุณจะสามารถ

  • ใช้ max-width จำกัดความกว้างสูงสุดของ content
  • อธิบายว่า margin: 0 auto จัด block element ให้อยู่กลางหน้าได้อย่างไร
  • ใช้ container pattern กับ navbar และ main ของ Landing Page

ปัญหา: content ยืดเต็มจอ

ตอนนี้เนื้อหาของเรายืดเต็มความกว้างของหน้าจอ บนจอเล็กอาจไม่เป็นไร แต่บนจอ desktop ใหญ่ ๆ ข้อความหนึ่งบรรทัดจะยาวมาก สายตาต้องกวาดไกลจนอ่านยาก และหน้าเว็บดูไม่เป็นมืออาชีพ ในเว็บจริงเราจึงไม่ค่อยปล่อยให้ content ยืดเต็มจอเสมอไป

max-width: จำกัดความกว้างสูงสุด

max-width: 1100px;

แปลว่า element นี้กว้างได้ไม่เกิน 1100px — ถ้าจอแคบกว่า 1100px element ก็หดตามจอได้ แต่ถ้าจอกว้างกว่า มันจะหยุดอยู่ที่ 1100px ต่างจาก width: 1100px ที่บังคับกว้าง 1100px เสมอ แม้จอจะแคบกว่าก็ตาม

margin: 0 auto: จัดให้อยู่กลางหน้า

margin: 0 auto;

เมื่อ margin มีค่าสองค่า ค่าแรกคือด้านบน/ล่าง ค่าที่สองคือด้านซ้าย/ขวา บรรทัดนี้จึงแปลว่า:

  • ด้านบนและล่าง margin เป็น 0
  • ด้านซ้ายและขวาเป็น auto — ให้เบราว์เซอร์คำนวณเอง โดยแบ่งพื้นที่ที่เหลือให้สองข้างเท่ากัน
  • ผลลัพธ์คือ element อยู่กลางหน้าในแนวนอน

สองบรรทัดนี้มักใช้คู่กันเสมอ รวมกับ padding ด้านข้างเพื่อไม่ให้เนื้อหาชิดขอบจอบนหน้าจอแคบ กลายเป็น pattern ที่พบบ่อยมากในงานจริง:

.container {
  max-width: 1100px;
  margin: 0 auto;
  padding: 0 32px;
}

margin: 0 auto จะจัดกลางได้ก็ต่อเมื่อ element มีความกว้างน้อยกว่า parent เช่น ตั้ง max-width ไว้ ถ้าไม่มีการจำกัดความกว้าง block element จะกว้างเต็ม parent อยู่แล้ว จึงไม่มีพื้นที่เหลือให้แบ่งซ้ายขวา และจะดูเหมือนไม่มีอะไรเกิดขึ้น

ขั้นที่ 1: Header และ Navbar

เพิ่มโค้ดนี้ต่อท้าย style.css:

.site-header {
  border-bottom: 1px solid #1e293b;
}

.navbar {
  max-width: 1100px;
  margin: 0 auto;
  padding: 20px 32px;
}

สังเกตว่าเราแยกหน้าที่กันระหว่างสองกล่อง:

  • .site-header (tag header) กว้างเต็มจอ และมีเส้นขอบล่างสีเทาเข้มยาวสุดจอ คั่นระหว่าง header กับเนื้อหา
  • .navbar (tag nav) ที่อยู่ข้างในเป็น container — กว้างไม่เกิน 1100px อยู่กลางหน้า และมี padding บน/ล่าง 20px ซ้าย/ขวา 32px

นี่คือเหตุผลที่เราแยก header กับ nav ออกจากกันในบทที่ 03 — เส้นขอบยาวเต็มจอได้ แต่เนื้อหาใน navbar ยังอยู่ในแนวเดียวกับ content ด้านล่าง

ขั้นที่ 2: Main

main {
  max-width: 1100px;
  margin: 0 auto;
  padding: 64px 32px;
}

main ใช้ container pattern เดียวกันกับ navbar (max-width: 1100px เท่ากัน) ขอบซ้ายของเนื้อหาจึงตรงกับโลโก้ใน navbar พอดี ส่วน padding: 64px 32px ให้ระยะห่างด้านบน/ล่าง 64px และซ้าย/ขวา 32px

สังเกตว่าเราเลือก main ด้วยชื่อ tag ตรง ๆ (ไม่มีจุดข้างหน้า) เพราะในหน้ามี main ตัวเดียว ส่วน .site-header และ .navbar เลือกด้วย class ซึ่งต้องมีจุด . นำหน้า — เราจะลงรายละเอียดเรื่องนี้ในบทที่ 08

refresh หน้าเว็บ บนจอกว้าง เนื้อหาจะไม่ยืดเต็มจออีกแล้ว แต่ถูกจำกัดความกว้างและอยู่กลางหน้า มีเส้นบาง ๆ ใต้ header ยาวเต็มจอ และมีระยะห่างด้านบนของเนื้อหาหลัก ลองย่อ-ขยายหน้าต่างเบราว์เซอร์ดูว่า content หดตามจอได้เมื่อจอแคบกว่า 1100px

  • อธิบายได้ว่า max-width ต่างจาก width อย่างไร
  • อธิบายได้ว่า margin: 0 auto ค่าแรกและค่าที่สองหมายถึงด้านไหน
  • style.css มี .site-header, .navbar และ main ตามโค้ดด้านบน
  • บนจอกว้าง เนื้อหาอยู่กลางหน้าและกว้างไม่เกิน 1100px
ก่อนหน้า: CSS Box Model และ box-sizing สารบัญบทเรียน ถัดไป: padding กับ margin ต่างกันอย่างไร
