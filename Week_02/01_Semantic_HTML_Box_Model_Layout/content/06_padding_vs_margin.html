บทเรียน 06 · CSS Box Model และระยะห่าง

padding กับ margin ต่างกันอย่างไร

Padding vs Margin

เมื่อจบบทนี้ คุณจะสามารถ

  • เลือกใช้ padding หรือ margin ได้ถูกกับสถานการณ์
  • อ่านค่า shorthand ของ margin และ padding แบบ 1, 2 และ 3 ค่าได้
  • จัดระยะห่างและหน้าตาของ hero section, feature cards และ footer

กฎจำง่าย

padding = ระยะห่างด้านใน
margin  = ระยะห่างด้านนอก
  • ถ้าอยากให้เนื้อหาข้างในไม่ชิดขอบกล่อง ให้ใช้ padding
  • ถ้าอยากให้กล่องนี้ห่างจากกล่องอื่น ให้ใช้ margin

นึกถึงกล่องพัสดุจากบทที่ 04: padding คือโฟมกันกระแทกที่อยู่ในกล่อง ส่วน margin คือระยะที่เราเว้นไว้ระหว่างกล่องแต่ละใบบนชั้นวาง

อยากได้ผลแบบนี้ ใช้ ตัวอย่างในหน้าเรา
ข้อความใน card ไม่ชิดขอบ card padding .feature-card { padding: 24px; }
hero section ห่างจาก section ถัดไป margin .hero-section { margin-bottom: 56px; }

อ่านค่า shorthand ให้เป็น

margin และ padding เขียนค่าได้หลายแบบ ซึ่งเราจะเจอทั้งหมดในบทนี้:

padding: 24px;          /* ทั้ง 4 ด้าน = 24px */
padding: 64px 32px;     /* บน/ล่าง = 64px, ซ้าย/ขวา = 32px */
margin: 0 0 16px;       /* บน = 0, ซ้าย/ขวา = 0, ล่าง = 16px */
margin-bottom: 56px;    /* กำหนดเฉพาะด้านล่าง */

ขั้นที่ 1: Hero Section

เพิ่มโค้ดนี้ต่อท้าย style.css:

.hero-section {
  max-width: 760px;
  margin-bottom: 56px;
}

.eyebrow {
  margin: 0 0 16px;
  color: #38bdf8;
  font-weight: bold;
  text-transform: uppercase;
  letter-spacing: 0.04em;
}

h1 {
  margin: 0 0 24px;
  font-size: 52px;
  line-height: 1.1;
}

.hero-description {
  margin: 0 0 32px;
  color: #cbd5e1;
  font-size: 20px;
}
  • .hero-section — max-width: 760px ทำให้ข้อความใน hero ไม่ยาวเกินไปจนอ่านยาก (แคบกว่า main) และ margin-bottom: 56px ดัน section การ์ดด้านล่างให้ห่างออกไป
  • .eyebrow — สีฟ้า #38bdf8 ตัวหนา text-transform: uppercase แปลงอักษรอังกฤษเป็นตัวพิมพ์ใหญ่ และ letter-spacing เพิ่มระยะห่างระหว่างตัวอักษรเล็กน้อย
  • h1 — ตัวใหญ่ 52px และ line-height: 1.1 ให้หัวข้อหลายบรรทัดชิดกันพอดี
  • ทั้ง .eyebrow, h1 และ .hero-description เริ่มด้วย margin: 0 0 ... คือล้าง margin เริ่มต้นที่เบราว์เซอร์ใส่ให้ แล้วกำหนดเองเฉพาะด้านล่าง ระยะห่างทุกจุดจึงคาดเดาได้

เบราว์เซอร์ใส่ margin เริ่มต้นให้ tag อย่าง h1, h2 และ p อยู่แล้ว ถ้าเราไม่ล้างมัน ระยะห่างจะมาจากสองแหล่ง (ค่าเริ่มต้น + ค่าที่เราตั้ง) และคุมยาก การใช้ margin ด้านเดียว (ด้านล่าง) อย่างสม่ำเสมอเป็นนิสัยที่ดี

ขั้นที่ 2: Feature Cards

.feature-card {
  padding: 24px;
  border-radius: 20px;
  background: #1e293b;
}

.feature-card h2 {
  margin: 0 0 12px;
  color: #38bdf8;
}

.feature-card p {
  margin: 0;
  color: #cbd5e1;
}
  • padding: 24px — ข้อความใน card ห่างจากขอบ card ทุกด้าน 24px
  • border-radius: 20px — ทำให้มุม card โค้งมน
  • background: #1e293b — พื้นหลังสีอ่อนกว่า body เล็กน้อย ทำให้เห็นขอบเขตของกล่องชัดเจน
  • .feature-card h2 และ .feature-card p คือdescendant selector — เลือกเฉพาะ h2 และ p ที่อยู่ใน .feature-card ไม่กระทบ p ที่อื่นในหน้า

ขั้นที่ 3: Footer

.site-footer {
  border-top: 1px solid #1e293b;
  padding: 24px 32px;
  text-align: center;
  color: #94a3b8;
}

Footer มีเส้นขอบบนคั่นจากเนื้อหา (เข้าคู่กับเส้นขอบล่างของ header) มี padding ภายใน จัดข้อความกึ่งกลางด้วย text-align: center และใช้สีเทาอ่อน #94a3b8 เพราะเป็นข้อมูลที่สำคัญน้อยกว่าเนื้อหาหลัก

hero section ดูเป็นระเบียบ มี eyebrow สีฟ้า หัวข้อใหญ่ และคำอธิบายสีเทาอ่อน การ์ดทั้งสามมีพื้นหลังและมุมโค้ง แต่ยังเรียงซ้อนกันลงมาในแนวตั้งและติดกันอยู่ (บทถัดไปจะจัดให้เรียงเป็นแถว) footer อยู่ด้านล่างสุดพร้อมเส้นขอบบน

ลองทำดู: padding vs margin

เพื่อให้เห็นความต่างด้วยตาตัวเอง ลองแก้ .feature-card ชั่วคราว:

  1. เปลี่ยน padding เป็น 40px แล้ว refresh:

    .feature-card {
  padding: 40px;
}

    เนื้อหาข้างใน card ห่างจากขอบ card มากขึ้น ตัว card ใหญ่ขึ้น

  2. เปลี่ยนกลับเป็น padding: 24px แล้วลองเพิ่ม margin:

    .feature-card {
  margin: 40px;
}

    รอบนี้เนื้อหาข้างในเท่าเดิม แต่ card ทั้งใบห่างจาก element รอบ ๆ แทน

ทดลองเสร็จแล้วอย่าลืมลบ margin: 40px ออก และให้ .feature-card กลับไปเป็นโค้ดในขั้นที่ 2 ก่อนไปบทถัดไป

  • ตอบได้ทันทีว่า "อยากให้ข้อความไม่ชิดขอบ card" ใช้ padding และ "อยากให้ section ห่างจาก section ถัดไป" ใช้ margin
  • อ่าน margin: 0 0 16px ได้ว่าเป็นระยะห่างด้านล่าง 16px
  • style.css มี .hero-section, .eyebrow, h1, .hero-description, .feature-card, .feature-card h2, .feature-card p และ .site-footer
ก่อนหน้า: จัด content ให้อยู่กลางหน้าด้วย max-width สารบัญบทเรียน ถัดไป: จัดแถวด้วย display: flex
