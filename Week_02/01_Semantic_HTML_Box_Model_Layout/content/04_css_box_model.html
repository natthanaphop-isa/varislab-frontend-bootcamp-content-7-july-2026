บทเรียน 04 · CSS Box Model และระยะห่าง

CSS Box Model และ box-sizing

CSS Box Model

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายส่วนประกอบทั้ง 4 ของกล่องใน CSS: content, padding, border และ margin
  • อธิบายว่า box-sizing: border-box ช่วยให้คุมขนาดกล่องง่ายขึ้นอย่างไร
  • เริ่มเขียน style.css ด้วย reset และสไตล์พื้นฐานของ body

ตอนนี้เรามีโครงสร้าง HTML ครบแล้ว ต่อไป CSS จะเข้ามาควบคุมว่าแต่ละส่วนควรมีหน้าตา ขนาด ระยะห่าง และการจัดวางอย่างไร CSS ไม่ได้มีไว้แค่เปลี่ยนสีหรือเปลี่ยน font — มันคือเครื่องมือควบคุมพื้นที่และ layout ของหน้าเว็บอย่างเป็นระบบ และก่อนจะจัด layout ได้ดี เราต้องเข้าใจ concept ที่สำคัญที่สุดก่อน นั่นคือ Box Model

ทุก element คือกล่อง

ใน CSS ทุก element บนหน้าเว็บ — ไม่ว่าจะเป็น header, h1, p หรือ a — จะถูกมองเป็นกล่องหนึ่งกล่อง และกล่องหนึ่งกล่องมีส่วนประกอบหลัก 4 ส่วน:

ส่วนประกอบ ความหมาย
Content เนื้อหาข้างใน เช่น ข้อความ รูปภาพ หรือปุ่ม
Padding ระยะห่างด้านในกล่อง ระหว่าง content กับ border
Border เส้นขอบของกล่อง
Margin ระยะห่างด้านนอกกล่อง ระหว่างกล่องนี้กับ element อื่น

ถ้าวาดเป็นชั้น ๆ จากนอกเข้าใน จะได้แบบนี้:

Margin
└── Border
    └── Padding
        └── Content

ถ้านึกภาพไม่ออก ให้เปรียบกับกล่องพัสดุ:

Content = ของที่อยู่ในกล่อง
Padding = โฟมหรือกันกระแทกด้านใน
Border  = กล่องกระดาษ
Margin  = ระยะห่างระหว่างกล่องนี้กับกล่องอื่น

ทำไมต้องเข้าใจ Box Model

ถ้าเราไม่เข้าใจ Box Model เวลา layout เพี้ยน เราจะไม่รู้เลยว่าเพี้ยนเพราะอะไร เพราะแต่ละ property ส่งผลต่อกล่องคนละแบบ:

  • padding ดันเนื้อหาข้างในให้ห่างจากขอบ
  • margin ดัน element ออกจากกัน
  • border ทำให้กล่องมีขอบเพิ่มขึ้นมา
  • width หรือ height ทำให้ขนาดกล่องเปลี่ยน

ปัญหาเรื่องขนาดกล่อง และ box-sizing

ลองดู CSS นี้:

.card {
  width: 300px;
  padding: 20px;
}

เราตั้งใจให้การ์ดกว้าง 300px แต่โดยค่าเริ่มต้น width หมายถึงความกว้างของ content เท่านั้น เบราว์เซอร์จะเอา padding (และ border ถ้ามี) ไปบวกเพิ่ม — padding ซ้าย 20px + ขวา 20px ทำให้กล่องกินพื้นที่จริง 340px ใหญ่กว่าที่เราคิด

ทางแก้คือใช้ box-sizing: border-box:

.card {
  width: 300px;
  padding: 20px;
  box-sizing: border-box;
}

เมื่อใช้ border-box ค่า width จะรวม padding และ border เข้าไปแล้ว กล่องจึงกว้าง 300px ตามที่เขียนไว้ ส่วน content ข้างในจะหดลงเองให้พอดี ทำให้คำนวณขนาดง่ายขึ้นมาก

ขั้นที่ 1: เริ่มเขียน style.css

เพราะ border-box ใช้สะดวกกว่า developer ส่วนใหญ่จึงตั้งค่านี้ให้ทุก element ตั้งแต่บรรทัดแรกของไฟล์ CSS เปิด style.css แล้วเขียน:

* {
  box-sizing: border-box;
}

* คือ universal selector แปลว่า "เลือกทุก element ในหน้า" บรรทัดนี้จึงเป็น CSS reset ที่นิยมใช้มากในงานจริง

ขั้นที่ 2: สไตล์พื้นฐานของ body

ต่อจาก reset ให้กำหนดหน้าตาพื้นฐานของทั้งหน้า:

body {
  margin: 0;
  font-family: Arial, sans-serif;
  background: #0f172a;
  color: white;
}
  • margin: 0 — เบราว์เซอร์ใส่ margin เริ่มต้นให้ body ทำให้มีขอบขาวเล็ก ๆ รอบหน้า เราตั้งเป็น 0 เพื่อให้พื้นหลังเต็มจอพอดี
  • font-family: Arial, sans-serif — ใช้ฟอนต์ Arial ถ้าเครื่องไม่มี ให้ใช้ฟอนต์ sans-serif ตัวอื่นแทน
  • background: #0f172a — พื้นหลังสีน้ำเงินเข้มเกือบดำ (ธีมมืดของหน้าเรา)
  • color: white — ตัวอักษรสีขาว เพื่อให้อ่านได้บนพื้นหลังเข้ม

refresh หน้าเว็บ พื้นหลังจะกลายเป็นสีเข้มเต็มจอ ตัวอักษรเป็นสีขาว ส่วนลิงก์ยังเป็นสีน้ำเงินมีขีดเส้นใต้ และเนื้อหายังชิดขอบซ้ายยาวเต็มจออยู่ — เราจะจัดการในบทถัดไป

ถ้าหน้าเว็บไม่เปลี่ยนเลย ให้ตรวจว่า <link rel="stylesheet" href="style.css" /> อยู่ใน head และชื่อไฟล์ตรงกันทุกตัวอักษร (เช่น ไม่ได้ตั้งชื่อเป็น styles.css) และไฟล์ทั้งสองอยู่ในโฟลเดอร์เดียวกัน

  • อธิบาย content, padding, border และ margin ได้ และเรียงลำดับจากในออกนอกได้
  • อธิบายได้ว่าทำไมการ์ด width: 300px; padding: 20px; ที่ไม่มี border-box จึงกว้างเกิน 300px
  • style.css มี * { box-sizing: border-box; } และ body ตามโค้ดด้านบน
  • หน้าเว็บเป็นพื้นหลังสีเข้ม ตัวอักษรสีขาว
ก่อนหน้า: สร้างโครงสร้าง Landing Page สารบัญบทเรียน ถัดไป: จัด content ให้อยู่กลางหน้าด้วย max-width
