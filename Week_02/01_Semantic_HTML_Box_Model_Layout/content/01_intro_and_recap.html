บทเรียน 01 · โครงสร้างหน้าเว็บด้วย Semantic HTML

ภาพรวมคอร์สและทบทวนพื้นฐาน

Intro & Recap

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายหน้าที่ของ HTML, CSS และ JavaScript ได้ด้วยประโยคเดียว
  • บอกได้ว่าทำไมเราต้องกลับมาเก็บพื้นฐาน HTML และ CSS ก่อนเข้า React
  • เห็นภาพ Landing Page ที่เราจะสร้าง และเตรียมไฟล์โปรเจกต์ให้พร้อม

ทบทวนสิ่งที่เรียนมาแล้ว

ก่อนเริ่มเรื่องใหม่ ลองทบทวนกันก่อนว่าเราเรียนอะไรมาแล้ว หน้าเว็บหนึ่งหน้าประกอบด้วยสามภาษาที่ทำงานคนละหน้าที่:

ภาษา หน้าที่
HTML สร้างโครงสร้างของหน้าเว็บ — มีหัวข้อ ย่อหน้า ลิงก์ ปุ่ม อะไรบ้าง
CSS จัดหน้าตา — สี ขนาด ระยะห่าง และการจัดวาง
JavaScript เพิ่ม interaction — ทำให้หน้าเว็บตอบสนองต่อผู้ใช้

ฝั่ง JavaScript เราได้ใช้เครื่องมือเหล่านี้ไปแล้ว:

  • getElementById — เลือก element จาก id
  • addEventListener — รอฟัง event เช่น การคลิก
  • value และ textContent — อ่านค่าจาก input และเปลี่ยนข้อความบนหน้าเว็บ
  • if, array, object และ forEach — logic และการจัดการข้อมูลพื้นฐาน

ทำไมต้องกลับมาที่ HTML และ CSS

คอร์สนี้เราจะยังไม่เพิ่ม JavaScript มากนัก แต่จะกลับมาเก็บ HTML และ CSS ให้แข็งแรงขึ้น เพราะถ้าโครงสร้างและ layout ยังไม่ดี พอเข้าสู่ React เราจะสับสนได้ง่ายมาก — React component ทุกตัวสุดท้ายก็ render ออกมาเป็น HTML และจัดหน้าตาด้วย CSS เหมือนเดิม

เป้าหมายของคอร์สนี้คือเข้าใจสองเรื่องหลัก:

  1. Semantic HTML — ใช้ tag ที่มีความหมายตรงกับเนื้อหา แทนการใช้ div ทั้งหน้า
  2. CSS Box Model — มองทุก element เป็นกล่อง แล้วควบคุมขนาด ระยะห่าง และการจัดวางอย่างเป็นระบบ

สิ่งที่เราจะสร้าง

ตลอดคู่มือนี้ เราจะสร้าง Landing Page ของ Full-Stack Bootcamp หนึ่งหน้า ธีมสีเข้ม ประกอบด้วย:

  • Navbar — โลโก้ "Varis Lab" ด้านซ้าย และลิงก์เมนู 3 ลิงก์ด้านขวา
  • Hero Section — ข้อความเล็กด้านบน (eyebrow) หัวข้อใหญ่ คำอธิบาย และปุ่ม "ดูรายละเอียดคอร์ส"
  • Feature Cards — การ์ด 3 ใบเรียงเป็นแถว: Manual Foundation, Frontend Development, Backend & Database
  • Footer — ข้อความลิขสิทธิ์ด้านล่าง

เตรียมไฟล์โปรเจกต์

โปรเจกต์นี้ใช้แค่ไฟล์ HTML และ CSS อย่างละไฟล์ ไม่ต้องติดตั้งอะไรเพิ่ม สร้างโฟลเดอร์ใหม่ของเราเองแล้วสร้างไฟล์ว่างสองไฟล์:

bootcamp-landing-page/
├── index.html   ← โครงสร้างหน้าเว็บ (บทที่ 02–03)
└── style.css    ← หน้าตาและ layout (บทที่ 04–08)

ในโฟลเดอร์ของคอร์สจะมีโฟลเดอร์ finish/ ซึ่งเก็บ index.html และ style.css ฉบับสมบูรณ์ไว้ เราจะค่อย ๆ เขียนโค้ดทีละส่วนตามคู่มือ และโค้ดสุดท้ายของเราจะตรงกับไฟล์ใน finish/

ระหว่างทำ ให้เปิด index.html ในเบราว์เซอร์ค้างไว้ แล้วกด refresh ทุกครั้งที่บันทึกไฟล์ จะได้เห็นผลของโค้ดแต่ละบรรทัดทันที การเห็นว่า "เพิ่มบรรทัดนี้แล้วหน้าเว็บเปลี่ยนตรงไหน" คือวิธีที่เร็วที่สุดในการเข้าใจ CSS

  • อธิบายได้ว่า HTML = โครงสร้าง, CSS = หน้าตา, JavaScript = interaction
  • รู้ว่าคอร์สนี้เราจะเรียน Semantic HTML และ CSS Box Model
  • มีโฟลเดอร์โปรเจกต์พร้อมไฟล์ index.html และ style.css แล้ว
