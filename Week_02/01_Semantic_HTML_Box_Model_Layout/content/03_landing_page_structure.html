บทเรียน 03 · โครงสร้างหน้าเว็บด้วย Semantic HTML

สร้างโครงสร้าง Landing Page

Building the Page Structure

เมื่อจบบทนี้ คุณจะสามารถ

  • เขียนโครงไฟล์ HTML พื้นฐานพร้อมเชื่อมไฟล์ style.css
  • สร้าง header, hero section, feature cards และ footer ด้วย semantic tags
  • ตั้งชื่อ class ให้สื่อความหมาย เพื่อเตรียมเลือกด้วย CSS ในบทถัดไป

บทนี้เราจะนำ Semantic HTML จากบทที่แล้วมาใช้จริง โดยเขียน index.html ของ Landing Page ทีละส่วน ตอนจบบทหน้าเว็บจะยังดูเรียบ ๆ ไม่มีสี (เพราะยังไม่มี CSS) แต่โครงสร้างจะครบทั้งหมดแล้ว

ขั้นที่ 1: โครงไฟล์ HTML

เปิด index.html แล้วเริ่มจากโครงพื้นฐาน:

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Bootcamp Landing Page</title>
    <link rel="stylesheet" href="style.css" />
  </head>

  <body>
  </body>
</html>
  • lang="th" — บอกเบราว์เซอร์และ screen reader ว่าเนื้อหาหลักของหน้าเป็นภาษาไทย
  • meta charset="UTF-8" — ทำให้ภาษาไทยแสดงผลถูกต้อง
  • meta name="viewport" — ทำให้หน้าเว็บแสดงผลพอดีกับความกว้างจอบนมือถือ
  • <title> — ชื่อที่แสดงบนแท็บของเบราว์เซอร์
  • <link rel="stylesheet" href="style.css" /> — เชื่อมไฟล์ CSS ที่เราจะเขียนในบทถัดไป

ขั้นที่ 2: Header และ Navbar

ใส่โค้ดนี้ไว้ใน <body>:

<header class="site-header">
  <nav class="navbar">
    <p class="logo">Varis Lab</p>

    <div class="nav-links">
      <a href="#">ภาพรวม</a>
      <a href="#">หลักสูตร</a>
      <a href="#">สมัครเรียน</a>
    </div>
  </nav>
</header>
  • header คือส่วนหัวของหน้า และข้างในมี nav ซึ่งเป็นเมนูนำทาง
  • ใน nav มีสองส่วน: โลโก้ (p.logo) กับกลุ่มลิงก์ (div.nav-links) — เราครอบลิงก์ทั้งสามด้วย div เพื่อให้ CSS จัดกลุ่มลิงก์นี้เป็นก้อนเดียวได้ในบทที่ 07
  • href="#" คือลิงก์ชั่วคราวที่ยังไม่ไปไหน ใช้ระหว่างที่ยังไม่มีหน้าจริง

ขั้นที่ 3: Main และ Hero Section

ต่อจาก header ให้เพิ่ม main ซึ่งจะครอบเนื้อหาหลักทั้งหมด แล้วใส่ section แรกคือ Hero Section — ส่วนบนสุดของหน้าที่บอกว่าเว็บนี้เกี่ยวกับอะไร:

<main>
  <section class="hero-section">
    <p class="eyebrow">Full-Stack Bootcamp — AI Edition</p>

    <h1>
      เรียนสร้างเว็บแอปจริง ตั้งแต่พื้นฐานจน Deploy ได้
    </h1>

    <p class="hero-description">
      เริ่มจากการเขียนโค้ดแบบ Manual ให้เข้าใจพื้นฐานจริง
      ก่อนต่อยอดไปสู่ React, Backend, Database และ AI Coding Workflow
    </p>

    <a class="primary-button" href="#">
      ดูรายละเอียดคอร์ส
    </a>
  </section>
</main>
  • p.eyebrow — ข้อความเล็กเหนือหัวข้อ ช่วยบอกหมวดหรือบริบทของหน้า
  • h1 — หัวข้อหลักของหน้า หนึ่งหน้าควรมี h1 เพียงตัวเดียว
  • p.hero-description — คำอธิบายสั้น ๆ ใต้หัวข้อ
  • a.primary-button — ปุ่ม Call-to-Action เราใช้ <a> เพราะมันคือลิงก์ไปยังหน้ารายละเอียดคอร์ส แล้วค่อยใช้ CSS ทำให้ดูเหมือนปุ่มในบทที่ 08

ขั้นที่ 4: Feature Cards

ใน main ต่อจาก hero section ให้เพิ่ม section ที่สองซึ่งมีการ์ด 3 ใบ การ์ดแต่ละใบเป็นเนื้อหาชิ้นหนึ่งที่แยกออกมาได้ จึงใช้ article:

<section class="features-section">
  <article class="feature-card">
    <h2>Manual Foundation</h2>
    <p>
      เข้าใจ HTML, CSS, JavaScript และ logic พื้นฐานด้วยตัวเองก่อนใช้ AI
    </p>
  </article>

  <article class="feature-card">
    <h2>Frontend Development</h2>
    <p>
      สร้าง UI ด้วย React, Tailwind CSS และ component thinking
    </p>
  </article>

  <article class="feature-card">
    <h2>Backend & Database</h2>
    <p>
      สร้าง API, Authentication และเชื่อมต่อ Database แบบ Full-Stack
    </p>
  </article>
</section>

สังเกตว่าการ์ดทุกใบใช้ class เดียวกันคือ feature-card เพราะหน้าตาเหมือนกัน เขียน CSS ครั้งเดียวก็ใช้ได้ทั้งสามใบ และหัวข้อในการ์ดใช้ h2 เพราะเป็นหัวข้อรองลงมาจาก h1 ของหน้า

ขั้นที่ 5: Footer

ปิดท้ายหน้าด้วย footer ซึ่งวางต่อจาก </main> (อยู่นอก main เพราะไม่ใช่เนื้อหาหลัก):

<footer class="site-footer">
  <p>© 2026 Varis Lab. All rights reserved.</p>
</footer>

โค้ด index.html ฉบับสมบูรณ์

เมื่อรวมทุกส่วนเข้าด้วยกัน index.html จะเป็นแบบนี้ (ตรงกับไฟล์ใน finish/index.html):

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Bootcamp Landing Page</title>
    <link rel="stylesheet" href="style.css" />
  </head>

  <body>
    <header class="site-header">
      <nav class="navbar">
        <p class="logo">Varis Lab</p>

        <div class="nav-links">
          <a href="#">ภาพรวม</a>
          <a href="#">หลักสูตร</a>
          <a href="#">สมัครเรียน</a>
        </div>
      </nav>
    </header>

    <main>
      <section class="hero-section">
        <p class="eyebrow">Full-Stack Bootcamp — AI Edition</p>

        <h1>
          เรียนสร้างเว็บแอปจริง ตั้งแต่พื้นฐานจน Deploy ได้
        </h1>

        <p class="hero-description">
          เริ่มจากการเขียนโค้ดแบบ Manual ให้เข้าใจพื้นฐานจริง
          ก่อนต่อยอดไปสู่ React, Backend, Database และ AI Coding Workflow
        </p>

        <a class="primary-button" href="#">
          ดูรายละเอียดคอร์ส
        </a>
      </section>

      <section class="features-section">
        <article class="feature-card">
          <h2>Manual Foundation</h2>
          <p>
            เข้าใจ HTML, CSS, JavaScript และ logic พื้นฐานด้วยตัวเองก่อนใช้ AI
          </p>
        </article>

        <article class="feature-card">
          <h2>Frontend Development</h2>
          <p>
            สร้าง UI ด้วย React, Tailwind CSS และ component thinking
          </p>
        </article>

        <article class="feature-card">
          <h2>Backend & Database</h2>
          <p>
            สร้าง API, Authentication และเชื่อมต่อ Database แบบ Full-Stack
          </p>
        </article>
      </section>
    </main>

    <footer class="site-footer">
      <p>© 2026 Varis Lab. All rights reserved.</p>
    </footer>
  </body>
</html>

เปิด index.html ในเบราว์เซอร์ จะเห็นข้อความทั้งหมดเรียงจากบนลงล่าง พื้นหลังขาว ตัวอักษรสีดำ ลิงก์มีขีดเส้นใต้สีน้ำเงิน และการ์ดทั้งสามเรียงต่อกันลงมาเป็นแนวตั้ง — นี่คือหน้าตาปกติของ HTML ที่ยังไม่มี CSS

ระวังเรื่องพิมพ์ข้อความผิดหรือปิด tag ไม่ครบ เช่น ลืม </html> ท้ายไฟล์ หรือพิมพ์ "ให้" เป็น "ให" เบราว์เซอร์มักจะยังแสดงผลได้โดยไม่เตือนอะไร ทำให้ข้อผิดพลาดหลุดไปถึงผู้ใช้ได้ง่าย ลองอ่านโค้ดทวนอีกรอบก่อนไปบทถัดไป

  • ไฟล์ใช้ semantic tags ครบ: header, nav, main, section, article, footer
  • มี h1 เพียงตัวเดียวในหน้า และการ์ดทั้งสามใบใช้ class feature-card
  • footer อยู่นอก main
  • มี <link rel="stylesheet" href="style.css" /> ใน head
