บทเรียน 05 · ประกอบหน้าเว็บด้วย CSS Grid (Page Composition with CSS Grid)

เพิ่ม Section “Bootcamp นี้เหมาะกับใคร”

Who This Is For Section

เมื่อจบบทนี้ คุณจะสามารถ

  • เพิ่ม section ใหม่โดยใช้ pattern เดียวกับ Curriculum Section ได้เอง
  • ใช้ CSS Grid ซ้ำกับ card ชุดใหม่
  • อธิบายได้ว่า page composition คืออะไร และทำไม section ควรมีโครงสร้างคล้ายกัน

Page composition คืออะไร

หน้าเว็บจริงมักประกอบจากหลาย section ที่มี rhythm เดียวกัน — หัวข้อหน้าตาเหมือนกัน ระยะห่างเท่ากัน card สไตล์คล้ายกัน section “Who This Is For” ช่วยให้ landing page ดูสมบูรณ์ขึ้น และเป็นโอกาสดีที่จะฝึกใช้ pattern เดิมซ้ำ: section-header + grid container + card

HTML

วาง section นี้ต่อจาก Curriculum Section และก่อน Pricing Section:

<section class="audience-section">
  <div class="section-header">
    <p class="eyebrow">Who This Is For</p>

    <h2>Bootcamp นี้เหมาะกับใคร</h2>

    <p>
      ออกแบบมาสำหรับผู้เรียนที่ต้องการเข้าใจการสร้างเว็บจริง
      และอยากใช้ AI เป็นตัวช่วยอย่างถูกวิธี
    </p>
  </div>

  <div class="audience-grid">
    <article class="audience-card">
      <h3>Career Changers</h3>
      <p>
        คนที่อยากเปลี่ยนสายงานเข้าสู่สาย Software Developer
        และต้องการเริ่มจากพื้นฐานอย่างเป็นระบบ
      </p>
    </article>

    <article class="audience-card">
      <h3>Self-Learners</h3>
      <p>
        คนที่เคยเรียนเองมาก่อน แต่ยังต่อภาพรวมของ Frontend,
        Backend และ Deployment ไม่ครบ
      </p>
    </article>

    <article class="audience-card">
      <h3>Working Professionals</h3>
      <p>
        คนทำงานที่อยากเข้าใจการสร้างระบบจริง และใช้ AI
        เพื่อเพิ่ม productivity ในการทำงาน
      </p>
    </article>
  </div>
</section>

สังเกตว่าโครงสร้างแทบจะเหมือน Curriculum Section ทุกอย่าง ต่างกันแค่ชื่อ class และ card ชุดนี้ไม่มีเลข module

CSS

เพิ่มต่อจาก CSS ของ Curriculum:

/* Audience */
.audience-section {
    margin-bottom: 72px;
}

.audience-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}

.audience-card {
    padding: 28px;
    border-radius: 24px;
    background: #0f172a;
    border: 1px solid #334155;
}

.audience-card:hover {
    border-color: #38bdf8;
}

.audience-card h3 {
    margin: 0 0 12px;
    color: #38bdf8;
}

.audience-card p {
    margin: 0;
    color: #cbd5e1;
    line-height: 1.7;
}

จุดที่ต่างจาก curriculum card

  • background: #0f172a — เป็นสีเดียวกับพื้นหลังของ body card ชุดนี้จึงดูเป็น “กรอบเส้น” (outline) แทนที่จะเป็นกล่องทึบ ทำให้ section นี้ดูต่างจาก Curriculum ที่อยู่ติดกันเล็กน้อย แต่ยังอยู่ในระบบสีเดียวกัน
  • h3 เป็นสีฟ้า — เพราะไม่มีเลข module คอยเป็นจุดเด่น หัวข้อกลุ่มผู้เรียนจึงรับหน้าที่นั้นแทน
  • Grid ตั้งค่าเหมือนเดิม — 3 คอลัมน์ gap: 24px พอดีกับ card 3 ใบในแถวเดียว

ถ้าสังเกตดี ๆ .curriculum-grid กับ .audience-grid มีค่าเหมือนกันทุกบรรทัด ตอนนี้เราแยก class ไว้เพื่อให้อ่านง่ายและปรับแต่ละ section แยกกันได้ ในบทที่ 08 เราจะเห็นว่าการที่มันเหมือนกันทำให้เขียน responsive รวมกันใน selector เดียวได้สะดวก

ถ้า card ขึ้นมาแต่ไม่มีกรอบเลย ให้เช็กว่า HTML ใช้ class="audience-card" ตรงกับ CSS หรือไม่ — ถ้าเผลอ copy มาจาก curriculum แล้วลืมเปลี่ยนเป็น curriculum-card card จะได้ style ของ curriculum แทน (พื้นทึบ) ซึ่งดูใกล้เคียงจนจับผิดยาก

ลองทำเอง

เพิ่ม audience card ใบที่ 4 (เช่นกลุ่มนักศึกษาจบใหม่ — เขียนคำอธิบายเอง) แล้วสังเกตว่า Grid ส่ง card ใบที่ 4 ลงไปแถวใหม่ให้อัตโนมัติ ลองเสร็จแล้วจะเก็บไว้หรือลบออกก็ได้ (ไฟล์ finish/ มี 3 ใบ)

  • ลำดับ section คือ features → curriculum → audience → pricing
  • audience card 3 ใบเรียงในแถวเดียว พื้นสีเดียวกับหน้าเว็บ มีเส้นขอบ และขอบเปลี่ยนเป็นสีฟ้าเมื่อ hover
  • หัวข้อ section ใหม่หน้าตาเหมือนหัวข้อ Curriculum เพราะใช้ .section-header ร่วมกัน
