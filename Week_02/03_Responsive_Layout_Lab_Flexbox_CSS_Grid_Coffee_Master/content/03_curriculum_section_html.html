เพิ่ม HTML ของ Curriculum Section

Curriculum Section HTML

เมื่อจบบทนี้ คุณจะสามารถ

  • เพิ่ม section ใหม่เข้าไปในหน้าเดิมได้ถูกตำแหน่ง
  • แยกได้ว่า element ไหนคือ grid container (parent) และ element ไหนคือ grid item (child)
  • นำ class .section-header และ .eyebrow ที่มีอยู่แล้วกลับมาใช้ซ้ำได้

ตำแหน่งของ section ใหม่

เปิด index.html แล้วหา <section class="features-section"> เราจะเพิ่ม Curriculum Section ต่อจาก Feature Section และก่อน Pricing Section ลำดับ section ใน <main> จะเป็นแบบนี้:

hero-section
features-section
curriculum-section   ← เพิ่มใหม่ในบทนี้
pricing-section

HTML ของ Curriculum Section

วาง code นี้ต่อจาก </section> ของ features-section:

<section id="curriculum" class="curriculum-section">
  <div class="section-header">
    <p class="eyebrow">Curriculum</p>

    <h2>สิ่งที่คุณจะได้เรียนใน Bootcamp นี้</h2>

    <p>
      เรียนแบบเป็นขั้นตอน ตั้งแต่พื้นฐานการเขียนโค้ด
      ไปจนถึงการสร้าง Full-Stack Application และการใช้ AI อย่างถูกวิธี
    </p>
  </div>

  <div class="curriculum-grid">
    <article class="curriculum-card">
      <p class="module-number">01</p>
      <h3>Manual Coding Foundation</h3>
      <p>
        เข้าใจ HTML, CSS, JavaScript และ logic พื้นฐานด้วยตัวเองก่อนใช้ AI
      </p>
    </article>

    <article class="curriculum-card">
      <p class="module-number">02</p>
      <h3>Modern Web Layout</h3>
      <p>
        ฝึก Semantic HTML, Box Model, Flexbox, Grid และ Responsive Layout
      </p>
    </article>

    <article class="curriculum-card">
      <p class="module-number">03</p>
      <h3>TypeScript Basics</h3>
      <p>
        เรียนรู้ type, function, interface และการ debug code อย่างเป็นระบบ
      </p>
    </article>

    <article class="curriculum-card">
      <p class="module-number">04</p>
      <h3>React Frontend</h3>
      <p>
        สร้าง UI ด้วย React, component thinking, props, state และ effects
      </p>
    </article>

    <article class="curriculum-card">
      <p class="module-number">05</p>
      <h3>Backend & Database</h3>
      <p>
        สร้าง API ด้วย Node.js, NestJS, PostgreSQL, Prisma และ Neon
      </p>
    </article>

    <article class="curriculum-card">
      <p class="module-number">06</p>
      <h3>Capstone Launch</h3>
      <p>
        รวมทุกอย่างเป็น Full-Stack Project พร้อม deploy และ present ผลงาน
      </p>
    </article>
  </div>
</section>

อ่านโครงสร้างทีละชั้น

section.curriculum-section
├── div.section-header        ← หัวข้อของ section (eyebrow + h2 + คำอธิบาย)
└── div.curriculum-grid       ← grid container (parent)
    ├── article.curriculum-card   ← grid item (child) ใบที่ 1
    ├── article.curriculum-card   ← ใบที่ 2
    └── … รวม 6 ใบ
  • .section-header — class เดิมที่ Pricing Section ใช้อยู่แล้ว เราใช้ซ้ำเพื่อให้หัวข้อทุก section หน้าตาเหมือนกัน (บทที่ 07 จะปรับ style ของมันเพิ่ม)
  • .eyebrow — label ตัวเล็กสีฟ้าเหนือหัวข้อ มี style อยู่แล้วจาก hero
  • .curriculum-grid — div ที่ครอบ card ทั้งหมด จะเป็นตัวที่ได้ display: grid ในบทถัดไป
  • <article class="curriculum-card"> — card แต่ละใบเป็นเนื้อหาที่อยู่ได้ด้วยตัวเอง จึงใช้ <article> ตามหลัก Semantic HTML
  • <h3> — หัวข้อ card ใช้ h3 เพราะอยู่ใต้ h2 ของ section (ลำดับ heading ไม่กระโดด)
  • id="curriculum" — ใส่ไว้ให้ลิงก์ “Curriculum” ใน navbar กระโดดมาที่ section นี้ได้ เราจะต่อลิงก์ในบทที่ 07

ระวังวาง section ใหม่ผิดที่ เช่น วางไว้ข้างใน .features-section (ก่อน </section> ของมัน) — curriculum ทั้งก้อนจะกลายเป็นลูกของ flex container แล้วไปเบียดอยู่ในแถวเดียวกับ feature cards ถ้าหน้าเว็บดูแปลก ให้เช็กว่า tag ปิด </section> ครบและอยู่ถูกลำดับ

ผลลัพธ์ตอนนี้

ควรได้ผลลัพธ์แบบนี้

หัวข้อ “สิ่งที่คุณจะได้เรียนใน Bootcamp นี้” โผล่ใต้ feature cards แต่ card ทั้ง 6 ใบยังเรียงลงมาเป็นแนวตั้งยาว ๆ ไม่มีกรอบ — เป็นเรื่องปกติ เพราะเรายังไม่ได้เขียน CSS ของ section นี้เลย

  • curriculum-section อยู่ระหว่าง features-section กับ pricing-section
  • ใน .curriculum-grid มี <article class="curriculum-card"> ครบ 6 ใบ (01–06)
  • ชี้ได้ว่า parent คือ .curriculum-grid และ child คือ .curriculum-card
