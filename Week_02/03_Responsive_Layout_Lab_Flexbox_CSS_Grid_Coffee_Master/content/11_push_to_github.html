บทเรียน 11 · ส่งงานขึ้น GitHub (GitHub Submission)

Push โปรเจกต์ขึ้น GitHub

Push Project to GitHub

เมื่อจบบทนี้ คุณจะสามารถ

  • เขียนไฟล์ README.md อธิบาย project แบบสั้น ๆ
  • สร้าง repository บน GitHub และ push project แรกขึ้นไปได้สำเร็จ
  • อัปเดตงานที่แก้ไขเพิ่มขึ้น GitHub ในครั้งถัดไป

เป้าหมายของบทนี้มีข้อเดียว: เอา project landing page ของเราขึ้น GitHub ให้สำเร็จ

ขั้นที่ 1: เขียน README.md

README คือไฟล์ที่บอกคนอื่นว่า project นี้คืออะไร เวลาเปิด repo บน GitHub คนอื่นจะเห็น README ก่อน จึงควรเขียนให้สั้นและเข้าใจง่าย สร้างไฟล์ README.md ในโฟลเดอร์ project (ระดับเดียวกับ index.html) แล้วใส่:

# Bootcamp Landing Page

This project is a landing page built with HTML and CSS.

## What I practiced

- Semantic HTML
- CSS Box Model
- Flexbox
- CSS Grid
- Responsive Layout
- Git and GitHub basics

ไฟล์นี้เขียนด้วย Markdown: # คือหัวข้อใหญ่ ## คือหัวข้อรอง และ - คือรายการ GitHub จะแสดงผลให้สวยงามเอง

ตอนนี้โฟลเดอร์ project ควรมีหน้าตาแบบนี้:

bootcamp-landing-page/
├── index.html
├── style.css
└── README.md

ขั้นที่ 2: สร้าง repository บน GitHub

  1. เข้าสู่ระบบที่ github.com แล้วสร้าง repository ใหม่ (ปุ่ม New)
  2. ตั้งชื่อ repo เช่น bootcamp-landing-page
  3. สร้าง repo ว่าง ๆ แล้ว copy URL ของ repo ที่ลงท้ายด้วย .git เก็บไว้

ตอนสร้าง repo ไม่ต้องติ๊กให้ GitHub สร้าง README ให้ เพราะเรามี README.md ในเครื่องแล้ว ถ้าบน GitHub มี commit อยู่ก่อน การ git push ครั้งแรกจะถูกปฏิเสธ (rejected) เพราะประวัติสองฝั่งไม่ตรงกัน

ถ้ายังไม่แน่ใจขั้นตอนบนหน้าเว็บ ดูคู่มือทางการได้ที่ docs.github.com — Creating a new repository

ขั้นที่ 3: รันชุดคำสั่ง push

เปิด terminal ในโฟลเดอร์ project แล้วรันทีละบรรทัด (เปลี่ยน URL เป็นของคุณเอง):

git init
git add .
git commit -m "Complete bootcamp landing page"
git branch -M main
git remote add origin https://github.com/username/bootcamp-landing-page.git
git push -u origin main

รูปแบบทั่วไปของชุดคำสั่งนี้คือ:

git init
git add .
git commit -m "Complete bootcamp landing page"
git branch -M main
git remote add origin <your-repo-url>
git push -u origin main

ก่อน git commit ลองรัน git status ดูว่ารายการไฟล์ที่จะเข้า commit มี index.html, style.css และ README.md ครบ ถ้าตอน push ถูกถามให้ยืนยันตัวตน ให้ทำตามที่ GitHub แนะนำ — ดูรายละเอียดได้ที่ docs.github.com

ควรได้ผลลัพธ์แบบนี้

refresh หน้า repo บน GitHub แล้วเห็นไฟล์ index.html, style.css, README.md และใต้รายการไฟล์มีเนื้อหา README แสดงผลเป็นหัวข้อ “Bootcamp Landing Page” — URL ของหน้านี้คือ repository link ที่ใช้ส่งงาน

ครั้งถัดไป: ถ้าเคย init แล้ว

ถ้า project มี Git อยู่แล้ว ไม่ต้อง git init ซ้ำ และไม่ต้อง remote add ใหม่ เวลาแก้งานเพิ่ม (เช่นทำ mini challenge) ใช้แค่:

git status
git add .
git commit -m "Update bootcamp landing page"
git push

ปัญหาที่พบบ่อย

  • fatal: not a git repository — รันคำสั่งผิดโฟลเดอร์ หรือยังไม่ได้ git init ให้เช็กว่า terminal อยู่ในโฟลเดอร์ project
  • nothing to commit — ยังไม่ได้ save ไฟล์ หรือไม่ได้แก้อะไรตั้งแต่ commit ล่าสุด
  • error: remote origin already exists — เคย remote add ไปแล้ว ไม่ต้องเพิ่มซ้ำ ถ้าใส่ URL ผิดให้แก้ด้วย git remote set-url origin <your-repo-url>
  • Git ขอให้ตั้งชื่อและอีเมลก่อน commit — ตั้งครั้งเดียวต่อเครื่องด้วย git config --global user.name "Your Name" และ git config --global user.email "you@example.com"
  • git init ในโฟลเดอร์ที่ใหญ่เกินไป (เช่นโฟลเดอร์ home ทั้งหมด) — ให้ init เฉพาะในโฟลเดอร์ project เท่านั้น
  • ในโฟลเดอร์ project มี README.md ตามตัวอย่าง
  • git status แสดงว่าไม่มีไฟล์ค้าง (working tree clean) หลัง commit
  • เปิด repository link แล้วเห็น index.html, style.css และ README.md บน GitHub
ก่อนหน้า: Git และ GitHub เบื้องต้น สารบัญบทเรียน ถัดไป: สรุปบทเรียนและการบ้าน
