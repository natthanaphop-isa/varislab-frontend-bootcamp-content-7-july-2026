สิ่งที่ได้เรียน

เราไม่ได้สร้างหน้าใหม่จากศูนย์ แต่ฝึกวิธีทำงานที่ใกล้กับงานจริง: เอาหน้าเว็บเดิมมาเพิ่ม section ใหม่ ปรับ layout และ polish ให้ดีขึ้น แล้วส่ง code ขึ้น GitHub

  • Flexbox กับ Grid ไม่ได้แทนกัน — Flexbox เหมาะกับ layout แนวเดียว เช่น navbar, hero หรือ CTA ส่วน Grid เหมาะกับ card หลายใบ หลายแถว หลายคอลัมน์ เช่น curriculum cards หรือ audience cards
  • CSS Grid พื้นฐาน — display: grid ที่ parent, grid-template-columns: repeat(3, 1fr), หน่วย fr และ gap
  • Page composition — section ที่มี rhythm เดียวกัน ใช้ .section-header ร่วมกัน ระยะห่างเท่ากัน
  • UI polish — เว็บที่ดูดีมาจาก spacing, typography, hover และ visual hierarchy ไม่ใช่สีอย่างเดียว
  • Responsive Grid — 3 → 2 → 1 คอลัมน์ด้วย media query ที่เรียงลำดับถูกต้อง
  • CSS organization — จัด CSS เป็นหมวดให้อ่านง่ายและดูแลต่อได้
  • Git & GitHub — add → commit → push และส่งงานเป็น repository link

Mini challenge

ลองทำเองประมาณ 15–20 นาที เสร็จแล้ว commit และ push ขึ้น GitHub ตามขั้นตอน “ครั้งถัดไป” ในบทที่ 11

  1. Challenge 1 — เพิ่ม curriculum card อีก 2 ใบ
  2. Challenge 2 — เปลี่ยน .curriculum-grid จาก 3 columns เป็น 4 columns แล้วดูผล: 
    grid-template-columns: repeat(4, 1fr);
  3. Challenge 3 — เพิ่ม hover effect ให้ curriculum card ในแบบของคุณเอง
  4. Challenge 4 — เพิ่ม section ใหม่ชื่อ Student Outcomes ที่มี card 3 ใบ เช่น Portfolio Project, GitHub Repository และ Interview Story
  5. Challenge 5 — จัด CSS เป็นหมวดให้ชัดเจน (รวมหมวดของ section ใหม่ด้วย)
  6. Challenge 6 — push งานขึ้น GitHub

Bonus — ทำ responsive ให้ grid ของ section ใหม่:

Desktop = 3 columns
Tablet  = 2 columns
Mobile  = 1 column

สำหรับ Challenge 4 ลองใช้ pattern เดิม: section-header + grid container + card แล้วอย่าลืมเพิ่ม grid ใหม่เข้าไปใน selector ของทั้งสอง media query

การบ้าน: Complete Bootcamp Landing Page + GitHub Submission

ต่อยอดหน้า Bootcamp Landing Page ให้เป็นหน้าเว็บที่สมบูรณ์ขึ้น โดยเพิ่ม section ใหม่ ใช้ CSS Grid และส่งงานผ่าน GitHub repository

Requirements

  1. ใช้ project Bootcamp Landing Page (จากโฟลเดอร์ start/) เป็น base
  2. เพิ่ม Curriculum Section
  3. Curriculum Section ต้องใช้ CSS Grid
  4. มี card อย่างน้อย 6 ใบ
  5. เพิ่มอีก 1 section เช่น Who This Is For, Outcomes, Testimonials หรือ FAQ
  6. ใช้ Grid อย่างน้อย 1 จุด
  7. ใช้ Flexbox อย่างน้อย 1 จุด
  8. มี UI polish เช่น hover, spacing, typography หรือ consistent card style
  9. จัด CSS เป็นหมวด
  10. ปรับ responsive สำหรับ grid อย่างน้อย 1 breakpoint
  11. สร้าง GitHub repository สำหรับ project นี้
  12. Push code ขึ้น GitHub
  13. มีไฟล์ README.md อธิบาย project แบบสั้น ๆ

1. GitHub repository link
2. Screenshot หน้าเว็บ
3. Reflection answers

style.css
README.md

Reflection

ตอบคำถามสั้น ๆ ด้วยคำพูดของคุณเอง:

  1. Flexbox กับ Grid ต่างกันอย่างไร?
  2. ทำไม Curriculum Section เหมาะกับ Grid?
  3. grid-template-columns ใช้ทำอะไร?
  4. UI polish ที่คุณปรับมีอะไรบ้าง?
  5. การจัด CSS เป็นหมวดช่วยอย่างไร?
  6. Git กับ GitHub ต่างกันอย่างไร?
  7. Commit คืออะไร?
  8. อยากให้ผู้สอน review จุดไหน?

ทบทวนตัวเอง

ลองตอบคำถามเหล่านี้โดยไม่เปิดบทเรียน ถ้าตอบไม่ได้ข้อไหน ให้กลับไปอ่านบทที่เกี่ยวข้อง:

  • display: grid; ควรใส่ที่ element ไหน?
  • grid-template-columns: repeat(3, 1fr); หมายถึงอะไร?
  • gap ใน Grid ใช้ทำอะไร?
  • navbar หรือ CTA ที่มี layout ซ้าย-ขวา ควรใช้ Flexbox หรือ Grid? แล้ว card 12 ใบหลายแถวล่ะ?
  • git add ., git commit -m "message" และ git push แต่ละคำสั่งทำอะไร?
  • หน้าเว็บมี hero, features, curriculum (Grid 6 ใบ), audience (Grid), pricing และ CTA (Flexbox) ครบ
  • grid เปลี่ยนจำนวนคอลัมน์ตามขนาดจอ และ style.css จัดเป็นหมวดโดยมี Responsive อยู่ท้ายสุด
  • repository บน GitHub มี index.html, style.css และ README.md
  • เตรียม repository link, screenshot และคำตอบ reflection พร้อมส่ง
ก่อนหน้า: Push โปรเจกต์ขึ้น GitHub สารบัญบทเรียน
