บทเรียน 01 · ทบทวนโปรเจกต์และเลือกเครื่องมือ (Review & Flexbox vs Grid)

ทบทวนโปรเจกต์เริ่มต้น

Project Review

เมื่อจบบทนี้ คุณจะสามารถ

  • เปิดโปรเจกต์เริ่มต้นจากโฟลเดอร์ start/ และดูผลในเบราว์เซอร์ได้
  • บอกได้ว่าหน้าเว็บตอนนี้มี section อะไรบ้าง และส่วนไหนใช้ Flexbox
  • อธิบายได้ว่าคอร์สนี้เราจะต่อยอดอะไรเข้าไปในหน้าเดิม

ทำไมไม่เริ่มจากไฟล์เปล่า

ในงานจริง developer ไม่ได้เริ่มงานจากศูนย์เสมอไป หลายครั้งเรามีหน้าเว็บเดิมอยู่แล้ว แล้วต้องเพิ่ม section ใหม่ ปรับ layout ให้ดีขึ้น ทำให้ code อ่านง่ายและ maintain ได้ง่ายขึ้น ทำให้หน้าเว็บดู professional ขึ้น และสุดท้ายต้องส่ง code ให้คนอื่นดูผ่าน GitHub

คอร์สนี้เราจึงใช้หน้า Bootcamp Landing Page ที่สร้างด้วย Flexbox มาเป็น base แล้วต่อยอดขึ้นไปทีละขั้น เป้าหมายของทั้งคอร์สสรุปได้ประโยคเดียว:

จากหน้าเว็บที่เขียนในเครื่อง → ไปสู่ project ที่จัดโครงสร้างดีขึ้น และส่งเป็น GitHub link ได้

เตรียมโฟลเดอร์โปรเจกต์

โฟลเดอร์ start/ มีไฟล์แค่สองไฟล์:

start/
├── index.html
└── style.css

แนะนำให้คัดลอกสองไฟล์นี้ไปไว้ในโฟลเดอร์ project ของคุณเอง เช่นโฟลเดอร์ชื่อ bootcamp-landing-page เพราะในบทท้าย ๆ เราจะเปลี่ยนโฟลเดอร์นี้ให้เป็น Git repository แล้ว push ขึ้น GitHub จากนั้นเปิดโฟลเดอร์ใน code editor และเปิด index.html ในเบราว์เซอร์

เก็บโฟลเดอร์ finish/ ไว้เทียบเท่านั้น — ลองพิมพ์ code เองตามแต่ละบทก่อน ถ้าหน้าเว็บไม่ออกมาตามที่คาด ค่อยเปิด finish/ ดูว่าต่างกันตรงไหน

สำรวจหน้าเว็บที่มีอยู่

เปิด start/index.html แล้วไล่ดูจากบนลงล่าง หน้าเว็บตอนนี้ประกอบด้วย:

ส่วนของหน้าclass หลักจัด layout ด้วย
Navbar (โลโก้ + ลิงก์).navbar, .nav-linksFlexbox — ซ้าย/ขวา และลิงก์เรียงแถวเดียว
Hero Section.hero-sectionFlexbox — ข้อความซ้าย การ์ดขวา
Feature Cards (3 ใบ).features-sectionFlexbox — card เรียงแถวเดียว flex: 1
Pricing Section (2 ใบ).pricing-cardsFlexbox — card เรียงแถวเดียว
Footer.site-footerข้อความกึ่งกลางธรรมดา

ตัวอย่าง layout แบบ Flexbox ที่มีอยู่แล้วใน style.css เช่น feature cards:

.features-section {
    display: flex;
    gap: 20px;
    margin-bottom: 72px;
}

.feature-card {
    flex: 1;
    padding: 24px;
    border-radius: 20px;
    background: #1e293b;
}

และท้ายไฟล์มี media query เดียวที่ทำให้ทุกอย่างเรียงเป็นแนวตั้งบนจอแคบ:

@media (max-width: 768px) {

    .navbar,
    .hero-section,
    .features-section,
    .pricing-cards {
        flex-direction: column;
        align-items: stretch;
    }

    h1 {
        font-size: 40px;
    }

    .nav-links {
        flex-wrap: wrap;
    }
}

ลองคิดก่อนเริ่ม

ถามตัวเองสั้น ๆ ก่อนไปบทถัดไป:

  • ตอนนี้หน้าเว็บมี section อะไรบ้าง? ส่วนไหนเป็น card layout?
  • ถ้าต้องเพิ่ม card เป็น 6 ใบหรือ 9 ใบ แล้วอยากให้เรียงเป็นหลายแถว — ยังใช้ Flexbox แบบ .features-section ได้สะดวกไหม?

คำตอบสั้น ๆ คือ ถ้ามี card หลายใบและอยากจัดเป็นตาราง CSS Grid จะเหมาะกว่า — ซึ่งเป็นหัวข้อของบทถัดไป

สิ่งที่เราจะเพิ่มในคอร์สนี้

  • Curriculum Grid — card 6 ใบ จัดด้วย CSS Grid
  • Who This Is For Section — card กลุ่มผู้เรียน 3 ใบ
  • Final CTA Section — ข้อความชวนสมัครพร้อมปุ่ม
  • UI Polish — spacing, typography, hover และ visual hierarchy
  • Responsive สำหรับ Grid และ CSS Organization
  • ส่ง project ขึ้น GitHub ครั้งแรก
  • คัดลอก index.html และ style.css จาก start/ ไปไว้ในโฟลเดอร์ project ของตัวเองแล้ว
  • เปิด index.html ในเบราว์เซอร์แล้วเห็น navbar, hero, feature cards, pricing และ footer
  • ชี้ได้ว่า section ไหนใช้ display: flex
สารบัญบทเรียน ถัดไป: Flexbox กับ Grid ใช้ตอนไหน
