บทเรียน 02 · ทบทวนโปรเจกต์และเลือกเครื่องมือ (Review & Flexbox vs Grid)

Flexbox กับ Grid ใช้ตอนไหน

Flexbox vs Grid

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายความต่างระหว่าง Flexbox กับ CSS Grid ได้ในประโยคเดียว
  • เลือกได้ว่า layout แบบไหนควรใช้ Flexbox และแบบไหนควรใช้ Grid
  • วางแผนได้ว่า section ใหม่ในหน้า landing page จะใช้เครื่องมือตัวไหน

หลักจำง่าย ๆ

Flexbox = จัดของในแนวเดียวเป็นหลัก
Grid    = จัดของเป็นตาราง หลายแถว หลายคอลัมน์

Flexbox และ Grid ไม่ได้มาแทนกัน แต่ใช้คนละสถานการณ์ ตอนสร้างหน้าเดิมเราใช้ Flexbox เพราะ layout ส่วนใหญ่เป็นแถวเดียว เช่น navbar ซ้าย-ขวา หรือ hero ซ้าย-ขวา แต่รอบนี้เราจะเพิ่ม Curriculum Section ที่มี card หลายใบ ซึ่ง Grid จะเหมาะกว่า

FlexboxCSS Grid
คิดแบบแถวเดียว (หรือคอลัมน์เดียว)ตาราง — ทั้งแถวและคอลัมน์พร้อมกัน
เหมาะกับNavbar, hero ซ้าย-ขวา, ปุ่มหลายปุ่มในแถวเดียว, pricing cards จำนวนน้อย, จัด element ให้อยู่กึ่งกลางCurriculum cards หลายใบ, course modules, product cards, gallery, dashboard cards, layout หลายแถวหลายคอลัมน์
ในหน้าของเรา.navbar, .hero-section, .features-section, .pricing-cards, .cta-section.curriculum-grid, .audience-grid

ตัวอย่าง: card 6 ใบ

สมมติเรามี 6 modules แล้วอยากให้:

Desktop = 3 columns (2 แถว แถวละ 3 ใบ)
Tablet  = 2 columns
Mobile  = 1 column

ถ้าใช้ Flexbox แบบที่ทำกับ .features-section (flex: 1) card ทั้ง 6 ใบจะพยายามเบียดกันอยู่ในแถวเดียว เราต้องไปเพิ่ม flex-wrap และคำนวณความกว้างของ card เอง แต่ใน Grid เราแค่บอก parent ว่า “ขอ 3 คอลัมน์เท่า ๆ กัน” แล้ว card จะไหลลงแถวใหม่ให้อัตโนมัติ:

.curriculum-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}

รายละเอียดของแต่ละบรรทัดเราจะลงมือทำจริงในบทที่ 04

ไม่ใช่ทุก layout ต้องใช้ Grid — ท้ายหน้าเว็บเราจะมี CTA section ที่มีแค่ “ข้อความซ้าย + ปุ่มขวา” ซึ่งยังใช้ Flexbox เหมาะกว่า เลือกเครื่องมือให้เหมาะกับงาน

ลองฝึกแยกประเภท

ก่อนไปบทถัดไป ลองตอบเองว่าแต่ละข้อควรใช้อะไร:

  1. โลโก้ซ้าย เมนูขวา ใน header
  2. รูปสินค้า 12 รูปเรียงเป็นตาราง
  3. ปุ่ม “สมัคร” กับ “ดูรายละเอียด” วางข้างกัน
  4. การ์ดสถิติ 8 ใบในหน้า dashboard
  • อธิบายได้ว่า Flexbox เหมาะกับ layout แนวเดียว ส่วน Grid เหมาะกับหลายแถวหลายคอลัมน์
  • ยกตัวอย่าง section ในหน้าของเราที่ใช้ Flexbox ได้อย่างน้อย 2 ตัวอย่าง
  • อธิบายได้ว่าทำไม card 6 ใบที่อยากให้เป็น 3 คอลัมน์จึงเหมาะกับ Grid
