บทเรียน 08 · ขัดเกลา UI และ Responsive (UI Polish & Responsive)

ทำ Grid ให้ Responsive

Responsive Grid

เมื่อจบบทนี้ คุณจะสามารถ

  • เปลี่ยนจำนวน column ของ Grid ตามขนาดจอด้วย media query
  • ใช้ breakpoint 2 ระดับ (tablet และ mobile) ร่วมกันได้ถูกลำดับ
  • ทดสอบหน้าเว็บในหลายขนาดจอด้วย DevTools

เป้าหมาย

เราใช้ media query กับ Flexbox มาแล้ว (เปลี่ยน flex-direction เป็น column) คราวนี้ใช้หลักเดียวกันกับ Grid แค่เปลี่ยนค่า grid-template-columns:

Desktop (กว้างกว่า 900px) = 3 columns
Tablet  (ไม่เกิน 900px)    = 2 columns
Mobile  (ไม่เกิน 600px)    = 1 column

แทนที่ media query เดิม

ไฟล์เริ่มต้นมี @media (max-width: 768px) อยู่ท้ายไฟล์ เราจะลบบล็อกนั้นทิ้ง แล้วแทนด้วย 2 บล็อกนี้ (วางไว้ท้ายสุดของ style.css เสมอ):

/* Responsive */
@media (max-width: 900px) {
    .hero-section {
        flex-direction: column;
        align-items: stretch;
    }

    .features-section,
    .pricing-cards {
        flex-direction: column;
    }

    .curriculum-grid,
    .audience-grid {
        grid-template-columns: repeat(2, 1fr);
    }

    .cta-section {
        flex-direction: column;
        align-items: flex-start;
    }

    h1 {
        font-size: 44px;
    }

    .section-header h2 {
        font-size: 34px;
    }
}

@media (max-width: 600px) {
    .navbar {
        flex-direction: column;
        gap: 16px;
    }

    .nav-links {
        flex-wrap: wrap;
        justify-content: center;
    }

    main {
        padding: 40px 20px;
    }

    h1 {
        font-size: 36px;
    }

    .hero-description {
        font-size: 18px;
    }

    .curriculum-grid,
    .audience-grid {
        grid-template-columns: 1fr;
    }

    .cta-section {
        padding: 28px;
    }
}

อ่านทีละ breakpoint

ไม่เกิน 900px (tablet)

  • Grid — .curriculum-grid และ .audience-grid เหลือ 2 คอลัมน์ รวม selector ไว้ด้วยกันได้เพราะทั้งคู่ต้องเปลี่ยนเหมือนกัน
  • Flexbox — hero, feature cards และ pricing cards เรียงเป็นแนวตั้ง เพราะที่ความกว้างนี้การวางข้างกันเริ่มเบียด
  • CTA — flex-direction: column ทำให้ปุ่มลงไปอยู่ใต้ข้อความ และ align-items: flex-start ให้ปุ่มชิดซ้ายตามข้อความ (ถ้าไม่ใส่ ค่า center เดิมจะดันทุกอย่างไปกลาง)
  • Typography — ลดขนาด h1 เหลือ 44px และหัวข้อ section เหลือ 34px

ไม่เกิน 600px (mobile)

  • Grid — เหลือ 1 คอลัมน์ (1fr) card เรียงลงมาใบละแถว
  • Navbar — โลโก้กับลิงก์เรียงแนวตั้ง ลิงก์ขึ้นบรรทัดใหม่ได้และอยู่กึ่งกลาง
  • Spacing — ลด padding ของ main และของกล่อง CTA ให้เนื้อหามีพื้นที่มากขึ้นบนจอแคบ
  • Typography — h1 เหลือ 36px และคำอธิบายใน hero เหลือ 18px

บนจอ 500px ทั้งสองบล็อกทำงานพร้อมกัน (เพราะ 500 ≤ 900 และ 500 ≤ 600) ค่าที่ซ้ำกันอย่าง grid-template-columns หรือ h1 จึงใช้ค่าจากบล็อกที่อยู่ทีหลัง — นี่คือเหตุผลที่บล็อก 600px ต้องวางหลังบล็อก 900px ส่วนค่าที่ไม่ได้เขียนทับ เช่น hero ที่เป็น column ก็ยังมีผลต่อไป

ข้อผิดพลาดที่พบบ่อย

  • สลับลำดับ ให้บล็อก 600px อยู่ก่อน 900px — บนมือถือ grid จะกลายเป็น 2 คอลัมน์ เพราะบล็อก 900px มาทีหลังและเขียนทับ
  • วาง media query ไว้ก่อน rule ปกติ เช่นก่อน .curriculum-grid — rule ปกติที่อยู่ทีหลังจะเขียนทับค่าใน media query ทำให้ดูเหมือน responsive ไม่ทำงาน
  • ลืมลบ @media (max-width: 768px) เดิม — จะมีค่าจากสามบล็อกตีกัน ทำให้งงว่าค่ามาจากไหน

ทดสอบด้วย DevTools

เปิด DevTools แล้วสลับเป็นโหมดจำลองอุปกรณ์ (device toolbar) หรือค่อย ๆ ลากหน้าต่างเบราว์เซอร์ให้แคบลง สังเกตจุดที่ layout เปลี่ยน:

  • กว้างกว่า 900px — curriculum 3 คอลัมน์, hero ซ้าย-ขวา, CTA ข้อความซ้ายปุ่มขวา
  • ระหว่าง 601–900px — curriculum/audience 2 คอลัมน์, hero และ CTA เรียงแนวตั้ง
  • ไม่เกิน 600px — ทุก grid เหลือ 1 คอลัมน์, navbar เรียงแนวตั้ง
  • ใน style.css ไม่มี @media (max-width: 768px) แล้ว และมีบล็อก 900px ตามด้วย 600px อยู่ท้ายไฟล์
  • ที่ความกว้าง ~800px audience card 3 ใบแสดงเป็น 2 คอลัมน์ (ใบที่ 3 ลงไปแถวสอง)
  • ที่ความกว้าง ~400px card ทุกชุดเรียงใบละแถว และไม่มี scroll แนวนอน
