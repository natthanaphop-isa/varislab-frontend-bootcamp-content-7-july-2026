จัด Curriculum Cards ด้วย CSS Grid

CSS Grid Basics

เมื่อจบบทนี้ คุณจะสามารถ

  • เปิดใช้ Grid ด้วย display: grid ที่ parent ได้ถูกตัว
  • อธิบาย grid-template-columns: repeat(3, 1fr) และหน่วย fr ได้
  • ใช้ gap กำหนดระยะห่างระหว่าง grid items
  • จัด style ของ card ให้มีกรอบ มุมโค้ง และ hover effect

CSS ของ Curriculum Section

เพิ่ม CSS ชุดนี้ลงใน style.css ต่อจาก style ของ .feature-card (ตอนนี้วางไว้ก่อน @media ท้ายไฟล์ก็พอ — บทที่ 09 เราจะจัดหมวดให้เรียบร้อยอีกครั้ง):

/* Curriculum */
.curriculum-section {
    margin-bottom: 72px;
}

.curriculum-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}

.curriculum-card {
    padding: 28px;
    border-radius: 24px;
    background: #1e293b;
    border: 1px solid #334155;
}

.curriculum-card:hover {
    border-color: #38bdf8;
}

.module-number {
    margin: 0 0 16px;
    color: #38bdf8;
    font-size: 14px;
    font-weight: bold;
    letter-spacing: 0.08em;
}

.curriculum-card h3 {
    margin: 0 0 12px;
    font-size: 22px;
}

.curriculum-card p {
    margin: 0;
    color: #cbd5e1;
    line-height: 1.7;
}

save แล้ว refresh เบราว์เซอร์ card ทั้ง 6 ใบจะเรียงเป็น 2 แถว แถวละ 3 ใบทันที มาดูว่าแต่ละส่วนทำงานอย่างไร

1. Grid ต้องใส่ที่ parent

.curriculum-grid {
    display: grid;
}

เหมือน Flexbox เลย — ถ้าอยากจัด card หลายใบ ต้องใส่ display: grid ที่ parent ที่ครอบ card ทั้งหมด ในตัวอย่างนี้ parent คือ .curriculum-grid ส่วนลูก (grid items) คือ .curriculum-card แต่ละใบ

2. กำหนดจำนวน column

grid-template-columns: repeat(3, 1fr);

บรรทัดนี้แปลว่า “สร้าง 3 columns ที่กว้างเท่า ๆ กัน” โดย repeat(3, 1fr) มีความหมายเท่ากับการเขียนยาว ๆ แบบนี้ แต่สั้นกว่า:

grid-template-columns: 1fr 1fr 1fr;

เมื่อมี card มากกว่าจำนวน column Grid จะขึ้นแถวใหม่ให้เอง card ใบที่ 4–6 จึงไปอยู่แถวที่สองโดยเราไม่ต้องเขียนอะไรเพิ่ม

3. 1fr คืออะไร

fr ย่อมาจาก fraction ให้คิดว่าเป็น “ส่วนแบ่งของพื้นที่ที่เหลือ” repeat(3, 1fr) จึงแปลว่าแบ่งพื้นที่เป็น 3 ส่วนเท่า ๆ กัน ถ้าลองเปลี่ยนเป็น 2fr 1fr 1fr คอลัมน์แรกจะกว้างเป็นสองเท่าของคอลัมน์อื่น

4. gap

gap: 24px;

ใช้กำหนดระยะห่างระหว่าง card ทั้งแนวนอนและแนวตั้ง ทั้ง Flexbox และ Grid ใช้ gap ได้เหมือนกัน ข้อดีคือเราไม่ต้องใส่ margin ให้ card แต่ละใบ

Style ของ card

  • ไม่ต้องมี flex: 1 — ต่างจาก .feature-card เพราะความกว้างของ card ถูกกำหนดโดย column ของ parent แล้ว
  • border: 1px solid #334155 — เส้นขอบสีเทาอ่อน ๆ แยก card ออกจากพื้นหลัง
  • :hover เปลี่ยน border-color เป็น #38bdf8 — รายละเอียดเล็ก ๆ ที่ทำให้ผู้ใช้รู้สึกว่า card ตอบสนองต่อเมาส์ แม้ยังไม่ได้ใช้ JavaScript
  • .module-number — ตัวเลข 01–06 ตัวเล็ก สีฟ้า ตัวหนา และ letter-spacing กว้างขึ้น ทำหน้าที่เป็น label ไม่ใช่หัวข้อ
  • .curriculum-card p ใส่ margin: 0 — ตัด margin เริ่มต้นของ <p> ออก แล้วคุมระยะเองผ่าน margin ของ h3 และ .module-number

เปิด DevTools (คลิกขวา → Inspect) แล้วเลือก .curriculum-grid เบราว์เซอร์ส่วนใหญ่จะมีป้าย grid ให้กดเพื่อแสดงเส้นแบ่ง column และ gap บนหน้าเว็บ ช่วยให้เห็นภาพ grid ชัดขึ้นมาก

ข้อผิดพลาดที่พบบ่อย

  • ใส่ display: grid ที่ .curriculum-card แทน parent — card จะไม่เรียงเป็น 3 คอลัมน์ (เพราะเราไปจัดของข้างใน card แทน)
  • พิมพ์ชื่อ property ผิด เช่น grid-template-column (ขาด s) — CSS จะเงียบ ๆ ไม่ทำงาน ให้ดูใน DevTools ว่ามีเส้นขีดฆ่าหรือไอคอนเตือนหรือไม่
  • ชื่อ class ใน CSS ไม่ตรงกับ HTML เช่น .curriculum-grids

ลองเล่นกับ Grid

  • เปลี่ยนเป็น repeat(2, 1fr) แล้วดูว่า card เรียงเป็นกี่แถว
  • เปลี่ยน gap เป็น 8px และ 48px แล้วเทียบกัน
  • ลอง grid-template-columns: 2fr 1fr 1fr;

ลองเสร็จแล้วอย่าลืมเปลี่ยนกลับเป็น repeat(3, 1fr) และ gap: 24px

  • Desktop เห็น curriculum card 6 ใบ เรียง 3 คอลัมน์ 2 แถว มีระยะห่างเท่ากัน
  • เอาเมาส์ชี้ card แล้วขอบเปลี่ยนเป็นสีฟ้า
  • อธิบายได้ว่า repeat(3, 1fr) เท่ากับ 1fr 1fr 1fr และ gap ใช้ทำอะไร
