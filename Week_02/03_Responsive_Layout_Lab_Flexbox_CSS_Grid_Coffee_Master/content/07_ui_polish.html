บทเรียน 07 · ขัดเกลา UI และ Responsive (UI Polish & Responsive)

ขัดเกลา UI ให้ดูเป็นมืออาชีพ

UI Polish

เมื่อจบบทนี้ คุณจะสามารถ

  • ทำระยะห่างระหว่าง section ให้สม่ำเสมอ (section rhythm)
  • ปรับ .section-header ที่ใช้ร่วมกันหลาย section ในจุดเดียว
  • อธิบาย visual hierarchy ของหน้าเว็บได้
  • ทำให้ลิงก์ใน navbar กระโดดไปยัง section ที่ถูกต้อง

UI ที่ดูดีไม่ได้มาจากสีอย่างเดียว แต่มาจาก spacing, typography และ visual hierarchy บทนี้เราจะเก็บรายละเอียดเล็ก ๆ ที่ทำให้หน้าเว็บดู professional ขึ้น

1. Section rhythm

แต่ละ section ควรมีระยะห่างที่สม่ำเสมอ ถ้าระยะห่างไม่เท่ากัน หน้าเว็บจะดูไม่เป็นระบบ แม้ code จะถูกก็ตาม ตอนนี้ hero, features, curriculum, audience และ CTA ต่างมี margin-bottom: 72px แล้ว แต่ .pricing-section ยังไม่มี ให้เพิ่ม:

/* Pricing */
.pricing-section {
    margin-bottom: 72px;
}

ถ้าไม่เพิ่ม กล่อง CTA จะชิดกับ pricing cards มากกว่าระยะระหว่าง section อื่น ๆ

อีกวิธีเขียนที่ได้ผลเหมือนกันคือรวม selector ไว้ในที่เดียว:

.features-section,
.curriculum-section,
.audience-section,
.pricing-section {
    margin-bottom: 72px;
}

ในไฟล์ finish/ เลือกเขียนแยกไว้ในหมวดของแต่ละ section แทน เพื่อให้เปิดหมวดไหนก็เห็น style ของ section นั้นครบ — เลือกแบบใดแบบหนึ่งก็ได้ แต่อย่าเขียนซ้ำทั้งสองแบบ

2. Section header ที่ใช้ซ้ำ

ตอนนี้มี 3 section ที่ใช้ .section-header ร่วมกัน (curriculum, audience, pricing) การ reuse class ช่วยให้ style consistent และลด code ซ้ำ — แก้ที่เดียว ทุก section เปลี่ยนตาม หา .section-header เดิมใน style.css แล้วแทนที่ด้วยชุดนี้:

.section-header {
    max-width: 680px;
    margin-bottom: 32px;
}

.section-header h2 {
    margin: 0 0 16px;
    font-size: 40px;
    line-height: 1.2;
}

.section-header p {
    margin: 0;
    color: #cbd5e1;
    line-height: 1.7;
}
Propertyเดิมใหม่เหตุผล
max-width640px680pxให้คำอธิบายภาษาไทยยาว ๆ ไม่ตัดบรรทัดถี่เกินไป แต่ยังไม่ยาวจนอ่านยาก
margin-bottom28px32pxเว้นระยะหัวข้อกับ card ให้โปร่งขึ้น
h2 margin00 0 16pxตอนนี้หัวข้อมีคำอธิบายตามมา จึงต้องมีระยะด้านล่าง
h2 font-size36px40px + line-height: 1.2หัวข้อ section เด่นขึ้น และบรรทัดไม่ห่างเกินเมื่อขึ้นบรรทัดใหม่
p—สีเทาอ่อน line-height: 1.7คำอธิบายเด่นน้อยกว่าหัวข้อ และอ่านสบายตา

เพื่อให้ทุก section หัวข้อครบชุดเหมือนกัน เพิ่มคำอธิบายใต้หัวข้อของ Pricing Section ใน index.html:

<div class="section-header">
  <p class="eyebrow">Pricing</p>

  <h2>เลือกรูปแบบการเรียนที่เหมาะกับคุณ</h2>

  <p>
    เรียนสดแบบเข้มข้น พร้อม project, code review และการเตรียม portfolio
    สำหรับเส้นทาง Software Developer
  </p>
</div>

3. Card hover

เราใส่ hover ให้ card ไปแล้วในบทก่อนหน้า:

.curriculum-card:hover {
    border-color: #38bdf8;
}

.audience-card:hover {
    border-color: #38bdf8;
}

Hover เป็นรายละเอียดเล็ก ๆ ที่ช่วยให้ผู้ใช้รู้สึกว่า card มี interaction แม้ยังไม่ได้ใช้ JavaScript ถ้าชอบเขียนสั้นก็รวมเป็น .curriculum-card:hover, .audience-card:hover { … } ได้เช่นกัน

4. Visual hierarchy

หน้าเว็บที่ดีต้องทำให้ผู้ใช้รู้ว่าอะไรสำคัญก่อนหลัง ไม่ใช่ทุกอย่างขนาดเท่ากันหมด ลองไล่ดูหน้าของเราตามลำดับนี้:

Elementบทบาทในหน้าของเรา
h1เด่นที่สุด52px ใน hero
h2หัวข้อ section40px ใน .section-header, 36px ใน CTA
h3หัวข้อ card22px ใน curriculum card
pคำอธิบายสี #cbd5e1 อ่อนกว่าหัวข้อ
.eyebrowlabel เล็ก ๆตัวพิมพ์ใหญ่ สีฟ้า ตัวหนา
buttonaction.primary-button สีฟ้าทึบ มุมโค้งเต็ม

5. ทำให้ลิงก์ใน navbar ใช้งานได้จริง

ตอนนี้ลิงก์ใน navbar ยังเป็น href="#" คลิกแล้วไม่ไปไหน เราจะใส่ id ให้ section ปลายทาง แล้วให้ลิงก์ชี้ไปด้วย #id:

<div class="nav-links">
  <a href="#overview">Overview</a>
  <a href="#curriculum">Curriculum</a>
  <a href="#pricing">Pricing</a>
</div>

แล้วเพิ่ม id ให้ section ที่เกี่ยวข้อง (id="curriculum" ใส่ไว้แล้วตั้งแต่บทที่ 03):

<section id="overview" class="hero-section">
  ...
  <a class="primary-button" href="#pricing">ดูรายละเอียดคอร์ส</a>
  ...
</section>

<section id="curriculum" class="curriculum-section">...</section>

<section id="pricing" class="pricing-section">...</section>

ปุ่ม “ดูรายละเอียดคอร์ส” ใน hero ก็เปลี่ยนให้พาไปที่ Pricing ด้วย ส่วนปุ่มใน CTA ยังเป็น href="#" เพราะยังไม่มีหน้าสมัครจริง

สุดท้าย เพิ่ม rule นี้ในส่วน Base (ต่อจาก body) เป็นค่าเริ่มต้นของลิงก์ทั้งหน้า:

a {
    color: inherit;
}

ลิงก์ในเบราว์เซอร์มีสีเริ่มต้นเป็นน้ำเงิน/ม่วง ซึ่งแทบมองไม่เห็นบนพื้นหลังสีเข้ม color: inherit ให้ลิงก์ใช้สีเดียวกับข้อความรอบ ๆ ไว้ก่อน แล้วลิงก์ที่ต้องการสีเฉพาะ (เช่น .nav-links a หรือ .primary-button) ก็กำหนดทับเองได้

ค่าใน href ต้องมี # นำหน้า แต่ค่าใน id ไม่ต้องมี — href="#pricing" คู่กับ id="pricing" ถ้าเขียน id="#pricing" หรือสะกดไม่ตรงกัน ลิงก์จะไม่กระโดด และ id ต้องไม่ซ้ำกันในหน้าเดียว

  • ระยะห่างระหว่างทุก section เท่ากัน รวมถึง pricing กับ CTA
  • หัวข้อของ curriculum, audience และ pricing ขนาดเท่ากัน และทุกอันมีคำอธิบายใต้หัวข้อ
  • คลิก Overview / Curriculum / Pricing ใน navbar แล้วหน้ากระโดดไปถูก section และปุ่มใน hero พาไป Pricing
