เพิ่ม Final CTA Section

Final CTA Section

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายได้ว่า CTA (Call to Action) section มีไว้ทำอะไร
  • สร้าง layout ข้อความซ้าย + ปุ่มขวาด้วย Flexbox
  • ตัดสินใจเลือกระหว่าง Flexbox กับ Grid จากจำนวนและลักษณะของ element

CTA คืออะไร

CTA ย่อมาจาก Call to Action คือส่วนที่ชวนผู้ใช้ “ลงมือทำ” อะไรสักอย่าง เช่น สมัครเรียน หลังจากผู้ใช้อ่านรายละเอียดทั้งหน้าจนจบ เราจึงวาง Final CTA ไว้เป็น section สุดท้ายใน <main> ต่อจาก Pricing Section

HTML

วาง code นี้ต่อจาก </section> ของ pricing-section (ยังอยู่ข้างใน <main> ก่อน </main>):

<section class="cta-section">
  <div>
    <p class="eyebrow">Ready to Start?</p>

    <h2>เริ่มสร้างเส้นทางสู่สายงาน Software Developer</h2>

    <p>
      เรียนแบบ Manual First เข้าใจพื้นฐานจริง
      แล้วค่อยใช้ AI เพื่อทำงานเร็วขึ้นอย่างมีคุณภาพ
    </p>
  </div>

  <a class="primary-button" href="#">สมัครเรียน Bootcamp</a>
</section>

โครงสร้างตั้งใจให้ .cta-section มีลูกโดยตรงแค่ 2 ตัว:

ฝั่งซ้าย = <div> ที่ครอบ eyebrow + h2 + p (ข้อความ)
ฝั่งขวา = <a class="primary-button"> (ปุ่ม)

ปุ่มใช้ class .primary-button เดิมจาก hero ทำให้หน้าตาปุ่มทั้งหน้าเหมือนกันโดยไม่ต้องเขียน CSS เพิ่ม

CSS

/* CTA */
.cta-section {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 32px;

    padding: 40px;
    border-radius: 28px;
    background: #1e293b;
    margin-bottom: 72px;
}

.cta-section h2 {
    margin: 0 0 12px;
    font-size: 36px;
    line-height: 1.2;
}

.cta-section p {
    margin: 0;
    color: #cbd5e1;
    line-height: 1.7;
}
  • display: flex + justify-content: space-between — ดันข้อความไปซ้ายสุด ปุ่มไปขวาสุด
  • align-items: center — ให้ปุ่มอยู่กึ่งกลางแนวตั้งเทียบกับก้อนข้อความ
  • gap: 32px — กันไม่ให้ข้อความยาว ๆ ชนปุ่ม
  • บรรทัดว่างกลาง rule — แบ่งกลุ่ม “layout” กับ “หน้าตากล่อง” ให้อ่านง่าย ไม่มีผลกับการทำงาน

ทำไมตรงนี้ใช้ Flexbox ไม่ใช่ Grid

CTA มีแค่ 2 ฝั่ง เรียงในแถวเดียว ซึ่งตรงกับจุดแข็งของ Flexbox พอดี นี่คือจุดที่ควรจำไว้:

ไม่ใช่ทุก layout ต้องใช้ Grid — เลือกเครื่องมือให้เหมาะกับงาน

ถ้าลืมครอบข้อความด้วย <div> แล้ววาง <p class="eyebrow">, <h2> และ <p> เป็นลูกของ .cta-section โดยตรง Flexbox จะเห็นลูก 4 ตัวและเรียง eyebrow, หัวข้อ, คำอธิบาย และปุ่มเป็นแถวเดียวกันทั้งหมด — หน้าตาจะเพี้ยนทันที

บนจอแคบ ข้อความกับปุ่มที่วางข้างกันจะเบียดกันมาก เราจะแก้ด้วย flex-direction: column ใน media query ในบทที่ 08

  • CTA เป็นกล่องมุมโค้งพื้นสี #1e293b อยู่ท้ายสุดของ <main> ก่อน footer
  • บนจอกว้าง ข้อความอยู่ซ้าย ปุ่ม “สมัครเรียน Bootcamp” อยู่ขวา และอยู่กึ่งกลางแนวตั้ง
  • อธิบายได้ว่าทำไม CTA ใช้ Flexbox ส่วน curriculum/audience ใช้ Grid
