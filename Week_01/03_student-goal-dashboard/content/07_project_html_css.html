บทเรียน 07 · สร้าง Student Goal Dashboard (Building the Dashboard)

เตรียมโปรเจกต์ HTML และ CSS

Project Setup, HTML & CSS

เมื่อจบบทนี้ คุณจะสามารถ

  • สร้างโฟลเดอร์และไฟล์ของโปรเจกต์ Student Goal Dashboard
  • เขียนโครง HTML ที่มี container ว่าง (#studentList) รอให้ JavaScript เติมการ์ด
  • เขียน CSS สำหรับหน้า dashboard, layout แบบ grid 3 คอลัมน์ และการ์ดนักเรียน
  • เข้าใจว่า class ที่ยังไม่มีใน HTML (.student-card, .badge) จะถูกใช้เมื่อ JavaScript สร้าง element

เราจะสร้างอะไร

เราจะสร้างหน้า Mini Dashboard ที่แสดงรายชื่อนักเรียนและเป้าหมายของแต่ละคนเป็นการ์ดเรียงกัน โดยข้อมูลนักเรียนทั้งหมดอยู่ใน JavaScript (array of objects) และให้ forEach สร้างการ์ดให้ทีละใบ

concept นี้ต่อยอดได้อีกมากในชีวิตจริง เช่น Student dashboard, Candidate list, Course enrollment list, Product list, Task list หรือ CRM list — ทั้งหมดคือ “ข้อมูลหลายรายการที่แสดงเป็นการ์ดหรือแถว” เหมือนกัน

สร้างโฟลเดอร์และไฟล์

สร้างโฟลเดอร์ใหม่ชื่อ student-goal-dashboard แล้วสร้างไฟล์เปล่า 3 ไฟล์ข้างใน:

student-goal-dashboard/
├── index.html
├── style.css
└── script.js

HTML

ใส่โค้ดนี้ใน index.html:

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Student Goal Dashboard</title>
    <link rel="stylesheet" href="style.css" />
  </head>

  <body>
    <main class="page">
      <section class="dashboard">
        <p class="label">Manual Logic</p>

        <h1>Student Goal Dashboard</h1>

        <p class="description">
          ตัวอย่างการใช้ Array, Object และ Loop เพื่อแสดงข้อมูลหลายรายการบนหน้าเว็บ
        </p>

        <div id="studentList" class="student-list"></div>
      </section>
    </main>

    <script src="script.js"></script>
  </body>
</html>

จุดที่ควรสังเกต

  • <div id="studentList" class="student-list"></div> — กล่องว่างที่ตั้งใจไว้ให้ JavaScript เอาการ์ดมาใส่ มี id ไว้ให้ JavaScript หาเจอ และมี class ไว้ให้ CSS จัด layout
  • <link rel="stylesheet" href="style.css" /> ใน <head> — เชื่อม CSS
  • <script src="script.js"></script> ก่อนปิด </body> — เชื่อม JavaScript โดยวางไว้ท้ายสุด เพื่อให้ HTML ด้านบน (รวมถึง #studentList) ถูกสร้างเสร็จก่อนที่ JavaScript จะเริ่มหา element

ถ้าย้าย <script src="script.js"></script> ขึ้นไปไว้ใน <head> โดยไม่ได้ตั้งค่าอะไรเพิ่ม JavaScript จะทำงานก่อนที่ #studentList จะมีอยู่บนหน้า getElementById จะได้ null ทั้งที่ id สะกดถูกทุกตัว — อาการเหมือน id ไม่ตรงกันทุกอย่าง จำไว้ว่าเป็นอีกสาเหตุหนึ่งที่ต้องเช็ก

CSS

ใส่โค้ดนี้ใน style.css:

* {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100vh;
  font-family: Arial, sans-serif;
  background: #0f172a;
  color: white;
}

.page {
  min-height: 100vh;
  padding: 40px;
}

.dashboard {
  max-width: 900px;
  margin: 0 auto;
}

.label {
  color: #38bdf8;
  font-weight: bold;
  letter-spacing: 0.04em;
  text-transform: uppercase;
}

h1 {
  margin: 12px 0;
  font-size: 40px;
}

.description {
  color: #cbd5e1;
  line-height: 1.7;
  margin-bottom: 32px;
}

.student-list {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 18px;
}

.student-card {
  padding: 24px;
  border-radius: 20px;
  background: #1e293b;
  box-shadow: 0 18px 40px rgba(0, 0, 0, 0.25);
}

.student-card h2 {
  margin: 0 0 12px;
  color: #38bdf8;
}

.student-card p {
  margin: 8px 0;
  color: #cbd5e1;
  line-height: 1.6;
}

.badge {
  display: inline-block;
  margin-top: 12px;
  padding: 6px 12px;
  border-radius: 999px;
  background: #0f172a;
  color: #7dd3fc;
  font-size: 14px;
  font-weight: bold;
}

แต่ละส่วนทำอะไร

  • * { box-sizing: border-box; } — ให้ padding ถูกนับรวมในความกว้างของ element คำนวณขนาดง่ายขึ้น
  • body — พื้นหลังสีน้ำเงินเข้ม ตัวอักษรสีขาว สูงอย่างน้อยเต็มจอ (100vh)
  • .dashboard — กว้างไม่เกิน 900px และจัดกึ่งกลางด้วย margin: 0 auto
  • .label — ข้อความเล็กสีฟ้าเหนือหัวข้อ แปลงเป็นตัวพิมพ์ใหญ่ด้วย text-transform: uppercase
  • .student-list — ใช้ display: grid แบ่งเป็น 3 คอลัมน์เท่า ๆ กัน (repeat(3, 1fr)) เว้นระยะห่าง 18px การ์ดที่ JavaScript ใส่เข้ามาจะเรียงลงช่องเองอัตโนมัติ
  • .student-card, .student-card h2, .student-card p — หน้าตาการ์ดและข้อความข้างในการ์ด
  • .badge — ป้ายทรงแคปซูล (border-radius: 999px) ท้ายการ์ด

ตอนนี้ยังไม่มี element ไหนใน HTML ที่ใช้ class student-card หรือ badge เลย ไม่ใช่ความผิดพลาด — เราเขียน CSS รอไว้ก่อน แล้วในบทที่ 9 JavaScript จะสร้างการ์ดที่มี class เหล่านี้ขึ้นมาเอง CSS จะมีผลกับ element ที่ JavaScript สร้างทันทีเหมือน element ที่เขียนใน HTML ตรง ๆ

ผลลัพธ์ที่ควรเห็น

เปิด index.html ในเบราว์เซอร์ จะเห็นพื้นหลังสีน้ำเงินเข้ม ข้อความ MANUAL LOGIC สีฟ้า หัวข้อใหญ่ Student Goal Dashboard และคำอธิบายสีเทาอ่อน ด้านล่างยังว่างอยู่ เพราะยังไม่มีการ์ด

ฝึก debug: หัวข้อไม่ใหญ่ตามที่ตั้งไว้

ลองเปลี่ยน <h1>Student Goal Dashboard</h1> ใน HTML เป็น <h2>Student Goal Dashboard</h2> แล้ว refresh สังเกตว่าหัวข้อเล็กลงและระยะห่างเปลี่ยนไป ทั้งที่ CSS ไม่ได้แก้เลย

สาเหตุ: rule h1 { font-size: 40px; } เลือกเฉพาะแท็ก h1 เมื่อเปลี่ยนแท็กเป็น h2 rule นี้จึงไม่มีผล นี่คือขั้น “เช็กการเชื่อมโยงระหว่าง HTML กับ CSS” — selector ใน CSS ต้องตรงกับแท็กหรือ class ใน HTML เหมือนที่ id ใน JavaScript ต้องตรงกับ HTML แก้กลับเป็น h1 ก่อนไปต่อ

  • มีโฟลเดอร์ student-goal-dashboard ที่มี index.html, style.css, script.js
  • HTML มี <div id="studentList" class="student-list"></div> ที่ว่างอยู่
  • HTML เชื่อม style.css ใน <head> และ script.js ก่อนปิด </body>
  • เปิดในเบราว์เซอร์แล้วเห็นพื้นหลังสีเข้ม หัวข้อ และคำอธิบายตามที่ออกแบบ
