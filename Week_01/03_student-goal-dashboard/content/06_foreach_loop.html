วนลูปด้วย forEach

Looping with forEach

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายได้ว่า loop คืออะไรและช่วยลดโค้ดซ้ำอย่างไร
  • ใช้ forEach วนผ่านสมาชิกทุกตัวใน array
  • อ่านโค้ด forEach เป็น “ภาษาคน” ได้
  • ไล่ได้ว่าแต่ละรอบของ loop ตัวแปร student มีค่าเป็นอะไร

ทำไมต้องมี loop

ถ้าเรามีนักเรียน 3 คน แล้วอยากแสดงชื่อทุกคน ด้วยความรู้จากบทที่แล้วเราอาจเขียนแบบนี้:

console.log(students[0].name);
console.log(students[1].name);
console.log(students[2].name);

ทำงานได้ แต่ถ้ามีนักเรียน 100 คน เราต้องเขียน 100 บรรทัด และถ้าเพิ่มนักเรียนคนใหม่ ก็ต้องกลับมาเพิ่มโค้ดทุกครั้ง เราไม่ควรเขียนโค้ดซ้ำด้วยมือแบบนี้ แต่ควรใช้ loop

Loop คือการสั่งให้โปรแกรมทำงานซ้ำกับข้อมูลหลายรายการ

forEach

forEach คือ loop แบบหนึ่งที่ใช้บ่อยมากกับ array

students.forEach(function (student) {
  console.log(student.name);
});

แปลเป็นภาษาคนคือ: สำหรับนักเรียนแต่ละคนใน list students ให้แสดงชื่อของนักเรียนคนนั้นออกมา

แยกส่วนประกอบทีละชิ้น

  • students.forEach(...) — สั่งให้วนผ่านสมาชิกทุกตัวใน array students
  • function (student) { ... } — ฟังก์ชันที่จะถูกเรียกหนึ่งครั้งต่อสมาชิกหนึ่งตัว
  • student — ตัวแปรที่เก็บ “สมาชิกของรอบนี้” เราตั้งชื่อเองได้ แต่นิยมใช้ชื่อเอกพจน์ของชื่อ array (students → student) เพื่อให้อ่านง่าย
  • โค้ดใน { } — สิ่งที่อยากทำกับสมาชิกแต่ละตัว

แต่ละรอบเกิดอะไรขึ้น

รอบที่student คือConsole แสดง
1students[0]Man
2students[1]Jane
3students[2]Pond

จำนวนรอบเท่ากับจำนวนสมาชิกใน array (students.length) เสมอ ถ้าเพิ่มนักเรียนคนที่ 4 เข้าไปใน array loop ก็จะวน 4 รอบเองโดยเราไม่ต้องแก้โค้ดใน loop เลย

ทำหลายอย่างในรอบเดียว

ในแต่ละรอบ เราทำได้มากกว่าหนึ่งคำสั่ง เช่น แสดงทุก field ของนักเรียนคนนั้น:

students.forEach(function (student) {
  console.log(student.name);
  console.log(student.goal);
  console.log(student.level);
});

ข้อผิดพลาดที่เจอบ่อยกับ forEach:

  • ใช้ชื่อ array แทนชื่อสมาชิก เช่น students.name ภายใน loop — array ไม่มี field name จึงได้ undefined ที่ถูกคือ student.name
  • วงเล็บปิดไม่ครบ — ท้าย forEach ต้องปิดด้วย }); (ปีกกาปิดฟังก์ชัน + วงเล็บปิด forEach) ถ้าขาดจะได้ SyntaxError
  • สะกด forEach ผิด เช่น foreach — JavaScript แยกตัวพิมพ์เล็ก–ใหญ่ จะได้ error ว่า students.foreach is not a function

ถ้าไม่แน่ใจว่าแต่ละรอบ loop ได้ข้อมูลอะไร ใส่ console.log(student); เป็นบรรทัดแรกใน loop เพื่อดู object ทั้งตัวของทุกรอบ — นี่คือเทคนิค debug จากบทที่ 3 ที่ใช้กับ loop ได้ดีมาก

ลองทำ

  1. ใช้ array students จากบทที่แล้ว เขียน forEach ที่แสดงข้อความ ชื่อ - เป้าหมาย ของทุกคนใน Console (ต่อข้อความด้วย + เช่น student.name + " - " + student.goal)
  2. เพิ่มนักเรียนคนใหม่เข้าไปใน array แล้วสังเกตว่า Console แสดงเพิ่มเองโดยไม่ต้องแก้ loop
  3. ลองเปลี่ยน student.name ใน loop เป็น students.name แล้วดูผลใน Console จากนั้นแก้กลับ
  • อธิบายได้ว่า loop = การทำงานซ้ำกับข้อมูลแต่ละรายการ
  • เขียน array.forEach(function (item) { ... }); ได้ถูก syntax
  • บอกได้ว่ารอบที่ 1 ตัวแปรใน loop คือสมาชิก index 0
  • รู้ว่าใน loop ต้องใช้ตัวแปรของรอบนั้น (student) ไม่ใช่ชื่อ array (students)
