บทเรียน 01 · ทบทวนและการ Debug (Recap & Debugging)

ทบทวนพื้นฐานและเป้าหมายของคอร์ส

Recap & Goals

เมื่อจบบทนี้ คุณจะสามารถ

  • ทบทวนได้ว่า HTML, CSS และ JavaScript ทำหน้าที่อะไรในหน้าเว็บ
  • นึกออกว่าคำสั่ง JavaScript พื้นฐานที่ใช้กับหน้าเว็บและ form แต่ละตัวใช้ทำอะไร
  • อธิบายได้ว่าทำไมเว็บจริงถึงต้องจัดการ “ข้อมูลหลายรายการ”
  • รู้ว่าคอร์สนี้จะพาไปเรียนอะไรและสร้างอะไร

พื้นฐานที่ควรมีก่อนเริ่ม

คอร์สนี้ต่อยอดจากพื้นฐานหน้าเว็บ: HTML คือโครงสร้าง CSS คือหน้าตา และ JavaScript คือพฤติกรรมของหน้าเว็บ ก่อนเริ่มเรื่องใหม่ ลองไล่เช็กดูว่าคุณยังจำสิ่งเหล่านี้ได้หรือไม่

JavaScript กับหน้าเว็บ (จากการทำ Profile Card)

  • HTML ใช้สร้างโครงสร้าง, CSS ใช้จัดหน้าตา, JavaScript ใช้ทำ interaction
  • document.getElementById("...") — หา element จาก id
  • addEventListener — รอฟังเหตุการณ์ เช่น การคลิกปุ่ม
  • textContent — เปลี่ยนข้อความใน element

รับข้อมูลจากผู้ใช้ผ่าน Form

  • <form> ใช้รับข้อมูลจากผู้ใช้
  • .value ใช้อ่านค่าที่ผู้ใช้กรอกใน input
  • ตัวแปรใช้เก็บข้อมูลไว้ใช้ต่อ
  • if ใช้ตรวจสอบว่าข้อมูลครบหรือไม่
  • event.preventDefault() ใช้ไม่ให้หน้าเว็บ refresh ตอนกด submit

ตัวอย่างสั้น ๆ ที่รวมหลายอย่างข้างบนไว้ด้วยกัน:

const fullNameInput = document.getElementById("fullName");

// ในฟังก์ชันที่ทำงานตอน submit form
const fullName = fullNameInput.value;

if (fullName === "") {
  // ยังไม่ได้กรอกชื่อ
}

ถ้ามีคำสั่งไหนที่นึกไม่ออก ไม่เป็นไร ในบทต่อ ๆ ไปเราจะได้ใช้ getElementById และ console.log อีกหลายครั้ง พร้อมคำอธิบายทีละบรรทัด

คำถามสำคัญ: ถ้ามีข้อมูลหลายรายการล่ะ?

จนถึงตอนนี้เราทำงานกับข้อมูลทีละชิ้น เช่น ชื่อคนหนึ่งคน เป้าหมายหนึ่งเป้าหมาย ข้อความหนึ่งข้อความ แต่ในเว็บจริง เราไม่ได้มีผู้ใช้แค่คนเดียว สินค้าแค่ชิ้นเดียว หรือคอร์สแค่คอร์สเดียว ข้อมูลมักมาเป็น ชุด เช่น

  • รายชื่อนักเรียนหลายคน
  • รายการสินค้า
  • รายการบทเรียน
  • รายการงานที่ต้องทำ
  • รายการผู้สมัครงาน
  • รายการคำสั่งซื้อ

คอร์สนี้เราจะรู้จักเครื่องมือ 3 อย่างของ JavaScript ที่ใช้จัดการข้อมูลเป็นชุด:

  • Array = รายการหลายชิ้น
  • Object = ข้อมูลหนึ่งชิ้นที่มีหลายรายละเอียด
  • Loop = การทำงานซ้ำกับข้อมูลแต่ละรายการ

และอีกหนึ่งทักษะที่สำคัญไม่แพ้กัน:

  • Debugging = การไล่หาปัญหาอย่างเป็นขั้นตอน

แผนการเรียนของคู่มือนี้

  1. ทบทวนและการ Debug — ดูข้อผิดพลาดที่เจอบ่อยจากการทำ assignment และวิธีไล่หาปัญหาด้วย console.log
  2. Array, Object และ Loop — ปูพื้นฐานการเก็บและวนผ่านข้อมูลหลายรายการ
  3. Student Goal Dashboard — สร้างหน้าเว็บที่แสดงการ์ดนักเรียนหลายคนพร้อมเป้าหมายของแต่ละคน โดยให้ JavaScript สร้างการ์ดให้จากข้อมูล
  4. ฝึกต่อยอดและสรุป — Mini Challenge และการบ้าน

ในคอร์สนี้เรายังฝึกเขียนโค้ดด้วยตัวเองทั้งหมด ยังไม่ใช้ AI ช่วย generate code เพราะอยากให้คุณได้ฝึกอ่านโค้ดเอง อ่าน error เอง เข้าใจ flow เอง และคิด logic เองก่อน เป้าหมายไม่ใช่การจำ syntax ให้ได้ทั้งหมด แต่คือเข้าใจว่าเวลามีข้อมูลหลายรายการ เราจะให้ JavaScript จัดการและแสดงผลซ้ำ ๆ ให้เราได้อย่างไร

  • อธิบายได้ว่า HTML, CSS และ JavaScript ต่างกันอย่างไร
  • บอกได้ว่า getElementById, textContent, .value และ event.preventDefault() ใช้ทำอะไร
  • ยกตัวอย่างข้อมูลที่มาเป็น “ชุด” ในเว็บที่คุณใช้อยู่ทุกวันได้อย่างน้อย 2 อย่าง
