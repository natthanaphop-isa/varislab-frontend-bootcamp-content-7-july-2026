Student Goal Dashboard และการ Debug

คอร์สนี้เราจะเริ่มจากทบทวนพื้นฐาน HTML, CSS, JavaScript และ form แล้วฝึกไล่หาปัญหาในโค้ดอย่างเป็นขั้นตอน จากนั้นขยับจากข้อมูลทีละชิ้นไปสู่ “ข้อมูลหลายรายการ” ด้วย array, object และ loop แล้วนำทั้งหมดมาสร้างหน้า Student Goal Dashboard ที่แสดงการ์ดนักเรียนหลายใบบนหน้าเว็บด้วย JavaScript

สิ่งที่ต้องเตรียม

  • Code editor (เช่น VS Code) และเบราว์เซอร์ (เช่น Google Chrome)
  • พื้นฐาน HTML/CSS และ JavaScript เบื้องต้น: getElementById, addEventListener, textContent, form และ .value
  • ไฟล์โปรเจกต์ของคอร์สนี้: โฟลเดอร์ finish/ คือโค้ดที่เสร็จแล้ว ใช้เทียบกับโค้ดของคุณเมื่อทำตามคู่มือจบ
