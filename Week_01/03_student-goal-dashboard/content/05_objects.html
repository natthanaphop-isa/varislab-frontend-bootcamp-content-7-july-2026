บทเรียน 05 · ข้อมูลหลายรายการ (Arrays, Objects & Loops)

Object และ Array of Objects

Objects

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายได้ว่า object คืออะไรและต่างจาก array อย่างไร
  • สร้าง object ที่มีหลาย field ด้วยรูปแบบ key: value
  • อ่านค่าใน object ด้วย dot notation (student.name) และ bracket notation (student["name"])
  • สร้าง array of objects สำหรับเก็บข้อมูลหลายรายการที่แต่ละรายการมีหลายรายละเอียด

Object คืออะไร

นักเรียนหนึ่งคนไม่ได้มีแค่ชื่อ แต่มีทั้งชื่อ เป้าหมาย และระดับพื้นฐาน ถ้าเก็บเป็นตัวแปรแยก 3 ตัว ข้อมูลของคนเดียวกันจะกระจัดกระจาย Object คือข้อมูลหนึ่งชิ้นที่รวมรายละเอียดหลายอย่างไว้ด้วยกัน

const student = {
  name: "Man",
  goal: "เปลี่ยนสายงานเป็น Developer",
  level: "เริ่มจากศูนย์",
};

สังเกต syntax:

  • object เริ่มด้วย { และจบด้วย }
  • ข้างในเป็นคู่ key: value เช่น name: "Man" เรียกแต่ละคู่ว่า field (หรือ property)
  • แต่ละ field คั่นด้วยจุลภาค ,

ดังนั้น object เหมาะกับข้อมูลที่มีหลาย field

อ่านค่าใน object

วิธีที่ใช้บ่อยที่สุดคือ dot notation — ชื่อ object ตามด้วยจุดและชื่อ field:

console.log(student.name);  // Man
console.log(student.goal);  // เปลี่ยนสายงานเป็น Developer
console.log(student.level); // เริ่มจากศูนย์

อีกวิธีคือ bracket notation — ใส่ชื่อ field เป็นข้อความในวงเล็บเหลี่ยม ได้ผลเหมือนกัน:

console.log(student["goal"]); // เปลี่ยนสายงานเป็น Developer

ในคอร์สนี้เราจะใช้ dot notation เป็นหลัก เพราะอ่านง่ายกว่า

ถ้าสะกดชื่อ field ผิด เช่น student.nmae หรือ student.Name จะได้ undefined โดยไม่มี error เตือน เวลาเห็น undefined บนหน้าเว็บ ให้ console.log(student) ดูทั้ง object แล้วเทียบชื่อ field ทีละตัว

ArrayObject
ใช้เก็บรายการหลายชิ้นข้อมูลหนึ่งชิ้นที่มีหลายรายละเอียด
วงเล็บ[ ]{ }
หยิบข้อมูลด้วยindex ตัวเลข เช่น goals[0]ชื่อ field เช่น student.name

Array of Objects

ในเว็บจริงเรามักใช้ array และ object พร้อมกัน: array เก็บรายการหลายคน และแต่ละคนเป็น object

const students = [
  {
    name: "Man",
    goal: "เปลี่ยนสายงานเป็น Developer",
    level: "เริ่มจากศูนย์",
  },
  {
    name: "Jane",
    goal: "สร้าง Portfolio",
    level: "เคยเรียนมาบ้าง",
  },
  {
    name: "Pond",
    goal: "เข้าใจ Full-Stack",
    level: "เคยทำโปรเจกต์เล็ก ๆ",
  },
];

นี่คือ list ของนักเรียนหลายคน แต่ละคนเป็น object ที่มี name, goal และ level เราหยิบข้อมูลได้โดยรวมสองวิธีเข้าด้วยกัน — เลือกคนด้วย index แล้วเลือก field ด้วยจุด:

console.log(students[0].name); // Man
console.log(students[1].goal); // สร้าง Portfolio
console.log(students.length);  // 3

โครงสร้างแบบนี้เจอบ่อยมากใน Web Application เช่น list ของสินค้า, list ของ user, list ของ course, list ของ job application หรือ list ของ transaction

จุดที่พิมพ์พลาดบ่อยใน array of objects คือลืมจุลภาคระหว่าง object (หลัง } ของแต่ละคน) หรือวงเล็บไม่ครบคู่ ซึ่งจะทำให้เกิด SyntaxError ใน Console และโค้ดทั้งไฟล์จะไม่ทำงานเลย ให้ดูเลขบรรทัดที่ error บอก แล้วเช็กบรรทัดนั้นและบรรทัดก่อนหน้า

object แต่ละตัวใน array ไม่จำเป็นต้องมี field เท่ากันเสมอไป และค่าของ field เป็น array ได้ด้วย เช่น lessons: ["lesson-1", "lesson-2", "lesson-3"] แต่เวลาจะนำไปแสดงผลแบบเดียวกันทุกตัว การให้ทุก object มี field ชุดเดียวกันจะช่วยให้ไม่เจอ undefined โผล่มาบางการ์ด

ลองทำ

  1. สร้าง object ของตัวคุณเองที่มี name, goal และ level แล้ว console.log ทีละ field
  2. สร้าง array students ตามตัวอย่างด้านบน แล้วเพิ่ม object ของคุณเป็นคนที่ 4
  3. console.log ชื่อของคนสุดท้าย และจำนวนนักเรียนทั้งหมด
  • อธิบายได้ว่า object = ข้อมูลหนึ่งชิ้นที่มีหลายรายละเอียด
  • สร้าง object ด้วย { key: value } และอ่านค่าด้วย object.field ได้
  • สร้าง array of objects และอ่านค่าอย่าง students[0].name ได้
  • รู้ว่าชื่อ field ที่สะกดผิดจะได้ undefined
