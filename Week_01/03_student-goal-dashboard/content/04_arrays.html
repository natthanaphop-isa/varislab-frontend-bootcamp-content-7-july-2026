บทเรียน 04 · ข้อมูลหลายรายการ (Arrays, Objects & Loops)

Array: เก็บข้อมูลหลายรายการ

Arrays

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายได้ว่า array คืออะไรและใช้เมื่อไร
  • สร้าง array ด้วยวงเล็บเหลี่ยม [ ]
  • หยิบข้อมูลใน array ด้วย index ที่เริ่มนับจาก 0
  • ดูจำนวนสมาชิกใน array ด้วย .length

ปัญหา: ข้อมูลหลายชิ้นในตัวแปรหลายตัว

ถ้าเราอยากเก็บเป้าหมาย 3 อย่าง ด้วยความรู้เดิม เราอาจเขียนแบบนี้:

const goal1 = "เปลี่ยนสายงานเป็น Developer";
const goal2 = "สร้าง Portfolio";
const goal3 = "เข้าใจ Full-Stack";

ใช้ได้ถ้ามีแค่ 3 อย่าง แต่ถ้ามี 30 หรือ 300 อย่างล่ะ? การตั้งตัวแปรทีละตัวจะยุ่งมาก และเราไม่มีทางบอก JavaScript ได้ง่าย ๆ ว่า “ทำอะไรบางอย่างกับเป้าหมาย ทุกตัว” นี่คือเหตุผลที่เราต้องมี array

Array คืออะไร

Array คือกล่องที่ใช้เก็บข้อมูลหลายรายการไว้ในตัวแปรเดียว ให้มอง array เหมือน list หรือรายการที่เรียงลำดับไว้

const goals = [
  "เปลี่ยนสายงานเป็น Developer",
  "สร้าง Portfolio",
  "เข้าใจ Full-Stack",
];

ตัวแปร goals ไม่ได้เก็บข้อความเดียว แต่เก็บข้อความหลายอันไว้ในชุดเดียวกัน สังเกต syntax:

  • array เริ่มด้วย [ และจบด้วย ]
  • สมาชิกแต่ละตัวคั่นด้วยเครื่องหมายจุลภาค ,
  • จุลภาคหลังตัวสุดท้าย (เช่นหลัง "เข้าใจ Full-Stack",) ใส่หรือไม่ใส่ก็ได้ JavaScript ยอมรับทั้งสองแบบ

หยิบข้อมูลด้วย index

สมาชิกแต่ละตัวใน array มีหมายเลขลำดับเรียกว่า index และ index เริ่มนับจาก 0 ไม่ใช่ 1

const students = [
  "Man",  // index 0
  "Jane", // index 1
  "Pond", // index 2
];

console.log(students[0]); // Man
console.log(students[1]); // Jane
console.log(students[2]); // Pond

เราหยิบข้อมูลด้วยการเขียนชื่อ array ตามด้วยวงเล็บเหลี่ยมที่มี index อยู่ข้างใน เช่น students[0]

ข้อผิดพลาดที่เจอบ่อย: คิดว่าตัวแรกคือ students[1] จริง ๆ แล้วตัวแรกคือ students[0] และถ้าขอ index ที่ไม่มีอยู่ เช่น students[3] ใน array ที่มี 3 ตัว จะได้ undefined (ไม่ใช่ error) ถ้าเห็นคำว่า undefined โผล่บนหน้าเว็บ ให้สงสัยเรื่อง index หรือชื่อข้อมูลที่เรียกผิดก่อน

นับจำนวนด้วย .length

ทุก array มี .length บอกว่ามีสมาชิกกี่ตัว:

console.log(students.length); // 3

ตัวสุดท้ายของ array จึงอยู่ที่ index students.length - 1 เสมอ

ใน array เก็บอะไรก็ได้ ทั้งข้อความ ตัวเลข หรือแม้แต่ array ซ้อนกัน และ (สำคัญมากสำหรับบทถัดไป) เก็บ object ได้ด้วย

ลองทำ

สร้างไฟล์ index.html ที่มี <script src="script.js"></script> แล้วเขียนใน script.js:

  1. สร้าง array ชื่อ goals ที่มีเป้าหมายของคุณเอง 4 อย่าง
  2. console.log เป้าหมายตัวแรกและตัวสุดท้าย
  3. console.log จำนวนเป้าหมายทั้งหมดด้วย .length
  4. ลอง console.log(goals[10]) แล้วดูว่าได้อะไร
  • อธิบายได้ว่า array = รายการหลายชิ้นในตัวแปรเดียว
  • สร้าง array ด้วย [ ] และคั่นสมาชิกด้วย , ได้
  • รู้ว่า index เริ่มจาก 0 และ index ที่ไม่มีอยู่จะได้ undefined
  • ใช้ .length ดูจำนวนสมาชิกได้
