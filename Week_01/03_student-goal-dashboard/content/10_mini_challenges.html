Mini Challenge: ต่อยอด Dashboard

Mini Challenges

เมื่อจบบทนี้ คุณจะสามารถ

  • เพิ่มข้อมูลใน array แล้วเห็นการ์ดใหม่โดยไม่ต้องแก้ loop
  • เพิ่ม field ใหม่ใน object และแสดงบนการ์ด
  • ปรับหน้าตาหรือข้อความของ badge
  • ใช้ if ภายใน loop เพื่อแสดงข้อความต่างกันตามข้อมูล

ใช้โปรเจกต์ที่ทำเสร็จในบทที่ 9 เป็นจุดเริ่ม ทำทีละ challenge และหลังแก้แต่ละครั้งให้ save, refresh และดู Console ว่าไม่มี error ใช้เวลาประมาณ 15–20 นาที

ก่อนเริ่ม แนะนำให้ copy โฟลเดอร์โปรเจกต์เก็บไว้อีกชุด ถ้าแก้แล้วพังจนงง จะได้มีเวอร์ชันที่ทำงานได้ไว้เทียบ

Challenge 1: เพิ่มนักเรียนคนที่ 4

เพิ่ม object ของคุณเองเข้าไปเป็นสมาชิกตัวสุดท้ายใน array students:

{
  name: "Your Name",
  goal: "เป้าหมายของคุณ",
  level: "พื้นฐานของคุณ",
}

สังเกตว่าเราไม่ได้แตะโค้ดใน forEach เลย แต่การ์ดใบที่ 4 ก็ขึ้นมาเอง นี่คือพลังของการแยก “ข้อมูล” ออกจาก “วิธีแสดงผล”

อย่าลืมจุลภาคหลัง } ของ object ก่อนหน้า (ของ Pond) ถ้าหน้าเว็บไม่แสดงการ์ดเลยสักใบหลังเพิ่มข้อมูล ให้เปิด Console หา SyntaxError ก่อน และสังเกตว่าการ์ดใบที่ 4 ขึ้นไปอยู่แถวใหม่ เพราะ grid ของเรามี 3 คอลัมน์

Challenge 2: เพิ่ม field targetRole

เพิ่ม field ใหม่ชื่อ targetRole ให้นักเรียน เช่น

{
  name: "Man",
  goal: "เปลี่ยนสายงานเป็น Developer",
  level: "เริ่มจากศูนย์",
  targetRole: "Frontend Developer",
}

แล้วแสดง targetRole บนการ์ด (เพิ่มบรรทัด <p> ใหม่ใน innerHTML)

ถ้าเพิ่ม targetRole ให้นักเรียนแค่บางคน การ์ดของคนที่ไม่มี field นี้จะขึ้นคำว่า undefined — ลองสังเกตอาการนี้ แล้วเพิ่ม field ให้ครบทุกคน

Challenge 3: ปรับ badge

เปลี่ยนสีของ badge (แก้ที่ .badge ใน style.css) หรือเปลี่ยนข้อความใน badge (แก้ที่ <span class="badge"> ใน innerHTML) ให้เป็นแบบของคุณ

Bonus: badge เปลี่ยนตามพื้นฐาน

ถ้า level เป็น "เริ่มจากศูนย์" ให้ badge แสดงว่า

Beginner Friendly

ถ้าไม่ใช่ ให้ badge แสดงว่า

Has Some Experience

ตัวอย่าง logic ที่ใช้ตัดสินใจ:

let badgeText = "Has Some Experience";

if (student.level === "เริ่มจากศูนย์") {
  badgeText = "Beginner Friendly";
}

คำใบ้สำหรับนำไปใช้:

  • logic นี้ต้องอยู่ข้างใน forEach เพราะต้องตัดสินใจใหม่สำหรับนักเรียนแต่ละคน และต้องอยู่ก่อนบรรทัด innerHTML
  • ใช้ let ไม่ใช่ const เพราะเราอาจเปลี่ยนค่า badgeText ภายหลังใน if
  • แทนข้อความ badge เดิมด้วยค่าจากตัวแปร โดยใช้ ${ } แบบเดียวกับ ${student.name}
  • === เทียบข้อความแบบตรงทุกตัวอักษร ถ้าพิมพ์ "เริ่มจากศูนย์" ใน if ไม่ตรงกับในข้อมูล (เช่น มีเว้นวรรคเกิน) เงื่อนไขจะไม่เป็นจริง ถ้าไม่แน่ใจให้ console.log(student.level); ดู

ผลลัพธ์ที่ควรเห็น

หน้าเว็บมีการ์ดอย่างน้อย 4 ใบ ทุกใบแสดง targetRole และถ้าทำ Bonus การ์ดของ Man (พื้นฐาน “เริ่มจากศูนย์”) จะแสดง badge Beginner Friendly ส่วนคนอื่นที่พื้นฐานไม่ใช่ “เริ่มจากศูนย์” จะแสดง Has Some Experience

  • เพิ่มนักเรียนคนที่ 4 แล้วการ์ดขึ้นเองโดยไม่แก้ loop
  • ทุกการ์ดแสดง targetRole โดยไม่มีคำว่า undefined
  • badge มีสีหรือข้อความตามที่คุณออกแบบ
  • (Bonus) ข้อความ badge เปลี่ยนตาม level ของนักเรียนแต่ละคน
  • Console ไม่มี error สีแดง
ก่อนหน้า: สร้างการ์ดบนหน้าเว็บด้วย JavaScript สารบัญบทเรียน ถัดไป: สรุปบทเรียนและการบ้าน
