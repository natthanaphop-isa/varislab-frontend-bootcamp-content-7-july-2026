สรุปสิ่งที่เรียนมา

คอร์สนี้เราขยับจากการทำงานกับหน้าเว็บหนึ่งหน้า ปุ่มหนึ่งปุ่ม และ form หนึ่ง form ไปสู่การจัดการข้อมูลหลายรายการ ซึ่งเป็นพื้นฐานที่สำคัญมาก เพราะในโลกจริงข้อมูลแทบทุกอย่างมาเป็น list เช่น รายชื่อนักเรียน รายการสินค้า รายการบทเรียน รายการผู้สมัครงาน หรือรายการ task

ถ้ายังจำ syntax ไม่ได้ทั้งหมด ไม่เป็นไร ขอให้จำ concept นี้ให้ได้ก่อน:

Conceptความหมายตัวอย่างในโปรเจกต์
Arrayรายการหลายชิ้นconst students = [ ... ];
Objectข้อมูลหนึ่งชิ้นที่มีหลายรายละเอียด{ name: "Man", goal: "...", level: "..." }
Loopการทำงานซ้ำกับข้อมูลแต่ละรายการstudents.forEach(function (student) { ... });
Debuggingการไล่หาปัญหาอย่างเป็นขั้นตอนอ่าน error → ดูสิ่งที่เพิ่งแก้ → เช็กการเชื่อมโยง → console.log

คำสั่งสำหรับสร้าง element ด้วย JavaScript

  • document.createElement("article") — สร้าง element ใหม่
  • element.classList.add("student-card") — ใส่ class
  • element.innerHTML = `...` — ใส่ HTML ข้างใน โดยแทรกข้อมูลด้วย ${ }
  • container.appendChild(element) — นำ element ไปแสดงบนหน้าเว็บ

เช็กลิสต์ debug ติดตัว

  • Save file แล้วหรือยัง? Refresh แล้วหรือยัง? แก้ถูกไฟล์หรือเปล่า?
  • เปิด Console แล้วมี error สีแดงไหม? บอกบรรทัดไหน?
  • id / class ใน HTML, CSS และ JavaScript ตรงกันไหม? เชื่อมไฟล์ครบไหม?
  • ได้ null → เช็ก id / ได้ undefined → เช็กชื่อ field หรือ index
  • ไม่แน่ใจค่าอะไร → console.log ดูเลย อย่าเดา

การบ้าน: Student Goal Dashboard ของคุณเอง

สร้างหน้า Dashboard เล็ก ๆ ที่แสดงข้อมูลหลายรายการ โดยใช้ array, object และ loop เลือกหัวข้อได้ตามความสนใจ เช่น

  • Student Goal Dashboard
  • Course List
  • Portfolio Project List
  • Job Application Tracker
  • Product List
  • Task List

Requirements

  1. มี array อย่างน้อย 4 รายการ
  2. แต่ละรายการเป็น object
  3. object แต่ละตัวมีอย่างน้อย 3 fields
  4. ใช้ forEach เพื่อแสดงข้อมูลทุก item บนหน้าเว็บ
  5. ใช้ document.createElement หรือ innerHTML เพื่อสร้าง card
  6. ใช้ CSS ตกแต่ง card ให้ดูเป็นระบบ
  7. มีอย่างน้อย 1 จุดที่ใช้ if เพื่อตัดสินใจแสดงข้อความแตกต่างกัน

ใช้โปรเจกต์ในบทที่ 7–10 เป็นแม่แบบได้ เริ่มจากออกแบบข้อมูล (array of objects) ให้เสร็จ แล้วตรวจใน Console ก่อน จากนั้นค่อยสร้างการ์ด — ทำทีละขั้นแบบเดียวกับที่เราทำในคอร์สนี้ และ Bonus ในบทที่ 10 คือตัวอย่างของ requirement ข้อ 7

Reflection

ตอบคำถามสั้น ๆ ส่งมาพร้อมงาน:

  1. Array คืออะไร?
  2. Object คืออะไร?
  3. Loop ช่วยเราอย่างไร?
  4. ระหว่างทำงานนี้ เจอ error อะไร?
  5. คุณ debug อย่างไร?
  6. อยากให้ review จุดไหน?

คำถามทบทวนหลังเรียน

ลองตอบด้วยตัวเองก่อนแล้วค่อยย้อนกลับไปเช็กในบทที่เกี่ยวข้อง

  1. Array ใช้ทำอะไร?
    1. เก็บข้อมูลหลายรายการ
    2. เปลี่ยนสีพื้นหลัง
    3. เปิด browser
    4. ลบไฟล์ในเครื่อง
  2. Object เหมาะกับข้อมูลแบบไหน?
    1. ข้อมูลหนึ่งรายการที่มีหลายรายละเอียด
    2. เฉพาะข้อความสั้น ๆ เท่านั้น
    3. เฉพาะตัวเลขเท่านั้น
    4. ใช้แทน CSS
  3. forEach ใช้ทำอะไร?
    1. วนทำงานกับข้อมูลแต่ละรายการใน array
    2. เปลี่ยนชื่อไฟล์
    3. ติดตั้ง Node.js
    4. ทำให้ปุ่มมีสีฟ้า
  4. document.createElement("article") ใช้ทำอะไร?
    1. สร้าง HTML element ใหม่ด้วย JavaScript
    2. ลบหน้าเว็บ
    3. เปลี่ยนสี text
    4. เปิด GitHub
  5. ถ้า JavaScript หา element ไม่เจอและได้ค่า null ควรเช็กอะไร?
    1. id ใน HTML ตรงกับ JavaScript หรือไม่
    2. สีปุ่มสวยหรือไม่
    3. ชื่อคนเรียนถูกไหม
    4. ใช้ font อะไร
  • อธิบาย Array, Object, Loop และ Debugging ได้ด้วยประโยคสั้น ๆ ของตัวเอง
  • โปรเจกต์ Student Goal Dashboard ของคุณแสดงการ์ดครบและไม่มี error ใน Console
  • assignment มีครบทั้ง 7 requirements
  • ตอบ reflection ครบ 6 ข้อ
