บทเรียน 08 · สร้าง Student Goal Dashboard (Building the Dashboard)

ตรวจข้อมูลใน Console ก่อน

Version 1: Console First

เมื่อจบบทนี้ คุณจะสามารถ

  • เก็บข้อมูลนักเรียนของ dashboard เป็น array of objects ใน script.js
  • ใช้ forEach กับ console.log ตรวจข้อมูลทุกรายการก่อนนำไปแสดงบนหน้าเว็บ
  • อธิบายได้ว่าทำไมการตรวจข้อมูลใน Console ก่อนจึงช่วยให้ debug ง่ายขึ้น

ทำไมต้องดูใน Console ก่อน

ก่อนจะแสดงผลบนหน้าเว็บ เราลองดูข้อมูลใน Console ก่อน นี่คือวิธีทำงานที่ดี เพราะเราต้องมั่นใจก่อนว่าข้อมูลของเราถูกต้อง

ลองนึกภาพว่าเราเขียนทั้งข้อมูล loop และโค้ดสร้างการ์ดทีเดียวพร้อมกัน แล้วหน้าเว็บไม่แสดงอะไรเลย ปัญหาอาจอยู่ได้หลายจุด: ข้อมูลพิมพ์ผิด, loop ผิด, หา container ไม่เจอ, หรือสร้างการ์ดผิด การแบ่งทำทีละขั้นแล้วตรวจแต่ละขั้นให้ผ่านก่อน ทำให้เมื่อพังเรารู้ทันทีว่าพังที่ขั้นไหน

JavaScript เวอร์ชัน 1

ใส่โค้ดนี้ใน script.js:

const students = [
  {
    name: "Man",
    goal: "เปลี่ยนสายงานเป็น Developer",
    level: "เริ่มจากศูนย์",
  },
  {
    name: "Jane",
    goal: "สร้าง Portfolio",
    level: "เคยเรียนมาบ้าง",
  },
  {
    name: "Pond",
    goal: "เข้าใจ Full-Stack",
    level: "เคยทำโปรเจกต์เล็ก ๆ",
  },
];

students.forEach(function (student) {
  console.log(student.name);
  console.log(student.goal);
  console.log(student.level);
});

โค้ดนี้มีสองส่วนที่เราเรียนมาแล้ว:

  1. ข้อมูล — students เป็น array ที่มี object 3 ตัว แต่ละตัวมี field name, goal, level
  2. Loop — forEach วนผ่านนักเรียนทีละคน และแสดงทั้ง 3 field ของคนนั้นใน Console

ผลลัพธ์ที่ควรเห็น

เปิด index.html แล้วเปิดแท็บ Console หน้าเว็บยังเหมือนบทที่แล้ว แต่ใน Console จะมี 9 บรรทัด เรียงเป็นชุดละ 3 บรรทัดต่อนักเรียนหนึ่งคน:

Man
เปลี่ยนสายงานเป็น Developer
เริ่มจากศูนย์
Jane
สร้าง Portfolio
เคยเรียนมาบ้าง
Pond
เข้าใจ Full-Stack
เคยทำโปรเจกต์เล็ก ๆ

ถ้าไม่เห็นตามนี้

อาการสาเหตุที่เป็นไปได้วิธีเช็ก
Console ว่างเปล่า ไม่มีอะไรเลย ไม่ได้ save, ไม่ได้ refresh หรือ script.js ไม่ได้เชื่อมกับ HTML เช็กลิสต์ save / refresh / ถูกไฟล์ และบรรทัด <script src="script.js">
มี SyntaxError สีแดง ลืมจุลภาคระหว่าง object หรือวงเล็บ/ปีกกา/เครื่องหมายคำพูดไม่ครบคู่ คลิกเลขบรรทัดที่ error บอก แล้วเช็กบรรทัดนั้นและบรรทัดก่อนหน้า
บางบรรทัดขึ้น undefined สะกดชื่อ field ใน console.log ไม่ตรงกับใน object ใส่ console.log(student); ใน loop แล้วเทียบชื่อ field
ข้อมูลขึ้นซ้ำหลายชุด copy object ซ้ำใน array โดยไม่ตั้งใจ console.log(students.length); ว่าได้ 3 หรือไม่

Console ของ Chrome ยุบข้อความที่เหมือนกันซึ่งแสดงติดกันไว้เป็นบรรทัดเดียว และมีตัวเลขบอกจำนวนครั้งกำกับไว้ ถ้าเห็นตัวเลขแบบนี้ แปลว่าบรรทัดนั้นถูกแสดงซ้ำหลายครั้ง

  • script.js มี array students ที่มี object 3 ตัว (Man, Jane, Pond)
  • Console แสดงชื่อ เป้าหมาย และพื้นฐานของทั้ง 3 คนครบ 9 บรรทัด
  • ไม่มี error สีแดงใน Console
  • อธิบายได้ว่าทำไมเราตรวจข้อมูลใน Console ก่อนสร้างการ์ด
ก่อนหน้า: เตรียมโปรเจกต์ HTML และ CSS สารบัญบทเรียน ถัดไป: สร้างการ์ดบนหน้าเว็บด้วย JavaScript
