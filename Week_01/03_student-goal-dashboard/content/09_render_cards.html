บทเรียน 09 · สร้าง Student Goal Dashboard (Building the Dashboard)

สร้างการ์ดบนหน้าเว็บด้วย JavaScript

Version 2: Rendering Cards

เมื่อจบบทนี้ คุณจะสามารถ

  • สร้าง HTML element ใหม่ด้วย document.createElement
  • ใส่ class ให้ element ด้วย classList.add
  • เติม HTML ข้างใน element จากข้อมูลด้วย innerHTML และ template literal
  • นำ element ไปแสดงบนหน้าเว็บด้วย appendChild
  • อธิบาย flow “ข้อมูล → loop → สร้าง HTML → แสดงผล” ได้ครบ 6 ขั้น
  • debug อาการที่เจอบ่อยตอน render การ์ด

JavaScript เวอร์ชัน 2

ข้อมูลในบทที่แล้วถูกต้องแล้ว ตอนนี้เราจะเปลี่ยนจาก “แสดงใน Console” เป็น “สร้างการ์ดบนหน้าเว็บ” แทนที่โค้ดทั้งหมดใน script.js ด้วยโค้ดนี้:

const studentList = document.getElementById("studentList");

const students = [
  {
    name: "Man",
    goal: "เปลี่ยนสายงานเป็น Developer",
    level: "เริ่มจากศูนย์",
  },
  {
    name: "Jane",
    goal: "สร้าง Portfolio",
    level: "เคยเรียนมาบ้าง",
  },
  {
    name: "Pond",
    goal: "เข้าใจ Full-Stack",
    level: "เคยทำโปรเจกต์เล็ก ๆ",
  },
];

students.forEach(function (student) {
  const studentCard = document.createElement("article");

  studentCard.classList.add("student-card");

  studentCard.innerHTML = `
    <h2>${student.name}</h2>
    <p><strong>เป้าหมาย:</strong> ${student.goal}</p>
    <p><strong>พื้นฐาน:</strong> ${student.level}</p>
    <span class="badge">Bootcamp Student</span>
  `;

  studentList.appendChild(studentCard);
});

อธิบายทีละบรรทัด

1. หา container

const studentList = document.getElementById("studentList");

ไปหากล่อง <div id="studentList"> ที่เตรียมไว้ใน HTML เพื่อใช้วางการ์ดนักเรียน เราหาแค่ครั้งเดียวนอก loop เพราะทุกการ์ดใส่ลงกล่องเดียวกัน

2. วนผ่านนักเรียนทุกคน

students.forEach(function (student) {

ให้วนผ่านนักเรียนทุกคนใน array students ในแต่ละรอบ JavaScript จะหยิบนักเรียนหนึ่งคนมาเก็บไว้ในตัวแปร student โค้ดทุกบรรทัดใน loop จึงทำงาน 3 รอบ ได้การ์ด 3 ใบ

3. สร้าง element ใหม่

const studentCard = document.createElement("article");

สร้าง HTML element ใหม่ขึ้นมาหนึ่งอัน เป็นแท็ก <article> ตอนนี้มันยังเป็นกล่องเปล่า ๆ ที่อยู่ในหน่วยความจำ ยังไม่ได้อยู่บนหน้าเว็บ

4. ใส่ class

studentCard.classList.add("student-card");

ใส่ class ชื่อ student-card ให้ element นี้ เพื่อให้ CSS ที่เราเขียนรอไว้ในบทที่ 7 ตกแต่งหน้าตาได้ ผลเหมือนเขียน <article class="student-card"> ใน HTML

5. ใส่เนื้อหาข้างในการ์ด

studentCard.innerHTML = `
  <h2>${student.name}</h2>
  ...
`;

ใส่ HTML ข้างในการ์ดโดยใช้ข้อมูลจาก student สองเรื่องที่ควรรู้:

  • Backtick ` — ข้อความที่ครอบด้วย backtick เรียกว่า template literal เขียนข้อความหลายบรรทัดได้ (เครื่องหมายคำพูด " ธรรมดาทำไม่ได้) ปุ่ม backtick มักอยู่ใต้ปุ่ม Esc บนคีย์บอร์ด
  • ${ } — ช่องสำหรับแทรกค่าจาก JavaScript ลงในข้อความ เช่น ${student.name} จะถูกแทนด้วย Man ในรอบแรก และ Jane ในรอบที่สอง

6. นำการ์ดไปแสดงบนหน้าเว็บ

studentList.appendChild(studentCard);

เอาการ์ดที่สร้างเสร็จแล้วไปใส่เป็นลูกตัวสุดท้ายของ studentList บรรทัดนี้คือจังหวะที่การ์ดปรากฏบนหน้าเว็บจริง ถ้าลืมบรรทัดนี้ การ์ดจะถูกสร้างขึ้นมาแต่ไม่มีใครเห็น

ผลลัพธ์ที่ควรเห็น

refresh หน้าเว็บ ใต้คำอธิบายจะมีการ์ดสีน้ำเงินเทา 3 ใบเรียงกันเป็นแถวเดียว 3 คอลัมน์ แต่ละใบมีชื่อนักเรียนสีฟ้า (Man, Jane, Pond) บรรทัด เป้าหมาย: และ พื้นฐาน: และป้าย Bootcamp Student ด้านล่าง

ถ้าคลิกขวาที่การ์ดแล้วเลือก Inspect จะเห็นในแท็บ Elements ว่ามี <article class="student-card"> 3 ตัวอยู่ใน <div id="studentList"> ทั้งที่ในไฟล์ HTML กล่องนี้ว่างเปล่า — JavaScript เป็นคนสร้างมันขึ้นมา

Flow ที่ควรจำ

  1. มีข้อมูลอยู่ใน array
  2. array เก็บ object หลายตัว
  3. object แต่ละตัวคือข้อมูลหนึ่งรายการ
  4. loop วนผ่านข้อมูลทีละตัว
  5. สร้าง HTML จากข้อมูล
  6. เอา HTML ไปแสดงบนหน้าเว็บ

นี่คือ pattern ที่จะเจอบ่อยมากเมื่อไปเรียน React ในอนาคต ตอนนี้เราเขียนแบบ manual ก่อน เพื่อให้เข้าใจพื้นฐานว่าเบื้องหลังเกิดอะไรขึ้น

Debug: อาการที่เจอบ่อยตอน render การ์ด

หน้าเว็บไม่มีการ์ด และ Console มี error เรื่อง null

ใน Chrome จะเห็นประมาณนี้:

Uncaught TypeError: Cannot read properties of null (reading 'appendChild')

อ่านทีละส่วน: “อ่าน property ของ null ไม่ได้ (ตอนกำลังเรียก appendChild)” แปลว่าตัวแปรที่อยู่หน้า .appendChild คือ studentList มีค่าเป็น null — getElementById หา element ไม่เจอ ให้เช็ก:

  • id ใน HTML (id="studentList") กับใน JavaScript (getElementById("studentList")) สะกดตรงกันทุกตัวหรือไม่
  • <script> อยู่ท้าย <body> หรือไม่ (ดูบทที่ 7)
  • ใส่ console.log(studentList); ต่อจากบรรทัด getElementById เพื่อยืนยัน

การ์ดขึ้น แต่หน้าตาเป็นข้อความธรรมดา ไม่มีกรอบ

CSS ไม่มีผลกับการ์ด มักเกิดจาก class ที่ใส่ใน classList.add สะกดไม่ตรงกับใน CSS (เช่น "studentCard" แทน "student-card") หรือ style.css ไม่ได้เชื่อมกับ HTML

การ์ดขึ้นคำว่า undefined

ชื่อ field ใน ${ } ไม่ตรงกับใน object เช่น ${student.goals} ทั้งที่ field ชื่อ goal หรือใช้ ${students.name} (ชื่อ array) แทน ${student.name}

แสดง ${student.name} ออกมาตรง ๆ ทั้งข้อความ

ใช้เครื่องหมายคำพูด " หรือ ' แทน backtick ` — ${ } ทำงานเฉพาะใน template literal ที่ครอบด้วย backtick เท่านั้น

การ์ดขึ้นซ้ำ มากกว่าจำนวนนักเรียน

มักเกิดจากข้อมูลใน array ถูก copy วางซ้ำโดยไม่ตั้งใจ (เช่น array มี 8 object แทน 4) ใช้ console.log(students.length); ตรวจจำนวนก่อน แล้วลบชุดที่ซ้ำออก

innerHTML ตีความข้อความเป็น HTML จริง เหมาะกับข้อมูลที่เราเขียนเองในโค้ดอย่างในโปรเจกต์นี้ แต่ถ้าวันหนึ่งข้อมูลมาจากสิ่งที่ผู้ใช้พิมพ์เข้ามา ควรระวังและเลือกใช้ textContent กับข้อความเหล่านั้นแทน อ่านเพิ่มเติมได้ที่ MDN: Element.innerHTML

เทียบกับโค้ดที่เสร็จแล้ว

เมื่อทำเสร็จ ลองเทียบโค้ดของคุณกับไฟล์ในโฟลเดอร์ finish/ ของโปรเจกต์ ผลลัพธ์ต้องเป็นการ์ดนักเรียน 3 ใบเหมือนกัน (การเว้นบรรทัดและย่อหน้าต่างกันได้ ไม่มีผลกับการทำงาน)

  • หน้าเว็บแสดงการ์ด 3 ใบ (Man, Jane, Pond) เรียง 3 คอลัมน์ พร้อมป้าย Bootcamp Student
  • ไม่มี error สีแดงใน Console
  • อธิบายได้ว่า createElement, classList.add, innerHTML และ appendChild ทำหน้าที่อะไร
  • ท่อง flow 6 ขั้นได้: array → object → ข้อมูลหนึ่งรายการ → loop → สร้าง HTML → แสดงบนหน้าเว็บ
  • เห็น error Cannot read properties of null แล้วรู้ว่าต้องเช็ก id ก่อน
