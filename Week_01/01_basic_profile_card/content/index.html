สร้าง Professional Profile Card

คอร์สนี้เริ่มจากโฟลเดอร์ว่าง ๆ แล้วสร้างการ์ดแนะนำตัวแบบมืออาชีพหนึ่งใบ มี label บอกเป้าหมาย ชื่อ ข้อความแนะนำตัว และปุ่มที่กดแล้วข้อความเปลี่ยน ระหว่างทางเราจะเห็นภาพชัดว่า HTML คือโครงสร้าง, CSS คือหน้าตา และ JavaScript คือพฤติกรรมของหน้าเว็บ

สิ่งที่ต้องเตรียม

  • Code editor อย่าง Cursor หรือ VS Code
  • Browser สำหรับเปิดไฟล์ index.html ดูผลลัพธ์
  • ไม่ต้องมีพื้นฐานเขียนโค้ดมาก่อน และไม่ต้องจำ syntax ทั้งหมดตั้งแต่วันแรก ขอแค่เข้าใจว่าแต่ละส่วนทำหน้าที่อะไร
