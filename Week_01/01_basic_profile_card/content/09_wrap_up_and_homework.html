Wrap Up & Homework

เมื่อจบบทนี้ คุณจะสามารถ

  • สรุปหน้าที่ของ HTML, CSS และ JavaScript จากโปรเจกต์ที่ทำจริง
  • เทียบโค้ดของคุณกับโค้ดฉบับสมบูรณ์ทั้ง 3 ไฟล์
  • รู้ว่าการบ้าน Personal Developer Intro Card ต้องส่งอะไรบ้าง

สิ่งที่เราได้เรียนไป

เราเริ่มจากโปรเจกต์เล็กมาก แต่ concept ข้างในคือพื้นฐานของ Web Development จริง:

ภาษา หน้าที่ ในโปรเจกต์นี้เราใช้ทำ
HTML สร้างโครงสร้างของหน้าเว็บ การ์ด, label, ชื่อ, ข้อความแนะนำตัว, ปุ่ม และการเชื่อมไฟล์ CSS/JS
CSS ควบคุมหน้าตา สี ระยะห่าง และ layout พื้นหลังเข้ม จัดการ์ดกลางจอ มุมโค้ง เงา ปุ่มแคปซูลที่เปลี่ยนสีตอน hover
JavaScript เพิ่มการโต้ตอบกับผู้ใช้ กดปุ่มแล้วเปลี่ยนข้อความ

การ์ดนี้ยังไม่ใช่ระบบใหญ่ แต่คือจุดเริ่มต้นของ component ที่ใช้ในเว็บจริง ไม่ว่าจะเป็นหน้า Portfolio, หน้า Profile, หน้า Course, หน้า Product หรือระบบหลังบ้าน

การเป็น Developer ไม่ได้เริ่มจากการจำทุกอย่างได้ แต่เริ่มจากการเข้าใจภาพรวม ทดลองแก้ ทดลองเปลี่ยน และค่อย ๆ สะสมความมั่นใจจากการลงมือทำ ถ้ายังจำ syntax ไม่ได้ทั้งหมด ไม่เป็นไรเลย ขอให้จำภาพนี้ไว้ก่อน:

HTML = โครงสร้าง
CSS = หน้าตา
JavaScript = พฤติกรรม

การบ้าน: Personal Developer Intro Card

ปรับ Professional Profile Card นี้ให้เป็นของตัวคุณเอง

Requirements

  1. เปลี่ยนชื่อเป็นชื่อของตัวเอง
  2. เปลี่ยน label เป็นเป้าหมายของตัวเอง เช่น Aspiring Software Developer
  3. เขียน summary แนะนำตัวเอง 2–3 บรรทัด
  4. ทำให้ปุ่มกดแล้วเปลี่ยนข้อความได้
  5. ปรับสีหรือ style อย่างน้อย 1 จุด

Bonus

  1. เพิ่มปุ่ม Reset ที่กดแล้วข้อความกลับมาเหมือนเดิม
  2. เพิ่ม section เล็ก ๆ เช่น ประสบการณ์เดิม หรือเป้าหมายหลังเรียนจบ
  3. ปรับ layout ให้ดู professional ขึ้น

สำหรับ Bonus ข้อ 1 ลองนึกถึงสี่ขั้นจากบทที่ 07: หาข้อความ → หาปุ่ม (ปุ่มใหม่ต้องมี id ของตัวเอง) → รอฟังการคลิก → เปลี่ยนข้อความ คำถามที่ต้องคิดเองคือ "ข้อความเดิม" จะเอามาจากไหน

Reflection ที่ต้องส่งพร้อมงาน

  1. เข้าใจ HTML, CSS, JavaScript ต่างกันอย่างไร?
  2. ตอนทำงานเจอ error อะไรไหม?
  3. แก้ปัญหาอย่างไร?
  4. อยากให้ช่วย review จุดไหน?

อย่ากลัวทำโค้ดพัง การทำให้พังแล้วค่อยแก้ คือวิธีเรียนเขียนโค้ดที่ดีที่สุดวิธีหนึ่ง ต่อจากนี้เราจะลงรายละเอียดมากขึ้นเกี่ยวกับ HTML structure, CSS layout และพื้นฐานการคิดแบบโปรแกรมเมอร์

เช็กลิสต์ก่อนส่งงาน

  • การ์ดแสดงชื่อ, label และ summary 2–3 บรรทัดของคุณเอง
  • กดปุ่มแล้วข้อความเปลี่ยน
  • ปรับสีหรือ style แล้วอย่างน้อย 1 จุด
  • เปิดไฟล์ใน browser ใหม่อีกรอบหลัง save ทุกไฟล์ แล้วทุกอย่างยังทำงาน
  • เขียนคำตอบ reflection ครบทั้ง 4 ข้อ
ก่อนหน้า: ปรับให้เป็นของตัวเอง และรับมือกับ Error สารบัญบทเรียน
