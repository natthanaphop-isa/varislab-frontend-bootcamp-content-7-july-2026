บทเรียน 07 · JavaScript และก้าวต่อไป (Interaction & Wrap Up)

ทำให้ปุ่มทำงานด้วย JavaScript

JavaScript Interaction

เมื่อจบบทนี้ คุณจะสามารถ

  • หา element ในหน้าเว็บด้วย document.getElementById
  • สั่งให้ปุ่มรอฟังการคลิกด้วย addEventListener
  • เปลี่ยนข้อความบนหน้าเว็บด้วย textContent

สิ่งที่เราจะทำ

ตอนนี้หน้าเว็บมีทั้งโครงสร้างและหน้าตาแล้ว แต่ปุ่มยังกดแล้วไม่เกิดอะไร JavaScript คือส่วนที่เพิ่มพฤติกรรมให้หน้าเว็บ ในโปรเจกต์นี้เราจะทำสิ่งง่าย ๆ อย่างเดียว:

เมื่อผู้ใช้กดปุ่ม ให้ข้อความในการ์ดเปลี่ยน

เขียน script.js

เปิดไฟล์ script.js แล้วเขียนโค้ดนี้:

const summary = document.getElementById("summary");
const toggleButton = document.getElementById("toggleButton");

toggleButton.addEventListener("click", function () {
  summary.textContent =
    "เป้าหมายของฉันคือการสร้างโปรเจกต์จริง เข้าใจพื้นฐาน Full-Stack และเตรียม Portfolio สำหรับสมัครงานสาย Developer";
});

Save แล้ว refresh browser จากนั้นลองกดปุ่ม ดูเป้าหมายของฉัน

อ่านโค้ดทีละบรรทัด

หาข้อความที่จะเปลี่ยน

const summary = document.getElementById("summary");

แปลว่า "ไปหา element ในหน้าเว็บที่มี id ชื่อ summary แล้วเก็บไว้ในตัวแปรชื่อ summary"

  • const — ประกาศตัวแปร คือตั้งชื่อให้ค่าบางอย่าง เพื่อเรียกใช้ทีหลัง
  • document — ตัวแทนของหน้าเว็บทั้งหน้าใน JavaScript
  • getElementById("summary") — ค้นหา element จาก id (ไม่ต้องใส่ # ข้างหน้า ต่างจาก CSS)

หาปุ่มที่ผู้ใช้จะกด

const toggleButton = document.getElementById("toggleButton");

แปลว่า "ไปหาปุ่มที่มี id ชื่อ toggleButton แล้วเก็บไว้ในตัวแปรชื่อ toggleButton"

รอฟังการคลิก

toggleButton.addEventListener("click", function () {
  // โค้ดในนี้จะทำงานเมื่อผู้ใช้กดปุ่ม
});

แปลว่า "ให้ปุ่มนี้รอฟังเหตุการณ์ (event) click ถ้าผู้ใช้กดปุ่ม ให้ทำงานที่อยู่ใน function นี้" โค้ดในวงเล็บปีกกาจะยังไม่ทำงานตอนโหลดหน้า แต่จะทำงานทุกครั้งที่มีการคลิก ส่วนบรรทัดที่ขึ้นต้นด้วย // คือ comment เป็นโน้ตสำหรับคนอ่าน browser จะข้ามไป

เปลี่ยนข้อความ

summary.textContent = "ข้อความใหม่";

แปลว่า "เปลี่ยนข้อความของ element summary ให้เป็นข้อความใหม่" เครื่องหมาย = ในที่นี้คือการกำหนดค่า ไม่ใช่การเปรียบเทียบ ในโค้ดจริงเราขึ้นบรรทัดใหม่หลัง = แค่เพราะข้อความยาว ผลลัพธ์เหมือนกัน

สรุปเป็นภาษาคน

  1. ไปหาข้อความที่เราต้องการเปลี่ยน
  2. ไปหาปุ่มที่ผู้ใช้จะกด
  3. ถ้าผู้ใช้กดปุ่ม
  4. ให้เปลี่ยนข้อความ

สี่ขั้นนี้คือพื้นฐานของ interaction บนหน้าเว็บ แทบทุกปุ่มที่คุณเคยกดบนเว็บทำงานด้วยแนวคิดเดียวกัน

HTML และ JavaScript เชื่อมกันตรงไหน

ใน index.html ใน script.js
<p id="summary"> document.getElementById("summary")
<button id="toggleButton"> document.getElementById("toggleButton")
<script src="script.js"></script> ทำให้โค้ดทั้งไฟล์นี้ถูกโหลดและรัน

ควรได้ผลลัพธ์แบบนี้

ก่อนกด การ์ดแสดงข้อความแนะนำตัวเดิม พอกดปุ่ม ดูเป้าหมายของฉัน ข้อความจะเปลี่ยนเป็น เป้าหมายของฉันคือการสร้างโปรเจกต์จริง เข้าใจพื้นฐาน Full-Stack และเตรียม Portfolio สำหรับสมัครงานสาย Developer ทันทีโดยไม่ต้อง refresh หน้า (ถ้า refresh ข้อความจะกลับเป็นแบบเดิม เพราะ browser โหลด HTML ใหม่)

ไม่ต้องกังวลถ้ายังจำ addEventListener ไม่ได้ทั้งหมด สิ่งที่สำคัญกว่าคือเข้าใจว่า JavaScript สามารถ "จับ element" และ "ตอบสนองต่อ action ของผู้ใช้" ได้ syntax จะค่อย ๆ คุ้นเองเมื่อเห็นซ้ำและฝึกบ่อยขึ้น อ่านเพิ่มได้ที่ MDN: addEventListener และ textContent

JavaScript เข้มงวดเรื่องสะกดมาก getElementById ต้องเป็น Id (I ใหญ่ d เล็ก) ไม่ใช่ ID, addEventListener ต้องมี L ใหญ่ และข้อความต้องอยู่ในเครื่องหมายคำพูด "..." ครบคู่ ถ้ากดแล้วไม่เกิดอะไร ให้ไล่เช็กจุดเหล่านี้ และดูวิธีหาสาเหตุเพิ่มเติมในบทถัดไป

ก่อนไปบทถัดไป เช็กว่า

  • กดปุ่มแล้วข้อความแนะนำตัวเปลี่ยนเป็นข้อความเป้าหมาย
  • อธิบายได้ว่า getElementById, addEventListener และ textContent แต่ละตัวทำอะไร
  • ชี้ได้ว่า id ใน script.js ตรงกับ id ตัวไหนใน index.html
ก่อนหน้า: ตกแต่งการ์ด ข้อความ และปุ่ม สารบัญบทเรียน ถัดไป: ปรับให้เป็นของตัวเอง และรับมือกับ Error
