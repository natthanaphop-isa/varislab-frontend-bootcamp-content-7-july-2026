บทเรียน 03 · โครงสร้างด้วย HTML (HTML Structure)

โครงของเอกสาร HTML

HTML Document Structure

เมื่อจบบทนี้ คุณจะสามารถ

  • เขียนโครงพื้นฐานของไฟล์ HTML ได้ครบ
  • อธิบายความต่างระหว่าง <head> กับ <body>
  • เชื่อมไฟล์ CSS เข้ากับหน้าเว็บด้วย <link>

HTML ทำหน้าที่อะไร

HTML มีหน้าที่สร้างโครงสร้างของหน้าเว็บ หรือพูดง่าย ๆ คือบอก browser ว่า "ในหน้านี้มีอะไรบ้าง" HTML เขียนด้วย tag ซึ่งอยู่ในวงเล็บมุม เช่น <p> ส่วนใหญ่มาเป็นคู่ มี tag เปิดและ tag ปิด (tag ปิดมี / นำหน้า) และเนื้อหาจะอยู่ตรงกลาง:

<p>นี่คือข้อความหนึ่งย่อหน้า</p>

tag เปิด + เนื้อหา + tag ปิด รวมกันเรียกว่า element คำนี้จะเจอบ่อยมากตลอดคอร์ส

เขียนโครงของไฟล์ index.html

เปิดไฟล์ index.html ที่สร้างไว้ แล้วพิมพ์โค้ดด้านล่าง แนะนำให้พิมพ์เองทีละส่วน แทนการ copy ทั้งก้อน เพราะมือจะเริ่มคุ้นกับ syntax ไปพร้อมกัน

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Professional Profile Card</title>
    <link rel="stylesheet" href="style.css" />
  </head>

  <body>
  </body>
</html>

<body> ยังว่างอยู่ เนื้อหาของการ์ดเราจะใส่กันในบทถัดไป ตอนนี้มาทำความเข้าใจทีละบรรทัดก่อน

อ่านโค้ดทีละส่วน

<!DOCTYPE html>

บรรทัดแรกของไฟล์ บอก browser ว่าเอกสารนี้เป็น HTML สมัยใหม่ (HTML5) ใส่ไว้บนสุดเสมอ

<html lang="th">

element ที่ครอบทุกอย่างในหน้า ส่วน lang="th" บอกว่าภาษาหลักของเนื้อหาเป็นภาษาไทย ข้อความ lang="th" แบบนี้เรียกว่า attribute คือข้อมูลเพิ่มเติมที่เขียนไว้ใน tag เปิด ในรูปแบบ ชื่อ="ค่า"

<head>

เก็บข้อมูลเกี่ยวกับหน้าเว็บ ที่ผู้ใช้ไม่ได้เห็นเป็นเนื้อหาโดยตรง เช่น ชื่อหน้า การตั้งค่า และการเชื่อมไฟล์ CSS:

  • <meta charset="UTF-8" /> — ตั้งค่าการเข้ารหัสตัวอักษร ทำให้ภาษาไทยแสดงผลถูกต้อง ไม่เป็นตัวอักษรเพี้ยน
  • <meta name="viewport" ... /> — ทำให้หน้าเว็บปรับขนาดตามความกว้างหน้าจอ เช่น บนมือถือ
  • <title>Professional Profile Card</title> — ชื่อหน้าที่จะไปโผล่บนแท็บของ browser
  • <link rel="stylesheet" href="style.css" /> — เชื่อมไฟล์ style.css เข้ามา ถ้าไม่มีบรรทัดนี้ CSS ที่เราจะเขียนจะไม่มีผลกับหน้าเว็บเลย

<body>

ทุกอย่างที่อยู่ใน <body> คือสิ่งที่ผู้ใช้เห็นจริงบนหน้าเว็บ การ์ดของเราทั้งใบจะอยู่ในส่วนนี้

ส่วน เก็บอะไร ผู้ใช้เห็นบนหน้าจอไหม
<head> ข้อมูลเกี่ยวกับหน้า การตั้งค่า การเชื่อมไฟล์ CSS ไม่เห็นเป็นเนื้อหา (ยกเว้น title บนแท็บ)
<body> เนื้อหาของหน้า เช่น หัวข้อ ข้อความ ปุ่ม เห็น

สังเกตว่าบางบรรทัดอย่าง <meta ... /> และ <link ... /> ไม่มี tag ปิดแยก เพราะเป็น element ที่ไม่มีเนื้อหาข้างใน ส่วนการย่อหน้า (indent) ช่วยให้คนอ่านโค้ดเห็นว่าอะไรอยู่ข้างในอะไร browser ไม่ได้บังคับ แต่ควรทำให้เป็นนิสัย

ลืมปิด tag หรือปิดผิดลำดับเป็นความผิดพลาดที่เจอบ่อย เช่น เปิด <head> แล้วลืม </head> ให้เช็กว่า tag ที่เปิดทีหลังต้องปิดก่อนเสมอ

ควรได้ผลลัพธ์แบบนี้

Save ไฟล์ แล้ว refresh browser หน้าเว็บยังว่างเปล่า (เพราะ <body> ยังไม่มีเนื้อหา) แต่แท็บของ browser จะแสดงชื่อ Professional Profile Card

ก่อนไปบทถัดไป เช็กว่า

  • แท็บ browser แสดงชื่อ Professional Profile Card
  • ใน <head> มีบรรทัด <link rel="stylesheet" href="style.css" /> และชื่อไฟล์สะกดตรงกับไฟล์จริง
  • tag ทุกตัวที่เปิดไว้ถูกปิดครบ
