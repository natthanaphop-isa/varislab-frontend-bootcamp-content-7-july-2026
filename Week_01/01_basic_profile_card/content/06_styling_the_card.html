บทเรียน 06 · ตกแต่งด้วย CSS (Styling with CSS)

ตกแต่งการ์ด ข้อความ และปุ่ม

Styling the Card

เมื่อจบบทนี้ คุณจะสามารถ

  • ตกแต่งการ์ดด้วยความกว้าง padding มุมโค้ง และเงา
  • จัดรูปแบบข้อความด้วยสี ขนาด น้ำหนัก และระยะบรรทัด
  • ตกแต่งปุ่มและเพิ่มเอฟเฟกต์ตอน hover ด้วย button:hover

ตกแต่งตัวการ์ด

ต่อท้ายไฟล์ style.css ด้วยกฎของการ์ด:

.profile-card {
  width: 460px;
  padding: 32px;
  border-radius: 24px;
  background: #1e293b;
  box-shadow: 0 24px 60px rgba(0, 0, 0, 0.35);
}

จุดข้างหน้า .profile-card แปลว่าเรากำลังเลือก class ชื่อ profile-card ซึ่งมาจาก <main class="profile-card"> ใน HTML

  • width: 460px — การ์ดกว้าง 460 pixel
  • padding: 32px — ระยะห่างระหว่างขอบการ์ดกับเนื้อหาข้างใน
  • border-radius: 24px — ทำมุมการ์ดให้โค้ง
  • background: #1e293b — สีการ์ดที่สว่างกว่าพื้นหลังหน้าเล็กน้อย จึงดูแยกออกมา
  • box-shadow: 0 24px 60px rgba(0, 0, 0, 0.35) — เงาใต้การ์ด ค่าตามลำดับคือ เลื่อนแนวนอน 0, เลื่อนลง 24px, ความฟุ้ง 60px และสีดำโปร่งแสง 35%

ตกแต่งข้อความ

.label {
  color: #38bdf8;
  font-weight: bold;
  letter-spacing: 0.04em;
  text-transform: uppercase;
}

h1 {
  margin: 16px 0;
  font-size: 32px;
}

#summary {
  color: #cbd5e1;
  font-size: 18px;
  line-height: 1.7;
}

.label

ตัวหนังสือสีฟ้า (#38bdf8) ตัวหนา (font-weight: bold) เว้นระยะห่างระหว่างตัวอักษรนิดหน่อย (letter-spacing) และแปลงเป็นตัวพิมพ์ใหญ่ทั้งหมด (text-transform: uppercase) สังเกตว่าใน HTML เราพิมพ์ Aspiring Software Developer แบบปกติ แต่บนจอจะเห็นเป็น ASPIRING SOFTWARE DEVELOPER เพราะ CSS เปลี่ยนแค่การแสดงผล ไม่ได้แก้ข้อความจริง

h1

selector ที่เป็นชื่อ tag ตรง ๆ margin: 16px 0 คือระยะห่างด้านบนและล่าง 16px ด้านซ้ายขวา 0 และ font-size: 32px กำหนดขนาดตัวอักษร

#summary

เครื่องหมาย # แปลว่าเลือก id ชื่อ summary ซึ่งมาจาก <p id="summary"> ใช้สีเทาอ่อน (#cbd5e1) ให้ดูรองลงมาจากหัวข้อ ขนาด 18px และ line-height: 1.7 เพิ่มระยะห่างระหว่างบรรทัดให้อ่านสบาย

ตกแต่งปุ่ม

button {
  margin-top: 24px;
  border: none;
  border-radius: 999px;
  padding: 12px 24px;
  background: #38bdf8;
  color: #0f172a;
  font-size: 16px;
  font-weight: bold;
  cursor: pointer;
}

button:hover {
  background: #7dd3fc;
}
  • margin-top: 24px — เว้นระยะเหนือปุ่ม ไม่ให้ชิดข้อความ
  • border: none — เอาเส้นขอบเริ่มต้นของปุ่มออก
  • border-radius: 999px — ใส่ค่าโค้งมาก ๆ ทำให้ปุ่มกลายเป็นทรงแคปซูล
  • padding: 12px 24px — ระยะในปุ่ม บน-ล่าง 12px ซ้าย-ขวา 24px
  • background สีฟ้าเดียวกับ label และ color สีเข้มเดียวกับพื้นหลังหน้า ให้ตัวหนังสือบนปุ่มอ่านง่าย
  • cursor: pointer — เปลี่ยนเคอร์เซอร์เป็นรูปมือเมื่อชี้ปุ่ม บอกผู้ใช้ว่ากดได้

button:hover คือกฎที่มีผลเฉพาะตอนเอาเมาส์ไปชี้ปุ่ม (:hover เรียกว่า pseudo-class) ในที่นี้เปลี่ยนพื้นหลังเป็นสีฟ้าอ่อนลง ผู้ใช้จะรู้สึกว่าปุ่มตอบสนอง

ไฟล์ style.css ฉบับเต็ม

เมื่อรวมกับบทที่แล้ว ไฟล์ style.css ทั้งไฟล์ควรเป็นแบบนี้:

* {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100vh;
  font-family: Arial, sans-serif;
  background: #0f172a;
  color: white;
  display: flex;
  justify-content: center;
  align-items: center;
}

.profile-card {
  width: 460px;
  padding: 32px;
  border-radius: 24px;
  background: #1e293b;
  box-shadow: 0 24px 60px rgba(0, 0, 0, 0.35);
}

.label {
  color: #38bdf8;
  font-weight: bold;
  letter-spacing: 0.04em;
  text-transform: uppercase;
}

h1 {
  margin: 16px 0;
  font-size: 32px;
}

#summary {
  color: #cbd5e1;
  font-size: 18px;
  line-height: 1.7;
}

button {
  margin-top: 24px;
  border: none;
  border-radius: 999px;
  padding: 12px 24px;
  background: #38bdf8;
  color: #0f172a;
  font-size: 16px;
  font-weight: bold;
  cursor: pointer;
}

button:hover {
  background: #7dd3fc;
}

ควรได้ผลลัพธ์แบบนี้

การ์ดสีน้ำเงินเข้มมุมโค้งมีเงา วางอยู่กลางจอ ด้านบนมี label ตัวพิมพ์ใหญ่สีฟ้า ตามด้วยชื่อตัวใหญ่สีขาว ข้อความแนะนำตัวสีเทาอ่อน และปุ่มทรงแคปซูลสีฟ้า เมื่อเอาเมาส์ชี้ปุ่ม สีจะอ่อนลงและเคอร์เซอร์เป็นรูปมือ แต่กดแล้วก็ยังไม่เกิดอะไรขึ้น

ถ้า refresh แล้วหน้าตาไม่เปลี่ยนเลยแม้แต่จุดเดียว ให้เช็กว่า save style.css แล้วหรือยัง และบรรทัด <link rel="stylesheet" href="style.css" /> ใน index.html สะกดชื่อไฟล์ตรงกับไฟล์จริงไหม ถ้าบางกฎทำงานแต่บางกฎไม่ทำงาน ให้เช็กว่า selector สะกดตรงกับ class/id ใน HTML และมีปีกกาปิดครบ

ก่อนไปบทถัดไป เช็กว่า

  • การ์ดอยู่กลางจอ มีมุมโค้งและเงา
  • label แสดงเป็นตัวพิมพ์ใหญ่สีฟ้า
  • ปุ่มเปลี่ยนสีตอนเอาเมาส์ชี้
  • ลองแก้ค่าอย่างน้อยหนึ่งค่า (เช่น border-radius หรือสีของปุ่ม) แล้วเห็นผลที่เปลี่ยนไป
ก่อนหน้า: พื้นฐาน CSS และการจัดพื้นหลัง สารบัญบทเรียน ถัดไป: ทำให้ปุ่มทำงานด้วย JavaScript
