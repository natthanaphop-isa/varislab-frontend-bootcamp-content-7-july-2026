บทเรียน 04 · โครงสร้างด้วย HTML (HTML Structure)

สร้างเนื้อหาของการ์ด

Building the Card Content

เมื่อจบบทนี้ คุณจะสามารถ

  • ใส่ element ของการ์ดลงใน <body> ได้ครบ
  • อธิบายความต่างระหว่าง class กับ id
  • เชื่อมไฟล์ script.js เข้ากับหน้าเว็บ และรู้ว่าทำไมต้องวางไว้ท้าย <body>

เติมเนื้อหาลงใน body

ต่อจากบทที่แล้ว ใส่โค้ดของการ์ดลงไปใน <body> ไฟล์ index.html ทั้งไฟล์จะเป็นแบบนี้:

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Professional Profile Card</title>
    <link rel="stylesheet" href="style.css" />
  </head>

  <body>
    <main class="profile-card">
      <p class="label">Aspiring Software Developer</p>

      <h1>สวัสดีครับ ผมชื่อ Varis</h1>

      <p id="summary">
        ผมกำลังเริ่มต้นเส้นทางสู่สายงาน Software Developer
        และกำลังเรียนรู้พื้นฐานการสร้าง Web Application
      </p>

      <button id="toggleButton">
        ดูเป้าหมายของฉัน
      </button>
    </main>

    <script src="script.js"></script>
  </body>
</html>

ตอนนี้พิมพ์ตามตัวอย่างไปก่อน รวมถึงชื่อ Varis ได้เลย ในบทที่ 08 เราจะมาเปลี่ยนชื่อ label และข้อความให้เป็นของคุณเอง

อ่านโค้ดทีละส่วน

<main class="profile-card">

<main> คือพื้นที่เนื้อหาหลักของหน้า ในโปรเจกต์นี้เราใช้มันเป็นตัวการ์ดที่ครอบทุกอย่างไว้ และตั้ง class ชื่อ profile-card เพื่อให้ CSS ตามมาตกแต่งได้ในภายหลัง

<p class="label">

<p> คือ paragraph หรือย่อหน้าข้อความ อันนี้เป็นข้อความเล็ก ๆ บอกเป้าหมายด้านบนการ์ด ตั้ง class ชื่อ label เพื่อให้ CSS ทำให้มันเด่นต่างจากข้อความอื่น

<h1>

หัวข้อที่สำคัญที่สุดของหน้า ใช้สำหรับชื่อของเรา

<p id="summary">

ข้อความแนะนำตัว ตั้ง id ชื่อ summary เพราะในบทที่ 07 JavaScript จะกลับมาหาข้อความนี้แล้วเปลี่ยนมันเมื่อผู้ใช้กดปุ่ม

<button id="toggleButton">

ปุ่มที่ผู้ใช้กดได้ ตั้ง id ชื่อ toggleButton เพื่อให้ JavaScript รู้ว่าปุ่มไหนคือปุ่มที่ต้องรอฟังการคลิก

<script src="script.js"></script>

บรรทัดนี้เชื่อมไฟล์ JavaScript เข้ามาในหน้าเว็บ ถ้าไม่มีบรรทัดนี้ ต่อให้เขียน JavaScript ใน script.js ถูกทั้งหมด ปุ่มก็จะไม่ทำงาน เพราะ HTML ไม่ได้โหลดไฟล์นั้นเข้ามา

เราวาง <script> ไว้ท้าย <body> หลังการ์ด เพราะ browser อ่าน HTML จากบนลงล่าง เมื่อถึงบรรทัด script การ์ดและปุ่มถูกสร้างเสร็จแล้ว JavaScript จึงหา element เหล่านั้นเจอ

class กับ id ต่างกันอย่างไร

ทั้งคู่เป็น attribute ที่ใช้ "ตั้งชื่อ" ให้ element เพื่อให้ CSS หรือ JavaScript อ้างถึงได้ แต่ใช้ต่างกันแบบนี้:

class id
ความหมาย กลุ่ม/ประเภทของ element ชื่อเฉพาะของ element ตัวเดียว
ใช้ซ้ำในหน้าเดียวกันได้ไหม ได้ หลาย element ใช้ class เดียวกันได้ ไม่ควร หนึ่งหน้าควรมี id นั้นแค่ตัวเดียว
ในโปรเจกต์นี้ profile-card, label — ให้ CSS ตกแต่ง summary, toggleButton — ให้ JavaScript หาเจอแบบเจาะจง

ชื่อ id และ class สะกดตัวพิมพ์เล็ก-ใหญ่ต้องตรงกันทุกที่ toggleButton กับ togglebutton ถือเป็นคนละชื่อ ถ้าพิมพ์ไม่ตรงกับที่ CSS หรือ JavaScript ใช้ จะหา element ไม่เจอ

ควรได้ผลลัพธ์แบบนี้

Save แล้ว refresh browser จะเห็นข้อความ Aspiring Software Developer หัวข้อตัวใหญ่ สวัสดีครับ ผมชื่อ Varis ข้อความแนะนำตัว และปุ่ม ดูเป้าหมายของฉัน ทั้งหมดเป็นตัวหนังสือดำบนพื้นขาวแบบเรียบ ๆ และกดปุ่มแล้วยังไม่เกิดอะไรขึ้น

นี่คือสิ่งที่ควรเห็นภาพให้ชัด: HTML ยังไม่ได้ทำให้เว็บสวย และยังไม่ได้ทำให้ปุ่มทำงาน HTML แค่บอกว่า "ในหน้านี้มีอะไรบ้าง" บทถัดไปเราจะใช้ CSS ทำให้มันดูดีขึ้น

ก่อนไปบทถัดไป เช็กว่า

  • หน้าเว็บแสดง label, ชื่อ, ข้อความแนะนำตัว และปุ่มครบ
  • ข้อความแนะนำตัวมี id="summary" และปุ่มมี id="toggleButton"
  • มีบรรทัด <script src="script.js"></script> อยู่ก่อน </body>
ก่อนหน้า: โครงของเอกสาร HTML สารบัญบทเรียน ถัดไป: พื้นฐาน CSS และการจัดพื้นหลัง
