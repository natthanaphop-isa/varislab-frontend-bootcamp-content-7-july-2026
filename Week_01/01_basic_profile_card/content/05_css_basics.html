พื้นฐาน CSS และการจัดพื้นหลัง

CSS Basics

เมื่อจบบทนี้ คุณจะสามารถ

  • อ่านและเขียนกฎ CSS ในรูปแบบ selector { property: value; }
  • เลือก element ด้วยชื่อ tag, class (.) และ id (#)
  • ตั้งพื้นหลังของหน้าและจัดการ์ดให้อยู่กลางจอ

CSS คืออะไร

ตอนนี้หน้าเว็บเรามีโครงสร้างแล้ว แต่ยังดูธรรมดามาก CSS คือภาษาที่ใช้บอก browser ว่า element แต่ละตัวควรแสดงผลอย่างไร เช่น สี พื้นหลัง ระยะห่าง ขนาดตัวอักษร และรูปทรงของการ์ด

ไฟล์ style.css มีผลกับหน้าเว็บได้เพราะบรรทัด <link rel="stylesheet" href="style.css" /> ที่เราใส่ไว้ใน <head> ตั้งแต่บทที่ 03

รูปแบบของกฎ CSS

CSS ทุกกฎมี pattern หลักแบบเดียวกัน:

selector {
  property: value;
}
  • selector — สิ่งที่เราต้องการเลือก (element ไหน)
  • property — คุณสมบัติที่ต้องการเปลี่ยน (เช่น สีพื้นหลัง)
  • value — ค่าที่กำหนดให้คุณสมบัตินั้น

ตัวอย่าง:

body {
  background: #0f172a;
  color: white;
}

แปลว่า "เลือก body แล้วกำหนดพื้นหลังเป็นสีเข้ม และตัวหนังสือเป็นสีขาว" ค่า #0f172a คือรหัสสีแบบ hex ส่วน white คือชื่อสีที่ CSS รู้จัก

ทุกบรรทัด property: value ต้องปิดท้ายด้วย ; และทุกกฎต้องมีวงเล็บปีกกา { } ครบคู่ ถ้าลืมปีกกาปิดตัวเดียว กฎที่อยู่ถัดจากนั้นอาจไม่ทำงานทั้งหมด

เลือก element ด้วย tag, class และ id

แบบ ตัวอย่าง selector เลือกอะไรใน HTML
ชื่อ tag body, h1, button ทุก element ที่เป็น tag นั้น
class (ขึ้นต้นด้วย .) .profile-card <main class="profile-card">
id (ขึ้นต้นด้วย #) #summary <p id="summary">

จำแบบง่าย ๆ ก่อน: . ใช้เลือก class และ # ใช้เลือก id (ใน HTML เราเขียนแค่ชื่อ ไม่ต้องมีจุดหรือ # นำหน้า)

เริ่มเขียน style.css

เปิดไฟล์ style.css แล้วเขียนสองกฎแรกนี้:

* {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100vh;
  font-family: Arial, sans-serif;
  background: #0f172a;
  color: white;
  display: flex;
  justify-content: center;
  align-items: center;
}

กฎ *

* คือ selector ที่เลือกทุก element ในหน้า box-sizing: border-box ทำให้ความกว้างที่เรากำหนดรวม padding และเส้นขอบไว้แล้ว เช่น การ์ดกว้าง 460px ก็จะกว้าง 460px จริง ๆ แม้จะมี padding ข้างใน ทำให้คำนวณขนาดง่ายขึ้น

กฎ body

  • margin: 0 — ลบระยะขอบที่ browser ใส่ให้ body โดยอัตโนมัติ
  • min-height: 100vh — ให้ body สูงอย่างน้อยเต็มความสูงหน้าจอ (vh คือ % ของความสูงหน้าจอ)
  • font-family: Arial, sans-serif — ใช้ฟอนต์ Arial ถ้าเครื่องไม่มีให้ใช้ฟอนต์ sans-serif แทน
  • background: #0f172a และ color: white — พื้นหลังสีน้ำเงินเข้มเกือบดำ ตัวหนังสือสีขาว
  • display: flex, justify-content: center, align-items: center — สามบรรทัดนี้ทำงานร่วมกันเพื่อจัดการ์ดให้อยู่กลางจอ ทั้งแนวนอนและแนวตั้ง (เรื่อง flexbox จะได้ลงลึกภายหลัง ตอนนี้ขอแค่รู้ว่ามันจัดให้อยู่ตรงกลาง)

ควรได้ผลลัพธ์แบบนี้

Save แล้ว refresh browser พื้นหลังทั้งหน้าจะเป็นสีเข้ม ตัวหนังสือเป็นสีขาว และเนื้อหาของการ์ดย้ายมาอยู่กลางจอ

ลองเล่น: เปลี่ยนสีพื้นหลัง

วิธีเรียน CSS ที่ดีที่สุดคือแก้ค่า แล้วดูผลลัพธ์บนหน้าจอ ลองเปลี่ยนค่าพื้นหลังของ body จาก:

background: #0f172a;

เป็นสีอื่น เช่น background: darkgreen; หรือรหัสสีที่คุณชอบ แล้ว save และ refresh ดูว่าหน้าเว็บเปลี่ยนอย่างไร ลองเสร็จแล้วจะเปลี่ยนกลับเป็น #0f172a หรือเก็บสีของคุณไว้ก็ได้

ยังไม่ต้องจำ CSS ทุก property ได้ทั้งหมด ขอให้เข้าใจว่า CSS คือ "การเลือก element แล้วบอกว่ามันควรหน้าตาเป็นอย่างไร" ถ้าอยากรู้ว่า property ไหนทำอะไร เปิดดูได้ที่ MDN CSS

ก่อนไปบทถัดไป เช็กว่า

  • พื้นหลังหน้าเว็บเป็นสีเข้ม และเนื้อหาอยู่กลางจอ
  • อธิบายได้ว่า selector, property และ value คืออะไร
  • บอกได้ว่า .profile-card กับ #summary เลือก element ไหนใน HTML
