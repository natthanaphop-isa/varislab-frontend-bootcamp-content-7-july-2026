บทเรียน 02 · ภาพรวมก่อนเริ่ม (Getting Started)

ดูผลลัพธ์และสร้างโปรเจกต์แรก

Project Preview & Setup

เมื่อจบบทนี้ คุณจะสามารถ

  • บอกได้ว่า Profile Card ที่จะสร้างประกอบด้วยอะไรบ้าง
  • สร้างโฟลเดอร์โปรเจกต์และไฟล์ 3 ไฟล์ใน Cursor หรือ VS Code
  • อธิบายได้ว่าไฟล์ index.html, style.css และ script.js มีหน้าที่อะไร

สิ่งที่เรากำลังจะสร้าง

ผลลัพธ์ของคอร์สนี้คือการ์ดแนะนำตัวหนึ่งใบ วางอยู่กลางหน้าจอบนพื้นหลังสีเข้ม ในการ์ดมี:

  • Label บอกเป้าหมาย เช่น Aspiring Software Developer
  • ชื่อของเรา เป็นหัวข้อตัวใหญ่
  • ข้อความแนะนำตัว สั้น ๆ
  • ปุ่ม หนึ่งปุ่ม
  • เมื่อกดปุ่ม ข้อความแนะนำตัวจะเปลี่ยนเป็นข้อความบอกเป้าหมาย

นี่ยังไม่ใช่ระบบใหญ่ แต่ concept ข้างในคือพื้นฐานของเว็บจริง และการ์ดแบบนี้ต่อยอดไปเป็นหน้า Portfolio, หน้าโปรไฟล์ผู้สมัครงาน, หน้าแนะนำคอร์ส หรือส่วนหนึ่งของระบบจริงได้ เราจะค่อย ๆ สร้างมันขึ้นมาจากไฟล์ว่าง ๆ

สร้างโฟลเดอร์โปรเจกต์

เปิด Cursor หรือ VS Code แล้วสร้างโฟลเดอร์ใหม่ชื่อ:

professional-profile-card

จากนั้นเปิดโฟลเดอร์นี้ใน editor (เมนู File → Open Folder) เพื่อให้เห็นไฟล์ทั้งหมดของโปรเจกต์ในแถบด้านข้าง

สร้างไฟล์ 3 ไฟล์

ในโฟลเดอร์นี้ สร้างไฟล์ว่าง ๆ 3 ไฟล์ ให้ได้โครงแบบนี้:

professional-profile-card/
├── index.html   # โครงสร้างของหน้าเว็บ
├── style.css    # ตกแต่งหน้าตา
└── script.js    # ทำให้หน้าเว็บมี interaction
ไฟล์ ภาษา หน้าที่
index.html HTML โครงสร้าง — ในหน้านี้มีอะไรบ้าง
style.css CSS หน้าตา — สี ระยะห่าง ขนาด การจัดวาง
script.js JavaScript พฤติกรรม — กดปุ่มแล้วเกิดอะไรขึ้น

สะกดชื่อไฟล์ให้ตรงเป๊ะ ใช้ตัวพิมพ์เล็กทั้งหมด และระวังนามสกุลไฟล์ เช่น style.css ไม่ใช่ styles.css หรือ style.css.txt เพราะในบทต่อ ๆ ไป HTML จะอ้างถึงไฟล์เหล่านี้ด้วยชื่อ ถ้าชื่อไม่ตรง browser จะหาไฟล์ไม่เจอ

เปิดหน้าเว็บใน browser

ไฟล์ index.html คือหน้าเว็บที่เราจะเปิดดูใน browser วิธีง่ายที่สุดคือไปที่โฟลเดอร์โปรเจกต์ในเครื่อง แล้วดับเบิลคลิกไฟล์ index.html (หรือลากไฟล์ไปวางในหน้าต่าง browser) ตอนนี้ไฟล์ยังว่างอยู่ หน้าจอจึงว่างเปล่า เดี๋ยวบทถัดไปเราจะเริ่มเติมเนื้อหากัน

รูปแบบการทำงานที่เราจะใช้ตลอดคอร์สคือ แก้โค้ด → Save ไฟล์ → Refresh browser → ดูผลลัพธ์ ทำซ้ำไปเรื่อย ๆ ถ้าแก้แล้วหน้าเว็บไม่เปลี่ยน ให้นึกถึงลำดับนี้ก่อนเสมอ

ก่อนไปบทถัดไป เช็กว่า

  • มีโฟลเดอร์ professional-profile-card เปิดอยู่ใน editor
  • ในโฟลเดอร์มีไฟล์ index.html, style.css และ script.js ครบ ชื่อสะกดถูก
  • เปิด index.html ใน browser ได้ (ตอนนี้หน้าว่างเป็นเรื่องปกติ)
