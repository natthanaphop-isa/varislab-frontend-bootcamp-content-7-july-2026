บทเรียน 08 · JavaScript และก้าวต่อไป (Interaction & Wrap Up)

ปรับให้เป็นของตัวเอง และรับมือกับ Error

Mini Challenge & Debugging

เมื่อจบบทนี้ คุณจะสามารถ

  • แก้ HTML, CSS และ JavaScript เพื่อปรับการ์ดให้เป็นของตัวเอง
  • ไล่เช็กสาเหตุพื้นฐานเมื่อแก้แล้วหน้าเว็บไม่เปลี่ยน
  • รู้จักและแก้ error ที่เจอบ่อย: id ไม่ตรงกัน และลืมเชื่อม script.js

Mini Challenge: ทำให้เป็นการ์ดของคุณ

ถึงเวลาลงมือแก้เอง เป้าหมายยังไม่ใช่ความ perfect แต่คือลองแก้โค้ดแล้วดูผลลัพธ์ ใช้เวลาประมาณ 10 นาที ทำ 4 อย่างนี้:

  1. เปลี่ยนชื่อใน <h1> เป็นชื่อของคุณ
  2. เปลี่ยน label เป็นเป้าหมายของคุณ เช่น Aspiring Frontend Developer
  3. เปลี่ยนข้อความใน <p id="summary"> เป็นประโยคแนะนำตัวของคุณ
  4. เปลี่ยนข้อความที่แสดงหลังจากกดปุ่ม (ใน script.js)

ถ้าทำเสร็จเร็ว ลองเปลี่ยนสีการ์ด (background ใน .profile-card) หรือสีปุ่ม (background ใน button และ button:hover) ด้วย

ข้อ 1–3 แก้ที่ index.html, ข้อ 4 แก้ที่ script.js และเรื่องสีแก้ที่ style.css การรู้ว่า "อยากเปลี่ยนอะไร ต้องไปแก้ไฟล์ไหน" คือการใช้ภาพ HTML = โครงสร้าง, CSS = หน้าตา, JavaScript = พฤติกรรม ในงานจริง

แก้แล้วหน้าเว็บไม่เปลี่ยน? เช็ก 3 อย่างนี้ก่อน

  1. Save ไฟล์แล้วหรือยัง — ใน editor แท็บของไฟล์ที่ยังไม่ save มักมีจุดหรือเครื่องหมายแสดงอยู่
  2. Refresh browser แล้วหรือยัง
  3. แก้ถูกไฟล์หรือเปล่า — เช่น เปิดไฟล์ในโฟลเดอร์อื่นอยู่ หรือแก้ CSS แต่ไปแก้ในไฟล์ HTML

ถ้าเจอปัญหา ไม่ต้องตกใจ ให้ดูว่าแก้ตรงไหนล่าสุด แล้วผลลัพธ์เปลี่ยนไปอย่างไร แก้ทีละจุดแล้วดูผลลัพธ์ นี่คือ process จริงของ Developer

ฝึกรับมือ Error ด้วยการทำให้พังเอง

เวลาทำงานเอง สิ่งที่เจอแน่นอนคือ error หรือบางครั้งกดแล้วไม่เกิดอะไรขึ้นเลย การเจอ error ไม่ใช่เรื่องแปลก สิ่งสำคัญคือค่อย ๆ ไล่ว่าปัญหาน่าจะอยู่ตรงไหน วิธีฝึกที่ดีคือตั้งใจทำให้พัง แล้วสังเกตอาการ เมื่อเจอของจริงจะจำได้ทันที

Error 1: id ไม่ตรงกัน

ใน script.js ลองแก้บรรทัดแรกจาก:

const summary = document.getElementById("summary");

เป็น:

const summary = document.getElementById("summaries");

Save, refresh แล้วลองกดปุ่ม

เกิดอะไรขึ้น: ข้อความไม่เปลี่ยน เพราะ JavaScript พยายามหา element ที่มี id ชื่อ summaries แต่ใน HTML มีแค่ id ชื่อ summary จึงหาไม่เจอ

วิธีแก้: กลับไปเช็กว่า id หรือ class ใน HTML สะกดตรงกับที่เขียนใน JavaScript ไหม แล้วแก้กลับเป็น "summary"

อยากเห็นว่า browser บอกอะไรเราบ้าง? เปิด Developer Tools ของ browser (คลิกขวาบนหน้าเว็บ → Inspect แล้วไปที่แท็บ Console) ขณะที่ id ยังผิดอยู่แล้วลองกดปุ่ม จะเห็นข้อความ error สีแดงเกี่ยวกับการตั้งค่า textContent ให้กับค่า null ซึ่งแปลว่า "หา element ไม่เจอ" การอ่าน Console เป็นทักษะที่จะใช้ไปตลอด

Error 2: ลืมเชื่อม script.js

ใน index.html ลองลบ (หรือ comment) บรรทัดนี้ออก:

<script src="script.js"></script>

ถ้าจะ comment ใน HTML ให้ครอบด้วย <!-- --> แบบนี้:

<!-- <script src="script.js"></script> -->

Save, refresh แล้วลองกดปุ่ม

เกิดอะไรขึ้น: ปุ่มไม่ทำงาน เพราะ HTML ไม่ได้โหลดไฟล์ JavaScript เข้ามา ต่อให้โค้ดใน script.js ถูกทั้งหมด browser ก็ไม่รู้ว่าต้องรันมัน

วิธีแก้: ใส่บรรทัด <script src="script.js"></script> กลับไว้ก่อน </body>

หลักคิดเวลาอะไรไม่ทำงาน

  • ถ้า CSS ไม่ทำงาน → เช็กว่า <link> ที่เชื่อม CSS ถูกไหม
  • ถ้า JavaScript ไม่ทำงาน → เช็กว่า <script> ถูกโหลดเข้ามาไหม
  • ถ้ากดปุ่มแล้วไม่เกิดอะไร → เช็ก id และ event listener

ก่อนไปบทถัดไป เช็กว่า

  • การ์ดแสดงชื่อ label และข้อความแนะนำตัวของคุณเอง
  • กดปุ่มแล้วข้อความเปลี่ยนเป็นข้อความที่คุณเขียน
  • ลองทำ Error 1 และ Error 2 แล้ว และแก้กลับจนปุ่มทำงานปกติ
  • บอกได้ว่าถ้า CSS ไม่ทำงาน, JavaScript ไม่ทำงาน หรือกดปุ่มแล้วไม่เกิดอะไร ควรเช็กตรงไหนก่อน
ก่อนหน้า: ทำให้ปุ่มทำงานด้วย JavaScript สารบัญบทเรียน ถัดไป: สรุปบทเรียนและการบ้าน
