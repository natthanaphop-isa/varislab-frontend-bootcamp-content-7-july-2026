บทเรียน 01 · ภาพรวมก่อนเริ่ม (Getting Started)

หน้าเว็บประกอบขึ้นจากอะไร

What Is a Web Page

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายได้ว่าหน้าเว็บจริงถูกประกอบขึ้นจาก component เล็ก ๆ หลายชิ้น
  • บอกหน้าที่ของ HTML, CSS และ JavaScript ได้ด้วยประโยคสั้น ๆ
  • เข้าใจว่าทำไมเราเริ่มต้นด้วยการสร้าง Profile Card

ยินดีต้อนรับ

ก่อนเริ่ม ขอบอกไว้ก่อนเลยว่าคอร์สนี้ไม่ได้คาดหวังให้คุณจำ syntax ได้ทั้งหมดตั้งแต่วันแรก และไม่ได้คาดหวังให้เขียนโค้ดคล่องทันที หลายคนอาจมาจากสายงานอื่น ไม่เคยเขียนโค้ดมาก่อน หรือเคยลองเรียนเองแต่ยังต่อภาพรวมไม่ติด ไม่เป็นไรเลย

สิ่งสำคัญที่สุดในช่วงแรกไม่ใช่ความเร็ว แต่คือการเข้าใจภาพรวม และกล้าลงมือทำทีละขั้น ในคอร์สนี้เราจะโฟกัสแค่ 3 เรื่อง:

  1. หน้าเว็บมีโครงสร้างอย่างไร
  2. CSS ทำให้หน้าเว็บดูดีขึ้นอย่างไร
  3. JavaScript ทำให้หน้าเว็บตอบสนองกับผู้ใช้อย่างไร

เรื่องอย่าง React, Backend, Database หรือ AI Coding แบบเต็มรูปแบบยังไม่อยู่ในคอร์สนี้ เพราะก่อนจะใช้เครื่องมือเหล่านั้นได้ดี เราต้องเข้าใจก่อนว่าเว็บธรรมดาหนึ่งหน้าเกิดขึ้นได้อย่างไร

Web Page คืออะไร

ทุกครั้งที่เราเปิดเว็บ ไม่ว่าจะเป็นหน้า Login, หน้า Course, หน้า Product, หน้า Dashboard หรือหน้า Portfolio สิ่งที่เห็นบนจอคือ Web Page

เว็บจริงอาจดูซับซ้อนมาก แต่ถ้าแยกออกมาทีละชิ้น มันมักประกอบจากส่วนเล็ก ๆ หลายส่วนรวมกัน เช่น:

  • Header
  • Card
  • Button
  • Form
  • Menu
  • Table
  • Profile section
  • Product section

ส่วนเล็ก ๆ แต่ละชิ้นแบบนี้เรามักเรียกว่า component ในคอร์สนี้เราจะเริ่มจากชิ้นเล็กชิ้นเดียวก่อน คือ Profile Card เพราะ card เป็น component ที่เจอบ่อยมากในงานจริง ทั้งเว็บสมัครงาน เว็บคอร์สออนไลน์ ระบบ CRM หรือ Dashboard หลังบ้าน

HTML / CSS / JavaScript: สามส่วนที่ทำงานร่วมกัน

ภาพที่อยากให้จำติดตัวไปตลอดคอร์สนี้คือ:

HTML = โครงสร้าง
CSS = หน้าตา
JavaScript = พฤติกรรม

ถ้าเปรียบเทียบให้เห็นภาพ:

ภาษา เปรียบเหมือน ตัวอย่างกับ "ปุ่มหนึ่งปุ่ม"
HTML โครงกระดูกของหน้าเว็บ "มีปุ่มอยู่ตรงนี้"
CSS เสื้อผ้า สีสัน และการจัดวาง "ปุ่มนี้สีฟ้า มุมโค้ง ตัวหนังสือหนา"
JavaScript สมอง หรือพฤติกรรม "ถ้าผู้ใช้กดปุ่ม ให้เปลี่ยนข้อความบนหน้าเว็บ"

ในโปรเจกต์นี้เราจะได้ใช้ครบทั้ง 3 ส่วน แต่ในระดับที่ยังไม่ยากเกินไป และแต่ละส่วนจะอยู่ในไฟล์ของตัวเองแยกกันชัดเจน

ระหว่างทางถ้าเจอ error ไม่ต้องตกใจ Error เป็นเรื่องปกติของการเขียนโปรแกรม ทักษะที่เราจะฝึกไปด้วยกันคือการอ่านปัญหา วิเคราะห์ และแก้ทีละขั้น ซึ่งสำคัญกว่าการจำคำสั่งได้ทั้งหมด

เช็กความเข้าใจ

  • ลองมองเว็บที่คุณใช้บ่อย แล้วชี้ให้ได้อย่างน้อย 3 component (เช่น header, card, button)
  • อธิบายได้ว่า HTML, CSS และ JavaScript ต่างกันอย่างไร โดยใช้ตัวอย่าง "ปุ่มหนึ่งปุ่ม"
สารบัญบทเรียน ถัดไป: ดูผลลัพธ์และสร้างโปรเจกต์แรก
