Mini Challenge

Mini Challenges

เมื่อจบบทนี้ คุณจะสามารถ

  • ปรับข้อความในฟอร์มให้เป็นฟอร์มของตัวเอง
  • เพิ่มช่องกรอกใหม่ครบทั้ง 3 ชั้น: HTML, JavaScript อ่านค่า และ validation
  • ใช้ let กับ if สร้างข้อความที่เปลี่ยนไปตามค่าที่ผู้ใช้เลือก

ถึงเวลาลองเองแล้ว ทำ challenge ตามลำดับ เพราะแต่ละข้อต่อยอดจากข้อก่อนหน้า ถ้าติด ให้ย้อนกลับไปดู pattern ในบทที่ 2–7 — ทุกข้อใช้แค่สิ่งที่เราเรียนมาแล้ว ไม่ต้องกลัวพัง การทำให้พังแล้วค่อยแก้คือวิธีเรียนเขียนโค้ดที่ดีที่สุดวิธีหนึ่ง

Challenge 1: ทำให้เป็นฟอร์มของตัวเอง

เปลี่ยนข้อความในฟอร์ม (หัวข้อ, คำอธิบาย, label, placeholder, ข้อความในกล่องผลลัพธ์) ให้เป็นฟอร์มของคุณเอง เช่น:

  • Job Application Form
  • Portfolio Contact Form

เปลี่ยนแค่ข้อความที่ผู้ใช้เห็น อย่าเพิ่งเปลี่ยน id ถ้าจะเปลี่ยน id ต้องไปแก้ใน JavaScript ให้ตรงกันด้วย (จำ Error 2 จากบทที่แล้วได้ไหม)

Challenge 2: เพิ่มช่องใหม่ 1 ช่อง

เพิ่ม input ใหม่ เช่น email หรือ phone ใช้ pattern form-group + label + input เดิม และอย่าลืมให้ for ตรงกับ id

คำใบ้: สำหรับ email ลองใช้ type="email" และสำหรับเบอร์โทรใช้ type="tel" — CSS ที่เราเขียนไว้กับ input จะใช้กับช่องใหม่ให้อัตโนมัติ

ถ้าใช้ type="email" แล้วพิมพ์ข้อความที่ไม่ใช่รูปแบบ email (เช่น abc) browser จะขึ้นคำเตือนเองและไม่ส่งฟอร์ม event submit จึงไม่เกิด และ JavaScript ของเราจะดูเหมือนไม่ทำงาน — นี่ไม่ใช่ bug ให้ทดสอบด้วย email ที่ถูกรูปแบบ

Challenge 3: อ่านค่าจากช่องใหม่แล้วแสดงผล

ให้ JavaScript อ่านค่าจากช่องใหม่ แล้วแสดงใน result box ต้องทำ 3 จุด:

  1. หยิบ element ด้วย document.getElementById ไว้ด้านบนร่วมกับตัวอื่น
  2. อ่าน .value (และ .trim()) มาเก็บในตัวแปรข้างใน function
  3. แทรกตัวแปรนั้นลงใน template literal ด้วย ${…}

Challenge 4: validate ช่องใหม่

เพิ่มเงื่อนไขว่าช่องใหม่ต้องไม่ว่าง คำใบ้: เติมเงื่อนไขต่อท้ายใน if เดิมด้วย || แล้วอย่าลืมแก้ข้อความเตือนให้บอกผู้ใช้ครบว่าต้องกรอกอะไรบ้าง

Bonus: ข้อความให้กำลังใจสำหรับคนเริ่มจากศูนย์

ถ้าผู้ใช้เลือกพื้นฐานเป็น "เริ่มจากศูนย์" ให้แสดงข้อความให้กำลังใจเพิ่ม เช่น "ไม่เป็นไรครับ Bootcamp นี้ออกแบบมาให้เริ่มอย่างเป็นขั้นตอน" ตัวอย่าง logic:

let extraMessage = "";

if (level === "เริ่มจากศูนย์") {
  extraMessage =
    "ไม่เป็นไรครับ Bootcamp นี้ออกแบบมาให้เริ่มอย่างเป็นขั้นตอน";
}

resultBox.textContent = `สวัสดีครับคุณ ${fullName}
เป้าหมายของคุณคือ ${goal}
ระดับพื้นฐานตอนนี้คือ ${level}
${extraMessage}`;
  • let — ประกาศตัวแปรที่เปลี่ยนค่าได้ทีหลัง ต่างจาก const เราเริ่มด้วยข้อความว่าง "" แล้วค่อยใส่ข้อความเมื่อเงื่อนไขเป็นจริง
  • ถ้าเลือกระดับอื่น extraMessage ยังเป็น "" จึงไม่มีอะไรแสดงเพิ่ม
  • โค้ดส่วนนี้ต้องวางหลัง if ที่ตรวจข้อมูลว่าง และแทนที่ resultBox.textContent เดิม — ลองคิดดูว่าจะรวมบรรทัด "ข้อความเพิ่มเติม" กลับเข้าไปด้วยอย่างไร

ถ้าประกาศ extraMessage ด้วย const แล้วพยายามกำหนดค่าใหม่ใน if จะเกิด error เพราะ const เปลี่ยนค่าไม่ได้ กรณีที่ต้องเปลี่ยนค่าทีหลังต้องใช้ let

ทดลองเพิ่มเติม (ไม่บังคับ): แสดงผลแยกบรรทัด

จากบทที่ 6 เรารู้ว่า browser ยุบการขึ้นบรรทัดใหม่ในข้อความเป็นช่องว่าง ถ้าอยากให้ข้อความสรุปแสดงแยกบรรทัดตามที่เขียนใน template literal ลองเพิ่ม property นี้ใน .result-box ของ style.css:

.result-box {
  /* property เดิมทั้งหมด … */
  white-space: pre-line;
}

white-space: pre-line บอก browser ให้เคารพการขึ้นบรรทัดใหม่ในข้อความ อ่านเพิ่มได้ที่ MDN: white-space

  • ฟอร์มมีหัวข้อและ label เป็นของตัวเอง
  • มีช่องใหม่อย่างน้อย 1 ช่อง ที่คลิก label แล้ว focus เข้าช่องถูกต้อง
  • ค่าจากช่องใหม่แสดงใน result box
  • ปล่อยช่องใหม่ว่างแล้วกดส่ง ได้ข้อความเตือน
  • (Bonus) เลือก "เริ่มจากศูนย์" แล้วเห็นข้อความให้กำลังใจ เลือกระดับอื่นแล้วไม่เห็น
ก่อนหน้า: Error ที่เจอบ่อยและวิธีแก้ สารบัญบทเรียน ถัดไป: สรุปบทเรียนและการบ้าน
