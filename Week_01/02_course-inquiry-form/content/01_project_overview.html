บทเรียน 01 · เริ่มต้น (Getting Started)

ภาพรวมโปรเจกต์และการเตรียมไฟล์

Project Overview & Setup

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายได้ว่า HTML Form ในเว็บจริงใช้ทำอะไร
  • บอก flow หลักของโปรแกรมที่เราจะสร้าง: รับข้อมูล → ตรวจสอบ → ประมวลผล → แสดงผล
  • สร้างโฟลเดอร์โปรเจกต์พร้อมไฟล์ index.html, style.css และ script.js

ทบทวนพื้นฐานสั้น ๆ

จากพื้นฐาน HTML, CSS และ JavaScript เราเห็นภาพแล้วว่าหน้าเว็บหนึ่งหน้าแบ่งหน้าที่กันเป็น 3 ส่วน:

ภาษาหน้าที่ในโปรเจกต์นี้
HTMLโครงสร้างช่องกรอกข้อมูล ปุ่มส่ง และกล่องแสดงผลลัพธ์
CSSหน้าตาทำให้ฟอร์มดูเป็นระบบ อ่านง่าย และรู้ว่ากำลังกรอกช่องไหน
JavaScriptพฤติกรรมอ่านค่าที่ผู้ใช้กรอก ตรวจสอบ แล้วแสดงข้อความสรุป

ฟอร์มในเว็บจริงใช้ทำอะไร

Form คือส่วนที่เจอบ่อยที่สุดส่วนหนึ่งใน Web Application จริง ลองนึกถึงหน้าเหล่านี้:

  • หน้า Login
  • หน้าสมัครเรียน หรือหน้าสมัครงาน
  • หน้า Checkout ตอนซื้อของออนไลน์
  • Contact Form
  • ระบบหลังบ้านของบริษัท

ทุกหน้าที่กล่าวมามี pattern เดียวกัน คือ รับข้อมูลจากผู้ใช้ แล้วเอาไปทำอะไรบางอย่างต่อ ในคอร์สนี้เราจะได้ลองทำ pattern นี้ด้วยตัวเองแบบครบวงจร

สิ่งที่เราจะสร้าง: Course Inquiry Form Card

เราจะสร้างการ์ดฟอร์มเล็ก ๆ สำหรับกรอกข้อมูลความสนใจเรียน Bootcamp หน้าตาโดยรวมของฟอร์มเป็นแบบนี้:

ชื่อ:
เป้าหมาย:
พื้นฐานตอนนี้:
ข้อความเพิ่มเติม:

[ส่งข้อมูล]

เมื่อผู้ใช้กรอกข้อมูลแล้วกดปุ่ม หน้าเว็บจะแสดงข้อความสรุปประมาณนี้:

สวัสดีครับคุณ Man
เป้าหมายของคุณคือ เปลี่ยนสายงานเป็น Developer
ระดับพื้นฐานตอนนี้คือ เริ่มจากศูนย์
ข้อความเพิ่มเติม: ไม่มีข้อความเพิ่มเติม

โปรเจกต์นี้ช่วยให้เห็นว่า JavaScript ไม่ได้มีไว้แค่ "กดปุ่มแล้วเปลี่ยนข้อความ" แต่ทำงานเป็นขั้นตอนแบบโปรแกรมจริงได้:

รับข้อมูล → เก็บข้อมูล → ตรวจสอบข้อมูล → แสดงผลลัพธ์

flow นี้คือพื้นฐานของ logic ที่เราจะใช้ต่อไปใน React, Backend, Database และระบบ Full-Stack ในอนาคต

สิ่งที่จะได้เรียนในคอร์สนี้

ส่วนConcept
HTMLform, label, input, select, textarea, button
CSSform layout, input styling, spacing, focus state, result box
JavaScriptconst, document.getElementById, addEventListener, event.preventDefault(), .value, .trim(), if / else, textContent

Step 1: สร้างโปรเจกต์

สร้างโฟลเดอร์ใหม่ชื่อ course-inquiry-form แล้วสร้างไฟล์เปล่า 3 ไฟล์ไว้ข้างใน:

course-inquiry-form/
├── index.html
├── style.css
└── script.js
  • index.html — โครงสร้างของฟอร์ม
  • style.css — หน้าตาของการ์ดและช่องกรอกข้อมูล
  • script.js — logic อ่านค่า ตรวจสอบ และแสดงผล

จากนั้นเปิดโฟลเดอร์นี้ใน code editor ของคุณ เราจะเริ่มเขียน HTML กันในบทถัดไป

ชื่อไฟล์ต้องสะกดให้ตรงเป๊ะ (ตัวพิมพ์เล็กทั้งหมด) เพราะเดี๋ยว index.html จะอ้างถึง style.css และ script.js ด้วยชื่อนี้ ถ้าสะกดไม่ตรง browser จะหาไฟล์ไม่เจอ

  • อธิบายได้ว่า form ในเว็บจริงถูกใช้ในหน้าไหนบ้าง อย่างน้อย 3 ตัวอย่าง
  • พูด flow รับข้อมูล → ตรวจสอบ → ประมวลผล → แสดงผล ได้ด้วยคำพูดของตัวเอง
  • มีโฟลเดอร์ course-inquiry-form ที่มีไฟล์ index.html, style.css, script.js ครบ
สารบัญบทเรียน ถัดไป: form, label และ input
