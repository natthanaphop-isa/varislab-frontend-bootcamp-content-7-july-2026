Wrap Up & Homework

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบาย flow ของฟอร์มตั้งแต่ผู้ใช้กรอกข้อมูลจนถึงแสดงผล
  • ทบทวน concept HTML, CSS และ JavaScript ที่ได้ใช้ในโปรเจกต์
  • รู้ requirement ของการบ้าน Personal Inquiry Form

เราทำอะไรไปบ้าง

เราขยับจากหน้าเว็บที่แสดงข้อมูลเฉย ๆ ไปสู่หน้าเว็บที่รับข้อมูลจากผู้ใช้ได้แล้ว:

  • ใช้ HTML Form เพื่อรับข้อมูล
  • ใช้ CSS ทำให้ฟอร์มดูเป็นระบบ และบอกสถานะด้วย :focus
  • ใช้ JavaScript อ่านค่าจาก input เก็บไว้ในตัวแปร ตรวจสอบเงื่อนไขด้วย if และแสดงผลลัพธ์บนหน้าเว็บ

Flow ที่ต้องจำให้ได้

ถ้ายังจำ syntax ไม่ได้ทั้งหมด ไม่เป็นไร แต่ขอให้จำ flow นี้:

ผู้ใช้กรอกข้อมูล → กดปุ่ม submit → JavaScript อ่านค่า → ตรวจสอบ → แสดงผล

Web Application จำนวนมากใช้ pattern เดียวกันนี้ และมันคือ logic พื้นฐานที่จะต่อยอดไปสู่ React Form, API Request, Backend Validation และ Database ในอนาคต

การบ้าน: Personal Inquiry Form

สร้างหรือปรับฟอร์มจากโปรเจกต์นี้ให้เป็นฟอร์มของตัวเอง ตัวอย่างหัวข้อ:

  • Developer Goal Form
  • Portfolio Contact Form
  • Job Application Mini Form
  • Course Inquiry Form

Requirements

  1. มี input สำหรับชื่อ
  2. มี input สำหรับเป้าหมาย
  3. มี select สำหรับเลือกระดับพื้นฐาน
  4. เพิ่มช่องใหม่อย่างน้อย 1 ช่อง เช่น email, phone, skill หรือ expected role
  5. เมื่อกด submit ต้องแสดงผลลัพธ์บนหน้าเว็บ
  6. ต้องมี validation ว่าช่องสำคัญต้องไม่ว่าง
  7. ปรับ style ให้ดูเป็นของตัวเอง

Challenge 1–4 ในบทที่ 9 ครอบคลุม requirement ข้อ 4–6 เกือบทั้งหมดแล้ว ถ้าทำ challenge ครบ คุณเหลือแค่ตกแต่ง style ให้เป็นของตัวเอง

Reflection

ตอบคำถามสั้น ๆ ส่งมาพร้อมการบ้าน:

  1. เข้าใจคำว่า variable เพิ่มขึ้นอย่างไร?
  2. if ใช้ทำอะไร?
  3. .value ใช้ทำอะไร?
  4. เจอ error อะไร และแก้อย่างไร?
  5. อยากให้ review จุดไหนของโค้ด?

แบบทดสอบตัวเอง

ลองตอบในใจก่อน แล้วย้อนกลับไปเช็กในบทที่เกี่ยวข้อง

  1. HTML form ใช้ทำอะไร?

    A. ใช้รับข้อมูลจากผู้ใช้
    B. ใช้เปลี่ยนสีพื้นหลังเท่านั้น
    C. ใช้เก็บข้อมูลลง database โดยอัตโนมัติ
    D. ใช้แทน browser

  2. .value ใช้สำหรับอะไร?

    A. อ่านค่าที่ผู้ใช้กรอกหรือเลือกใน input
    B. เปลี่ยนสีของปุ่ม
    C. สร้างไฟล์ใหม่
    D. เปิด browser

  3. event.preventDefault() ในโปรเจกต์นี้ใช้เพื่ออะไร?

    A. ป้องกันไม่ให้ form refresh หน้าเว็บทันที
    B. ทำให้ปุ่มใหญ่ขึ้น
    C. เปลี่ยน font
    D. ลบข้อมูลใน database

  4. if ใช้ทำอะไร?

    A. ใช้ตรวจสอบเงื่อนไข
    B. ใช้จัดสี
    C. ใช้สร้าง HTML file
    D. ใช้เปิด Terminal

  5. ถ้า JavaScript อ่านค่า input ไม่ได้ ควรเช็กอะไรเป็นอย่างแรก?

    A. id ใน HTML ตรงกับ JavaScript หรือไม่
    B. สีพื้นหลังสวยหรือไม่
    C. ชื่อ folder ยาวเกินไปหรือไม่
    D. มีรูปภาพหรือไม่

  • พูด flow ผู้ใช้กรอกข้อมูล → submit → อ่านค่า → ตรวจสอบ → แสดงผล ได้โดยไม่ต้องดูโน้ต
  • โปรเจกต์ Course Inquiry Form ทำงานครบ: validation ทำงาน และแสดงข้อความสรุปได้
  • การบ้านผ่าน requirement ครบทั้ง 7 ข้อ
  • ตอบคำถาม reflection ครบ 5 ข้อ
