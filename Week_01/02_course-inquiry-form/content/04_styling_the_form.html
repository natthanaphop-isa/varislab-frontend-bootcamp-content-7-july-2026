บทเรียน 04 · สร้างฟอร์มด้วย HTML และ CSS (Form Structure & Styling)

ตกแต่งฟอร์มด้วย CSS

Styling the Form

เมื่อจบบทนี้ คุณจะสามารถ

  • จัดการ์ดฟอร์มให้อยู่กลางหน้าจอด้วย flexbox
  • เลือก element หลายตัวพร้อมกันด้วย selector ที่คั่นด้วย comma
  • ใช้ :focus และ :hover บอกสถานะให้ผู้ใช้เห็น
  • มีไฟล์ style.css ที่สมบูรณ์ของโปรเจกต์

บทนี้ไม่ได้ต้องการให้คุณจำ property ทั้งหมด แต่อยากให้เห็นแนวคิดสำคัญ 2–3 อย่างที่ใช้บ่อยมากกับฟอร์มจริง เราจะเขียน style.css ทีละส่วน แล้วดูไฟล์เต็มตอนท้าย

Step 3.1: พื้นฐานของหน้า

* {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100vh;
  font-family: Arial, sans-serif;
  background: #0f172a;
  color: white;
}
  • * { box-sizing: border-box; } — ให้ width ของทุก element รวม padding และ border ไว้ด้วย สำคัญมากกับช่องกรอกที่เราจะตั้ง width: 100% ไม่อย่างนั้นช่องจะล้นการ์ด
  • body — ลบ margin เริ่มต้นของ browser และตั้งพื้นหลังสีเข้มกับตัวอักษรสีขาว

Step 3.2: จัดการ์ดให้อยู่กลางจอ

.page {
  min-height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
  padding: 32px;
}

.form-card {
  width: 520px;
  padding: 32px;
  border-radius: 24px;
  background: #1e293b;
  box-shadow: 0 24px 60px rgba(0, 0, 0, 0.35);
}

.page สูงอย่างน้อยเต็มจอ (100vh) และใช้ flexbox — justify-content: center จัดกลางแนวนอน, align-items: center จัดกลางแนวตั้ง ส่วน .form-card คือตัวการ์ดที่มีมุมโค้งและเงา

Step 3.3: หัวการ์ดและระยะห่างของแต่ละช่อง

.label {
  margin: 0 0 12px;
  color: #38bdf8;
  font-weight: bold;
  letter-spacing: 0.04em;
  text-transform: uppercase;
}

h1 {
  margin: 0 0 12px;
  font-size: 32px;
}

.description {
  margin: 0 0 24px;
  color: #cbd5e1;
  line-height: 1.7;
}

.form-group {
  margin-bottom: 18px;
}

label {
  display: block;
  margin-bottom: 8px;
  color: #e2e8f0;
  font-weight: bold;
}
  • .form-group — เว้นระยะด้านล่างของทุกช่อง ฟอร์มจึงไม่อัดแน่น (นี่คือเหตุผลที่เราห่อแต่ละช่องด้วย div ในบทก่อน)
  • label { display: block; } — ปกติ label เป็น inline คืออยู่บรรทัดเดียวกับช่องกรอก การตั้งเป็น block ทำให้ label อยู่บรรทัดของตัวเอง แล้วช่องกรอกลงมาอยู่ด้านล่าง

ระวังชื่อที่คล้ายกัน: .label (มีจุด) คือ class ของป้าย "Varis Lab Bootcamp" ส่วน label (ไม่มีจุด) คือแท็ก <label> ทุกตัวในฟอร์ม ลืมจุดตัวเดียว สไตล์จะไปผิดที่

Step 3.4: เลือกหลาย element พร้อมกัน

input, select และ textarea เป็นช่องรับข้อมูลเหมือนกัน เราจึงอยากให้หน้าตาเหมือนกัน แทนที่จะเขียน 3 รอบ ให้คั่น selector ด้วย comma แล้วเขียนครั้งเดียว:

input,
select,
textarea {
  width: 100%;
  border: 1px solid #334155;
  border-radius: 12px;
  padding: 12px 14px;
  background: #0f172a;
  color: white;
  font-size: 16px;
}

Step 3.5: focus state — บอกผู้ใช้ว่ากำลังกรอกช่องไหน

input:focus,
select:focus,
textarea:focus {
  outline: none;
  border-color: #38bdf8;
}

:focus คือสถานะตอนที่ผู้ใช้คลิก (หรือกด Tab) เข้าไปในช่องกรอก เราเอา outline เริ่มต้นของ browser ออก แล้วเปลี่ยนสีขอบเป็นสีฟ้าแทน นี่คือตัวอย่างเล็ก ๆ ของ UX (user experience) — ทำให้ผู้ใช้รู้ว่าตอนนี้กำลังกรอกช่องไหนอยู่

ถ้าใช้ outline: none ต้องใส่สไตล์อื่นแทนเสมอ (อย่างที่เราเปลี่ยน border-color) เพราะผู้ใช้ที่กรอกฟอร์มด้วยคีย์บอร์ดต้องมองเห็นว่าช่องไหนกำลังถูกเลือก

Step 3.6: ปุ่มและกล่องผลลัพธ์

button {
  width: 100%;
  border: none;
  border-radius: 999px;
  padding: 14px 24px;
  background: #38bdf8;
  color: #0f172a;
  font-size: 16px;
  font-weight: bold;
  cursor: pointer;
}

button:hover {
  background: #7dd3fc;
}

.result-box {
  margin-top: 24px;
  padding: 18px;
  border-radius: 16px;
  background: #0f172a;
  color: #cbd5e1;
  line-height: 1.7;
}
  • border-radius: 999px — ค่าที่ใหญ่มากทำให้ปุ่มโค้งมนเป็นทรงแคปซูล
  • cursor: pointer — เปลี่ยนเมาส์เป็นรูปมือ บอกว่ากดได้
  • button:hover — สีปุ่มสว่างขึ้นเมื่อเอาเมาส์ไปวาง
  • .result-box — กล่องสีเข้มด้านล่างฟอร์ม ที่ JavaScript จะเขียนข้อความลงไป

ควรได้ผลลัพธ์แบบนี้

พื้นหลังสีน้ำเงินเข้ม มีการ์ดกว้าง 520px อยู่กลางจอ ป้าย "VARIS LAB BOOTCAMP" เป็นตัวพิมพ์ใหญ่สีฟ้า ช่องกรอกทุกช่องกว้างเต็มการ์ด ขอบกลายเป็นสีฟ้าเมื่อคลิกเข้าไป ปุ่มทรงแคปซูลสีฟ้าที่สว่างขึ้นเมื่อ hover และกล่องผลลัพธ์สีเข้มด้านล่าง

  • การ์ดอยู่กลางจอทั้งแนวนอนและแนวตั้ง
  • คลิกหรือกด Tab ไล่ช่องแล้วเห็นขอบสีฟ้าเปลี่ยนตามช่องที่ focus อยู่
  • อธิบายได้ว่า input, select, textarea { … } ต่างจากเขียน 3 กฎแยกกันอย่างไร (ผลเหมือนกัน แต่สั้นกว่าและแก้ที่เดียว)
  • แยกได้ว่า .label กับ label เลือกอะไรต่างกัน
ก่อนหน้า: select, textarea, button และกล่องผลลัพธ์ สารบัญบทเรียน ถัดไป: อ่านค่าจากฟอร์มด้วย JavaScript
