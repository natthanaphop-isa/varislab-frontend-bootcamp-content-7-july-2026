บทเรียน 05 · เริ่มคิดแบบ JavaScript (Thinking in JavaScript)

อ่านค่าจากฟอร์มด้วย JavaScript

Reading Form Values

เมื่อจบบทนี้ คุณจะสามารถ

  • หยิบ element จาก HTML มาเก็บในตัวแปรด้วย const และ document.getElementById
  • ดักฟังการส่งฟอร์มด้วย addEventListener("submit", …)
  • อธิบายได้ว่าทำไมต้องเรียก event.preventDefault()
  • อ่านค่าที่ผู้ใช้กรอกด้วย .value แล้วแสดงบนหน้าเว็บด้วย textContent

ถึงตอนนี้ฟอร์มสวยแล้ว แต่ยังทำอะไรไม่ได้ ถ้าเคยเขียน JavaScript แบบ "กดปุ่มแล้วเปลี่ยนข้อความ" มาก่อน บทนี้จะขยับขึ้นอีกขั้น: ให้ JavaScript อ่านค่าจากหลายช่อง แล้วเอาข้อมูลเหล่านั้นมาประกอบเป็นข้อความใหม่

Step 4.1: หยิบ element ที่ต้องใช้

เปิดไฟล์ script.js แล้วเริ่มจากหยิบทุก element ที่เราจะใช้ มาเก็บไว้ในตัวแปร:

const inquiryForm = document.getElementById("inquiryForm");
const fullNameInput = document.getElementById("fullName");
const goalInput = document.getElementById("goal");
const levelSelect = document.getElementById("level");
const messageInput = document.getElementById("message");
const resultBox = document.getElementById("result");
  • document.getElementById("inquiryForm") — ไปหา element ในหน้าเว็บที่มี id="inquiryForm" (คือ id ที่เราตั้งไว้ใน HTML ทั้ง 6 ตัว)
  • const — ประกาศตัวแปรไว้เก็บ element นั้น ใช้ const เพราะเราจะไม่เปลี่ยนให้ตัวแปรนี้ชี้ไปที่ element อื่น
  • ชื่อตัวแปรลงท้ายด้วย Input, Select, Box เพื่อเตือนตัวเองว่านี่คือตัว element ไม่ใช่ข้อความที่ผู้ใช้กรอก

Step 4.2: รอฟังว่าฟอร์มถูกส่งเมื่อไหร่

inquiryForm.addEventListener("submit", function (event) {
  event.preventDefault();

  // โค้ดที่จะทำงานเมื่อผู้ใช้ส่งฟอร์ม
});

addEventListener คือการบอกว่า "เมื่อฟอร์มนี้เกิด event submit ให้เรียก function นี้" event submit เกิดขึ้นเมื่อผู้ใช้กดปุ่ม type="submit" (หรือกด Enter ในช่อง input)

function ที่เราส่งเข้าไปจะได้รับ event มาเป็น parameter ซึ่งเป็นข้อมูลของเหตุการณ์ที่เพิ่งเกิดขึ้น

ทำไมต้อง event.preventDefault()

พฤติกรรมปกติของ HTML form คือ เมื่อ submit แล้ว browser จะพยายามส่งข้อมูลและ refresh หน้าเว็บ (ลองกดปุ่มในบทที่ 3 จะเห็นหน้ากระพริบ) แต่ในโปรเจกต์นี้เราต้องการให้ JavaScript จัดการข้อมูลบนหน้าเดิม

event.preventDefault() จึงเป็นการบอก browser ว่า: อย่าเพิ่ง reload หน้าเว็บหลังจากกด submit ให้เรียกไว้เป็นบรรทัดแรกใน function

Step 4.3: อ่านค่าด้วย .value แล้วเก็บในตัวแปร

ภายใน function ต่อจาก event.preventDefault() ให้อ่านค่าจากแต่ละช่อง:

const fullName = fullNameInput.value;
const goal = goalInput.value;
const level = levelSelect.value;
const message = messageInput.value;

.value คือค่าที่ผู้ใช้กรอกหรือเลือกไว้ในช่องนั้น เช่น ถ้าผู้ใช้กรอกชื่อว่า Man แล้ว fullNameInput.value ก็จะได้ค่าเป็น "Man" สำหรับ select ค่าที่ได้คือ value ของ option ที่ถูกเลือก

ลองอ่านบรรทัดนี้เป็นภาษาคน:

const fullName = fullNameInput.value;
เอาค่าจากช่องชื่อ มาเก็บไว้ในตัวแปรชื่อ fullName

ตัวแปร (variable) คือที่เก็บข้อมูลชั่วคราวระหว่างที่โปรแกรมกำลังทำงาน ทุกครั้งที่กดส่งฟอร์ม function จะทำงานใหม่ และตัวแปรเหล่านี้จะได้ค่าล่าสุดที่ผู้ใช้กรอก

ตัวแปรเก็บอะไรตัวอย่างค่า
fullNameInputตัว input ทั้งกล่อง (element)ช่องกรอกบนหน้าเว็บ
fullNameข้อความที่ผู้ใช้พิมพ์ในกล่อง"Man"

ตัวแปร fullName ต้องประกาศข้างใน function เพราะเราต้องการค่า ณ ตอนที่ผู้ใช้กดส่ง ถ้าประกาศไว้ด้านบนนอก function มันจะอ่านค่าตอนเปิดหน้าเว็บ ซึ่งตอนนั้นช่องยังว่างอยู่

Step 4.4: แสดงผลบนหน้าเว็บด้วย textContent

สุดท้าย เอาค่าทั้งหมดมาต่อกันเป็นข้อความ แล้วใส่ลงในกล่องผลลัพธ์ ไฟล์ script.js ทั้งไฟล์ตอนนี้เป็นแบบนี้:

const inquiryForm = document.getElementById("inquiryForm");
const fullNameInput = document.getElementById("fullName");
const goalInput = document.getElementById("goal");
const levelSelect = document.getElementById("level");
const messageInput = document.getElementById("message");
const resultBox = document.getElementById("result");

inquiryForm.addEventListener("submit", function (event) {
  event.preventDefault();

  const fullName = fullNameInput.value;
  const goal = goalInput.value;
  const level = levelSelect.value;
  const message = messageInput.value;

  resultBox.textContent =
    "สวัสดีครับคุณ " +
    fullName +
    " เป้าหมายของคุณคือ " +
    goal +
    " ระดับพื้นฐานตอนนี้คือ " +
    level +
    " ข้อความเพิ่มเติม: " +
    message;
});
  • resultBox.textContent = … — แทนที่ข้อความในกล่องผลลัพธ์ด้วยข้อความใหม่
  • เครื่องหมาย + ระหว่างข้อความ (string) คือการต่อข้อความเข้าด้วยกัน
  • สังเกตช่องว่างใน " เป้าหมายของคุณคือ " — ถ้าไม่เว้นไว้ ข้อความจะติดกันเป็นพรืด

ควรได้ผลลัพธ์แบบนี้

กรอกชื่อ Man, เป้าหมาย "เปลี่ยนสายงานเป็น Developer", เลือก "เริ่มจากศูนย์" แล้วกด "ส่งข้อมูล" — หน้าเว็บไม่ reload และกล่องด้านล่างแสดงข้อความ "สวัสดีครับคุณ Man เป้าหมายของคุณคือ เปลี่ยนสายงานเป็น Developer ระดับพื้นฐานตอนนี้คือ เริ่มจากศูนย์ ข้อความเพิ่มเติม: …"

ตอนนี้ถ้ากดส่งทั้งที่ยังไม่กรอกอะไรเลย ก็ยังได้ข้อความ "สวัสดีครับคุณ เป้าหมายของคุณคือ …" ที่มีช่องว่างโหว่ ๆ อยู่ ยังไม่ต้องกังวล — เราจะแก้ด้วย validation ในบทที่ 7

  • กดส่งแล้วหน้าไม่ reload และข้อความในกล่องผลลัพธ์เปลี่ยน
  • อธิบายได้ว่า fullNameInput กับ fullNameInput.value ต่างกันอย่างไร
  • บอกได้ว่า event.preventDefault() ป้องกันอะไร
  • เปลี่ยนตัวเลือกใน dropdown แล้วกดส่งใหม่ ข้อความเปลี่ยนตาม
