บทเรียน 06 · เริ่มคิดแบบ JavaScript (Thinking in JavaScript)

ประกอบข้อความด้วย Template Literal

Template Literals

เมื่อจบบทนี้ คุณจะสามารถ

  • เขียนข้อความด้วย backtick (`) และแทรกค่าตัวแปรด้วย ${…}
  • Refactor โค้ดต่อข้อความด้วย + ให้เป็น template literal โดยผลลัพธ์ยังเหมือนเดิม
  • อธิบายได้ว่าการขึ้นบรรทัดใหม่ใน template literal แสดงผลบนหน้าเว็บอย่างไร

ปัญหาของการต่อข้อความด้วย +

ลองดูโค้ดส่วนแสดงผลจากบทที่แล้วอีกครั้ง:

resultBox.textContent =
  "สวัสดีครับคุณ " +
  fullName +
  " เป้าหมายของคุณคือ " +
  goal +
  " ระดับพื้นฐานตอนนี้คือ " +
  level +
  " ข้อความเพิ่มเติม: " +
  message;

มันทำงานได้ แต่อ่านยาก ต้องคอยเปิดปิดเครื่องหมายคำพูด ใส่ + ทุกช่วง และระวังช่องว่างหน้าหลังข้อความ ยิ่งข้อความยาว โอกาสพิมพ์พลาดยิ่งเยอะ

Template Literal คืออะไร

Template literal คือข้อความที่ครอบด้วยเครื่องหมาย backtick ` (ปุ่มเดียวกับ ~ มุมซ้ายบนของคีย์บอร์ดส่วนใหญ่) แทนเครื่องหมายคำพูด ข้างในเราแทรกค่าตัวแปรได้ด้วย ${ชื่อตัวแปร}:

const fullName = "Man";

// แบบเดิม
"สวัสดีครับคุณ " + fullName

// แบบ template literal
`สวัสดีครับคุณ ${fullName}`

ทั้งสองบรรทัดได้ข้อความ "สวัสดีครับคุณ Man" เหมือนกัน — ${fullName} แปลว่า "เอาค่าของตัวแปร fullName มาใส่ตรงนี้"

Step 5: Refactor script.js

แก้ส่วน resultBox.textContent ใน script.js ให้เป็น template literal ไฟล์ทั้งไฟล์จะเป็นแบบนี้:

const inquiryForm = document.getElementById("inquiryForm");
const fullNameInput = document.getElementById("fullName");
const goalInput = document.getElementById("goal");
const levelSelect = document.getElementById("level");
const messageInput = document.getElementById("message");
const resultBox = document.getElementById("result");

inquiryForm.addEventListener("submit", function (event) {
  event.preventDefault();

  const fullName = fullNameInput.value;
  const goal = goalInput.value;
  const level = levelSelect.value;
  const message = messageInput.value;

  resultBox.textContent = `สวัสดีครับคุณ ${fullName}
เป้าหมายของคุณคือ ${goal}
ระดับพื้นฐานตอนนี้คือ ${level}
ข้อความเพิ่มเติม: ${message}`;
});

อ่านง่ายขึ้นมาก ข้อความเรียงเป็นบรรทัดเหมือนผลลัพธ์ที่อยากได้ และไม่มี + ให้พลาดอีกแล้ว การปรับโค้ดให้อ่านง่ายขึ้นโดยที่การทำงานยังเหมือนเดิมแบบนี้เรียกว่า refactor

ต้องใช้ backtick ` เท่านั้น ถ้าเผลอใช้ " หรือ ' ครอบ JavaScript จะแสดง ${fullName} ออกมาตรง ๆ เป็นตัวอักษร ไม่ได้แทนค่าให้ และถ้าขึ้นบรรทัดใหม่ในข้อความที่ครอบด้วย " จะเกิด error ทันที

ใน template literal ช่องว่างและการขึ้นบรรทัดใหม่ถือเป็นส่วนหนึ่งของข้อความ นี่คือเหตุผลที่บรรทัด เป้าหมายของคุณคือ … ในโค้ดถูกเขียนชิดซ้ายสุด ไม่ได้ย่อหน้าตามโค้ดด้านบน — ถ้าย่อหน้า ช่องว่างเหล่านั้นจะติดไปในข้อความด้วย

ทำไมบนหน้าเว็บยังเห็นเป็นบรรทัดเดียว

ข้อความของเรามีการขึ้นบรรทัดใหม่อยู่จริง แต่โดยปกติ browser จะยุบการขึ้นบรรทัดใหม่ในข้อความให้กลายเป็นช่องว่าง ดังนั้นในกล่องผลลัพธ์คุณจะเห็นข้อความต่อกันเป็นย่อหน้าเดียว ซึ่งเป็นพฤติกรรมปกติ ไม่ใช่ bug ในโค้ดของเรา (ถ้าอยากทดลองให้แสดงแยกบรรทัด ดูไอเดียได้ในบทที่ 9)

ควรได้ผลลัพธ์แบบนี้

กรอกฟอร์มแล้วกดส่ง ได้ข้อความสรุปเหมือนบทที่แล้วทุกอย่าง (ต่างกันแค่ในโค้ดที่อ่านง่ายขึ้น) — ถ้าเห็น ${fullName} โผล่มาในกล่องผลลัพธ์ แปลว่าใช้เครื่องหมายครอบผิด

  • หาปุ่ม backtick บนคีย์บอร์ดของตัวเองเจอ
  • แปลงข้อความ "เป้าหมาย: " + goal เป็น template literal ได้เอง
  • อธิบายได้ว่า ${level} ทำอะไร
  • ผลลัพธ์หลัง refactor เหมือนก่อน refactor
ก่อนหน้า: อ่านค่าจากฟอร์มด้วย JavaScript สารบัญบทเรียน ถัดไป: ตรวจสอบข้อมูลด้วย if/else
