Error ที่เจอบ่อยและวิธีแก้

Common Errors

เมื่อจบบทนี้ คุณจะสามารถ

  • จำอาการของฟอร์มที่ลืม event.preventDefault() ได้
  • ไล่เช็ก id ระหว่าง HTML กับ JavaScript เมื่อ JavaScript ไม่ทำงาน
  • แยกได้ว่าเมื่อไหร่ต้องใช้ element และเมื่อไหร่ต้องใช้ .value

การทำให้โค้ดพังแบบตั้งใจแล้วดูว่าเกิดอะไรขึ้น คือวิธีที่ดีมากในการจำ error เพราะวันที่มันพังจริง คุณจะจำอาการได้ทันที ในบทนี้ให้ลองทำทีละข้อกับโปรเจกต์ที่เสร็จแล้ว และอย่าลืมแก้กลับทุกครั้งก่อนไปข้อถัดไป

เปิด DevTools ของ browser ไว้ที่แท็บ Console ระหว่างทดลอง (คลิกขวาที่หน้าเว็บ → Inspect แล้วเลือก Console) error ของ JavaScript จะแสดงเป็นข้อความสีแดงที่นี่

Error 1: ลืม event.preventDefault()

ลองลบ (หรือใส่ // หน้า) บรรทัดนี้ใน script.js:

event.preventDefault();

แล้วกรอกฟอร์มและกดส่ง

อาการ: หน้าเว็บ refresh ทันทีหลัง submit ผลคือเราอาจไม่เห็นข้อความที่ JavaScript แสดงเลย หรือเห็นแว้บเดียวแล้วหายไป และข้อมูลที่กรอกไว้ก็หายไปด้วย

ทำไมถึงเป็นแบบนี้: นี่คือพฤติกรรมปกติของ form ใน HTML — submit แล้ว reload หน้า JavaScript ของเราทำงานจริง แต่หน้าเว็บถูกโหลดใหม่ทับไปก่อนที่เราจะได้เห็น

วิธีแก้: ใส่ event.preventDefault(); กลับไปเป็นบรรทัดแรกใน function ของ submit

Error 2: id ไม่ตรงกัน

ใน HTML ช่องชื่อของเรามี id="fullName":

<input id="fullName" />

ลองแก้ JavaScript ให้พิมพ์ id ผิดเป็น:

const fullNameInput = document.getElementById("name");

อาการ: กดส่งแล้วฟอร์มอ่านค่าจากช่องนี้ไม่ได้ ใน Console จะเห็น error สีแดงประมาณว่าอ่าน value จาก null ไม่ได้ (Cannot read properties of null) และเพราะ event.preventDefault() ถูกเรียกไปก่อนแล้ว หน้าเว็บจึงไม่ reload แต่กล่องผลลัพธ์ก็ไม่เปลี่ยน

ทำไมถึงเป็นแบบนี้: JavaScript ไปหา element ที่มี id ชื่อ name แต่ใน HTML ไม่มี id นี้ getElementById จึงคืนค่า null (ไม่เจออะไร) พอเราสั่ง null.value โปรแกรมก็พัง

วิธีแก้: เวลา JavaScript ไม่ทำงาน ให้เช็ก id ใน HTML กับ JavaScript ให้ตรงกันก่อนเสมอ — ตัวสะกด ตัวพิมพ์เล็ก-ใหญ่ ต้องเหมือนกันทุกตัวอักษร

Error 3: ลืม .value

ลองแก้บรรทัดอ่านค่าชื่อให้ผิดเป็น (ลบ .trim() ออกด้วยเพื่อให้เห็นอาการชัด):

const fullName = fullNameInput;

แทนที่จะเป็น:

const fullName = fullNameInput.value;

อาการ: ไม่มี error สีแดง แต่ข้อความสรุปแสดงชื่อเป็นอะไรแปลก ๆ อย่าง [object HTMLInputElement] แทนชื่อที่พิมพ์ — error แบบนี้หาเจอยากกว่า เพราะโปรแกรมไม่ได้พัง แค่ได้ค่าผิด

ทำไมถึงเป็นแบบนี้: fullNameInput คือตัว input ทั้งกล่อง ส่วน fullNameInput.value คือค่าที่ผู้ใช้พิมพ์เข้าไปในกล่อง

วิธีแก้: ถ้าต้องการข้อมูลที่ผู้ใช้กรอก ต้องใช้ .value เสมอ
