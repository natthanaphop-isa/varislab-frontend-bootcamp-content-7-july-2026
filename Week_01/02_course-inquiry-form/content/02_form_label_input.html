บทเรียน 02 · สร้างฟอร์มด้วย HTML และ CSS (Form Structure & Styling)

form, label และ input

Form, Label & Input

เมื่อจบบทนี้ คุณจะสามารถ

  • เขียนโครง HTML ของหน้าเว็บและการ์ดฟอร์ม พร้อมเชื่อม style.css และ script.js
  • อธิบายหน้าที่ของ form, label และ input
  • เชื่อม label กับ input ด้วย for และ id และเข้าใจว่าทำไม id สำคัญกับ JavaScript

Step 2.1: โครงหน้าเว็บและหัวการ์ด

เปิดไฟล์ index.html แล้วเริ่มจากโครง HTML พื้นฐานที่เราคุ้นเคย ภายใน body เราจะมี main เป็นพื้นที่ทั้งหน้า และ section เป็นตัวการ์ดฟอร์ม:

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Course Inquiry Form</title>
    <link rel="stylesheet" href="style.css" />
  </head>

  <body>
    <main class="page">
      <section class="form-card">
        <p class="label">Varis Lab Bootcamp</p>

        <h1>แบบฟอร์มความสนใจเรียน</h1>

        <p class="description">
          กรอกข้อมูลเบื้องต้น เพื่อสรุปเป้าหมายการเรียนของคุณ
        </p>

        <!-- ฟอร์มจะอยู่ตรงนี้ -->
      </section>
    </main>

    <script src="script.js"></script>
  </body>
</html>
  • <link rel="stylesheet" href="style.css" /> ใน head — ดึง CSS มาใช้
  • <script src="script.js"></script> วางไว้ท้าย body — เพื่อให้ HTML ทุกส่วนถูกสร้างเสร็จก่อน JavaScript เริ่มทำงาน JavaScript จะได้หา element เจอ
  • class อย่าง page, form-card, label, description มีไว้ให้ CSS ใช้ตกแต่งในบทที่ 4

Step 2.2: เพิ่ม form

form คือพื้นที่สำหรับรับข้อมูลจากผู้ใช้ ทุกช่องกรอกข้อมูลและปุ่มส่งจะอยู่ข้างในนี้ แทนที่ comment <!-- ฟอร์มจะอยู่ตรงนี้ --> ด้วย:

<form id="inquiryForm">
</form>

เราตั้ง id="inquiryForm" ไว้ เพราะในบทที่ 5 JavaScript จะใช้ id นี้ไปหยิบฟอร์มมา แล้ว "รอฟัง" ว่าผู้ใช้กดส่งฟอร์มเมื่อไหร่

Step 2.3: ช่องกรอกชื่อ — label + input

ข้างใน form ให้เพิ่มช่องแรก:

<form id="inquiryForm">
  <div class="form-group">
    <label for="fullName">ชื่อของคุณ</label>
    <input
      id="fullName"
      type="text"
      placeholder="เช่น Man"
    />
  </div>
</form>
  • label — ข้อความบอกผู้ใช้ว่าช่องนี้ต้องกรอกอะไร
  • input — ช่องกรอกข้อมูลแบบสั้น (บรรทัดเดียว) type="text" บอกว่าเป็นข้อความทั่วไป
  • placeholder — ข้อความตัวอย่างสีจาง ๆ ที่หายไปเมื่อผู้ใช้เริ่มพิมพ์
  • div class="form-group" — กล่องที่จับ label กับ input ของช่องเดียวกันไว้ด้วยกัน ช่วยให้จัดระยะห่างด้วย CSS ได้ง่าย

for กับ id: สายที่เชื่อม label กับ input

จุดที่ต้องจำให้ขึ้นใจของบทนี้:

label for="fullName" เชื่อมกับ input id="fullName"

ค่าของ for ต้องตรงกับ id ของช่องที่ label นั้นอธิบาย เมื่อเชื่อมกันแล้ว ลองคลิกที่ข้อความ "ชื่อของคุณ" — cursor จะกระโดดเข้าไปในช่องกรอกทันที

และ id ยังสำคัญมากอีกเรื่อง: JavaScript จะใช้ id เพื่อไปหยิบค่าจากช่องกรอกแต่ละช่อง ดังนั้นตั้งชื่อ id ให้สื่อความหมาย และสะกดให้ตรงกันทุกที่

id แยกตัวพิมพ์เล็ก-ใหญ่ fullName กับ fullname ถือเป็นคนละชื่อกัน และ id ต้องไม่ซ้ำกันภายในหน้าเดียว

Step 2.4: ช่องกรอกเป้าหมาย

เพิ่ม form-group ที่สองต่อจากช่องชื่อ ใช้ pattern เดิมทุกอย่าง เปลี่ยนแค่ข้อความและ id:

<div class="form-group">
  <label for="goal">เป้าหมายของคุณ</label>
  <input
    id="goal"
    type="text"
    placeholder="เช่น เปลี่ยนสายงานเป็น Developer"
  />
</div>

บันทึกไฟล์แล้วเปิด index.html ใน browser ตอนนี้หน้าเว็บยังไม่มีสไตล์ (พื้นขาว ตัวอักษรธรรมดา) ซึ่งถูกต้องแล้ว เพราะเรายังไม่ได้เขียน CSS

ควรได้ผลลัพธ์แบบนี้

เห็นป้าย "Varis Lab Bootcamp", หัวข้อ "แบบฟอร์มความสนใจเรียน", คำอธิบาย และช่องกรอก 2 ช่องที่มีข้อความตัวอย่างสีจาง ๆ คลิกที่คำว่า "ชื่อของคุณ" หรือ "เป้าหมายของคุณ" แล้ว cursor เข้าไปอยู่ในช่องที่ถูกต้อง

  • อธิบายได้ว่า form, label, input ทำหน้าที่อะไร
  • ค่า for ของ label ทุกตัวตรงกับ id ของ input ที่คู่กัน
  • คลิก label แล้ว cursor เข้าไปในช่องกรอกที่ถูกต้อง
  • บอกได้ว่าทำไม <script> ถึงวางไว้ท้าย body
ก่อนหน้า: ภาพรวมโปรเจกต์และการเตรียมไฟล์ สารบัญบทเรียน ถัดไป: select, textarea, button และกล่องผลลัพธ์
