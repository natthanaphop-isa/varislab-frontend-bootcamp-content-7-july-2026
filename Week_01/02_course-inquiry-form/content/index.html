สร้างฟอร์มรับข้อมูลคอร์ส (Course Inquiry Form)

คอร์สนี้เราจะขยับจากหน้าเว็บที่ "แสดงข้อมูลเฉย ๆ" ไปสู่หน้าเว็บที่ "รับข้อมูลจากผู้ใช้ได้" โดยสร้างการ์ดฟอร์มความสนใจเรียน Bootcamp ด้วย HTML Form ตกแต่งด้วย CSS แล้วใช้ JavaScript อ่านค่า ตรวจสอบว่ากรอกครบไหมด้วย if และแสดงข้อความสรุปกลับบนหน้าเว็บ — รับข้อมูล → ตรวจสอบ → ประมวลผล → แสดงผล

สิ่งที่ต้องเตรียม

  • มีพื้นฐาน HTML, CSS และ JavaScript เบื้องต้น (เช่น เคยทำโปรเจกต์ Profile Card) — รู้ว่า HTML คือโครงสร้าง, CSS คือหน้าตา และ JavaScript คือพฤติกรรมของหน้าเว็บ
  • Code editor (เช่น VS Code) และ browser สำหรับเปิดไฟล์ index.html
  • ไม่ต้องจำ syntax ทั้งหมด ขอแค่เข้าใจ flow: ผู้ใช้กรอกข้อมูล → กด submit → JavaScript อ่านค่า → ตรวจสอบ → แสดงผล
