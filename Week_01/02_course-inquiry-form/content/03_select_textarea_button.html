บทเรียน 03 · สร้างฟอร์มด้วย HTML และ CSS (Form Structure & Styling)

select, textarea, button และกล่องผลลัพธ์

Select, Textarea, Button & Result Box

เมื่อจบบทนี้ คุณจะสามารถ

  • สร้างช่องให้เลือกจากตัวเลือกด้วย select และ option และเข้าใจบทบาทของ value
  • สร้างช่องกรอกข้อความยาวด้วย textarea
  • เพิ่มปุ่ม button type="submit" และพื้นที่แสดงผลลัพธ์สำหรับ JavaScript
  • มีไฟล์ index.html ของฟอร์มที่สมบูรณ์

Step 2.5: ช่องเลือกระดับพื้นฐาน — select

ข้อมูลบางอย่างเราไม่อยากให้ผู้ใช้พิมพ์เอง เพราะแต่ละคนจะพิมพ์ไม่เหมือนกัน เช่น ระดับพื้นฐาน เราจึงให้เลือกจากตัวเลือกแทนด้วย select เพิ่ม form-group ที่สามต่อจากช่องเป้าหมาย:

<div class="form-group">
  <label for="level">พื้นฐานตอนนี้</label>
  <select id="level">
    <option value="">เลือกระดับพื้นฐาน</option>
    <option value="เริ่มจากศูนย์">เริ่มจากศูนย์</option>
    <option value="เคยเรียนมาบ้าง">เคยเรียนมาบ้าง</option>
    <option value="เคยทำโปรเจกต์เล็ก ๆ">เคยทำโปรเจกต์เล็ก ๆ</option>
  </select>
</div>
  • select — กล่อง dropdown ให้ผู้ใช้เลือก
  • option — ตัวเลือกแต่ละตัว ข้อความระหว่างแท็กคือสิ่งที่ผู้ใช้เห็น
  • value — ค่าที่ JavaScript จะอ่านได้เมื่อผู้ใช้เลือกตัวเลือกนั้น

สังเกตตัวเลือกแรก <option value="">เลือกระดับพื้นฐาน</option> มี value เป็นข้อความว่าง นี่ตั้งใจทำ — มันเป็นแค่ข้อความชวนให้เลือก ถ้าผู้ใช้ไม่ได้เปลี่ยนตัวเลือก JavaScript จะอ่านค่าได้เป็น "" และในบทที่ 7 เราจะใช้จุดนี้เช็กว่า "ยังไม่ได้เลือกระดับพื้นฐาน"

Step 2.6: ช่องข้อความเพิ่มเติม — textarea

input เหมาะกับข้อความสั้นบรรทัดเดียว ถ้าอยากให้ผู้ใช้เขียนยาวหลายบรรทัด ให้ใช้ textarea:

<div class="form-group">
  <label for="message">ข้อความเพิ่มเติม</label>
  <textarea
    id="message"
    rows="4"
    placeholder="อยากบอกอะไรเพิ่มเติมเกี่ยวกับเป้าหมายของคุณ"
  ></textarea>
</div>
  • rows="4" — กำหนดความสูงเริ่มต้นประมาณ 4 บรรทัด
  • ต่างจาก input ตรงที่ textarea ต้องมีแท็กปิด </textarea> เสมอ

อย่าเว้นช่องว่างหรือขึ้นบรรทัดใหม่ระหว่าง > กับ </textarea> เพราะอะไรที่อยู่ระหว่างแท็กจะกลายเป็นข้อความเริ่มต้นในช่อง ทำให้ placeholder ไม่แสดง

Step 2.7: ปุ่มส่งข้อมูล

ปิดท้ายฟอร์ม (ก่อน </form>) ด้วยปุ่ม:

<button type="submit">
  ส่งข้อมูล
</button>

type="submit" บอก browser ว่าปุ่มนี้มีไว้ส่งฟอร์ม เมื่อกดแล้วฟอร์มจะเกิด event ชื่อ submit ซึ่ง JavaScript จะดักฟังในบทที่ 5 (ผู้ใช้กด Enter ในช่อง input ก็ส่งฟอร์มได้เช่นกัน)

Step 2.8: กล่องแสดงผลลัพธ์

สุดท้าย เราต้องมีที่ให้ JavaScript เขียนข้อความสรุปกลับมาแสดง วางไว้นอก form แต่ยังอยู่ในการ์ด:

<div id="result" class="result-box">
  กรุณากรอกข้อมูล แล้วกดส่งข้อมูล
</div>

id="result" ให้ JavaScript หยิบกล่องนี้มาเปลี่ยนข้อความ ส่วนข้อความข้างในคือข้อความเริ่มต้นก่อนผู้ใช้กดส่ง

index.html ฉบับสมบูรณ์

ประกอบทุกส่วนเข้าด้วยกัน ไฟล์ index.html ของคุณควรเป็นแบบนี้:

<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Course Inquiry Form</title>
    <link rel="stylesheet" href="style.css" />
  </head>

  <body>
    <main class="page">
      <section class="form-card">
        <p class="label">Varis Lab Bootcamp</p>

        <h1>แบบฟอร์มความสนใจเรียน</h1>

        <p class="description">
          กรอกข้อมูลเบื้องต้น เพื่อสรุปเป้าหมายการเรียนของคุณ
        </p>

        <form id="inquiryForm">
          <div class="form-group">
            <label for="fullName">ชื่อของคุณ</label>
            <input
              id="fullName"
              type="text"
              placeholder="เช่น Man"
            />
          </div>

          <div class="form-group">
            <label for="goal">เป้าหมายของคุณ</label>
            <input
              id="goal"
              type="text"
              placeholder="เช่น เปลี่ยนสายงานเป็น Developer"
            />
          </div>

          <div class="form-group">
            <label for="level">พื้นฐานตอนนี้</label>
            <select id="level">
              <option value="">เลือกระดับพื้นฐาน</option>
              <option value="เริ่มจากศูนย์">เริ่มจากศูนย์</option>
              <option value="เคยเรียนมาบ้าง">เคยเรียนมาบ้าง</option>
              <option value="เคยทำโปรเจกต์เล็ก ๆ">เคยทำโปรเจกต์เล็ก ๆ</option>
            </select>
          </div>

          <div class="form-group">
            <label for="message">ข้อความเพิ่มเติม</label>
            <textarea
              id="message"
              rows="4"
              placeholder="อยากบอกอะไรเพิ่มเติมเกี่ยวกับเป้าหมายของคุณ"
            ></textarea>
          </div>

          <button type="submit">
            ส่งข้อมูล
          </button>
        </form>

        <div id="result" class="result-box">
          กรุณากรอกข้อมูล แล้วกดส่งข้อมูล
        </div>
      </section>
    </main>

    <script src="script.js"></script>
  </body>
</html>

สรุปหน้าที่ของแต่ละแท็ก

แท็กหน้าที่id ในโปรเจกต์นี้
formพื้นที่รับข้อมูลจากผู้ใช้inquiryForm
labelบอกว่าช่องนี้ต้องกรอกอะไร— (ใช้ for ชี้ไปหาช่อง)
inputช่องกรอกข้อมูลแบบสั้นfullName, goal
selectช่องให้เลือกจากตัวเลือกlevel
textareaช่องกรอกข้อความยาวmessage
button type="submit"ปุ่มสำหรับส่งฟอร์ม—
div ผลลัพธ์พื้นที่แสดงผลหลัง JavaScript ประมวลผลresult

จด id ทั้ง 6 ตัวในตารางไว้ให้ดี (inquiryForm, fullName, goal, level, message, result) — ในบทที่ 5 เราจะพิมพ์ชื่อเหล่านี้ใน JavaScript ทุกตัว

ควรได้ผลลัพธ์แบบนี้

เปิดใน browser แล้วเห็นฟอร์มครบ 4 ช่อง (ชื่อ, เป้าหมาย, dropdown ระดับพื้นฐาน, ช่องข้อความยาว), ปุ่ม "ส่งข้อมูล" และข้อความ "กรุณากรอกข้อมูล แล้วกดส่งข้อมูล" ด้านล่าง ยังไม่มีสไตล์ ถ้ากดปุ่มตอนนี้หน้าเว็บจะ reload เฉย ๆ — นั่นคือพฤติกรรมปกติของ form ที่เราจะจัดการด้วย JavaScript

  • dropdown มี 4 ตัวเลือก และตัวแรกมี value=""
  • อธิบายความต่างระหว่างข้อความที่ผู้ใช้เห็นใน option กับ value ได้
  • textarea มีแท็กปิด และ placeholder แสดงผล
  • ปุ่มมี type="submit" และกล่องผลลัพธ์มี id="result" อยู่นอก form
ก่อนหน้า: form, label และ input สารบัญบทเรียน ถัดไป: ตกแต่งฟอร์มด้วย CSS
