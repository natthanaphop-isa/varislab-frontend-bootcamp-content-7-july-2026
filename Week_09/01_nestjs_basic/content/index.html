NestJS Fundamentals: สร้าง REST API ตั้งแต่ศูนย์ถึงโปรดักชัน

เส้นทางเรียนรู้ NestJS แบบต่อเนื่อง 77 บทเรียน: เราจะสร้าง REST API เกี่ยวกับกาแฟชื่อ iluvcoffee ตั้งแต่ scaffold โปรเจกต์, สร้าง CRUD endpoints, เชื่อม PostgreSQL ด้วย Prisma, เข้าใจ Dependency Injection ถึงแก่น, ใช้ building blocks อย่าง filters/guards/interceptors/pipes, ทำเอกสารด้วย Swagger, เขียน unit และ e2e tests และปิดท้ายด้วยเส้นทางโบนัส MongoDB + Mongoose

เมื่อเรียนจบ: คุณจะออกแบบ API เป็น modules ตาม business domain, ตรวจสอบและแปลงข้อมูลขาเข้าด้วย DTO + ValidationPipe, ทำงานกับฐานข้อมูลทั้ง SQL และ NoSQL อย่างปลอดภัย (relations, transactions, indexes, migrations), เลือกใช้ custom providers และ scopes ได้ถูกสถานการณ์ และมีชุดทดสอบที่พิสูจน์ว่าระบบทำงานจริง

สิ่งที่ควรเตรียม: พื้นฐาน TypeScript และ HTTP; ติดตั้ง Node.js และ Docker Desktop; มี REST client เช่น Insomnia หรือ Postman สำหรับยิงทดสอบ endpoint
