เตรียมเครื่องมือ: ติดตั้ง Insomnia

บทนี้เราจะทำอะไรบ้าง

  • ติดตั้ง REST client สำหรับใช้ทดสอบ API ตลอดทั้งคอร์ส
  • สร้าง request แรกและจัดกลุ่ม request เป็น collection ของโปรเจกต์
  • เลือกเครื่องมือทดแทน (Postman, curl) ได้ตามความถนัด

ทำไมต้องมี REST client

ตั้งแต่บทที่ 6 เป็นต้นไป เราจะสร้าง endpoint ใหม่แทบทุกบท — ทั้ง GET, POST, PATCH และ DELETE — ซึ่ง browser ธรรมดายิงได้สะดวกแค่ GET เท่านั้น REST client ช่วยให้เรากำหนด HTTP method, แนบ JSON body, ใส่ query parameters และดู status code กับ response ได้ครบในที่เดียว

ในคอร์สนี้ใช้ Insomnia เป็นหลัก เพราะหน้าตาเรียบง่ายและสร้าง request ได้เร็ว ดาวน์โหลด installer ตามระบบปฏิบัติการจากเว็บไซต์ได้เลย

ถ้าถนัด Postman อยู่แล้วก็ใช้แทนได้ทุกบท — หรือจะใช้ curl ใน terminal ก็ได้ ทุกบทเรียนจะระบุ method, path และ body ไว้ชัดเจนพอให้แปลงเป็นเครื่องมือไหนก็ได้

ตั้งค่าให้พร้อมสำหรับ iluvcoffee

สิ่งที่ควรทำหลังติดตั้งเสร็จเพื่อให้บทถัด ๆ ไปลื่นไหล:

  • สร้าง collection (Insomnia เรียกว่า Request Collection) ชื่อ iluvcoffee เก็บ request ของคอร์สนี้ไว้ด้วยกัน
  • สร้าง request แรก: GET http://localhost:3000 — จะได้ใช้ทันทีในบทถัดไป
  • ทำความคุ้นเคยกับแท็บ Body (เลือก JSON) และแถบเลือก method เพราะเราจะสลับใช้บ่อยมาก

ติดตั้งและสร้าง request แรก

ติดตั้ง Insomnia จาก insomnia.rest แล้วสร้าง collection iluvcoffee พร้อม request GET http://localhost:3000 เก็บไว้ (ยังยิงไม่ได้จนกว่าจะรันแอปในบทถัดไป — แค่เตรียมไว้ก่อน)

# ทางเลือกสำหรับสาย terminal — ทดสอบด้วย curl แทนได้เสมอ curl -i http://localhost:3000

ควรได้ผลลัพธ์แบบนี้

Insomnia เปิดใช้งานได้ มี collection iluvcoffee ที่มี request GET http://localhost:3000 รออยู่ ถ้ายิงตอนนี้จะได้ connection refused ซึ่งถูกต้องแล้ว เพราะเรายังไม่ได้รันแอป

ลองเช็กให้แน่ใจ

  • เปิด Insomnia แล้วเห็น collection iluvcoffee ที่สร้างไว้
  • ใน request ตัวอย่าง เปลี่ยน method ระหว่าง GET/POST/PATCH/DELETE ได้จาก dropdown
  • รู้ตำแหน่งแท็บ Body สำหรับแนบ JSON payload (จะใช้จริงในบทที่ 8)
  • ถ้าใช้ curl: รัน curl --version ผ่าน ไม่มี error

แหล่งอ้างอิง

  • Insomnia
  • Postman — ทางเลือกที่ใช้แทนกันได้
  • Controllers (NestJS) — endpoints ที่เราจะยิงทดสอบ
