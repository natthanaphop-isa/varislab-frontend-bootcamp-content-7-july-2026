ดูฐานข้อมูล Postgres ด้วย GUI

บทนี้เราจะทำอะไรบ้าง

  • เลือกเครื่องมือ GUI สำหรับสำรวจฐานข้อมูล PostgreSQL ที่เหมาะกับ workflow ของคุณ
  • สร้าง connection จาก pgAdmin ไปยัง Postgres container ที่รันด้วย Docker Compose ในบทที่แล้ว
  • ใช้ GUI ตรวจสอบตารางและข้อมูลจริง เพื่อยืนยันผลของโค้ดที่จะเขียนในบทถัด ๆ ไป

ทำไมต้องมี GUI ทั้งที่ยิง API ก็เห็นข้อมูล

ตลอดหลายบทต่อจากนี้ เราจะให้ Prisma สร้างตาราง เพิ่มคอลัมน์ และสร้างตารางเชื่อม relation ให้จาก schema.prisma การเห็นสภาพจริงของฐานข้อมูล — ตารางชื่ออะไร คอลัมน์เป็นชนิดไหน ข้อมูลถูก insert จริงไหม — ช่วยให้เราแยกได้ทันทีว่าปัญหาอยู่ที่โค้ดฝั่ง NestJS หรืออยู่ที่ฐานข้อมูล การไล่ดูผ่าน psql ใน terminal ทำได้เช่นกัน แต่ GUI ทำให้การสำรวจ schema และไล่ข้อมูลทีละแถวเร็วกว่ามาก

เครื่องมือที่คอร์สแนะนำคือ pgAdmin ซึ่งเป็นเครื่องมือฟรีสำหรับดู แก้ไข และ browse ฐานข้อมูล Postgres แต่ถ้าคุณคุ้นเคยกับเครื่องมืออื่นอยู่แล้ว เช่น TablePlus, DBeaver หรือ DataGrip ก็ใช้แทนกันได้ทั้งหมด เพราะสิ่งที่เราต้องการมีแค่การเชื่อมต่อแบบ Postgres มาตรฐาน

ข้อมูลการเชื่อมต่อมาจาก docker-compose.yml

ค่าที่ต้องใช้สร้าง connection คือค่าเดียวกับที่เรากำหนดไว้ใน docker-compose.yml ของบทที่แล้ว ซึ่ง map port 5432 ของ container ออกมาที่เครื่องเรา และตั้งรหัสผ่านผ่าน environment variable

ฟิลด์ใน GUIค่ามาจากไหน
Hostlocalhostcontainer map port ออกมาที่เครื่องเรา
Port5432ports: "5432:5432" ใน docker-compose.yml
Usernamepostgresค่า default ของ image postgres
Passwordpass123POSTGRES_PASSWORD ใน docker-compose.yml
Databasepostgresdatabase เริ่มต้นที่ image สร้างให้

การใช้งาน pgAdmin เชิงลึกอยู่นอกขอบเขตของคอร์สนี้ หากติดขัดตอนสร้าง connection ให้ดูเอกสารการเชื่อมต่อของ pgAdmin ประกอบ

ค่า pass123 เป็นรหัสผ่านสำหรับเครื่อง dev เท่านั้น ในบทถัดไปค่าทั้งหมดนี้จะถูกรวมเป็น connection string เดียวชื่อ DATABASE_URL ในไฟล์ .env (ห้าม commit) และในบท Application Configuration เราจะให้ NestJS โหลดและ validate ค่านี้อย่างเป็นระบบ

เชื่อม pgAdmin เข้ากับ Postgres ใน Docker

ตรวจว่า container จากบทที่แล้วยังรันอยู่ แล้วติดตั้ง pgAdmin จากเว็บทางการ จากนั้นสร้าง Server connection ใหม่ด้วยค่าจากตารางด้านบน

# ตรวจว่า Postgres container รันอยู่ docker-compose up -d docker ps # จากนั้นใน pgAdmin: Object > Register > Server... # General > Name: iluvcoffee-local # Connection > Host: localhost, Port: 5432, # Username: postgres, Password: pass123

ควรได้ผลลัพธ์แบบนี้

pgAdmin เชื่อมต่อสำเร็จและเห็น database ชื่อ postgres ใน tree ด้านซ้าย ตอนนี้ยังไม่มีตารางของแอปเรา — นั่นถูกต้องแล้ว เพราะเราจะให้ Prisma สร้างตาราง coffee ให้ในบทที่ 23 เมื่อถึงตอนนั้นให้กลับมา refresh ดูใน GUI นี้อีกครั้ง

ลองเช็กให้แน่ใจ

  • รัน docker ps แล้วเห็น container ของ image postgres เปิด port 5432 อยู่
  • สร้าง connection ใน GUI สำเร็จโดยไม่มี error เรื่องรหัสผ่านหรือ host
  • Browse เข้าไปเห็น database postgres และ schema public ได้
  • ทดลองเปิด Query Tool แล้วรัน SELECT 1; ได้ผลลัพธ์กลับมา
