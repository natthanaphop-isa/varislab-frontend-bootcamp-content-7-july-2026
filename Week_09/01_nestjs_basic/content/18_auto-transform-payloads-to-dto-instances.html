แปลง Payload เป็น DTO Instance อัตโนมัติ

เมื่อจบบทนี้ คุณจะสามารถ

  • เปิดคุณสมบัติ auto-transform ของ ValidationPipe
  • อธิบายความต่างระหว่าง plain object กับ instance ของ DTO class จริง
  • ใช้ transform แปลง route/query parameter จาก string เป็น type ที่ประกาศไว้

Payload ที่ผ่านมาเป็นแค่ Plain Object

โดย default สิ่งที่ @Body() ส่งให้ handler คือ plain JavaScript object ที่ Nest แปลงจาก JSON — ต่อให้เราประกาศ type เป็น CreateCoffeeDto การเช็ก instanceof CreateCoffeeDto ก็ได้ false เพราะ type annotation ของ TypeScript หายไปหมดตอน runtime การเปิด transform ทำให้ ValidationPipe ใช้ class-transformer สร้าง instance ของ DTO จริง ๆ ให้:

/* main.ts */
app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true,
    forbidNonWhitelisted: true,
    transform: true,
  }),
);

ลองพิสูจน์ใน handler:

@Post()
create(@Body() createCoffeeDto: CreateCoffeeDto) {
  console.log(createCoffeeDto instanceof CreateCoffeeDto); // true เมื่อเปิด transform
  return this.coffeesService.create(createCoffeeDto);
}

โบนัสใหญ่: แปลง Primitive Type ให้ด้วย

ทุกอย่างที่มากับ URL เป็น string เสมอ — @Param('id') และ @Query('limit') ที่เราเจอมาจึงต้องมานั่งแปลงเองด้วย +id เมื่อเปิด transform แล้ว แค่ประกาศ type เป็น number pipe จะแปลงให้ก่อนถึงมือเรา:

@Get(':id')
findOne(@Param('id') id: number) {
  console.log(typeof id); // 'number'
  return this.coffeesService.findOne('' + id);
}
สิ่งที่รับเข้าไม่เปิด transformเปิด transform
JSON bodyplain objectinstance ของ DTO class (validate + สร้างด้วย class-transformer)
@Param('id') id: numberstring เสมอ ต้องแปลงเองnumber ตาม type ที่ประกาศ
Query parametersstring ทั้งหมดแปลงตาม type ของ DTO/annotation ที่ประกาศ

การแปลง type มีต้นทุน performance เล็กน้อยต่อ request แต่แลกกับโค้ดที่สะอาดขึ้นและ bug จาก type ผิดที่หายไป — สำหรับแอปส่วนใหญ่ถือว่าคุ้มมาก และชุดตัวเลือก whitelist + forbidNonWhitelisted + transform นี้คือ baseline ที่เราจะใช้ตลอดทั้งคอร์ส

เปิด transform แล้วพิสูจน์ด้วย instanceof และ typeof

เพิ่ม transform: true ใน main.ts ใส่ console.log ชั่วคราวใน create() และ findOne() ตามตัวอย่าง แล้วยิง request ดูผลใน terminal ของ dev server

curl -X POST http://localhost:3000/coffees \ -H "Content-Type: application/json" \ -d '{"name": "Roast", "brand": "Brew", "flavors": ["mocha"]}' curl http://localhost:3000/coffees/1

ผลลัพธ์ที่คาดหวัง

terminal แสดง true จาก instanceof CreateCoffeeDto และ number จาก typeof id — payload กับ parameter ถูกแปลงเป็น type ที่ประกาศไว้จริงโดยเราไม่ต้องเขียนโค้ดแปลงเองสักบรรทัด

ตรวจว่าใช้งานได้จริง

  • instanceof CreateCoffeeDto ใน create() พิมพ์ true
  • typeof id ใน findOne() พิมพ์ number ทั้งที่ค่ามาจาก URL
  • validation จากบทก่อน (400 เมื่อ payload ผิด) ยังทำงานครบ
  • ลบ console.log ทดลองออกแล้วเมื่อยืนยันเสร็จ
