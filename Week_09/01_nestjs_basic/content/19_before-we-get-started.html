ก่อนเริ่มบทฐานข้อมูล: เก็บความคืบหน้าไว้ใน Branch

เมื่อจบบทนี้ คุณจะสามารถ

  • อธิบายโครงสร้างสองเส้นทางฐานข้อมูลของคอร์ส (PostgreSQL หลัก, MongoDB โบนัส) ได้
  • บันทึก snapshot ของโค้ด ณ จุดจบ Chapter 2 ไว้ใน git branch แยก
  • กลับมาใช้ snapshot นั้นเป็นจุดตั้งต้นของบท MongoDB ได้ในภายหลัง

ทางแยกของคอร์ส: SQL กับ NoSQL

บทนี้เป็นจุดต่อจาก Chapter 2 Creating a REST API Application ซึ่งเป็นเส้นทางหลัก (standard path) ของคอร์ส แต่คอร์สนี้ยังมีบทโบนัส NoSQL / MongoDB (บทที่ 70–77) ที่เริ่มจากจุดเดียวกันคือโค้ด ณ ตอนจบ Chapter 2 เช่นกัน — ไม่ใช่ต่อจากบท Prisma

การแยกสองเส้นทางแบบนี้ทำให้คุณเลือกเรียนเฉพาะฐานข้อมูลที่โปรเจกต์ของคุณใช้จริงได้ หรือจะโค้ดตามทั้งสองเส้นทางก็ได้ ขอแค่มี snapshot ของจุดตั้งต้นเก็บไว้

สำคัญมาก: ถ้าคุณตั้งใจจะโค้ดตามทั้งบท PostgreSQL และบท MongoDB ให้บันทึกความคืบหน้าปัจจุบัน (จุดจบ Chapter 2) ลง branch แยกก่อนเริ่มบทถัดไป มิฉะนั้นเมื่อถึงบท MongoDB คุณจะต้องมานั่งถอนโค้ด Prisma ออกเอง

บันทึก Snapshot ด้วย Git Branch

วิธีที่ตรงไปตรงมาที่สุด: สร้าง branch ใหม่เก็บสถานะปัจจุบันไว้ แล้วกลับมาทำงานต่อบน branch หลักตามเดิม

git add .
git commit -m "Finish Chapter 2: REST API application"

git branch end-of-chapter-2

git branch
# * master (หรือ main)
#   end-of-chapter-2

เท่านี้ branch end-of-chapter-2 จะชี้ไปที่ commit ปัจจุบันตลอดไป ส่วนเราทำงานต่อบน master เข้าสู่บท Prisma ได้เลย เมื่อถึงบทที่ 70 ค่อย git checkout end-of-chapter-2 (หรือแตก branch ใหม่จากจุดนั้น) เพื่อเริ่มเส้นทาง MongoDB จากจุดที่ถูกต้อง

ถ้ายังไม่ได้ init git ในโปรเจกต์ ให้รัน git init ก่อน — โปรเจกต์ที่สร้างด้วย nest new มักมี git repository ให้แล้ว ตรวจได้ด้วย git status

สร้างจุดเซฟก่อนเดินหน้า

commit งานทั้งหมดของ Chapter 2 แล้วสร้าง branch ชื่อสื่อความหมาย เช่น end-of-chapter-2 จากนั้นยืนยันว่าตัวเองยังอยู่บน branch หลัก

git status git add . git commit -m "Finish Chapter 2: REST API application" git branch end-of-chapter-2 git branch

ผลลัพธ์ที่คาดหวัง

git branch แสดงทั้ง branch หลัก (มีเครื่องหมาย *) และ end-of-chapter-2 โดย working tree สะอาด (nothing to commit) — คุณพร้อมเริ่มติดตั้ง PostgreSQL ในบทถัดไปโดยมีจุดถอยหลังที่ปลอดภัย

ตรวจว่าใช้งานได้จริง

  • git status ตอบ nothing to commit, working tree clean
  • git branch เห็น end-of-chapter-2 อยู่ในรายการ
  • git log --oneline -1 end-of-chapter-2 ชี้ไปที่ commit ล่าสุดของ Chapter 2
  • คุณยังอยู่บน branch หลัก (master/main) พร้อมเรียนบทที่ 20 ต่อ
