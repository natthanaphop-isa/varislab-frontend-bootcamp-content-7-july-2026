ติดตั้ง NestJS CLI

เมื่อจบบทนี้ คุณจะสามารถ

  • ตรวจสอบว่าเครื่องมี Node.js เวอร์ชันที่ใช้งานกับ NestJS ได้
  • ติดตั้ง NestJS CLI แบบ global และยืนยันว่าติดตั้งสำเร็จ
  • ใช้ nest --help สำรวจคำสั่งทั้งหมดที่ CLI มีให้

ทำไมต้องเริ่มที่ CLI

NestJS CLI คือเครื่องมือหลักที่เราจะใช้ตลอดทั้งคอร์ส ตั้งแต่ scaffold โปรเจกต์ใหม่, generate ไฟล์อย่าง controller/service/module ตาม convention ของ Nest ไปจนถึงรันแอปในโหมด development การติดตั้งไว้แบบ global ทำให้เรียกคำสั่ง nest ได้จากทุกที่ใน terminal โดยไม่ต้องพึ่ง npx ทุกครั้ง

NestJS เป็น framework ที่รันบน Node.js ดังนั้นก่อนติดตั้ง CLI ต้องมี Node.js ในเครื่องก่อน ดาวน์โหลดได้จาก nodejs.org (แนะนำเวอร์ชัน LTS ล่าสุด) ซึ่งจะติดตั้ง npm มาให้พร้อมกัน

ติดตั้งและตรวจสอบเวอร์ชัน

เปิด terminal แล้วไล่ตามคำสั่งต่อไปนี้ทีละขั้น: ตรวจ Node ก่อน จากนั้นติดตั้ง CLI แบบ global แล้วยืนยันเวอร์ชันของ Nest ที่ติดตั้งได้

# ตรวจว่า Node.js ติดตั้งแล้วและเป็นเวอร์ชันอะไร
node --version

# ติดตั้ง NestJS CLI แบบ global
npm i -g @nestjs/cli

# ตรวจเวอร์ชันของ Nest CLI (หลังติดตั้งเสร็จ)
nest --version

# 💡 TIP: แสดงคำสั่งทั้งหมดของ Nest CLI
nest --help

ถ้าติดตั้งแบบ global แล้วเจอ permission error บน macOS/Linux อย่าเพิ่งใช้ sudo ทันที — ทางที่ปลอดภัยกว่าคือใช้ Node version manager อย่าง nvm ซึ่งทำให้ npm global packages อยู่ใน home directory ของเราเอง

คำสั่ง nest --help คุ้มค่าที่จะเปิดดูตั้งแต่วันแรก เพราะมันสรุปทั้งคำสั่ง (new, generate, build, start ฯลฯ) และ alias แบบย่อ เช่น nest g co แทน nest generate controller ที่เราจะได้ใช้บ่อยมากในบทถัด ๆ ไป

เตรียมเครื่องให้พร้อมสำหรับทั้งคอร์ส

ติดตั้ง Node.js LTS จาก nodejs.org (ถ้ายังไม่มี) แล้วติดตั้ง NestJS CLI พร้อมตรวจสอบว่าทั้งสองอย่างพร้อมใช้งาน

node --version npm i -g @nestjs/cli nest --version nest --help

ผลลัพธ์ที่คาดหวัง

node --version พิมพ์เลขเวอร์ชันออกมา (เช่น v22.x.x), การติดตั้ง CLI จบโดยไม่มี error, nest --version แสดงเลขเวอร์ชัน 12.x.x ของ CLI และ nest --help แสดงตารางคำสั่งพร้อม alias แบบย่อของแต่ละคำสั่ง — คอร์สนี้เขียนสำหรับ NestJS 12 ซึ่ง scaffold โปรเจกต์เป็น ES module และใช้ Vitest เป็นเครื่องมือทดสอบ (เราจะเห็นผลของเรื่องนี้ในบทถัดไป)

ตรวจว่าใช้งานได้จริง

  • รัน node --version และ npm --version ได้ผลเป็นเลขเวอร์ชัน ไม่ใช่ command not found
  • รัน nest --version จาก directory ไหนก็ได้ (ยืนยันว่า global install สำเร็จ) และได้เลข 12.x.x
  • เปิด nest --help แล้วหา alias ของ generate controller เจอ (ควรเป็น g co)
  • ถ้าคำสั่ง nest ไม่เจอ ให้ตรวจว่า npm global bin path อยู่ใน $PATH ด้วย npm bin -g
