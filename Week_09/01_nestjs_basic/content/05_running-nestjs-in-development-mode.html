รัน NestJS ในโหมด Development

บทนี้เราจะทำอะไรบ้าง

  • รันแอปในโหมด watch ที่ recompile อัตโนมัติเมื่อไฟล์เปลี่ยน
  • อ่าน log ตอน bootstrap เพื่อยืนยันว่า route ไหนถูก map แล้วบ้าง
  • เลือก script รันที่เหมาะกับสถานการณ์ (dev, debug, production)

โหมด development คือเพื่อนสนิทตลอดคอร์ส

ตั้งแต่บทนี้เป็นต้นไป ให้เปิด terminal ค้างไว้หนึ่งจอเพื่อรันแอปด้วยคำสั่งเดียว

# Development mode:
npm run start:dev

คำสั่งนี้รัน Nest ใน watch mode: ทุกครั้งที่บันทึกไฟล์ .ts แอปจะ recompile และ restart ให้เอง เราจึงแก้โค้ด สลับไปยิง request ใน Insomnia แล้วเห็นผลได้ทันทีโดยไม่ต้องสั่งรันใหม่เอง ระหว่างเรียนคอร์สนี้แทบทั้งหมดเราจะอยู่ในโหมดนี้

สังเกต log ตอนเริ่ม: Nest จะพิมพ์ลำดับการโหลด modules และบรรทัด Mapped {/, GET} route ซึ่งเป็นวิธีเช็กเร็ว ๆ ว่า controller และ route ที่เพิ่งสร้างถูกลงทะเบียนจริง ถ้าสร้าง endpoint ใหม่แล้วไม่เห็นบรรทัด mapped ของมัน แปลว่ามีอะไรผิดตั้งแต่ประกาศ route

Script อื่นที่ควรรู้จัก

คำสั่งใช้เมื่อพฤติกรรม
npm run startรันครั้งเดียว ไม่ต้อง watchcompile แล้วรัน — แก้ไฟล์แล้วต้องรันใหม่เอง
npm run start:devระหว่างพัฒนา (ใช้ตลอดคอร์สนี้)watch mode — recompile + restart อัตโนมัติ
npm run start:debugต้องต่อ debugger/breakpointwatch mode + เปิด inspector ของ Node
npm run start:prodรันของจริงหลัง buildรัน JavaScript ที่ compile แล้วจาก dist/

ค่าเริ่มต้นแอปฟังที่ port 3000 (กำหนดใน main.ts) ถ้า port ชนกับโปรแกรมอื่นจะเห็น error EADDRINUSE ตอน start — ปิดโปรแกรมที่ใช้ port อยู่ หรือเปลี่ยนเลข port ใน app.listen()

รันแอปแล้วพิสูจน์ว่า watch mode ทำงาน

รัน iluvcoffee ในโหมด development แล้วยิง GET http://localhost:3000 ด้วย Insomnia (หรือ curl) จากนั้นแก้ข้อความใน src/app.service.ts จาก Hello World! เป็นข้อความอื่น บันทึกไฟล์ แล้วยิงซ้ำโดยไม่ต้อง restart เอง

cd iluvcoffee npm run start:dev # อีก terminal หนึ่ง curl http://localhost:3000

ควรได้ผลลัพธ์แบบนี้

ยิงครั้งแรกได้ Hello World! หลังแก้ service และบันทึก terminal ที่รันแอปจะ recompile เอง และยิงครั้งที่สองได้ข้อความใหม่ทันที — โดยที่เราไม่ได้แตะคำสั่งรันเลย

ลองเช็กให้แน่ใจ

  • log ตอน start มีบรรทัด Nest application successfully started
  • เห็นบรรทัด Mapped {/, GET} route ใน log ตอน bootstrap
  • curl http://localhost:3000 คืนข้อความจาก AppService
  • แก้ไฟล์แล้ว terminal แสดงการ recompile โดยไม่ต้องสั่งอะไรเพิ่ม
  • รู้ว่าจะหยุดแอปด้วย Ctrl+C และรันใหม่ได้ทุกเมื่อ
